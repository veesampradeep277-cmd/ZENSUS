FOUNDATION

What is a Graph?

Definition

A graph is a non-linear data structure consisting of a collection of vertices (nodes) connected by edges.

Mathematically, a graph is represented as:

G = (V, E)

where V represents the set of vertices and E represents the set of edges.

Real-World Graphs

🗺️

Google Maps

Cities/intersections are vertices and roads are edges.

👥

Social Network

Users are vertices and friendships/follows are edges.

✈️

Flight Network

Airports are vertices and flights are edges.

Visualizing a Graph

Vertices represent entities. Edges represent relationships.

CLASSIFICATION

Types of Graphs

DIRECTED

Directed Graph

Edges have a direction. A → B is different from B → A.

UNDIRECTED

Undirected Graph

Edges have no direction. A — B means both vertices are connected.

WEIGHTED

Weighted Graph

Every edge can contain a cost, distance, time or weight.

UNWEIGHTED

Unweighted Graph

All edges are treated equally unless another cost is specified.

CYCLIC

Cyclic Graph

Contains at least one cycle.

ACYCLIC

Acyclic Graph

Contains no cycles. A DAG is a directed acyclic graph.

CONNECTED

Connected Graph

Every vertex is reachable from every other vertex.

DISCONNECTED

Disconnected Graph

At least two vertices belong to separate components.

SIMPLE

Simple Graph

No self-loops and no parallel edges.

MULTIGRAPH

Multigraph

Multiple edges may connect the same pair of vertices.

MATHEMATICAL VIEW

Graph Properties

Degree

degree(v) = number of edges incident to v

In an undirected graph, every edge contributes one to the degree of each endpoint.

Degree Sum Formula

Σ degree(v) = 2E

The sum of degrees of all vertices equals twice the number of edges.

Directed Graph

total degree = in-degree + out-degree

Directed graphs distinguish incoming and outgoing edges.

Maximum Edges

E ≤ V(V − 1) / 2

Maximum number of edges in a simple undirected graph.

🌱 Sparse Graph

A graph with relatively few edges compared with the maximum possible number.

Adjacency List is usually efficient.

🕸️ Dense Graph

A graph with a large number of edges.

Adjacency Matrix can be useful.

Breadth-First Search (BFS)

Core idea: BFS explores a graph level by level. It uses a Queue. Queue follows FIFO — First In, First Out.

How BFS Thinks

Why Does BFS Need a Queue?

Suppose we start from A. We first want to process all vertices directly connected to A before moving to the next level.

Python Implementation

from collections import deque

def bfs(graph, start):

    visited = set()
    queue = deque([start])

    visited.add(start)

    while queue:

        node = queue.popleft()

        print(node, end=" ")

        for neighbour in graph[node]:

            if neighbour not in visited:

                visited.add(neighbour)
                queue.append(neighbour)


graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "E"],
    "D": ["B"],
    "E": ["C"]
}

bfs(graph, "A")

CORE TRAVERSAL

Depth-First Search (DFS)

Core idea: DFS goes as deep as possible before backtracking. It can be implemented using an explicit Stack or using recursion.

Why Does DFS Use a Stack?

A Stack follows LIFO — Last In, First Out. Therefore, the most recently discovered vertex is processed first.

STACK
C B D
↑ TOP — D is removed first

Iterative DFS Dry Run

01

A
02

Visit A and push its neighbours.

C B
03
Pop B

Visit B and push D.

C D
04
Continue deeper

DFS continues until no unvisited neighbour remains, then backtracks.

A B D C

Recursive DFS — Understanding the Call Stack

Recursion automatically uses the program's call stack. Every recursive call creates a new stack frame.

CALL STACK LIFO

Recursive DFS — Python

def dfs(graph, node, visited):

    visited.add(node)

    print(node, end=" ")

    for neighbour in graph[node]:

        if neighbour not in visited:

            dfs(graph, neighbour, visited)


graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "E"],
    "D": ["B"],
    "E": ["C"]
}

visited = set()

dfs(graph, "A", visited)

Iterative DFS — Python

def dfs_iterative(graph, start):

    visited = set()
    stack = [start]

    while stack:

        node = stack.pop()

        if node in visited:
            continue

        visited.add(node)

        print(node, end=" ")

        for neighbour in reversed(graph[node]):

            if neighbour not in visited:
                stack.append(neighbour)

GRAPH PROPERTY

Cycle Detection

UNDIRECTED

Cycle Detection using DFS

While traversing an undirected graph, if we encounter an already visited neighbour that is not the current node's parent, a cycle exists. 

def has_cycle(node, parent):

    visited[node] = True

    for neighbour in graph[node]:

        if not visited[neighbour]:

            if has_cycle(neighbour, node):
                return True

        elif neighbour != parent:

            return True

    return False
DIRECTED

Cycle Detection using Recursion Stack

In a directed graph, a cycle exists if DFS reaches a vertex that is already in the current recursion path. 

def dfs(node):

    visited[node] = True
    path[node] = True

    for neighbour in graph[node]:

        if not visited[neighbour]:

            if dfs(neighbour):
                return True

        elif path[neighbour]:

            return True

    path[node] = False
    return False

DEPENDENCY ORDER

Topological Sort

Definition: Topological sorting produces a linear ordering of vertices in a DAG such that for every directed edge u → v, u appears before v.

Dependency Example

Basics
→
Python
→
DSA
→
Interviews

Method 1 — DFS

  1. Run DFS from every unvisited vertex.
  2. After processing all neighbours, push the vertex into a stack.
  3. Reverse the stack to obtain topological order.

Method 2 — Kahn's Algorithm

  1. Calculate the indegree of every vertex.
  2. Add all zero-indegree vertices to a Queue.
  3. Remove a vertex and decrease neighbours' indegrees.
  4. Add newly zero-indegree vertices.

Python — Kahn's Algorithm

from collections import deque

def topological_sort(graph):

    indegree = {
        node: 0
        for node in graph
    }

    for node in graph:

        for neighbour in graph[node]:
            indegree[neighbour] += 1

    queue = deque(
        node for node in graph
        if indegree[node] == 0
    )

    order = []

    while queue:

        node = queue.popleft()

        order.append(node)

        for neighbour in graph[node]:

            indegree[neighbour] -= 1

            if indegree[neighbour] == 0:
                queue.append(neighbour)

    return order
Important: A valid topological ordering exists only when the directed graph is acyclic. If a directed cycle exists, topological sorting is impossible.

Dijkstra — Core Algorithm

  1. Set source distance to 0 and every other distance to infinity.
  2. Choose the unvisited vertex with the smallest distance.
  3. Relax every outgoing edge.
  4. If a shorter distance is found, update it.
  5. Mark the current vertex as finalized.
  6. Repeat until all reachable vertices are processed.

CONNECT EVERYTHING CHEAPLY

Minimum Spanning Tree

What is a Spanning Tree?

A spanning tree of a connected undirected graph is a subgraph that connects all vertices without creating cycles.

Edges in a spanning tree = V − 1

Minimum Spanning Tree — MST

An MST is a spanning tree whose total edge weight is minimum among all possible spanning trees.

A-B : 2 ✓ B-C : 3 ✓ A-C : 7 ✕ C-D : 4 ✓ B-D : 6 ✕

Kruskal's Algorithm

  1. Sort all edges by increasing weight.
  2. Take the smallest edge.
  3. Check whether it creates a cycle.
  4. If not, include it in the MST.
  5. Continue until V − 1 edges are selected.
O(E log E)

Prim's Algorithm

  1. Start from any vertex.
  2. Select the minimum-weight edge connecting the tree to an unvisited vertex.
  3. Add that vertex.
  4. Repeat until every vertex is included.
O(E log V)

UNION-FIND

Disjoint Set Union

DSU, also called Union-Find, efficiently maintains multiple disjoint sets and supports two major operations: Find and Union.
Set A
1 2 3
Set B
4 5
After Union
1 2 3 4 5

Find

Determines the representative/root of the set containing a given element.

find(x)

Union

Merges two different sets into one set.

union(a, b)

Path Compression

During find(), nodes are directly connected to the root, making future operations faster.

Union by Rank / Size

Attach the smaller tree under the larger tree to keep the DSU structure shallow.

With path compression and union by rank/size, DSU operations are effectively almost constant time: O(α(V))

AVOID THESE

Common Mistakes

01
Forgetting the visited array/set

Cyclic graphs can cause infinite traversal without proper visited tracking.

02
Using BFS for every shortest-path problem

BFS is suitable for unweighted/equal-cost edges. Weighted graphs may require Dijkstra or another algorithm.

03
Using Dijkstra with negative edges

Standard Dijkstra assumes non-negative edge weights.

04
Confusing tree and graph

Trees have exactly V − 1 edges and contain no cycles.

05
Incorrect directed cycle detection

A visited node alone does not prove a directed cycle. The recursion-path state matters.

06
Ignoring disconnected graphs

Running BFS/DFS from only one vertex does not necessarily visit the entire graph.
