What is a String?

Understanding text data in Python

💡

Definition

A string is a sequence of characters enclosed inside quotation marks.

Strings are used to store text such as names, messages, passwords, email addresses, URLs, sentences and much more.

" H e l l o "
A sequence of characters
Python 
name = "Pradeep"
message = 'Welcome to ZENSUS'

print(name)
print(message)
OUTPUT 
Pradeep
Welcome to ZENSUS

Strings are Immutable

A very important Python concept

🔒

What does immutable mean?

Once a string is created, its individual characters cannot be changed directly. 

name = "Python"

name[0] = "J"
ERROR 
TypeError:
'str' object does not support item assignment

How can we change it?

Create a new string instead of modifying the existing string. 

name = "Python"

new_name = "J" + name[1:]

print(new_name)
OUTPUT 
Jython

String Formatting

Create dynamic messages

✨

Why formatting?

String formatting allows us to insert variables and expressions into text.

Recommended

1. F-Strings

F-strings provide a clean and readable way to insert variables into strings. 

name = "Pradeep"
course = "Python"
score = 95

message = f"{name} is learning {course} and scored {score}%."

print(message)
OUTPUT 
Pradeep is learning Python and scored 95%.

2. format()

name = "Pradeep"
score = 95

text = "{} scored {} marks.".format(name, score)

print(text)
OUTPUT 
Pradeep scored 95 marks.

3. Formatting Numbers

price = 99.5678

print(f"Price: ₹{price:.2f}")
OUTPUT 
Price: ₹99.57

Common Mistakes

Errors beginners frequently make

01

Forgetting zero-based indexing

text = "Python"

print(text[1])

This prints y, not P. The first index is 0.

02

Trying to modify a string directly

text[0] = "J"

Strings are immutable.

03

Using + with incompatible data types

age = 20

print("Age: " + age)

Convert the number to a string or use an f-string. 

print(f"Age: {age}")
04

Confusing find() and index()

find() returns -1 when the substring is not found, while index() raises an error.

05

Forgetting that methods return values

text = "python"

text.upper()

print(text)

The original string remains unchanged. Store the returned value if needed.
