What are Input and Output?

Most programs need to communicate with the user. They receive information from the user and then produce a result.

Input

Information given to a program.

Output

Displaying Output with print()

The print() function displays information on the screen. 

print("Hello, ZENSUS!")
Terminal Output 
Hello, ZENSUS!

The value inside the parentheses is passed to print().

📢

Printing Multiple Values

You can pass multiple values to print(). Python separates them with a space by default. 

name = "Pradeep"
age = 19

print(name, age)
Pradeep 19
Default separator: sep=" "
↔️

Using the sep Parameter

sep controls the separator between printed values. 

print("Python", "Java", "C++", sep=" | ")
Python | Java | C++

You can choose your own separator. 

print(2026, 9, 7, sep="-")
2026-9-7
↩️

Using the end Parameter

end controls what print() adds after displaying text.

By default, print() moves the cursor to a new line using end="\n". 

print("Hello")
print("Python")
Hello
Python

Changing end 

print("Hello", end=" ")
print("Python")
Hello Python
🔣

Getting User Input

Python uses input() to receive information from the user. 

name = input("Enter your name: ")

print(name)

When Python reaches input(), the program pauses and waits for the user to enter something.

🖥️ Enter your name:
→
📦 Variable
name
⚠️

Important: input() Returns a String

One of the most important things to remember is that input() returns the user's input as a string. 

age = input("Enter your age: ")

print(type(age))
Enter your age: 19
<class 'str'>
Remember:

Even if the user types 19, Python initially receives it as "19".

Taking Integer Input

Use int() to convert input into an integer. 

age = int(input("Enter your age: "))

print(age)
Enter your age: 19
19

The operations happen in this order:

input() → receives text

int() → converts text to integer

Result → integer value

🔢

Taking Floating-Point Input 

cgpa = float(input("Enter your CGPA: "))

print(cgpa)
Enter your CGPA: 8.63
8.63
👥

Taking Multiple Inputs

Method 1 — Separate input() Statements 

name = input("Name: ")
age = input("Age: ")

print(name)
print(age)

Method 2 — Multiple Values Using split() 

name, city = input("Enter name and city: ").split()

print(name)
print(city)
Enter name and city: Pradeep Guntur
Pradeep
Guntur
✂️

Using split()

The split() method divides a string into multiple parts. 

data = input("Enter values: ")

parts = data.split()

print(parts)
Enter values: Python Java C++
['Python', 'Java', 'C++']
Default behavior:

split() separates text using whitespace.

🧮

Multiple Integer Inputs 

a, b = map(int, input().split())

print(a + b)
10 20
30

Here Python performs three important operations:

  1. input() receives the complete line.
  2. split() separates the values.
  3. map(int, ...) converts each value to integer.
✨

Formatting Output

Good output makes programs easier to understand.

Using Commas 

name = "Pradeep"
age = 19

print("Name:", name)
print("Age:", age)

Using String Concatenation 

name = "Pradeep"

print("Hello " + name)
Important:

Concatenation with + requires compatible string values.

🚀

F-Strings

A clean and powerful way to format strings. 

name = "Pradeep"
age = 19

print(f"My name is {name}")
print(f"I am {age} years old.")
My name is Pradeep
I am 19 years old.

Place an f before the string and put variables inside { }.

Expressions Inside F-Strings 

a = 10
b = 20

print(f"Sum = {a + b}")
Sum = 30
🧩

format() Method 

name = "Pradeep"
age = 19

print("My name is {} and I am {} years old.".format(name, age))
My name is Pradeep and I am 19 years old.
Modern recommendation:

F-strings are generally preferred for simple modern string formatting.

💰

Formatting Numbers 

price = 99.98765

print(f"Price: ₹{price:.2f}")
Price: ₹99.99

:.2f means display the floating-point number with two digits after the decimal point.

Common Beginner Mistakes

❌
Forgetting that input() returns a string 
age = input("Age: ")
print(age + 1)

This causes a type error because age is a string.

❌
Correct approach 
age = int(input("Age: "))
print(age + 1)
❌
Concatenating string and integer directly 
age = 19
print("Age: " + age)

Convert the number to a string or use an f-string.

❌
Invalid numeric input 
age = int(input("Age: "))

Entering text such as hello causes a conversion error.

Key Points

✓ Input is information given to a program.
✓ Output is information produced by a program.
✓ print() is used to display output.
✓ input() is used to receive user input.
✓ input() returns a string by default.
✓ int() converts values to integers.
✓ float() converts values to floating-point numbers.
✓ split() separates a string into multiple parts.
✓ map() can apply a conversion function to multiple values.
✓ sep controls the separator used by print().
✓ end controls what print() adds after its output.
✓ Escape sequences represent special characters.
✓ F-strings provide convenient string formatting.
✓ Input conversion is important when working with numbers.
