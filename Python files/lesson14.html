FOUNDATION

What is Object-Oriented Programming?

Object-Oriented Programming (OOP) is a programming paradigm where programs are designed using objects that combine data and behavior.

In Python, a class acts as a blueprint for creating objects. An object represents a particular instance of that class.

Remember

A class defines what an object should have and do. An object is the actual instance created from that class.

🧩

Modularity

Divide a large application into smaller classes and components.

♻️

Reusability

Reuse classes, methods and existing functionality instead of rewriting code.

📈

Scalability

Make applications easier to expand as requirements grow.

The __init__() Method

The __init__() method is commonly used to initialize an object's attributes when an object is created.

It is automatically called during object creation.

IMPORTANT SYNTAX

06
VERY IMPORTANT

The self Parameter

self refers to the current object.

It allows methods to access the attributes and other methods belonging to that object.

Interview Tip

self.name means the name attribute belonging to the current object.

Understanding self EXAMPLE 04 
class Student:

    def __init__(self, name):
        self.name = name

    def display(self):
        print("Student:", self.name)


student = Student("Arjun")

student.display()
Student: Arjun

08
BEHAVIOR

Methods

A method is a function defined inside a class. Methods describe what an object can do.

🔹

Instance Method

Works with object-specific data. 

def display(self):
    print(self.name)
🏛️

Class Method

Works with class-level data. 

@classmethod
def show(cls):
    print(cls.college)
🛠️

Static Method

Utility method that does not require instance or class state. 

@staticmethod
def add(a, b):
    return a + b

OOP PILLAR 01

Inheritance

Inheritance allows a child class to acquire attributes and methods from a parent class.

It promotes code reuse and allows developers to create hierarchical relationships.

INHERITANCE HIERARCHY
🐾 Animal
↓
🐶 Dog
🐱 Cat
🐮 Cow

INHERITANCE SYNTAX 

class Parent:

    pass


class Child(Parent):

    pass
Basic inheritance EXAMPLE 05 
class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):

    def bark(self):
        print("Dog is barking")


dog = Dog()

dog.eat()
dog.bark()
Animal is eating Dog is barking
1️⃣

Single Inheritance

One child inherits from one parent.

2️⃣

Multiple Inheritance

One child inherits from multiple parents.

3️⃣

Multilevel Inheritance

A class inherits from a class that itself inherits from another class.

4️⃣

Hierarchical

Multiple child classes inherit from one parent class.

5️⃣

Hybrid

Combination of different inheritance structures.

OOP PILLAR 02

Polymorphism

Polymorphism means "many forms".

The same method or interface can behave differently depending on the object using it.

ONE METHOD → MANY BEHAVIORS
🔊 speak()
→
🐶 Bark
🐱 Meow
🐮 Moo
Method overriding EXAMPLE 06 
class Animal:

    def speak(self):
        print("Animal speaks")


class Dog(Animal):

    def speak(self):
        print("Dog barks")


class Cat(Animal):

    def speak(self):
        print("Cat meows")


animals = [Dog(), Cat()]

for animal in animals:
    animal.speak()
Dog barks Cat meows

OOP PILLAR 03

Encapsulation

Encapsulation means bundling data and methods together inside a class and controlling access to internal data.

Python commonly uses naming conventions such as _variable and __variable for controlled access.

PRIVATE-STYLE ATTRIBUTE 

class BankAccount:

    def __init__(self, balance):
        self.__balance = balance
Encapsulation example EXAMPLE 07 
class BankAccount:

    def __init__(self, balance):
        self.__balance = balance

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance


account = BankAccount(5000)

account.deposit(1000)

print(account.get_balance())
6000
13
OOP PILLAR 04

Abstraction

Abstraction hides unnecessary implementation details and exposes only the functionality required by the user.

Real-World Example

When you use an ATM, you select "Withdraw Cash". You do not need to know the internal banking operations that happen behind the screen.

ABSTRACT CLASS SYNTAX 

from abc import ABC, abstractmethod


class Shape(ABC):

    @abstractmethod
    def area(self):
        pass
Abstraction example EXAMPLE 08 
from abc import ABC, abstractmethod


class Shape(ABC):

    @abstractmethod
    def area(self):
        pass


class Circle(Shape):

    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius ** 2


circle = Circle(5)

print(circle.area())
78.5
14
ADVANCED OOP

Magic / Dunder Methods

Magic methods are special methods whose names begin and end with double underscores.

Examples include __init__(), __str__(), __len__() and __add__().

Method Purpose Common Usage
__init__() Initialize an object Constructor-style initialization
__str__() String representation print(object)
__len__() Define length behavior len(object)
__add__() Customize + Operator overloading
__str__() example EXAMPLE 09 
class Student:

    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Student: {self.name}"


student = Student("Ravi")

print(student)
Student: Ravi
15
DESIGN

Composition

Composition represents a "has-a" relationship between objects.

Instead of inheriting functionality, one class contains an object of another class.

HAS-A RELATIONSHIP
🚗 Car
→
⚙️ Engine
Composition example EXAMPLE 10 
class Engine:

    def start(self):
        print("Engine started")


class Car:

    def __init__(self):
        self.engine = Engine()

    def start(self):
        self.engine.start()
        print("Car started")


car = Car()

car.start()
Engine started Car started

DEBUG BETTER

Common OOP Mistakes

❌

Forgetting self

Instance methods normally need self to access the current object's data.

❌

Confusing class and object

A class is the blueprint; an object is an instance created from it.

❌

Incorrect inheritance design

Do not use inheritance simply to reuse code when a "has-a" relationship is more appropriate.

❌

Misusing class variables

Be careful when mutable class-level data is unintentionally shared among instances.

❌

Overusing inheritance

Deep inheritance hierarchies can make applications difficult to understand and maintain.

PLACEMENT PREPARATION

Python OOP Interview Questions

1. What is OOP?

OOP is a programming paradigm that organizes programs around objects containing data and behavior.

2. What is a class?

A class is a blueprint or template used to create objects.

3. What is an object?

An object is an instance of a class.

4. What is the difference between a class and an object?

A class defines structure and behavior, while an object is a concrete instance created from that class.

5. What is __init__()?

It is commonly used to initialize an object's instance attributes when an object is created.

6. What is self?

self refers to the current instance and is used to access instance attributes and methods.

7. What are the four pillars of OOP?

Encapsulation, inheritance, polymorphism and abstraction.

8. What is inheritance?

Inheritance allows a child class to acquire attributes and methods from a parent class.

9. What is polymorphism?

Polymorphism allows the same interface or method name to represent different behavior depending on the object.

10. What is encapsulation?

Encapsulation combines data and methods within a class while controlling access to internal state.

11. What is abstraction?

Abstraction hides unnecessary implementation details and exposes essential functionality.

12. What is method overriding?

Method overriding occurs when a child class provides its own implementation of a method inherited from its parent.

13. What is the difference between classmethod and staticmethod?

A class method receives the class through cls, while a static method does not automatically receive either the instance or class.

14. What are magic methods?

Magic methods are special double-underscore methods such as __init__(), __str__() and __len__() that allow classes to integrate with Python's built-in operations.

15. What is composition?

Composition models a "has-a" relationship where an object contains another object.
