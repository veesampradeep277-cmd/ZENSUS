What is a Function?

The foundation of reusable Python code

Definition

A function is a reusable block of code designed to perform a specific task. The function runs when it is called.

Functions help reduce code duplication, improve readability, simplify testing and divide a large program into smaller manageable components.

How a Function Works
Input Arguments
→
Function Processing
→
Output Return value

Input → Processing → Output

Why functions?
  • Code reusability
  • Modularity
  • Better readability
  • Easier debugging
  • Easier testing
  • Reduced repetition

Function Syntax

⭐ The most important syntax in this lesson

⭐ Interview & coding rule

You must understand every part of the following syntax. Function questions in interviews often test parameters, arguments, return values and indentation.

Basic Syntax

def function_name():
    # function body
    statement

With Parameters

def function_name(parameter1, parameter2):
    # function body
    statement

With Return

def function_name(a, b):
    result = a + b
    return result

Complete Pattern

def function_name(parameters):
    """Optional documentation"""
    
    # processing
    
    return result
SYNTAX BREAKDOWN ⭐ Remember this 
def calculate_sum(a, b):
    return a + b

result = calculate_sum(10, 20)
print(result)
Output 30

Syntax Breakdown

  • def → defines a function
  • calculate_sum → function name
  • a, b → parameters
  • : → starts the function block
  • Indented statements → function body
  • return → sends a value back
  • calculate_sum(10, 20) → function call

Parameters vs Arguments

A very common interview question

Term Meaning Example
Parameter Variable written in the function definition def add(a, b):
Argument Actual value passed during function call add(10, 20) 
def greet(name):

"Pradeep" is the argument.

*args and **kwargs

Variable-length arguments

⭐ Very important for interviews

*args collects extra positional arguments into a tuple, while **kwargs collects extra keyword arguments into a dictionary.

*args

def add(*numbers):
    total = 0

    for number in numbers:
        total += number

    return total

print(add(10, 20))
print(add(1, 2, 3, 4, 5))
Output 30
15

Inside the function, numbers is a tuple.

**kwargs

def student(**details):

    for key, value in details.items():
        print(key, ":", value)

student(
    name="Pradeep",
    branch="CSE",
    age=20
)
Output name : Pradeep
branch : CSE
age : 20

*args + **kwargs 

def information(*args, **kwargs):

    print("Positional:", args)
    print("Keyword:", kwargs)

information(
    "Python",
    "Functions",
    level="Beginner",
    lesson=10
)
Remember:
  • *args → tuple
  • **kwargs → dictionary
  • * collects positional values
  • ** collects keyword values

Argument Unpacking 

def add(a, b, c):
    return a + b + c

numbers = [10, 20, 30]

print(add(*numbers))
def student(name, age):
    print(name, age)

data = {
    "name": "Pradeep",
    "age": 20
}

student(**data)

Positional-Only & Keyword-Only Arguments

Advanced function syntax

Positional-Only Arguments 

def greet(name, /):

Parameters before / must be supplied positionally.

Keyword-Only Arguments 

def student(*, name, age):

Meaning of *

Parameters after * must be supplied using keywords.

Combining Both 

def example(a, b, /, c, *, d, e):

example(

    3,
    d=4,
    e=5
)

def function(

    normal,
    *args,

    **kwargs
):
    pass

Function Scope & LEGB

Where Python searches for variables

LEGB Rule
L Local
→
E Enclosing
→
G Global
→
B Built-in

Local Scope

def my_function():

    x = 100

    print(x)

my_function()

Global Scope

x = 100

def show():
    print(x)

show()

Local vs Global 

x = 100

def show():
    x = 200
    print("Inside:", x)

show()

print("Outside:", x)
Output Inside: 200
Outside: 100

global Keyword 

x = 100

def change():
    global x
    x = 500

change()

print(x)

nonlocal Keyword 

def outer():

    x = 10

    def inner():

        nonlocal x

        x = 20

    inner()

    return x

print(outer())

Nested Functions

A function defined inside another function

def outer():

    print("Outer function")

    def inner():
        print("Inner function")

    inner()

outer()

A nested function can access variables from its enclosing function.

Returning an Inner Function 

def outer():

    message = "Hello from outer"

    def inner():
        return message

    return inner

function = outer()

print(function())
Output Hello from outer

First-Class Functions

Functions are objects in Python

Python treats functions as first-class objects. This means functions can be stored in variables, passed as arguments and returned from other functions.

Store a Function in a Variable 

def greet():
    return "Hello"

message = greet

print(message())

Pass Function as Argument 

def square(x):
    return x * x

def apply_function(func, value):
    return func(value)

print(apply_function(square, 5))
Output 25

Return a Function 

def outer():

    def inner():
        return "Hello"

    return inner

func = outer()

print(func())

Lambda Functions

Small anonymous functions

Syntax — memorize this 
lambda arguments : expression

Basic Lambda 

square = lambda x: x * x

print(square(5))
Output 25

Multiple Arguments 

add = lambda a, b: a + b

print(add(10, 20))

Lambda with Conditional Expression 

check = lambda x: "Even" if x % 2 == 0 else "Odd"

print(check(10))
print(check(7))
Lambda rules:
  • Uses lambda keyword
  • Can accept multiple arguments
  • Contains one expression
  • The expression's result is returned automatically
  • Useful for short temporary functions

map(), filter() & reduce()

Functional programming with functions

map()

numbers = [1, 2, 3, 4]

squares = list(
    map(lambda x: x * x, numbers)
)

print(squares)
Output [1, 4, 9, 16]

filter()

numbers = [1, 2, 3, 4, 5, 6]

even = list(
    filter(lambda x: x % 2 == 0, numbers)
)

print(even)
Output [2, 4, 6]

reduce()

from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(
    lambda a, b: a + b,
    numbers
)

print(result)
Output 10
Remember:
  • map() → transform items
  • filter() → select items
  • reduce() → combine values into one result
15

Recursion

A function calling itself

Recursive Flow
Function Call itself
→
Smaller Problem
→
Base Case Stop
Every recursive function needs:
  1. Base case
  2. Recursive case

Factorial Example 

def factorial(n):

    if n == 0:
        return 1

    return n * factorial(n - 1)

print(factorial(5))
Output 120

How factorial(5) works 

factorial(5)
= 5 × factorial(4)
= 5 × 4 × factorial(3)
= 5 × 4 × 3 × factorial(2)
= 5 × 4 × 3 × 2 × factorial(1)
= 120

Fibonacci 

def fibonacci(n):

    if n <= 1:
        return n

    return (
        fibonacci(n - 1)
        + fibonacci(n - 2)
    )

print(fibonacci(6))

Decorators

Add behavior without changing original function code

A decorator is a function that takes another function and extends or modifies its behavior.

Basic Decorator 

def decorator(func):

    def wrapper():
        print("Before function")
        func()
        print("After function")

    return wrapper


@decorator
def greet():
    print("Hello")


greet()
Output Before function
Hello
After function
What does @decorator mean? 
@decorator
def greet():
    pass

is conceptually equivalent to:

def greet():
    pass

greet = decorator(greet)

Decorator with Arguments 

def decorator(func):

    def wrapper(*args, **kwargs):

        print("Function started")

        result = func(*args, **kwargs)

        print("Function finished")

        return result

    return wrapper


@decorator
def add(a, b):

    return a + b


print(add(10, 20))

Generators & yield

Functions that produce values lazily

A generator function uses yield instead of returning all values at once. Execution pauses at each yield and resumes when the next value is requested. 

def numbers():

    yield 1
    yield 2
    yield 3


for number in numbers():

    print(number)
Output 1
2
3

return vs yield

return yield
Ends function execution Pauses function execution
Returns a value Produces values one at a time
Regular function Generator function

Generator Example 

def count_up_to(n):

    current = 1

    while current <= n:

        yield current

        current += 1


for value in count_up_to(5):

    print(value)

Common Mistakes

Errors beginners frequently make

01

Forgetting parentheses

# Wrong
greet

# Correct
greet()
02

Forgetting indentation

# Wrong
def greet():
print("Hello")

# Correct
def greet():
    print("Hello")
03

Confusing print and return

Use return when the caller needs the result for further computation.

04

Wrong argument count

def add(a, b):
    return a + b

add(10)   # TypeError
05

Non-default after default

# Wrong
def test(a=10, b):
    pass
06

Missing recursion base case

Without a base case, recursive calls can continue until Python raises a recursion error.

07

Mutable default argument

# Avoid this pattern
def add_item(item, items=[]):
    items.append(item)
    return items

Default values are created once when the function is defined, not freshly for every call.

Python Functions — Interview Questions

Questions you should be able to answer confidently

Q1 What is a function in Python?

A function is a reusable block of code that performs a specific task. It is defined using the def keyword and executes when called.

Q2 What is the difference between a parameter and an argument? 
def greet(name):     # parameter
    print(name)

greet("Pradeep")     # argument

A parameter appears in the function definition. An argument is the actual value supplied during the function call.

Q3 What is the difference between print() and return?

print() displays information. return sends a value back to the caller and terminates the current function execution.

Q4 What are default arguments? 
def greet(name="Guest"):
    print(name)

greet()

A default argument has a predefined value that is used when the caller does not supply that argument.

Q5 What are *args and **kwargs?
  • *args collects variable positional arguments into a tuple.
  • **kwargs collects variable keyword arguments into a dictionary.
Q6 What is a lambda function? 
square = lambda x: x * x

A lambda is a small anonymous function containing one expression whose result is returned automatically.

Q7 What is recursion?

Recursion occurs when a function calls itself. A recursive solution normally requires a base case and a recursive case.

Q8 What is the LEGB rule?

Python searches for variable names in this order:

Local Enclosing Global Built-in
Q9 Can a function return another function? 
def outer():

    def inner():
        return "Hello"

    return inner

f = outer()

print(f())

Yes. Python functions are first-class objects and can be returned from other functions.

Q10 Can a function be passed as an argument? 
def square(x):
    return x * x

def apply(func, value):
    return func(value)

print(apply(square, 5))
Output 25
Q11 What is a decorator?

A decorator is a function that accepts another function and adds behavior to it without changing the original function's source code.

Q12 What is the difference between return and yield?

return terminates the function and sends back a result. yield pauses a generator and produces a value, allowing execution to resume later.

Q13 What does / mean in a function definition? 
def greet(name, /):
    pass

Parameters before / are positional-only.

Q14 What does * mean in a function definition? 
def greet(*, name):
    pass

Parameters after * are keyword-only.

Q15 What happens when a function has no return statement? 
def test():
    print("Hello")

result = test()

print(result)
Output Hello
None
Q16 Predict the output 
x = 10

def test():
    x = 20
    print(x)

test()

print(x)
Answer 20
10

The function's x is local and does not modify the global x.

Q17 Predict the output 
def add(a, b=10):
    return a + b

print(add(5))
print(add(5, 20))
Answer 15
25
Q18 Predict the output 
def fun(*args):
    print(type(args))
    print(args)

fun(1, 2, 3)
Answer <class 'tuple'>
(1, 2, 3)
Q19 Predict the output 
def fun(**kwargs):
    print(type(kwargs))
    print(kwargs)

fun(name="Pradeep", age=20)
Answer <class 'dict'>
{'name': 'Pradeep', 'age': 20}
Q20 ⭐ Tricky Interview Question 
def test(value=[]):

    value.append(1)

    return value


print(test())
print(test())
print(test())
Answer [1]
[1, 1]
[1, 1, 1]

The default list is created once when the function is defined and is reused across calls.
