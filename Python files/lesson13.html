Exception Handling in Python

Learn how to detect, handle, raise and manage runtime errors in Python applications without abruptly terminating your program.

try except else finally raise custom exceptions
01
FOUNDATION

What is Exception Handling?

An exception is an unexpected event that occurs while a Python program is executing.

For example, dividing a number by zero, converting invalid input to an integer, accessing a missing list index or opening a file that does not exist can produce exceptions.

Exception handling allows developers to detect these situations and respond to them gracefully instead of allowing the application to terminate unexpectedly.

Important Idea

Exception handling does not mean hiding every error. It means anticipating recoverable runtime problems and handling them appropriately.

04
MOST IMPORTANT

try and except

The try block contains code that may raise an exception.

The except block defines what Python should do when the specified exception occurs.

BASIC SYNTAX 

try:
    # Code that may cause an exception

except ExceptionType:
    # Code that handles the exception
Division by Zero EXAMPLE 01 
try:
    result = 10 / 0
    print(result)

except ZeroDivisionError:
    print("Cannot divide by zero.")
Output → Cannot divide by zero.

05
PRECISION

Handling Specific Exceptions

It is usually better to catch a specific exception instead of using a broad except:.

Specific exception handling makes programs easier to understand and prevents unrelated errors from being accidentally hidden.

Invalid Number Input EXAMPLE 02 
try:
    age = int(input("Enter your age: "))
    print("Age:", age)

except ValueError:
    print("Please enter a valid integer.")
List Index Error EXAMPLE 03 
numbers = [10, 20, 30]

try:
    print(numbers[5])

except IndexError:
    print("Index does not exist.")
06
ADVANCED

Multiple Exceptions

A single program may encounter different types of exceptions.

Python allows multiple except blocks so each exception can have its own handling logic.

Multiple except Blocks EXAMPLE 04 
try:

    number = int(input("Enter number: "))

    result = 100 / number

    print(result)

except ValueError:
    print("Enter numbers only.")

except ZeroDivisionError:
    print("Zero is not allowed.")

MULTIPLE EXCEPTIONS IN ONE BLOCK 

try:
    value = int(input("Enter value: "))

except (ValueError, TypeError):
    print("Invalid value.")
07
ERROR INFORMATION

Using the Exception Object

You can store the exception object using as.

This allows you to access the exception's message and provide more informative output.

SYNTAX 

except ExceptionType as e:
    print(e)
Using as e EXAMPLE 05 
try:
    result = 10 / 0

except ZeroDivisionError as e:
    print("Error:", e)
Output → Error: division by zero
08
CONTROL FLOW

The else Block

The else block executes only when the code inside the try block completes successfully without raising an exception.

SYNTAX 

try:
    # risky code

except ExceptionType:
    # error handling

else:
    # runs when no exception occurs
try + except + else EXAMPLE 06 
try:

    number = int(input("Enter number: "))

except ValueError:

    print("Invalid input.")

else:

    print("You entered:", number)
Remember

else is not for handling errors. It is for code that should execute only after the try block succeeds.

09
CLEANUP

The finally Block

The finally block executes regardless of whether an exception occurs.

It is commonly used for cleanup operations, such as closing files, releasing resources, or performing final actions.

COMPLETE STRUCTURE 

try:
    # risky code

except ExceptionType:
    # handle exception

else:
    # runs when successful

finally:
    # always executes
finally Always Runs EXAMPLE 07 
try:

    result = 10 / 0

except ZeroDivisionError:

    print("Cannot divide by zero.")

finally:

    print("Program execution completed.")
Output → Cannot divide by zero.
Output → Program execution completed.

MANUAL EXCEPTIONS

The raise Keyword

Python's raise keyword allows a developer to explicitly generate an exception when a specific condition occurs.

SYNTAX 

raise ExceptionType("Error message")
Raise ValueError EXAMPLE 08 
age = -5

if age < 0:
    raise ValueError("Age cannot be negative.")
Raise TypeError EXAMPLE 09 
value = "100"

if not isinstance(value, int):
    raise TypeError("Value must be an integer.")
Why use raise?

Use raise when your application detects an invalid state or input that should be reported explicitly.

ADVANCED PYTHON

Custom Exceptions

Python allows developers to create their own exception classes for application-specific situations.

A custom exception normally inherits from Python's built-in Exception class or one of its subclasses.

CUSTOM EXCEPTION SYNTAX 

class CustomError(Exception):
    pass
Custom Age Exception EXAMPLE 10 
class InvalidAgeError(Exception):
    pass


def check_age(age):

    if age < 18:
        raise InvalidAgeError(
            "Age must be 18 or above."
        )

    print("Eligible.")


try:

    check_age(15)

except InvalidAgeError as e:

    print(e)
Output → Age must be 18 or above.

ADVANCED

Nested try-except

A try-except statement can be placed inside another try-except statement.

Nested exception handling can be useful when different sections of an operation require different recovery logic.

Nested Exception Handling EXAMPLE 11 
try:

    number = int(input("Enter number: "))

    try:

        result = 100 / number
        print(result)

    except ZeroDivisionError:

        print("Cannot divide by zero.")

except ValueError:

    print("Please enter a number.")

PROFESSIONAL CODING

Exception Handling Best Practices

🎯

Catch Specific Exceptions

Prefer specific exceptions over a completely generic except block. 

except ValueError:
    ...
📝

Give Useful Messages

Error messages should explain what went wrong and, where useful, what the user can do. 

except ValueError:
    print("Enter a valid age.")
🧹

Clean Up Resources

Use finally or context managers when cleanup is required. 

finally:
    close_resource()
🚫

Don't Hide Errors

Avoid silently ignoring exceptions without a good reason. 

except Exception:
    log_error()
📦

Use Custom Exceptions

Create domain-specific exceptions when built-in exceptions do not communicate the problem clearly. 

class PaymentError(Exception):
    pass
🔍

Preserve Context

Keep useful exception information for debugging and logging. 

except ValueError as e:
    print(e)
15
AVOID THESE

Common Mistakes

❌

Using bare except everywhere

A broad except can hide programming problems and make debugging difficult. Catch the exceptions you expect.

❌

Putting too much code inside try

Keep the try block focused around the operation that can actually fail.

❌

Ignoring the exception message

Use the exception object when useful so the actual problem is not lost.

❌

Confusing else and finally

else runs only after successful try execution. finally runs regardless of whether an exception occurred.

❌

Raising the wrong exception type

Choose an exception that accurately represents the problem.

❌

Using exceptions instead of validation

Do not use exception handling as a replacement for simple logical checks when validation is clearer.

INTERVIEW PREPARATION

Python Exception Handling Interview Questions

1. What is exception handling in Python?

Exception handling is a mechanism for detecting and managing runtime exceptions using constructs such as try, except, else and finally.

2. What is the difference between an error and an exception?

Errors can refer broadly to problems in a program, while exceptions are runtime events represented by Python exception objects that can often be handled using try-except.

3. What is the purpose of try?

The try block contains code that may raise an exception.

4. What is the purpose of except?

except defines how a matching exception should be handled.

5. What is the difference between else and finally?

else executes when the try block completes without an exception. finally executes regardless of whether an exception occurs.

6. Can we have multiple except blocks?

Yes. Multiple except blocks can handle different exception types separately.

7. What is raise in Python?

raise explicitly generates an exception from the program.

8. What is a custom exception?

A custom exception is a user-defined exception class, usually derived from Exception, designed for application-specific error conditions.

9. What does "as e" mean in except?

It assigns the caught exception object to a variable so its information can be inspected or logged.

10. Can finally execute if an exception occurs?

Yes. The finally block is designed to execute whether the try block succeeds or an exception occurs.

11. Why should we avoid bare except?

A bare except can catch unexpected exceptions and make debugging more difficult. Specific exception types are generally clearer.

12. Can try be used without except?

Yes. A try statement can be paired with finally without an except block when cleanup must be guaranteed.
