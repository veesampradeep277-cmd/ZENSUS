02 · Web Fundamentals

What is HTTP?

HTTP stands for HyperText Transfer Protocol.


It is an application-layer protocol used for communication between clients and servers on the Web.


A browser, mobile application or another program can act as an HTTP client. A Node.js application can act as an HTTP server.

03 · Node.js HTTP

Creating an HTTP Server

Node.js includes a built-in http module. This module provides APIs for creating HTTP servers and clients.

server.js 
const http = require('http');

const server = http.createServer(
    (req, res) => {

        res.writeHead(200, {
            'Content-Type': 'text/plain'
        });

        res.end('Hello from ZENSUS');
    }
);

server.listen(3000, () => {

    console.log(
        'Server running on port 3000'
    );

});
Core idea:
http.createServer() creates an HTTP server and receives a callback that is invoked when an HTTP request is received.

Run the Server

node server.js

The server starts listening on port 3000.

04 · Request

The Request Object

The req object represents the incoming HTTP request.


Important properties include:

req.method METHOD
Contains the HTTP method such as GET or POST.
req.url URL
Contains the requested URL path and query string.
req.headers HEADERS
Contains request headers sent by the client.
req.on() EVENT
Can be used to listen for request stream events.
Inspecting a Request 
const http = require('http');

const server = http.createServer(
    (req, res) => {

        console.log('Method:', req.method);
        console.log('URL:', req.url);
        console.log('Headers:', req.headers);

        res.end('Request received');
    }
);

server.listen(3000);
05 · Response

The Response Object

The res object represents the response that Node.js sends back to the client.

res.writeHead() STATUS
Sets the HTTP status code and response headers.
res.write() BODY
Writes response data.
res.end() FINISH
Ends the response.
res.setHeader() HEADER
Sets an individual response header. 
res.writeHead(200, {
    'Content-Type': 'text/plain'
});

res.end(
    'Response sent successfully'
);
Important:
A response should eventually be ended using res.end(). Otherwise the connection may remain open waiting for more response data.

09 · Routing

URLs and Basic Routing

A Node.js HTTP server can inspect req.url and req.method to determine which route should handle the request. 

const http = require('http');

const server = http.createServer(
    (req, res) => {

        if (
            req.method === 'GET' &&
            req.url === '/'
        ) {

            res.writeHead(200, {
                'Content-Type': 'text/plain'
            });

            res.end('Home Page');

        } else if (
            req.method === 'GET' &&
            req.url === '/about'
        ) {

            res.writeHead(200, {
                'Content-Type': 'text/plain'
            });

            res.end('About Page');

        } else {

            res.writeHead(404, {
                'Content-Type': 'text/plain'
            });

            res.end('Page Not Found');
        }

    }
);

server.listen(3000);

10 · Architecture

Event-Driven Architecture

Node.js uses an event-driven programming model. Instead of continuously waiting for every operation to finish, applications can register handlers that execute when particular events occur.


Examples of events include:

  • An HTTP request arrives
  • A file has finished reading
  • A network connection is established
  • A stream receives data
  • A timer expires
  • An application-defined event is emitted
Important distinction:
Event-driven does not mean that JavaScript code runs multiple pieces of JavaScript simultaneously. Node.js coordinates asynchronous work and invokes JavaScript callbacks/handlers when their corresponding operations are ready.

Creating and Listening to Events

const EventEmitter =
    require('events');

const emitter =
    new EventEmitter();

emitter.on(
    'welcome',
    (name) => {

        console.log(
            `Welcome ${name}`
        );

    }
);

emitter.emit(
    'welcome',
    'Pradeep'
);
emitter.on() LISTEN
Registers a listener for an event.
emitter.emit() TRIGGER
Emits an event and passes optional arguments to listeners.
emitter.once() ONE TIME
Registers a listener that runs at most once.
emitter.off() REMOVE
Removes a previously registered listener.

Mini Project — Node.js REST-Style Server

Build a small server that responds differently to multiple API routes.

const http = require('http');

const server =
    http.createServer((req, res) => {

        res.setHeader(
            'Content-Type',
            'application/json'
        );

        if (
            req.method === 'GET' &&
            req.url === '/api/status'

            res.statusCode = 200;

            res.end(
                JSON.stringify({
                    status: 'online'
                })
            );

            return;
        }


        if (
            req.method === 'GET' &&
            req.url === '/api/users'

            res.end(
                JSON.stringify({
                    users: [
                        'Alice',
                        'Bob',
                        'Charlie'
                    ]
                })
            );

            return;
        }


        res.statusCode = 404;

        res.end(
            JSON.stringify({
                error: 'Route not found'
            })
        );

    });


server.listen(3000, () => {

    console.log(
        'API server running on port 3000'
    );

});

17 · Reliability

HTTP Server Error Handling

A production server should handle errors carefully rather than allowing unexpected failures to produce unclear responses. 

const http = require('http');

const server = http.createServer(
    (req, res) => {

        try {

            if (req.url === '/error') {
                throw new Error(
                    'Something went wrong'
                );
            }

            res.statusCode = 200;
            res.end('Success');

        } catch (error) {

            console.error(error);

            res.statusCode = 500;

            res.end(
                'Internal Server Error'
            );
        }
    }
);

server.listen(3000);
Production note:
Error handling strategy becomes more sophisticated in real applications. Frameworks such as Express provide middleware patterns that make centralized HTTP error handling easier.

19 · Interview Preparation

Professional Interview Questions

What is the http module in Node.js? +
The built-in http module provides APIs for creating HTTP servers and clients. It allows Node.js applications to receive requests and send HTTP responses.
What does http.createServer() do? +
It creates an HTTP server. A callback is associated with the server and is invoked for incoming HTTP requests.
What is the difference between req and res? +
req represents the incoming client request, while res represents the response that the server sends back.
What is routing? +
Routing is the process of determining which server logic should handle an incoming request based on information such as its HTTP method and URL.
What is EventEmitter? +
EventEmitter is a Node.js class used to create objects that can emit named events and allow other code to register listeners for those events.
What is event-driven architecture? +
It is an architecture where program behavior can be organized around events and handlers. Components emit events when something happens, while listeners respond to those events.
Is Node.js completely single-threaded? +
JavaScript execution in a Node.js process is primarily handled by a single main thread, but Node.js can rely on the operating system and libuv mechanisms for asynchronous I/O and certain background operations. Therefore, "Node.js is single-threaded" is an oversimplification.
Why is Node.js suitable for I/O-heavy applications? +
Node.js uses non-blocking I/O and an event-driven architecture, allowing the application to continue processing JavaScript work while many I/O operations are waiting for external resources.
