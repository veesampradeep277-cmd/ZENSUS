Foundation

What is NPM?

NPM stands for Node Package Manager. It is the standard package manager commonly used with Node.js.

N

Package Manager

NPM helps developers install and manage reusable JavaScript packages in their projects.

⌘

Command Line Tool

NPM provides commands such as npm install, npm update, npm uninstall and npm run.

◈

Package Registry

NPM also refers to the public registry where JavaScript packages are published.

Simple Definition: NPM is the tool that helps your Node.js project find, install and manage the packages it needs.
Important Difference

Node.js vs NPM

Node.js

Node.js is a JavaScript runtime environment. It allows JavaScript code to execute outside the browser, including on servers.


node app.js

NPM

NPM is primarily used to manage packages, dependencies and project scripts in Node.js applications.


npm install express

Core File

Understanding package.json

package.json is one of the most important files in a Node.js project.

package.json 
{
  "name":
    "zensus-app",

  "version":
    "1.0.0",

  "description":
    "Node.js learning app",

  "main":
    "app.js",

  "scripts": {
    "start":
      "node app.js",
    "dev":
      "nodemon app.js"
  },

  "dependencies": {
    "express":
      "^5.1.0"
  },

  "devDependencies": {
    "nodemon":
      "^3.1.0"
  }
}
name
version
main
scripts
dependencies
devDependencies
The package name identifies your project. It should normally be lowercase and suitable for use as an NPM package name.
Package Installation

Installing Packages

NPM makes installing third-party libraries extremely simple.

Install a Dependency

Installs a package for use by your application.

npm install express

Install Dev Dependency

Installs a package mainly required during development.

npm install nodemon --save-dev

Remove a Package

Removes the package from the project and updates package.json.

npm uninstall express

Essential Commands

NPM Command Reference

Updates packages according to the version ranges defined by the project.

Project Structure

Three Important NPM Files

◆

package.json

Describes your project, scripts and dependency requirements.

◇

package-lock.json

Records resolved dependency versions and other installation information so installs can be reproduced more consistently.

▣

node_modules

Contains the packages installed for your project and their dependencies.

Important: node_modules is normally excluded from Git repositories because dependencies can be recreated from the project's package files.

Useful Tool

What is npx?

NPM and npx are related but serve different purposes.

npm

Primarily manages packages and project dependencies.


npm install express

npx

Can execute package-provided command-line tools without requiring you to install the tool globally first.


npx create-something
Installation Scope

Local vs Global Packages

Local

Installed inside the current project. This is the normal approach for application dependencies and project-specific tools.


npm install express

Global

Installed for broader system-wide use. Global installation should be used selectively; project-local dependencies and npx are often preferable.


npm install -g package-name
Automation

NPM Scripts

Scripts provide convenient names for commands used frequently in your project.

package.json 
"scripts": {

  "start":
    "node app.js",

  "dev":
    "nodemon app.js",

  "test":
    "node test.js"

}
▶

Run Your Scripts

Instead of typing long commands repeatedly, define them once inside package.json.


npm start

npm run dev

npm test
Security

Dependency Security

Third-party packages can introduce security risks, so dependency health should be monitored.

npm audit

Checks installed dependencies for known security advisories recorded by the package ecosystem.

npm audit fix

Attempts to apply available automated fixes. Always review changes, especially when updates may involve major version changes.

Good Practice

Keep dependencies reasonably current, review important updates and avoid installing packages you do not actually need.

Hands-On Practice

Mini Project: Express Setup

Let's imagine creating a small Node.js web server using Express.

Terminal + app.js

mkdir my-server
cd my-server

# 2. Create package.json
npm init -y

# 3. Install Express

app.js

app.get("/", (req, res) => {
    res.send("Welcome to ZENSUS!");

    console.log("Server running on port 3000");
});

Run it: After creating the application, you can start the server using node app.js.
Interview Preparation

NPM Interview Questions

What is NPM? +
NPM is the package manager and package ecosystem commonly used with Node.js. It helps developers install, update and manage JavaScript packages.
What is package.json? +
package.json is a project configuration file. It can contain project metadata, scripts, dependency declarations and other configuration.
What is package-lock.json? +
It records the resolved dependency tree, including specific package versions and integrity information, helping installations remain more reproducible.
What is node_modules? +
node_modules is the directory where packages installed for the project are stored.
Difference between dependencies and devDependencies? +
dependencies contain packages needed by the application at runtime, while devDependencies are primarily used for development, testing or build tooling.
What does npm install do? +
It installs the project's declared dependencies or a specified package and updates relevant package-management files.
What is npx? +
npx is a command runner associated with the NPM ecosystem. It is commonly used to execute package binaries without requiring a global installation.
