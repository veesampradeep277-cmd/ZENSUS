React Router & Navigation

Learn how React applications manage URLs, pages, navigation, dynamic resources, nested layouts, protected screens and browser history without requiring a full page reload for every navigation.

1. What is Client-Side Routing?

Traditional websites often request a new HTML document from the server when the user navigates to another page. In a client-side routed React application, JavaScript can update the displayed UI in response to the URL while the application remains loaded in the browser.

Traditional Navigation vs Client-Side Routing
URL
→
Router
→
Match Route
→
Render UI
Important: Client-side routing does not mean the server becomes irrelevant. The server still needs to correctly serve the application entry point for URLs that the client router handles, depending on the deployment setup.

2. Why Routing?

Real applications usually contain multiple screens and resources. For example, ZENSUS might contain a dashboard, courses, individual lessons, projects, profile pages and authentication screens.

Dashboard

/dashboard

Courses

Routing gives different URLs meaningful application states. Users can bookmark, refresh and navigate between those states.

3. React Router

React Router is a routing library used to connect URL paths with React UI. It provides components and hooks for declaring routes, navigating between locations and reading URL information.

Install

npm install react-router-dom

A modern React application can then import routing APIs from react-router-dom.

5. Routes & Route

Routes contains the route definitions. Each Route connects a URL pattern to an element that should be rendered when that pattern matches.

import { BrowserRouter, Routes, Route } from "react-router-dom"; function App() { return ( <BrowserRouter> <Routes> <Route path="/" element={<Home />} /> <Route path="/courses" element={<Courses />} /> <Route path="/about" element={<About />} /> </Routes> </BrowserRouter> ); }
Think of a Route as a mapping: URL pattern → React element.

6. Link

Link creates navigation between routes without requiring developers to manually manipulate browser URLs.

import { Link } from "react-router-dom"; function Navigation() { return ( <nav> <Link to="/"> Home </Link> <Link to="/courses"> Courses </Link> <Link to="/about"> About </Link> </nav> ); }
Avoid using ordinary anchor navigation for internal SPA routes when you want React Router to handle the transition. Use Router navigation components such as Link for internal application navigation.

7. NavLink

NavLink is similar to Link but provides information about whether the link matches the current route, which is especially useful for navigation menus.

import { NavLink } from "react-router-dom"; <NavLink to="/courses" className={({ isActive }) => isActive ? "active" : "" } > Courses </NavLink>

8. Dynamic Routes

Dynamic routes allow one route definition to represent many related URLs. A segment beginning with a colon represents a dynamic parameter.

<Route path="/courses/:courseId" element={<Course />} />

The same route can match:

React

/courses/react

Python

/courses/python

Java

/courses/java

The route pattern is reusable because :courseId changes according to the URL.

9. URL Parameters

useParams() reads dynamic parameters from the matched URL.

import { useParams } from "react-router-dom"; function Course() { const { courseId } = useParams(); return ( <div> <h1> Course: {courseId} </h1> </div> ); }
URL /courses/react
Route /courses/:courseId
useParams() courseId = "react"

10. Query Parameters

Query parameters are values placed after a question mark in a URL. They are useful for filters, searches, sorting and optional UI state.

/courses?category=react&level=beginner

A component can read the current location and search string.

import { useSearchParams } from "react-router-dom"; function Courses() { const [ searchParams ] = useSearchParams(); const category = searchParams.get("category"); const level = searchParams.get("level"); return ( <p> Category: {category} <br /> Level: {level} </p> ); }
Path parameter: /courses/react usually identifies a resource.

Query parameter: /courses?level=beginner usually modifies how a resource collection is displayed or filtered.

11. Nested Routes

Nested routes allow child routes to render inside a parent route's UI. This is especially useful for dashboards and course systems.

<Route path="/dashboard" element={<DashboardLayout />} > <Route path="overview" element={<Overview />} /> <Route path="courses" element={<DashboardCourses />} /> <Route path="profile" element={<Profile />} /> </Route>

The parent layout renders an Outlet where the matched child route appears.

import { Outlet } from "react-router-dom"; function DashboardLayout() { return ( <div> <Sidebar /> <main> <Outlet /> </main> </div> ); }

13. Navigation

Navigation can happen through visible links or programmatically in response to an application event.

Declarative Navigation

Use Link or NavLink when the user should click a visible navigation element.

<Link to="/courses"> Courses </Link>

Programmatic Navigation

Use useNavigate when navigation occurs as part of application logic.

navigate("/dashboard");

14. useNavigate()

useNavigate() returns a function that can change the current location programmatically.

import { useNavigate } from "react-router-dom"; function Login() { const navigate = useNavigate(); function handleLogin() { // Authentication logic... navigate("/dashboard"); } return ( <button onClick={handleLogin}> Login </button> ); }

Going Back

navigate(-1);

Going Forward

navigate(1);
Do not use programmatic navigation for every link. If the user is simply choosing a destination from a menu, a Link or NavLink usually communicates the intent more clearly.

15. useParams()

useParams reads the dynamic segments defined in the matched route.

<Route path="/students/:studentId" element={<Student />} /> function Student() { const { studentId } = useParams(); return ( <h1> Student: {studentId} </h1> ); }
Route definition:

/students/:studentId

URL:

/students/1024

Parameter:

studentId = "1024"

16. useLocation()

useLocation gives access to information about the current location. It is useful when application logic needs to react to changes in the URL.

import { useLocation } from "react-router-dom"; function CurrentPage() { const location = useLocation(); return ( <div> <p> Path: {location.pathname} </p> <p> Search: {location.search} </p> </div> ); }

18. 404 Pages

A catch-all route can provide a custom interface when no defined route matches.

<Routes> <Route path="/" element={<Home />} /> <Route path="/courses" element={<Courses />} /> <Route path="*" element={<NotFound />} /> </Routes>

Example NotFound Component

function NotFound() { return ( <div> <h1> 404 </h1> <p> Page not found. </p> <Link to="/"> Return Home </Link> </div> ); }

19. Protected Routes

Protected routing is a UI/navigation pattern where access to certain routes depends on application authentication or authorization state.

Protected Route Decision
User Requests Route
→
Auth State
→
Authenticated?

YES → Protected UI
|
NO → Login

Simple Protected Route

import { Navigate } from "react-router-dom"; function ProtectedRoute({ isAuthenticated, children }) { if (!isAuthenticated) { return ( <Navigate to="/login" replace /> ); } return children; }

Usage

<Route path="/dashboard" element={ <ProtectedRoute isAuthenticated={isAuthenticated} > <Dashboard /> </ProtectedRoute> } />
Security warning: A client-side protected route is not a security boundary. A user interface can hide a screen, but sensitive data and privileged operations must also be protected by the backend/server.

21. Complete React Router Example

The following example combines the major concepts introduced in this lesson.

import { BrowserRouter, Routes, Route, Link, NavLink, Outlet, useParams, useNavigate, Navigate } from "react-router-dom"; function App() { return ( <BrowserRouter> <Routes> <Route element={<MainLayout />} > <Route path="/" element={<Home />} /> <Route path="/courses" element={<Courses />} /> <Route path="/courses/:courseId" element={<Course />} /> <Route path="/login" element={<Login />} /> <Route path="/dashboard" element={ <ProtectedRoute> <Dashboard /> </ProtectedRoute> } /> <Route path="*" element={<NotFound />} /> </Route> </Routes> </BrowserRouter> ); } function MainLayout() { return ( <> <nav> <NavLink to="/"> Home </NavLink> <NavLink to="/courses"> Courses </NavLink> <NavLink to="/dashboard"> Dashboard </NavLink> </nav> <main> <Outlet /> </main> </> ); } function Course() { const { courseId } = useParams(); const navigate = useNavigate(); return ( <div> <h1> {courseId} </h1> <button onClick={() => navigate("/courses") } > Back to Courses </button> </div> ); } function ProtectedRoute({ children }) { const isAuthenticated = true; if (!isAuthenticated) { return ( <Navigate to="/login" replace /> ); } return children; }

23. Common React Router Mistakes

Mistake 1 — Forgetting BrowserRouter

Router hooks and components need the appropriate routing context.

Mistake 2 — Using the Wrong Navigation Mechanism

Use Link or NavLink for normal internal navigation instead of manually changing the browser location.

Mistake 3 — Confusing Params and Query Parameters

A path such as /courses/react uses a route segment, while /courses?level=beginner uses a query string.

Mistake 4 — Forgetting Outlet

Nested child routes need an Outlet in the parent UI where the child content should render.

Mistake 5 — Making Every Route Protected

Public pages such as login and registration generally need to remain accessible before authentication.

Mistake 6 — Treating Client Routing as Security

Frontend route guards improve user experience and navigation, but backend authorization must enforce access to protected data and operations.

Mistake 7 — Ignoring Server Configuration

A deployed SPA needs server configuration that can return the application entry point for client-managed URLs when users directly visit or refresh them.

26. Quick Quiz

Check whether you understand the core routing concepts before moving forward.

1. What is the primary purpose of a React Router Route?

A Route connects a URL pattern with the React element that should render when that route matches.

2. Which component is useful for navigation links that need an active state?

NavLink provides navigation and information about whether its destination matches the current route.

3. Given the route /courses/:courseId and the URL /courses/react, what does useParams() provide for courseId?

The dynamic segment :courseId matches the value react in the URL.

4. What does Outlet do in a nested routing structure?

Outlet is the location in a parent route's UI where the matched nested child route is rendered.

5. Which hook is designed for programmatic navigation?

useNavigate() returns a navigation function that can change the current location from application logic.
