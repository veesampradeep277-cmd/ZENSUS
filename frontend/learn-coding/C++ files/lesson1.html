02 • FUNDAMENTALS

What is C++?

C++ is a general-purpose programming language designed for performance, flexibility and control.

⚡

High Performance

C++ gives programmers significant control over memory and hardware resources, making it suitable for performance-critical applications.

🧩

Multi-Paradigm

C++ supports procedural, object-oriented and generic programming, along with many functional programming techniques.

🛠️

General Purpose

It can be used to build games, system software, applications, embedded software, financial systems and many other types of software.

💡 Simple definition

C++ is a compiled, general-purpose, multi-paradigm programming language that combines high-level programming features with low-level control and high performance.

03 • HISTORY

Evolution of C++

Understanding the history helps explain why C++ contains both low-level and high-level programming features.

C

The C language

C became widely important for systems programming because it provided efficient execution and relatively direct hardware control.

+

C with Classes

Bjarne Stroustrup extended C with features such as classes, supporting object-oriented programming.

C++

C++

The language evolved into C++, adding features including inheritance, virtual functions, templates and stronger abstraction mechanisms.

STL

Standard Library

The Standard Template Library introduced powerful reusable containers and algorithms such as vector, map, set and sort.

17+

Modern C++

Modern standards introduced safer and more expressive techniques including smart pointers, move semantics, lambdas, range-based loops and many library improvements.

Output

Understand every line

#include <iostream>

Includes the standard input/output stream library. It provides facilities such as std::cout and std::cin.

int main()

Defines the program's main function. Execution of a normal hosted C++ program begins from main.

{ }

Curly braces define the body of the function. Statements inside execute when the function runs.

std::cout

Refers to the standard output stream provided by the C++ standard library.

<<

The stream insertion operator sends data into the output stream.

return 0;

Returns the value 0 from main, conventionally indicating successful program termination.

09 • INPUT & OUTPUT

Input and Output in C++

C++ uses stream-based input and output. The most common beginner tools are std::cin and std::cout.

📤

std::cout

Used to send formatted output to the standard output stream. 

std::cout << "Hello";
std::cout << 100;
📥

std::cin

Used to extract formatted input from the standard input stream. 

int age;

std::cin >> age;
↩️

New line

'\n' inserts a newline. std::endl also inserts a newline and flushes the stream. 

std::cout << "Hello\n";
std::cout << "World";
input_output.cpp 
#include <iostream>

int main()
{
    std::string name;
    int age;

    std::cout << "Enter your name: ";
    std::cin >> name;

    std::cout << "Enter your age: ";
    std::cin >> age;

    std::cout << "\nHello " << name << "!\n";
    std::cout << "Age: " << age << '\n';

    return 0;
}
⚠️ Beginner note: cin and getline

Formatted extraction such as std::cin >> value can leave a newline in the input buffer. When using std::getline afterward, you often need std::ws or appropriate input handling.

10 • NAMESPACE

Understanding std::

C++ uses namespaces to organize names and reduce naming conflicts. 

#include <iostream>

int main()
{
    std::cout << "Hello!";
    return 0;
}
📦

What is std?

std is the standard namespace containing names provided by the C++ standard library.

🎯

What does :: mean?

:: is the scope resolution operator. It allows you to specify which namespace or scope a name belongs to.

✅

Recommended habit

For beginner and professional code, using explicit names such as std::cout and std::vector keeps the origin of names clear.

11 • LANGUAGE BASICS

What are C++ tokens?

A token is one of the fundamental units recognized by the C++ compiler when processing source code.

🔑

Keywords

Reserved words such as int, return, class and if.

🏷️

Identifiers

Names given to program entities such as variables, functions, classes and objects.

🔢

Literals

Fixed values such as 10, 3.14, 'A' and "Hello".

➕

Operators

Symbols used to perform operations, such as +, -, == and <<.

;

Punctuators

Symbols such as semicolons, commas, parentheses and braces that structure the program.

💬

Comments

Explanatory text ignored by the compiler: // comment and block comments.

15 • DEBUGGING

Common beginner mistakes

These small mistakes are extremely common when starting C++.

Missing semicolon

int age = 19
int age = 19;

Most C++ statements end with a semicolon.

Wrong output operator

std::cout > "Hello";
std::cout << "Hello";

Output uses the insertion operator <<.

Missing std::

cout << "Hello";
std::cout << "Hello";

The standard library name is inside the std namespace.

Wrong capitalization

Std::Cout
std::cout

C++ is case-sensitive.

Wrong main syntax

int main
int main()

The function declaration requires parentheses.

Missing braces

int main()
std::cout << "Hi";
int main() { ... }

The function body needs braces.

16 • DEBUGGING BASICS

Errors you should know

❌

Compile-time error

An error detected while compiling the source code. The program generally cannot be built successfully until the error is fixed.

💥

Runtime error

An error that occurs while the program is executing, such as accessing an invalid resource or encountering an unhandled exceptional condition.

⚠️

Logical error

The program runs but produces an incorrect result because the algorithm or logic is wrong.

18 • INTERVIEW PREPARATION

C++ interview questions

These are beginner-level questions you should be able to answer after Lesson 1.

What is C++? +
C++ is a general-purpose, compiled, multi-paradigm programming language designed for performance, flexibility and control.
Who created C++? +
Bjarne Stroustrup is strongly associated with the creation and early development of C++, which began as an extension of C with classes.
Why is C++ called a multi-paradigm language? +
Because C++ supports multiple programming approaches, including procedural, object-oriented and generic programming, along with functional techniques.
What is a compiler? +
A compiler translates source code written in a programming language into a lower-level representation that can be processed further to produce an executable program.
What is std::cout? +
std::cout is the standard output stream object provided by the C++ standard library. It is commonly used to display formatted output.
What is the difference between cin and cout? +
std::cin is commonly used to read formatted input from standard input, while std::cout is commonly used to write formatted output to standard output.
Why is C++ useful for DSA? +
C++ provides efficient language features and a powerful Standard Library containing containers and algorithms commonly used to implement and solve data structure and algorithm problems.
What is a namespace? +
A namespace provides a named scope for identifiers, helping organize code and reduce naming conflicts.
