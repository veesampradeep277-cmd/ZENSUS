1. Real-World Problem

Every good project starts with a problem.

🎓 Problem Statement

Managing student records manually becomes difficult when the number of students increases. A college needs a system to store student details, search records, update information, delete records and calculate useful statistics.

Our solution: Build a menu-driven C++ application that manages student records and permanently stores them using file handling.

Start with this single-file C++17 version. 

#include <algorithm>
#include <fstream>
#include <iomanip>
#include <iostream>
#include <limits>
#include <string>
#include <vector>

using namespace std;


// =====================================================
// STUDENT CLASS
// =====================================================

class Student {

private:

    int roll;
    string name;
    string department;
    double marks;

public:

    // Default constructor
    Student()
        : roll(0),
          marks(0.0)
    {
    }


    // Parameterized constructor
    Student(
        int r,
        const string& n,
        const string& d,
        double m
    )
        : roll(r),
          name(n),
          department(d),
          marks(m)
    {
    }


    // Getters

    int getRoll() const {
        return roll;
    }

    const string& getName() const {
        return name;
    }

    const string& getDepartment() const {
        return department;
    }

    double getMarks() const {
        return marks;
    }


    // Setters

    void setName(
        const string& value
    ) {
        name = value;
    }


    void setDepartment(
        const string& value
    ) {
        department = value;
    }


    void setMarks(
        double value
    ) {
        marks = value;
    }


    // Display student

    void display() const {

        cout
            << left
            << setw(8)
            << roll

            << setw(22)
            << name

            << setw(18)
            << department

            << fixed
            << setprecision(2)

            << marks

            << '\n';
    }
};


// =====================================================
// STUDENT MANAGER
// =====================================================

class StudentManager {

private:

    vector<Student> students;

    const string fileName =
        "students.txt";


    // Check duplicate roll

    bool rollExists(
        int roll
    ) const {

        return any_of(
            students.begin(),
            students.end(),

            [roll](
                const Student& student
            ) {
                return
                    student.getRoll()
                    == roll;
            }
        );
    }


    // Find student

    Student* findStudent(
        int roll
    ) {

        auto it = find_if(
            students.begin(),
            students.end(),

            [roll](
                const Student& student
            ) {
                return
                    student.getRoll()
                    == roll;
            }
        );


        if (it == students.end()) {
            return nullptr;
        }

        return &(*it);
    }


    // Clear invalid input

    void clearInput() {

        cin.clear();

        cin.ignore(
            numeric_limits<streamsize>::max(),
            '\n'
        );
    }


public:

    // =================================================
    // LOAD
    // =================================================

    void load() {

        ifstream in(fileName);

        if (!in) {
            return;
        }


        string line;


        while (getline(in, line)) {

            // Simple parser:
            // roll|name|department|marks

            size_t p1 =
                line.find('|');

            size_t p2 =
                line.find('|', p1 + 1);

            size_t p3 =
                line.find('|', p2 + 1);


            if (
                p1 == string::npos ||
                p2 == string::npos ||
                p3 == string::npos
            ) {
                continue;
            }


            try {

                int roll =
                    stoi(
                        line.substr(
                            0,
                            p1
                        )
                    );


                string name =
                    line.substr(
                        p1 + 1,
                        p2 - p1 - 1
                    );


                string department =
                    line.substr(
                        p2 + 1,
                        p3 - p2 - 1
                    );


                double marks =
                    stod(
                        line.substr(
                            p3 + 1
                        )
                    );


                if (
                    roll > 0 &&
                    marks >= 0 &&
                    marks <= 100
                ) {

                    if (!rollExists(roll)) {

                        students.emplace_back(
                            roll,
                            name,
                            department,
                            marks
                        );
                    }
                }

            }
            catch (...) {

                // Skip malformed records
                continue;
            }
        }
    }


    // =================================================
    // SAVE
    // =================================================

    void save() const {

        ofstream out(fileName);

        if (!out) {

            cerr
                << "Error: unable to save file.\n";

            return;
        }


        for (
            const auto& student :
            students
        ) {

            out
                << student.getRoll()
                << '|'

                << student.getName()
                << '|'

                << student.getDepartment()
                << '|'

                << student.getMarks()

                << '\n';
        }
    }


    // =================================================
    // ADD
    // =================================================

    void addStudent() {

        int roll;
        double marks;

        string name;
        string department;


        cout
            << "\nEnter Roll Number: ";


        while (
            !(cin >> roll) ||
            roll <= 0
        ) {

            cout
                << "Enter a positive integer: ";

            clearInput();
        }


        if (rollExists(roll)) {

            cout
                << "Roll number already exists.\n";

            return;
        }


        cin.ignore(
            numeric_limits<streamsize>::max(),
            '\n'
        );


        cout
            << "Enter Name: ";

        getline(
            cin,
            name
        );


        cout
            << "Enter Department: ";

        getline(
            cin,
            department
        );


        cout
            << "Enter Marks (0-100): ";


        while (
            !(cin >> marks) ||
            marks < 0 ||
            marks > 100
        ) {

            cout
                << "Enter marks between 0 and 100: ";

            clearInput();
        }


        students.emplace_back(
            roll,
            name,
            department,
            marks
        );


        save();


        cout
            << "Student added successfully!\n";
    }


    // =================================================
    // VIEW
    // =================================================

    void viewStudents() const {

        if (students.empty()) {

            cout
                << "\nNo students found.\n";

            return;
        }


        cout
            << "\n"
            << left

            << setw(8)
            << "Roll"

            << setw(22)
            << "Name"

            << setw(18)
            << "Department"

            << "Marks\n";


        cout
            << string(
                60,
                '-'
            )
            << '\n';


        for (
            const auto& student :
            students
        ) {

            student.display();
        }
    }


    // =================================================
    // SEARCH
    // =================================================

    void searchStudent() const {

        int roll;


        cout
            << "\nEnter Roll Number: ";


        if (!(cin >> roll)) {

            clearInput();

            cout
                << "Invalid input.\n";

            return;
        }


        auto it = find_if(
            students.begin(),
            students.end(),

            [roll](
                const Student& student
            ) {

                return
                    student.getRoll()
                    == roll;
            }
        );


        if (it == students.end()) {

            cout
                << "Student not found.\n";
        }
        else {

            cout
                << "\nStudent Found:\n";

            it->display();
        }
    }


    // =================================================
    // UPDATE
    // =================================================

    void updateStudent() {

        int roll;

        cout
            << "\nEnter Roll Number: ";


        if (!(cin >> roll)) {

            clearInput();

            cout
                << "Invalid input.\n";

            return;
        }


        Student* student =
            findStudent(roll);


        if (!student) {

            cout
                << "Student not found.\n";

            return;
        }


        string name;
        string department;

        double marks;


        cin.ignore(
            numeric_limits<streamsize>::max(),
            '\n'
        );


        cout
            << "New Name: ";

        getline(
            cin,
            name
        );


        cout
            << "New Department: ";

        getline(
            cin,
            department
        );


        cout
            << "New Marks: ";


        while (
            !(cin >> marks) ||
            marks < 0 ||
            marks > 100
        ) {

            cout
                << "Enter marks between 0 and 100: ";

            clearInput();
        }


        student->setName(
            name
        );


        student->setDepartment(
            department
        );


        student->setMarks(
            marks
        );


        save();


        cout
            << "Student updated successfully!\n";
    }


    // =================================================
    // DELETE
    // =================================================

    void deleteStudent() {

        int roll;


        cout
            << "\nEnter Roll Number: ";


        if (!(cin >> roll)) {

            clearInput();

            cout
                << "Invalid input.\n";

            return;
        }


        size_t oldSize =
            students.size();


        students.erase(

            remove_if(

                students.begin(),
                students.end(),

                [roll](
                    const Student& student
                ) {

                    return
                        student.getRoll()
                        == roll;
                }
            ),

            students.end()
        );


        if (
            students.size()
            == oldSize
        ) {

            cout
                << "Student not found.\n";
        }
        else {

            save();

            cout
                << "Student deleted successfully!\n";
        }
    }


    // =================================================
    // SORT
    // =================================================

    void sortByMarks() {

        sort(

            students.begin(),
            students.end(),

            [](
                const Student& a,
                const Student& b
            ) {

                return
                    a.getMarks()
                    > b.getMarks();
            }
        );


        cout
            << "Students sorted by marks.\n";
    }


    // =================================================
    // STATISTICS
    // =================================================

    void statistics() const {

        if (students.empty()) {

            cout
                << "No data available.\n";

            return;
        }


        double total = 0;


        for (
            const auto& student :
            students
        ) {

            total +=
                student.getMarks();
        }


        auto highest =
            max_element(

                students.begin(),
                students.end(),

                [](
                    const Student& a,
                    const Student& b
                ) {

                    return
                        a.getMarks()
                        < b.getMarks();
                }
            );


        auto lowest =
            min_element(

                students.begin(),
                students.end(),

                [](
                    const Student& a,
                    const Student& b
                ) {

                    return
                        a.getMarks()
                        < b.getMarks();
                }
            );


        cout
            << "\nAverage Marks: "
            << fixed
            << setprecision(2)
            << total / students.size()
            << '\n';


        cout
            << "Highest: "
            << highest->getName()
            << " ("
            << highest->getMarks()
            << ")\n";


        cout
            << "Lowest: "
            << lowest->getName()
            << " ("
            << lowest->getMarks()
            << ")\n";
    }


    // =================================================
    // MENU
    // =================================================

    void showMenu() const {

        cout
            << "\n"
            << "========================================\n"
            << "       STUDENT MANAGEMENT SYSTEM\n"
            << "========================================\n"
            << "1. Add Student\n"
            << "2. View Students\n"
            << "3. Search Student\n"
            << "4. Update Student\n"
            << "5. Delete Student\n"
            << "6. Sort by Marks\n"
            << "7. Statistics\n"
            << "0. Exit\n"
            << "========================================\n";
    }
};


// =====================================================
// MAIN
// =====================================================

int main() {

    StudentManager manager;


    // Load previous data

    manager.load();


    while (true) {

        manager.showMenu();


        int choice;


        cout
            << "Enter Choice: ";


        if (!(cin >> choice)) {

            cin.clear();

            cin.ignore(
                numeric_limits<streamsize>::max(),
                '\n'
            );

            cout
                << "Invalid choice.\n";

            continue;
        }


        switch (choice) {

            case 1:

                manager.addStudent();

                break;


            case 2:

                manager.viewStudents();

                break;


            case 3:

                manager.searchStudent();

                break;


            case 4:

                manager.updateStudent();

                break;


            case 5:

                manager.deleteStudent();

                break;


            case 6:

                manager.sortByMarks();

                break;


            case 7:

                manager.statistics();

                break;


            case 0:

                manager.save();

                cout
                    << "Thank you for using the system!\n";

                return 0;


            default:

                cout
                    << "Please choose a valid option.\n";
        }
    }
}

14. Time Complexity

Interviewers may ask you about this.

Operation Complexity Why?
Add O(1) amortized vector insertion at end
Search O(n) Linear search
Delete O(n) Search + shifting elements
Update O(n) Search first
Sort O(n log n) std::sort
View O(n) Every record is displayed
Interview insight: If the application grows to millions of records, linear search through a vector may not be ideal. A database with indexing or a suitable hash-based structure could provide much faster lookup.

16. Common Project Mistakes

Avoid these mistakes while building your project.

❌ Everything inside main()

Huge main functions become difficult to understand and maintain.

❌ No input validation

Users can enter invalid marks, negative rolls or non-numeric values.

❌ while(!file.eof())

Prefer reading based on the success of the actual extraction operation.

❌ No duplicate check

Two students should not accidentally receive the same unique roll number.

❌ No testing

A program that compiles can still contain many logical errors.

❌ Copying without understanding

You should be able to explain every important part of your project.

20. Project Interview Questions

Learn to explain the project, not merely run it.

Why did you use vector? +
Vector provides dynamically sized contiguous storage and works naturally with STL algorithms. It is a strong default when we frequently iterate through records and need random access.
Why are getters marked const? +
The getter does not modify the Student object. const communicates this guarantee and allows the function to be called on const Student objects.
Why use find_if? +
find_if expresses the search operation using a predicate. It avoids writing the complete search loop manually and works naturally with STL.
What is CRUD? +
CRUD means Create, Read, Update and Delete. These are the fundamental operations performed by many data-management applications.
What happens if the file does not exist? +
The input file stream fails to open. The program can treat that as an empty initial dataset and create the file when the first save operation occurs.
How would you scale this application? +
I would separate the UI, business logic and persistence layers, replace flat-file storage with a database, add indexing, validation, automated tests and eventually expose the functionality through an API.
What is the time complexity of searching? +
Searching the vector using find_if is O(n) because, in the worst case, every student may need to be checked.
