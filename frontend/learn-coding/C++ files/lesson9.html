01 · Foundation

What is a String?

A string is a sequence of characters used to represent text.

A string is a collection or sequence of characters. For example:

H index 0
e index 1
l index 2
l index 3
o index 4
Important idea

String indexing starts from 0. Therefore, for "Hello", H is at index 0 and o is at index 4.

02 · String Types

Strings in C++

C++ provides multiple ways to represent character sequences.

C-Style Character Array

C-style string 
char name[] = "Pradeep";

Traditional C-style strings are character arrays terminated by a null character '\0'.

Modern C++ String

std::string 
std::string name = "Pradeep";

std::string is the preferred choice for most modern C++ programs.

Recommended for beginners

Learn std::string first. It provides convenient operations such as length, searching, insertion, deletion and substring extraction.

03 · std::string

The Modern C++ String

std::string belongs to the C++ Standard Library. Include the <string> header.

Basic declaration 
#include <iostream>
#include <string>

int main() {

    std::string name = "ZENSUS";

    std::cout << name << '\\n';

    return 0;
}
Why std::string?

It manages its own storage and provides useful member functions, making string manipulation much easier than manually managing character arrays.

04 · Input

Taking String Input

This is one of the most important topics for beginners.

Using cin

Single word 
std::string name;

std::cin >> name;

cin >> reads until whitespace.

Example

Input: Venkata Pradeep
cin reads only Venkata.

Using getline()

Complete line 
std::string name;

std::getline(std::cin, name);

getline() reads the entire line, including spaces.

cin vs getline()

Feature cin >> getline()
Reads spaces ❌ No ✅ Yes
Reads one word ✅ Yes ✅ Yes
Reads entire line ❌ No ✅ Yes
Common use Single words Names, sentences, addresses
Important: Mixing cin and getline()

After cin >>, the newline may remain in the input buffer. A convenient solution is: 

int age;
std::string name;

std::cin >> age;

std::getline(std::cin >> std::ws, name);

06 · Character Access

Accessing Characters

Every character in a string has an index.

C 0
O 1
D 2
E 3
Access by index 
std::string s = "CODE";

std::cout << s[0];
std::cout << s[2];
Output

C followed by D

at() vs []

s[2];

s.at(2);

at() performs bounds checking and can throw an exception for an invalid position. [] does not perform bounds checking in the same way.

09 · Comparison

Comparing Strings

Strings can be compared using normal relational operators. 

std::string a = "apple";
std::string b = "banana";

if (a == b) {
    std::cout << "Equal";
} else {
    std::cout << "Not Equal";
}
Operators

You can use ==, !=, <, >, <=, >= with std::string.

compare()

int result = a.compare(b);

compare() returns 0 when the strings are equal, a negative value when the left string compares before the right string, and a positive value when it compares after it.

10 · Searching

Searching Inside a String

find()

std::string s = "I love C++ programming";

size_t pos = s.find("C++");

if (pos != std::string::npos) {
    std::cout << "Found at index: " << pos;
}
What is std::string::npos?

npos represents a special value meaning that the requested search was not successful.

Find a character

std::string s = "programming";

size_t pos = s.find('g');

Find from a specific position

size_t pos = s.find('g', 5);

13 · Problem Solving

Important String Patterns

These patterns appear repeatedly in coding interviews.

Count Characters

std::string s = "banana";

int count = 0;

for (char ch : s) {

    if (ch == 'a') {
        count++;
    }
}

std::cout << count;

Reverse a String

std::string s = "HELLO";

int left = 0;
int right = s.length() - 1;

while (left < right) {

    std::swap(s[left], s[right]);

    left++;
    right--;
}

Palindrome

std::string s = "madam";

int left = 0;
int right = s.length() - 1;

bool palindrome = true;

while (left < right) {

    if (s[left] != s[right]) {
        palindrome = false;
        break;
    }

    left++;
    right--;
}

Count Vowels

int count = 0;

for (char ch : s) {

    if (
        ch == 'a' ||
        ch == 'e' ||
        ch == 'i' ||
        ch == 'o' ||
        ch == 'u'
    ) {
        count++;
    }
}

16 · Avoid Errors

Common String Mistakes

Wrong: cin >> fullName;

If the input is "Venkata Pradeep", only the first word is read. Use getline() for a complete line.
For "HELLO", H is index 0, E is index 1 and O is index 4.
If a string has length 5, valid indexes are 0 through 4. Accessing an invalid position is an error in your program's logic and can lead to undefined behavior when using operator[].
Character: 'A'
String: "A"
If you are not using using namespace std;, write std::string and include <string>.

21 · Mini Project

String Analyzer

Combine loops, conditions and strings into one useful program.

C++ Mini Project 
#include <iostream>
#include <string>
#include <cctype>

int main() {

    std::string s;

    std::cout << "Enter a sentence: ";

    std::getline(std::cin, s);

    int vowels = 0;
    int digits = 0;
    int spaces = 0;

    for (char ch : s) {

        if (std::isalpha(
                static_cast<unsigned char>(ch))) {

            char lower =
                static_cast<char>(std::tolower(
                    static_cast<unsigned char>(ch)));

            if (
                lower == 'a' ||
                lower == 'e' ||
                lower == 'i' ||
                lower == 'o' ||
                lower == 'u'
            ) {
                vowels++;
            }
        }

        if (std::isdigit(
                static_cast<unsigned char>(ch))) {
            digits++;
        }

        if (ch == ' ') {
            spaces++;
        }
    }

    std::cout << "Length: " << s.length() << '\\n';
    std::cout << "Vowels: " << vowels << '\\n';
    std::cout << "Digits: " << digits << '\\n';
    std::cout << "Spaces: " << spaces << '\\n';

    return 0;
}
