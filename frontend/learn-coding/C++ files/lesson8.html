01 — Foundation

What is an Array?

An array stores multiple objects of the same type in a contiguous sequence of elements.

Suppose you want to store the marks of 5 students. Without an array, you might create five variables:

Without Array 
int mark1 = 85;
int mark2 = 91;
int mark3 = 76;
int mark4 = 88;
int mark5 = 95;

An array lets us store them under one variable:

With Array 
int marks[5] = {85, 91, 76, 88, 95};
Key idea

One array name can represent multiple elements, and each element is accessed using an index.

02 — Memory

Array Memory & Indexing

Understanding indexing is essential for avoiding bugs.

int marks[5] = {85, 91, 76, 88, 95}
85 index 0
91 index 1
76 index 2
88 index 3
95 index 4
Important: C++ uses zero-based indexing

The first element is at index 0, not index 1. For an array of size 5, valid indexes are 0, 1, 2, 3 and 4.

04 — Initialization

Initializing Arrays

Complete Initialization 

int a[5] = {10, 20, 30, 40, 50};

Size Deduction 

int a[] = {10, 20, 30, 40};

The compiler determines the size from the initializer.

Partial Initialization 

int a[5] = {10, 20};

Remaining elements are value-initialized to zero.

All Zero 

int a[5] = {};

All elements become zero.

Avoid uninitialized local arrays

A local built-in array such as int a[5]; does not automatically initialize its elements to zero. Initialize it when you need known values.

05 — Access

Accessing & Updating Elements 

int marks[5] = {85, 91, 76, 88, 95};

std::cout << marks[0];

marks[2] = 80;
What happens?

marks[0] accesses 85.
marks[2] originally contains 76. After the assignment, it becomes 80.

06 — Traversal

Traversing an Array

Traversal means visiting each element of an array. 

int numbers[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++)
{
    std::cout << numbers[i] << " ";
}
10 0
20 1
30 2
40 3
50 4
Important

Finding Array Size 

int numbers[] = {10, 20, 30, 40, 50};

int size =
    sizeof(numbers) /
    sizeof(numbers[0]);

For a built-in array in the same scope where it is actually an array, this computes the number of elements.

Interview point

When a built-in array is passed to a function as a parameter, it does not retain its array size there. Usually pass the size separately or use a modern container such as std::array or std::vector.

Problem Solving

Find Minimum & Maximum 

int arr[] = {42, 17, 89, 23, 55};

int minimum = arr[0];
int maximum = arr[0];

for (int i = 1; i < 5; i++)
{
    if (arr[i] < minimum)
        minimum = arr[i];

    if (arr[i] > maximum)
        maximum = arr[i];
}

std::cout << minimum << " " << maximum;
Why start from index 1?

We already used arr[0] as the initial minimum and maximum.

Calculation

Average of Elements 

int arr[] = {10, 20, 30, 40};

int sum = 0;

for (int i = 0; i < 4; i++)
{
    sum += arr[i];
}

double average =
    static_cast<double>(sum) / 4;

std::cout << average;
Avoid integer division

If both operands are integers, division produces an integer result. Convert at least one operand to a floating-point type when you need a decimal result.

09 — Searching

Linear Search

Check elements one by one until the target is found. 

int arr[] = {10, 25, 30, 45, 50};

int target = 30;

int index = -1;

for (int i = 0; i < 5; i++)
{
    if (arr[i] == target)
    {
        index = i;
        break;
    }
}

std::cout << index;

Time Complexity: O(n)

In the worst case, every element may need to be checked.

Pattern

Count Even Numbers 

int arr[] = {10, 13, 24, 31, 42};

int count = 0;

for (int i = 0; i < 5; i++)
{
    if (arr[i] % 2 == 0)
    {
        count++;
    }
}

std::cout << count;
DSA Foundation

Reverse an Array 

int arr[] = {1, 2, 3, 4, 5};

int left = 0;
int right = 4;

while (left < right)
{
    int temp = arr[left];

    arr[left] = arr[right];

    arr[right] = temp;

    left++;
    right--;
}
Key DSA pattern: Two Pointers

One pointer starts from the left and another from the right. They move toward each other.

Problem Solving

Count Frequency of a Value 

int arr[] = {2, 5, 2, 7, 2, 9};

int target = 2;

int frequency = 0;

for (int i = 0; i < 6; i++)
{
    if (arr[i] == target)
    {
        frequency++;
    }
}

std::cout << frequency;
Output: 3

The value 2 occurs three times.

2D Problem

Matrix Addition 

int A[2][2] = {
    {1, 2},
    {3, 4}
};

int B[2][2] = {
    {5, 6},
    {7, 8}
};

int C[2][2];

for (int i = 0; i < 2; i++)
{
    for (int j = 0; j < 2; j++)
    {
        C[i][j] = A[i][j] + B[i][j];
    }
}
Pattern to remember

Outer loop → rows. Inner loop → columns.

11 — Functions

Passing Arrays to Functions

Built-in arrays can be passed to functions, but the function does not automatically receive the array's element count. Pass the size separately when needed. 

void printArray(
    const int arr[],
    int size
)
{
    for (int i = 0; i < size; i++)
    {
        std::cout << arr[i] << " ";
    }
}

int numbers[] = {10, 20, 30};

printArray(
    numbers,
    3
);
Why const?

The function only reads the elements, so const communicates that it should not modify them through that parameter.

Important Comparison

C-style Array vs Modern Containers

Feature Built-in Array std::array std::vector
Size Fixed Fixed Dynamic
Size known at runtime? Not as a standard built-in feature Fixed at compile time Yes
Bounds checking No automatic checking at() provides checking at() provides checking
Typical use Low-level / legacy / simple fixed arrays Modern fixed-size collections Resizable collections
Modern C++ note

For new C++ code, prefer std::array when the size is fixed and std::vector when the collection needs to grow or shrink dynamically.

Avoid These

Common Array Mistakes

❌ Off-by-one error 

int arr[5];

for (int i = 0; i <= 5; i++)
{
    arr[i] = i;
}

arr[5] is outside the valid indexes. Use i < 5.

❌ Starting index at 1

C++ arrays start at index 0.

❌ Accessing beyond bounds

Reading or writing outside an array's bounds can cause undefined behavior.

❌ Forgetting array size

When passing a built-in array to a function, don't assume the function can automatically determine the element count.

14 — Interview Ready

Top Array Interview Questions

Q1. What is an array?

An array is a fixed-size collection of elements of the same type stored in a contiguous sequence.

Q2. Why does indexing start at 0?

The index represents an offset from the first element, so the first element has offset 0.

Q3. What is the time complexity of arr[i]?

O(1), assuming valid indexing.

Q4. What happens outside array bounds?

For a built-in array, accessing outside its bounds results in undefined behavior.

Q5. Can an array store different data types?

A built-in array has one element type. For example, int arr[5] stores integers.

Q6. What is a 2D array?

A two-dimensional array is an array whose elements are themselves arrays, commonly represented using rows and columns.

Q7. Array vs vector?

A built-in array has fixed size. std::vector is a dynamic sequence container that can grow and shrink.

Q8. How do you reverse an array?

A common in-place technique uses two pointers, one at each end, and swaps elements while moving inward.

Exam Preparation

Important Theory Questions

An array is a fixed-size collection of elements of the same type. Its elements are accessed using indexes, and built-in array elements occupy a contiguous sequence.
A one-dimensional array stores elements in a single sequence. Example: int a[5] = {10,20,30,40,50};
A two-dimensional array organizes elements using rows and columns, such as int matrix[3][3];
Array traversal is the process of visiting each element, commonly using a loop from index 0 to size - 1.
Linear search checks array elements sequentially until the target is found or all elements have been examined. Its worst-case time complexity is O(n).

Student Marks Analyzer

Build a program that accepts marks and calculates total, average, highest and lowest marks. 

int marks[5];

int total = 0;

for (int i = 0; i < 5; i++)
{
    std::cin >> marks[i];

    total += marks[i];
}

int highest = marks[0];
int lowest = marks[0];

for (int i = 1; i < 5; i++)
{
    if (marks[i] > highest)
        highest = marks[i];

    if (marks[i] < lowest)
        lowest = marks[i];
}

double average =
    static_cast<double>(total) / 5;

std::cout << "Total: " << total << '\n';
std::cout << "Average: " << average << '\n';
std::cout << "Highest: " << highest << '\n';
std::cout << "Lowest: " << lowest << '\n';
