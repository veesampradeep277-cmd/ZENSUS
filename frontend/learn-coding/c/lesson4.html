Complete Example

arithmetic.c 
#include <stdio.h>

int main() {

    int a = 20;
    int b = 6;

    printf("Addition       = %d\n", a + b);
    printf("Subtraction    = %d\n", a - b);
    printf("Multiplication = %d\n", a * b);
    printf("Division       = %d\n", a / b);
    printf("Remainder      = %d\n", a % b);

    return 0;
}
Important: Integer Division When both operands are integers, division produces an integer result. 7 / 2 produces: 3 not 3.5. To obtain a floating-point result: 7.0 / 2 or (float)7 / 2

Modulus Operator %

The modulus operator returns the remainder after integer division. It is extremely important in programming. 

10 % 3 = 1

17 % 5 = 2

20 % 4 = 0
Common applications Even / odd checking → n % 2 Last digit → n % 10 Divisibility → n % divisor == 0 Circular indexing → index % size

5 Relational Operators

Relational operators compare two values and produce either true or false. In C, a false result is 0 and a true result is represented by a nonzero value, typically 1.

Operator Meaning Example
> Greater than 10 > 5
< Less than 10 < 5
>= Greater than or equal 10 >= 10
<= Less than or equal 5 <= 10
== Equal to 10 == 10
!= Not equal 10 != 5 
#include <stdio.h>

int main() {

    int age = 19;

    printf("%d\n", age >= 18);
    printf("%d\n", age < 18);

    return 0;
}
🔥 Very common mistake = means assignment. == means comparison. Wrong: if (age = 18) Correct: if (age == 18)

Memory shortcut Think: x += 5 as: Take old x → add 5 → store back in x.

8 Increment & Decrement Operators

The increment and decrement operators change a variable by one.

++x — Pre-increment

First increase x, then use the new value. 

int x = 5;

int y = ++x;

printf("%d", y);

Result: y = 6

x++ — Post-increment

First use the old value, then increase x. 

int x = 5;

int y = x++;

printf("%d", y);

Result: y = 5

11 Conditional / Ternary Operator

The ternary operator is a compact way to choose between two expressions based on a condition.

Condition
?
TRUE
Expression 1
:
FALSE
Expression 2

Syntax 

condition ? expression1 : expression2;

Example 

#include <stdio.h>

int main() {

    int age = 19;

    const char *result =
        (age >= 18) ? "Eligible" : "Not Eligible";

    printf("%s", result);

    return 0;
}
Think of it as: condition ? if_true : if_false

12 sizeof Operator

The sizeof operator determines the size, in bytes, of a type or object. 

#include <stdio.h>

int main() {

    int x;

    printf("%zu\n", sizeof(x));
    printf("%zu\n", sizeof(int));
    printf("%zu\n", sizeof(double));
    printf("%zu\n", sizeof(char));

    return 0;
}
Important The exact sizes of many C types depend on the implementation. Therefore, use sizeof() when you need the actual size on the system where the program is compiled.

14 Short-Circuit Evaluation

C's logical operators can stop evaluating an expression once the final result is already known.

Logical AND 

if (age >= 18 && feePaid == 1)
{
    printf("Eligible");
}

If the first condition is false, the second condition does not need to be evaluated because AND cannot become true.

Logical OR 

if (isAdmin || isOwner)
{
    printf("Access granted");
}

If the first condition is already true, the second condition does not need to be evaluated because OR is already true.

Interview concept This behavior is called short-circuit evaluation. It can improve efficiency and can also be important for safe condition ordering.

15 Comma Operator

The comma operator evaluates expressions from left to right and produces the value of the final expression. 

int x;

x = (2, 3, 4);

printf("%d", x);

The value assigned to x is 4.

Important Do not confuse the comma operator with commas used simply to separate function arguments or variable declarations.

#include <stdio.h>

int main() {

    int quantity = 3;

    float price = 250.0f;
    float taxRate = 0.18f;

    float subtotal = quantity * price;

    float tax = subtotal * taxRate;

18 Common Operator Mistakes

❌ = instead of == 

if (x = 10)

Assignment is not comparison.

❌ Integer division 

float x = 5 / 2;

The division occurs as integer division first.

❌ Confusing % with percentage

In C, % is the remainder operator, not a percentage operator.

❌ Misunderstanding ++ 

int y = x++;

The value assigned to y is the old value of x.

❌ Ignoring precedence 

a + b * c

Multiplication is evaluated before addition. Use parentheses when clarity is needed.

❌ Confusing & and &&

& is bitwise AND. && is logical AND.

❌ Confusing | and ||

| is bitwise OR. || is logical OR.

❌ Overcomplicated expressions

Huge expressions are difficult to debug. Break complex calculations into meaningful variables.
