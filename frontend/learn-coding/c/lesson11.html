02 • The Problem

Why do we need structures?

A normal variable stores one value. Arrays store multiple values of the same data type. But real-world entities usually contain different kinds of information.

Real-world example: A student has a roll number, name, age, CGPA and branch. These values have different data types but describe the same student. 
int rollNo;
char name[50];
int age;
float cgpa;
char branch[20];

Without structures, managing thousands of students becomes difficult because the related data is separated.

06 • Creating Objects

Declare and initialize structures

Step 1 — Define the structure

struct Student {
    int rollNo;
    char name[50];
    float cgpa;
};

Step 2 — Create a structure variable

struct Student s1;

Step 3 — Initialize

struct Student s1 = {101, "Pradeep", 8.63};
Think like this: struct Student describes the blueprint. s1 is an actual object created from that blueprint.

Designated initialization

struct Student s1 = {
    .rollNo = 101,
    .name = "Pradeep",
    .cgpa = 8.63
};

Designated initializers improve readability because each value is explicitly associated with its member.

07 • Member Access

The dot operator .

When you have a normal structure object, use the dot operator to access its members. 

#include <stdio.h>

struct Student {
    int rollNo;
    char name[50];
    float cgpa;
};

int main(void) {

    struct Student s1 = {101, "Pradeep", 8.63};

    printf("Roll No: %d\n", s1.rollNo);
    printf("Name: %s\n", s1.name);
    printf("CGPA: %.2f\n", s1.cgpa);

    return 0;
}

08 • Memory Model

How is a structure stored in memory?

A structure object occupies enough storage for all of its members, including possible padding inserted by the implementation.

Conceptual memory layout

1000 101 int
1004... "Pradeep" char[]
1054... 8.63 float

Important

Structure members appear in declaration order, although padding may occur between members or at the end.

Never assume that: sizeof(struct) equals the simple mathematical sum of member sizes.

Use sizeof() when you need the actual size on the current implementation.

09 • Collections

Array of structures

When you need multiple objects of the same structure type, use an array of structures. 

struct Student {
    int rollNo;
    char name[50];
    float cgpa;
};

struct Student students[3];

Initialization

struct Student students[3] = {
    {101, "Pradeep", 8.63},
    {102, "Rahul",   8.21},
    {103, "Anil",    9.02}
};

Access

printf("%s\n", students[0].name);
printf("%.2f\n", students[1].cgpa);

Traversal

for (int i = 0; i < 3; i++) {

    printf("Roll: %d\n", students[i].rollNo);
    printf("Name: %s\n", students[i].name);
    printf("CGPA: %.2f\n\n", students[i].cgpa);
}
Real-world applications: student databases, employee records, products, bank accounts, books, hospital records and inventory systems.

11 • Functions

Structures and functions

Structures can be passed to functions and returned from functions.

Passing a structure by value

#include <stdio.h>

struct Student {
    int rollNo;
    float cgpa;
};

void display(struct Student s) {

    printf("Roll: %d\n", s.rollNo);
    printf("CGPA: %.2f\n", s.cgpa);
}

int main(void) {

    struct Student s = {101, 8.63};

    display(s);

    return 0;
}
Passing by value creates a separate parameter object. Changes made to the parameter do not modify the original object.

Passing a pointer to a structure

void updateCGPA(struct Student *s) {

    s->cgpa = 9.00;
}

This allows the function to modify the original structure object.

14 • Cleaner Syntax

typedef struct

Normally, you must write struct Student every time. typedef allows you to create a shorter alias. 

typedef struct {
    int rollNo;
    char name[50];
    float cgpa;
} Student;

Now:

Student s1;
Student s2;

Student students[100];
Common professional style: typedef struct { ... } Student; is widely used when the structure tag itself is not needed.

typedef with a structure tag

typedef struct Student {
    int rollNo;
    float cgpa;
} Student;
15 • Structure Operations

Copying and assigning structures

Structure objects of the same compatible structure type can be assigned directly. 

struct Student s1 = {101, 8.63};
struct Student s2;

s2 = s1;

After the assignment, the values of the members are copied.

Comparison warning

C does not provide a built-in s1 == s2 comparison for structures.

If you need logical comparison, compare the relevant members yourself. 

if (s1.rollNo == s2.rollNo &&
    s1.cgpa == s2.cgpa) {

    printf("Same student data");
}
16 • Advanced

Self-referential structures

A structure cannot directly contain an object of its own type, because that would require infinite size.

This is invalid: 
struct Node {
    int data;
    struct Node next;   /* invalid */
};

But it can contain a pointer to its own type. 

struct Node {
    int data;
    struct Node *next;
};

17 • Data Structures Foundation

Structures form the foundation of linked lists

struct Node {
    int data;
    struct Node *next;
};

Concept

data

Stores the actual information.

next

Stores the address of the next node.

NULL

Indicates that there is no next node.

Basic traversal

struct Node *current = head;

while (current != NULL) {

    printf("%d ", current->data);

    current = current->next;
}

18 • Memory & Performance

Structure padding and alignment

C implementations may insert unused bytes between members or at the end of a structure. These bytes are called padding. 

struct Example {
    char c;
    int x;
};

On many common systems, the int may need stricter alignment than char, so padding can appear between them.

Never assume the exact byte layout or size of a structure without checking the target implementation.

Check size

printf("%zu\n", sizeof(struct Example));

19 • Advanced C

Bit-fields

Bit-fields allow certain structure members to occupy a specified number of bits. They can be useful when representing compact collections of flags or fields. 

struct Flags {

    unsigned int isActive : 1;
    unsigned int isAdmin  : 1;
    unsigned int level    : 3;
};

Here, the numbers after : specify the requested bit-field widths.

Bit-field layout, allocation order and some implementation details are implementation-dependent. Do not use them when portable binary layout is required unless you understand the target ABI.
20 • Heap Memory

Dynamic structures

A structure object can also be created dynamically using malloc(). 

#include <stdio.h>
#include <stdlib.h>

struct Student {
    int rollNo;
    float cgpa;
};

int main(void) {

    struct Student *p =
        malloc(sizeof *p);

    if (p == NULL) {
        return 1;
    }

    p->rollNo = 101;
    p->cgpa = 8.63f;

    printf("%d %.2f\n",
           p->rollNo,
           p->cgpa);

    free(p);
    p = NULL;

    return 0;
}
Notice: malloc(sizeof *p) automatically uses the size of the object pointed to by p. In C, you generally do not need to cast the result of malloc().

Dynamic memory allocation will be covered in depth in Lesson 14 — Dynamic Memory Allocation.

21 • Comparison

Structure vs Union

Feature Structure Union
Storage Members have separate storage Members share overlapping storage
Values Members can hold values simultaneously Only one member's stored value is generally meaningful at a time
Size At least enough for all members, plus possible padding Enough for its largest member, plus possible padding
Keyword struct union 
struct Data {
    int i;
    float f;
};

union Data {
    int i;
    float f;
};

25 • Avoid These

Common mistakes students make

❌ Mistake 1 — Missing semicolon 
struct Student {
    int rollNo;
}   /* wrong */

struct Student {
    int rollNo;
};  /* correct */
❌ Mistake 2 — Using dot with a pointer 
struct Student *p = &s;

p.cgpa;       /* wrong */

p->cgpa;      /* correct */
❌ Mistake 3 — Forgetting parentheses 
*p.cgpa;       /* wrong */

(*p).cgpa;      /* correct */
❌ Mistake 4 — Thinking structures can be compared with == 
s1 == s2;      /* invalid for structures */
Compare the required members explicitly.
❌ Mistake 5 — Returning address of a local structure 
struct Student *create(void) {

    struct Student s;

    return &s;   /* WRONG */
}
The local object's lifetime ends when the function returns.
❌ Mistake 6 — Confusing structure and union Structures provide separate member storage; unions overlap their members' storage.
❌ Mistake 7 — Assuming sizeof(struct) is always the sum of member sizes Padding and alignment can change the size.

30 • Complete Example

Mini student record system

#include <stdio.h>

typedef struct {
    int rollNo;
    char name[50];
    float cgpa;
} Student;

void displayStudent(const Student *s) {

    printf("\n----- Student -----\n");
    printf("Roll No : %d\n", s->rollNo);
    printf("Name    : %s\n", s->name);
    printf("CGPA    : %.2f\n", s->cgpa);
}

int main(void) {

    Student students[3] = {

        {101, "Pradeep", 8.63f},
        {102, "Rahul",   8.21f},
        {103, "Anil",    9.02f}

    };

    for (int i = 0; i < 3; i++) {
        displayStudent(&students[i]);
    }

    return 0;
}
This one example combines: typedef + structure + array + pointer + const + function + arrow operator .
