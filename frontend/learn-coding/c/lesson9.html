What is a String?

The foundation of strings in C

String = Sequence of Characters

In C, there is no separate built-in string data type. A string is represented using an array of characters terminated by a special character called the null character.

Key idea: A C string is a character array ending with '\0'.
Basic string 
char name[] = "Pradeep";

Internally, the compiler stores the characters followed by \0.

Character vs String

Character

'A'

Single character → single quotes.

String

"A"

Character sequence → double quotes.

Example 
char ch = 'A';

char str[] = "A";

String Input & Output

How to safely read and display strings

Printing a String — printf()

printf() 
char name[] = "Pradeep";

printf("%s", name);

%s is the format specifier used to print a string.

Reading a Single Word — scanf()

scanf() 
char name[50];

scanf("%49s", name);
Important: %s stops reading when whitespace is encountered. So it cannot normally read a full sentence containing spaces.

Reading a Full Line — fgets()

Safer line input 
#include <stdio.h>

int main() {

    char name[100];

    printf("Enter your name: ");

    fgets(name, sizeof(name), stdin);

    printf("Hello %s", name);

    return 0;
}
Best practice: For line-oriented input, prefer fgets() with the actual buffer size.

puts()

puts() 
char message[] = "Welcome to ZENSUS";

puts(message);

puts() prints a string followed by a newline.

strlen()

Find the number of characters

strlen() returns the number of characters before \0. The null character itself is not counted.

strcpy() & strncpy()

Copying strings

strcpy()

Copy string 
char source[] = "ZENSUS";

Warning: The destination must have enough space for the copied string including the terminating \0.

strncpy()

Limited copy 
char source[] = "Programming";

/* Add terminator when needed */
destination[5] = '\0';
Important: strncpy() does not always guarantee a terminating \0 when the source length is at least the requested count. Understand the buffer size and termination rules.

strcmp() & strncmp()

Comparing strings correctly

Never compare strings using ==

Wrong idea 
if(name1 == name2) {
    printf("Same");
}

For ordinary C strings stored in arrays, == compares pointer/address values when used on array expressions after decay, not the character contents.

Correct Method — strcmp()

String comparison 
#include <stdio.h>
#include <string.h>

int main() {

    char a[] = "hello";
    char b[] = "hello";

    if(strcmp(a, b) == 0) {
        printf("Strings are equal");
    }

    return 0;
}
Result Meaning
0 Strings are equal
< 0 First string compares before second
> 0 First string compares after second
Interview tip: Do not depend on the exact positive/negative value. Check whether the result is zero, negative, or positive.

String Algorithms Without Library Functions

Essential for exams and interviews

1. Find String Length Manually

Interview classic 
#include <stdio.h>

int main() {

    char str[] = "ZENSUS";

    int length = 0;

    while(str[length] != '\0') {
        length++;
    }

    printf("Length = %d", length);

    return 0;
}
Time Complexity: O(n)

2. Reverse a String

Two-pointer technique 
#include <stdio.h>
#include <string.h>

int main() {

    char str[] = "HELLO";

    int left = 0;
    int right = (int)strlen(str) - 1;

    while(left < right) {

        char temp = str[left];

        str[left] = str[right];
        str[right] = temp;

        left++;
        right--;
    }

    printf("%s", str);

    return 0;
}

3. Check Palindrome

Palindrome 
#include <stdio.h>
#include <string.h>

int main() {

    char str[100];

    scanf("%99s", str);

    int left = 0;
    int right = (int)strlen(str) - 1;

    int palindrome = 1;

    while(left < right) {

        if(str[left] != str[right]) {
            palindrome = 0;
            break;
        }

        left++;
        right--;
    }

    if(palindrome)
        printf("Palindrome");
    else
        printf("Not Palindrome");

    return 0;
}

4. Count Vowels and Consonants

Character classification 
#include <stdio.h>
#include <ctype.h>

int main() {

    char str[] = "ZENSUS";

    int vowels = 0;
    int consonants = 0;

    for(int i = 0; str[i] != '\0'; i++) {

        char ch = (char)tolower((unsigned char)str[i]);

        if(ch >= 'a' && ch <= 'z') {

            if(ch == 'a' || ch == 'e' ||
               ch == 'i' || ch == 'o' || ch == 'u') {

                vowels++;

            } else {
                consonants++;
            }
        }
    }

    printf("Vowels = %d\n", vowels);
    printf("Consonants = %d\n", consonants);

    return 0;
}

5. Count Digits, Letters and Spaces

Classification problem 
#include <stdio.h>
#include <ctype.h>

int main() {

    char str[] = "Zensus 2026";

    int letters = 0;
    int digits = 0;
    int spaces = 0;

    for(int i = 0; str[i] != '\0'; i++) {

        unsigned char ch = (unsigned char)str[i];

        if(isalpha(ch))
            letters++;

        else if(isdigit(ch))
            digits++;

        else if(isspace(ch))
            spaces++;
    }

    printf("Letters = %d\n", letters);
    printf("Digits = %d\n", digits);
    printf("Spaces = %d\n", spaces);

    return 0;
}

Character Frequency

Count how many times each character occurs

Frequency array 
#include <stdio.h>

int main() {

    char str[] = "banana";

    int freq[256] = {0};

    for(int i = 0; str[i] != '\0'; i++) {
        freq[(unsigned char)str[i]]++;
    }

    for(int i = 0; i < 256; i++) {

        if(freq[i] > 0) {
            printf("%c = %d\n", i, freq[i]);
        }
    }

    return 0;
}
Idea: Map every character to an index in a frequency array.

Remove Duplicate Characters

Useful interview problem

Using frequency tracking 
#include <stdio.h>

int main() {

    char str[] = "programming";

    int seen[256] = {0};
    int write = 0;

    for(int i = 0; str[i] != '\0'; i++) {

        unsigned char ch = (unsigned char)str[i];

        if(!seen[ch]) {

            seen[ch] = 1;
            str[write++] = str[i];
        }
    }

    str[write] = '\0';

    printf("%s", str);

    return 0;
}

Anagram Checking

Compare character frequencies

Two strings are anagrams if they contain the same characters with the same frequencies, ignoring order.

Example: listen and silent are anagrams.
Anagram algorithm 
#include <stdio.h>
#include <string.h>

int main() {

    char a[] = "listen";
    char b[] = "silent";

    if(strlen(a) != strlen(b)) {
        printf("Not Anagram");
        return 0;
    }

    int freq[256] = {0};

    for(int i = 0; a[i] != '\0'; i++) {
        freq[(unsigned char)a[i]]++;
        freq[(unsigned char)b[i]]--;
    }

    for(int i = 0; i < 256; i++) {

        if(freq[i] != 0) {
            printf("Not Anagram");
            return 0;
        }
    }

    printf("Anagram");

    return 0;
}

Count Words in a Sentence

Whitespace-aware string processing

Word counting 
#include <stdio.h>
#include <ctype.h>

int main() {

    char str[] = "C programming is powerful";

    int words = 0;
    int insideWord = 0;

    for(int i = 0; str[i] != '\0'; i++) {

        if(!isspace((unsigned char)str[i]) && !insideWord) {

            words++;
            insideWord = 1;

        } else if(isspace((unsigned char)str[i])) {

            insideWord = 0;
        }
    }

    printf("Words = %d", words);

    return 0;
}

Pointers and Strings

Important connection between arrays and pointers

Character Pointer

Pointer to string literal 
const char *message = "Hello";

printf("%s", message);
Important: Do not attempt to modify a string literal through a pointer. Using const char * expresses that intent correctly.

Character Array vs Pointer

Character Array Pointer to String Literal
char s[] = "Hello"; const char *s = "Hello";
Creates an array containing the characters. Points to a string literal.
Elements can be modified. Do not modify the literal.
Storage is part of the array object. Pointer stores an address.

Tokenization with strtok()

Split a string into tokens

strtok() 
#include <stdio.h>
#include <string.h>

int main() {

    char str[] = "C,Python,Java";

    char *token = strtok(str, ",");

    while(token != NULL) {

        printf("%s\n", token);

        token = strtok(NULL, ",");
    }

    return 0;
}
Important: strtok() modifies the input string and maintains internal parsing state. It should be used with care when reentrancy or nested parsing matters.

Strings vs Memory Functions

Important distinction for interviews

String Functions

Functions such as strlen(), strcmp() and strcpy() operate according to C string conventions, which rely on the terminating null character where applicable.

Memory Functions

Function Purpose
memcpy() Copy a specified number of bytes; regions must not overlap.
memmove() Copy bytes safely when source and destination may overlap.
memcmp() Compare a specified number of bytes.
memset() Set a specified number of bytes to a byte value.
Interview distinction: String functions understand strings; memory functions work with raw bytes and explicit sizes.

Common Mistakes

Errors students frequently make

❌ Forgetting '\0'

char s[5] = {'H','E','L','L','O'};

This is not a properly null-terminated C string.

❌ Buffer Too Small

char s[5] = "HELLO";

Five visible characters require six array elements for a conventional C string because of \0.

❌ Comparing with ==

if(a == b)

Use strcmp() for content comparison.

❌ Unsafe scanf("%s")

char name[10];
scanf("%s", name);

Input can exceed the array. A field width or preferably line-oriented input should be used.

❌ Using gets()

gets() was removed from the C standard because it cannot limit the input size safely.

❌ Modifying String Literal

char *p = "Hello";
p[0] = 'J';

Do not modify string literals. Use a writable character array when modification is required.

Advanced String Concepts

Concepts that separate beginners from strong C programmers

String Literal

A sequence written using double quotes, such as "Hello".

Null Character

'\0' marks the end of a C string.

String Length

Number of characters before the null character.

Array Decay

In many expressions, an array expression converts to a pointer to its first element.

const char *

Useful when pointing to string literals that must not be modified.

Buffer Capacity

Always consider both the data length and storage required for the terminating null character.

Interview Questions

Questions you should be able to answer confidently

Q1. Does C have a string data type?

No. C represents strings using null-terminated character arrays.

Q2. Why is '\0' important?

It marks the end of a C string so string-processing routines know where the character sequence ends.

Q3. strlen() vs sizeof()?

strlen() counts characters before \0. sizeof gives the size of the object/type in bytes when applied in a context where the array itself is available.

Q4. Why use strcmp()?

It compares string contents rather than array/pointer addresses.

Q5. scanf("%s") vs fgets()?

scanf("%s") reads a word and stops at whitespace; fgets() can read an entire line while accepting a buffer size.

Q6. What is a string literal?

A character sequence written inside double quotes, such as "Hello".

Q7. What is an array of strings?

A collection of character sequences, commonly represented using a 2D character array or an array of character pointers.

Q8. What does strtok() do?

It breaks a modifiable string into tokens using delimiter characters.
