What Is a String?

A string is a sequence of text characters. JavaScript provides strings for representing names, messages, URLs, passwords, sentences, source code, JSON text, and much more. 

const name = "Pradeep";

const message = "Welcome to ZENSUS!";

console.log(name);
console.log(message);
Mental model: Think of a string as an ordered sequence of characters where positions are identified using zero-based indexes.

07

Strings Are Immutable

This is an important JavaScript concept.

You cannot directly change an individual character of an existing string. 

let word = "CAT";

word[0] = "B";

console.log(word);

// Still:
// CAT

Instead, create a new string. 

let word = "CAT";

word = "BAT";

console.log(word);
Interview point: String methods generally return new strings rather than modifying the original string.

🔥 Palindrome

A classic interview problem.

A palindrome reads the same forward and backward. 

function isPalindrome(text) {

    const clean =
        text
            .toLowerCase()
            .replace(/[^a-z0-9]/g, "");

    const reversed =
        clean
            .split("")
            .reverse()
            .join("");

    return clean === reversed;
}

console.log(
    isPalindrome("Madam")
);
Examples: madam, level, radar, civic

Anagram

Another important interview pattern.

Two strings are anagrams when they contain the same characters with the same frequencies, ignoring differences such as spaces or case when your problem definition says to ignore them. 

function isAnagram(a, b) {

    const cleanA =
        a.toLowerCase()
         .replace(/\s/g, "");

    const cleanB =
        b.toLowerCase()
         .replace(/\s/g, "");

    if (cleanA.length !== cleanB.length) {
        return false;
    }

    const count = {};

    for (const char of cleanA) {
        count[char] =
            (count[char] || 0) + 1;
    }

    for (const char of cleanB) {

        if (!count[char]) {
            return false;
        }

        count[char]--;
    }

    return true;
}

Character Frequency

Frequency counting is one of the most useful patterns for string problems. 

function frequency(text) {

    const count = {};

    for (const char of text) {

        count[char] =
            (count[char] || 0) + 1;
    }

    return count;
}

🌍 Unicode & Character Handling

JavaScript strings use UTF-16 code units. Many common characters behave as expected, but some Unicode symbols and emoji use more than one UTF-16 code unit. 

const text = "A";

console.log(text.length);

console.log(
    text.codePointAt(0)
);

For Unicode-aware iteration, use for...of or other code-point-aware techniques where appropriate. 

const emoji = "😊";

console.log(emoji.length);

for (const character of emoji) {
    console.log(character);
}

⚡ String Performance

Search

Operations such as includes() and indexOf() generally require scanning the string, so think in terms of O(n) worst-case behavior.

Transformations

Methods that create new strings generally require work proportional to the amount of text processed.

split + reverse + join

Reversing through an array involves additional memory for the intermediate array.

Regex

Regex performance depends heavily on the pattern. Avoid unnecessarily complex patterns.

🚨 Common String Mistakes

❌ Off-by-One

Remember that string indexes start at 0.

❌ Expecting Mutation

Methods such as toUpperCase() return a new string.

❌ Case Sensitivity

"JavaScript" and "javascript" are different strings.

❌ Wrong slice End

slice(start, end) excludes the end index.

❌ Reversing Directly

Strings do not have a direct reverse() method.

❌ Unicode Assumptions

String length does not always equal the number of visible characters.

40

Professional String Practices

  • Prefer const when a string variable does not need reassignment.
  • Use template literals for readable interpolation.
  • Normalize user input when your application requires consistent comparisons.
  • Use explicit case conversion when comparisons should ignore case.
  • Remember that strings are immutable.
  • Avoid unnecessary repeated string transformations inside performance-critical loops.
  • Be careful with Unicode when building internationalized applications.
  • Use regex only when it improves the solution rather than making the code unnecessarily difficult.
