01 / FUNDAMENTALS

What is an Array?

An array is a linear data structure that stores multiple values under one variable name. Elements are stored in an ordered sequence and are accessed using an index.

CORE IDEA

One variable → many values

Instead of creating separate variables for every student's marks, we can store all marks inside one array.

Python 
marks = [85, 72, 91, 66, 88]

print(marks)
Output → [85, 72, 91, 66, 88]

Array Visualization

index 1 72
index 2 91
index 3 66
index 4 88
Important: Most programming languages use zero-based indexing. Therefore, the first element is at index 0.

21 / MAJOR PATTERN

Two Pointer Pattern

Two pointers use two indices to process an array efficiently, often replacing nested loops with a linear scan.

Think Two Pointers when: the array is sorted, you need a pair, elements must be compared from both ends, or you need to compact/filter an array.

Opposite-Direction Pointers

LEFT
1 2 4 6 8 10
RIGHT
Pair Sum — Python 
arr = [1, 2, 4, 6, 8, 10]
target = 10

left = 0
right = len(arr) - 1

while left < right:

    total = arr[left] + arr[right]

    if total == target:
        print(left, right)
        break

    elif total < target:
        left += 1

    else:
        right -= 1

Same-Direction Pointers

Remove Duplicates

Use one pointer to track the position of the next unique element while another scans the array.

read pointer → scans    |    write pointer → stores

22 / MAJOR PATTERN

Sliding Window

Sliding Window is used when a problem asks about a contiguous range of elements and repeatedly examining overlapping ranges.

2
4
6
3
5
1
→ → →
FIXED WINDOW

Window Size = K

Example: maximum sum of any subarray of size 3.

O(n)
VARIABLE WINDOW

Window Changes

Expand and shrink the window based on a condition.

O(n) — common case
Maximum Sum — Fixed Window 
arr = [2, 1, 5, 1, 3, 2]
k = 3

window_sum = sum(arr[:k])
maximum = window_sum

for i in range(k, len(arr)):

    window_sum += arr[i]
    window_sum -= arr[i-k]

    maximum = max(maximum, window_sum)

print(maximum)
Output → 9

Sliding Window Variants

• Maximum sum subarray of size K

• Minimum window satisfying a condition

• Longest subarray satisfying a condition

• At most K distinct elements

• Exactly K distinct elements

23 / MAJOR PATTERN

Prefix Sum

Prefix sums preprocess cumulative totals so range-sum queries can be answered quickly.

Original
3 2 5 1 4
↓
Prefix
3 5 10 11 15
Python 
arr = [3, 2, 5, 1, 4]

prefix = [0] * len(arr)

prefix[0] = arr[0]

for i in range(1, len(arr)):
    prefix[i] = prefix[i-1] + arr[i]

print(prefix)
[3, 5, 10, 11, 15]
Range Sum: sum(l...r) = prefix[r] - prefix[l-1] when l > 0.

Prefix Sum + HashMap

Combining prefix sums with a frequency map allows us to solve important subarray problems such as Subarray Sum = K.

Subarray Sum = K 
arr = [1, 2, 3]
k = 3

count = 0
prefix = 0

freq = {0: 1}

for x in arr:

    prefix += x

    if prefix - k in freq:
        count += freq[prefix-k]

    freq[prefix] = freq.get(prefix, 0) + 1

print(count)
Output → 2
24 / MAJOR ALGORITHM

Kadane's Algorithm

Kadane's Algorithm finds the maximum sum of a contiguous subarray in linear time.

-2 1 -3 4 -1 2 1
Best subarray → [4, -1, 2, 1] → Sum = 6
Python 
arr = [-2, 1, -3, 4, -1, 2, 1]

current = arr[0]
best = arr[0]

for x in arr[1:]:

    current = max(x, current + x)

    best = max(best, current)

print(best)
Output → 6
Core idea: At every element, decide whether it is better to start a new subarray or extend the current subarray.

Negative Numbers

Kadane's Algorithm must not blindly initialize the answer to zero when the problem requires the maximum non-empty subarray.

[-5, -2, -8] → answer = -2

Maximum Subarray With Indices

Keep track of the start position and update the best range whenever a new maximum is found.

27 / SEARCH PATTERN

Binary Search on Arrays

Binary Search repeatedly cuts a sorted search space roughly in half.

1 3 5 7 9 11 13 15
↓
1 3 5 7
↓
5 7
Binary Search 
arr = [1, 3, 5, 7, 9, 11]
target = 7

left = 0
right = len(arr) - 1

while left <= right:

    mid = (left + right) // 2

    if arr[mid] == target:
        print(mid)
        break

    elif arr[mid] < target:
        left = mid + 1

    else:
        right = mid - 1
Output → 3

Important Variants

First Occurrence

Continue searching left after finding the target.

Last Occurrence

Continue searching right after finding the target.

Lower Bound

First position where value is greater than or equal to target.

Upper Bound

First position where value is strictly greater than target.

29 / THREE POINTER

Dutch National Flag

The Dutch National Flag algorithm sorts an array containing 0, 1 and 2 in one pass using three pointers.

2 0 2 1 1 0
LOW MID UNKNOWN HIGH
Python 
arr = [2, 0, 2, 1, 1, 0]

low = 0
mid = 0
high = len(arr) - 1

while mid <= high:

    if arr[mid] == 0:
        arr[low], arr[mid] = arr[mid], arr[low]
        low += 1
        mid += 1

    elif arr[mid] == 1:
        mid += 1

    else:
        arr[mid], arr[high] = arr[high], arr[mid]
        high -= 1

print(arr)
[0, 0, 1, 1, 2, 2]

33 / SUBSEQUENCE

Subsequences

SUBARRAY

Contiguous

Every selected element must be next to the previous selected element in the original array.

[2, 3, 4]
SUBSEQUENCE

Not Necessarily Contiguous

Elements keep their original relative order but elements may be skipped.

[1, 3, 5]
Generate Subsequences 
def generate(arr, index, current):

    if index == len(arr):
        print(current)
        return

    # Take
    generate(
        arr,
        index + 1,
        current + [arr[index]]
    )

    # Skip
    generate(
        arr,
        index + 1,
        current
    )
Subsequences are the bridge toward important recursion and dynamic programming problems.

39 / MISTAKES

Common Array Mistakes

01

Off-by-One

Using i <= n instead of i < n.

02

Wrong Index

Forgetting that indexing usually begins at zero.

03

Modifying While Iterating

Changing array size during traversal can skip elements or create unexpected behavior.

04

Ignoring Constraints

Choosing O(n²) when n is large can cause time-limit failures.

05

Wrong Window

Updating the sliding-window sum incorrectly can include or remove the wrong element.

06

Binary Search Bugs

Incorrect boundary updates can cause infinite loops or skip valid candidates.

07

Duplicate Handling

Forgetting whether duplicate values should count once or multiple times.

08

Empty Input

Always consider what happens when the array is empty.
