01 • FOUNDATION

What is a Heap?

Understand the structure before learning its operations.

Simple Definition

A Heap is a specialized tree-based data structure that satisfies a special ordering property called the heap property.

Important: A Binary Heap is always a Complete Binary Tree.

Real-World Example

Imagine a hospital emergency room. Patients do not necessarily receive treatment in arrival order. The patient with the highest priority is treated first.

This is the basic idea behind a Priority Queue.

Binary Heap Structure

Example of a Min Heap: every parent is smaller than or equal to its children.

02 • CORE CONCEPT

Heap Properties

These properties are extremely important for exams and interviews.

🌳

Complete Binary Tree

Every level is completely filled except possibly the last level, which is filled from left to right.

⚖️

Heap Property

Every parent follows the required ordering relationship with its children.

⚡

Efficient Access

The minimum or maximum element can be accessed at the root in O(1).

Why must a Binary Heap be Complete?

Completeness allows a heap to be stored efficiently inside an array without requiring explicit pointers.

Complete structure + array representation = compact and efficient Heap.

05 • FORMULAS

Heap Index Formulas

Memorize these formulas for array-based heaps.

Parent

parent = (i - 1) // 2

Works for every node except the root.

Left Child

left = 2i + 1

Gives the index of the left child.

Right Child

right = 2i + 2

Gives the index of the right child.

Example

Suppose the node is at index 2.

Left = 2(2) + 1 = 5
Right = 2(2) + 2 = 6
Therefore, the node at index 2 has children at indexes 5 and 6.
06 • CORE ALGORITHM

Heapify

Learn how a tree is adjusted to satisfy the heap property.

What is Heapify?

Heapify is the process of rearranging elements so that the heap property is restored.

Heapify is NOT sorting the entire array. It is restoring the heap property.

Down-Heap / Sift-Down Flow

Start with node
↓
Compare node with its children
↓
Find smaller child for Min Heap
↓
Is parent already smaller?
↓
Yes → Stop
OR
No → Swap with correct child
↓
Continue downward

Heapify Dry Run

Consider this invalid Min Heap:

[50, 20, 30, 40, 10]

The root is 50, but a smaller element exists below. We compare the root with its children and move the smaller value upward.

After repeated swaps, the heap property is restored.
07 • OPERATIONS

Heap Operations

Master insertion, deletion and peek operations.

O(1)

Peek

View the root without removing it.

heap[0]
O(log n)

Insert

Add an element and restore the heap using sift-up.

O(log n)

Delete Root

Remove root, move last element to root, then sift down.

Insertion — Sift Up

  1. Add the new element at the end.
  2. Compare it with its parent.
  3. If the heap property is violated, swap.
  4. Continue until the correct position is reached.
Min Heap Insert 

insert(value)

1. Add value at the end
2. i = last index

while i > 0:
    parent = (i - 1) // 2

    if heap[parent] <= heap[i]:
        break

    swap(heap[parent], heap[i])

    i = parent

Deletion — Sift Down

  1. Remove the root.
  2. Move the last element to the root.
  3. Compare it with its children.
  4. Swap with the appropriate child.
  5. Continue until the heap property is restored.
08 • BUILD HEAP

Build Heap

Convert an ordinary array into a valid heap.

Bottom-Up Heap Construction

Instead of inserting elements one by one, we can build a heap efficiently by starting from the last non-leaf node and applying heapify.

Build Heap → O(n)
Interview fact: Building a heap using bottom-up heap construction takes O(n), not O(n log n).

Algorithm

Build Min Heap 

build_heap(heap):

    n = len(heap)

    for i in range(n // 2 - 1, -1, -1):

        heapify_down(heap, i)
09 • SORTING

Heap Sort

Use the heap structure to sort an array efficiently.

Heap Sort Idea

Heap Sort first creates a heap and repeatedly removes the root to place elements into their correct position.

Input Array
↓
Build Max Heap
↓
Swap Root with Last Element
↓
Reduce Heap Size
↓
Heapify Root
↓
Repeat Until Sorted

Time

O(n log n)

Space

O(1)

Stable?

No
Heap Sort provides guaranteed O(n log n) time complexity.
10 • APPLICATION

Priority Queue

Understand why Heaps are commonly used to implement Priority Queues.

What is a Priority Queue?

A Priority Queue is an abstract data type in which every element has a priority, and the element with the highest or lowest priority is served first.

A Binary Heap is one of the most efficient data structures for implementing a Priority Queue.

Normal Queue

FIFO

First In → First Out

Example: people standing in a normal line.

Priority Queue

Priority First

Highest/lowest priority is processed first.

Example: emergency patients.

Priority Queue Operations

Operation Meaning Typical Heap Complexity
Insert Add element O(log n)
Peek View highest priority O(1)
Extract Remove highest priority O(log n)
Build Create priority structure O(n)
11 • PYTHON

Heap in Python

Python provides the heapq module for heap-based priority queues.

Min Heap using heapq

Python 

import heapq

heap = []

heapq.heappush(heap, 30)
heapq.heappush(heap, 10)
heapq.heappush(heap, 20)

print(heap)

smallest = heapq.heappop(heap)

print(smallest)
Python's heapq implements a Min Heap.

Max Heap in Python

A common technique is to insert negative values when using the traditional Min Heap API.

Python 

import heapq

heap = []

heapq.heappush(heap, -50)
heapq.heappush(heap, -20)
heapq.heappush(heap, -40)

maximum = -heapq.heappop(heap)

print(maximum)

Priority Queue Example

Python 

import heapq

tasks = []

heapq.heappush(tasks, (2, "Study"))
heapq.heappush(tasks, (1, "Emergency"))
heapq.heappush(tasks, (3, "Entertainment"))

while tasks:

    priority, task = heapq.heappop(tasks)

    print(priority, task)
Smaller priority number is processed first in this example.

14 • INTERVIEW SKILLS

Recognize Heap Problems

Learn when your brain should immediately think about a Heap.

Pattern 1 — Top K

If a problem asks for:

  • K largest elements
  • K smallest elements
  • K most frequent elements
  • K closest points
Think: Heap / Priority Queue

Pattern 2 — Repeated Minimum

If the problem repeatedly asks you to find and remove the smallest element, think Min Heap.

Repeated minimum → Min Heap

Pattern 3 — Repeated Maximum

If you repeatedly need the largest element, think Max Heap.

Repeated maximum → Max Heap

Pattern 4 — Scheduling

If tasks/events must be processed according to priority, deadline or cost, a Priority Queue may be useful.

Dynamic priority → Priority Queue
15 • AVOID THESE

Common Heap Mistakes

These mistakes frequently appear in interviews and coding implementations.

1
Confusing Heap with BST

A Heap does not require the left subtree to be smaller and right subtree larger.

2
Forgetting Complete Binary Tree

A Binary Heap must maintain completeness.

3
Wrong child selection

During sift-down, select the appropriate child before swapping.

4
Wrong index formulas

For zero-based indexing: left = 2i+1 and right = 2i+2.

5
Assuming heap array is sorted

A heap array is NOT necessarily sorted. It only satisfies the heap property.

17 • CHECK YOURSELF

Heap Quiz

Test whether you really understand the concepts.

1. What is always true about a Binary Heap?

Correct! A Binary Heap is a Complete Binary Tree that satisfies the heap property.

2. What is the time complexity of inserting an element into a Binary Heap?

Correct! The element may move upward through the height of the heap, which is O(log n).

3. Which data structure is commonly used to implement a Priority Queue?

Correct! A Binary Heap is a standard efficient implementation of a Priority Queue.

4. What is the left-child index of node i in a zero-based heap array?

Correct! For zero-based indexing, left child = 2i + 1.
