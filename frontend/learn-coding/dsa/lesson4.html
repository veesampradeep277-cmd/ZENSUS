What is a Linked List?

A linked list is a linear data structure made of nodes. Each node stores data and a reference to another node.

Think of a linked list as a chain of nodes
10 DATA
→
20 DATA
→
30 DATA
→
NULL

Node

The basic building block of a linked list.

Data

The actual value stored inside a node.

Next

Reference pointing to the next node.

Head

Reference to the first node.

Core idea: A linked list does not need elements to occupy consecutive memory locations. Nodes are connected through references.
02

Why Linked Lists?

Arrays are excellent when fast random access is required. Linked lists become useful when frequent insertion and deletion operations are important.

Advantages

  • Dynamic size
  • Easy insertion at known positions
  • Easy deletion with references
  • No requirement for contiguous storage
  • Useful for implementing other data structures

Limitations

  • No direct random access
  • Extra memory for references
  • More pointer management
  • Sequential traversal
  • More edge cases
03

Linked List vs Array

Understanding this comparison helps you decide which data structure to choose before writing code.

Array

10 20 30 40

Direct indexing allows access by position.

Linked List

10 → 20 → 30 → 40 → NULL

Nodes are connected using references.

Operation Array Linked List
Random access O(1) O(n)
Search O(n) O(n)
Insert at beginning O(n) O(1) with head
Delete at beginning O(n) O(1)
Extra reference memory No Yes
Interview rule: Never say "linked list insertion is always O(1)". It depends on whether the required node/reference is already known.

Three ideas control the structure of a linked list: head, tail and the termination reference.

HEAD →

  • HEAD points to the first node.
  • TAIL refers to the final node when maintained explicitly.
  • In a normal singly linked list, the final next reference is NULL.
  • An empty list has head = NULL.

Types of Linked Lists

Linked lists can be classified according to how nodes connect.

Singly Linked List

Each node points only to the next node.

10 → 20 → 30 → NULL

Doubly Linked List

Each node contains previous and next references.

NULL ← 10 ⇄ 20 ⇄ 30 → NULL

Circular Singly

The final node points back to the first node.

10 → 20 → 30 ↘ ↑_____________↓

Circular Doubly

Previous and next references form a complete cycle.

10 ⇄ 20 ⇄ 30 ⇄ 10

Traversal means visiting every node from the head until the termination condition is reached.

↓

↓
current != NULL?
↓

↓
current = current.next
↺

Python 
current = head

while current:
    print(current.data)
    current = current.next
Time: O(n)   |   Extra Space: O(1)

Searching in a Linked List

Since linked lists do not support direct indexing, searching normally requires sequential traversal.

10 20 30 40
Python 
current = head

while current:
    if current.data == target:
        return True

    current = current.next

return False
Best: O(1)   |   Worst: O(n)

Traverse the list and increment a counter for each node.

return count

Reverse a Linked List

Reversing a linked list means changing the direction of every next reference.

The three-pointer technique
prev = NULL    current = 10    next = 20
NULL ← 10    20 → 30 → NULL
NULL ← 10 ← 20    30 → NULL
NULL ← 10 ← 20 ← 30
Python 
prev = None
current = head

while current:

    next_node = current.next

    current.next = prev

    prev = current

    current = next_node

head = prev
Time: O(n)   |   Extra Space: O(1)
Memory rule: Always save current.next before changing current.next. Otherwise you can lose the remaining list.

Maintain two pointers. Slow moves one step while fast moves two. This pattern is one of the most important linked-list techniques.

S → 30      F → 50

Find Middle

Detect Cycle

Split List

Detect Cycle

Floyd's Cycle Detection Algorithm uses fast and slow pointers. If the two pointers meet while traversing, the list contains a cycle.

Floyd's Tortoise and Hare
10 → 20 → 30 → 40
↑         ↓
← ← ← ← ←
Python 
slow = head
fast = head

while fast and fast.next:

    slow = slow.next
    fast = fast.next.next

    if slow == fast:
        return True

return False
Time: O(n)   |   Extra Space: O(1)

Remove Nth Node From End

Combine a fixed pointer gap with a dummy node to simplify deletion near the head.

Core pattern 
dummy = Node(0)
dummy.next = head

fast = dummy
slow = dummy

# create gap

for _ in range(n + 1):
    fast = fast.next

# move together

while fast:
    fast = fast.next
    slow = slow.next

# remove target

slow.next = slow.next.next

head = dummy.next

Merge Two Sorted Lists

Compare the current nodes of two sorted lists and repeatedly attach the smaller node.

L1: 1 → 3 → 5
L2: 2 → 4 → 6
Result: 1 → 2 → 3 → 4 → 5 → 6
Time: O(n + m)   |   Extra Space: O(1) iterative

Intersection of Two Linked Lists

Intersection means the lists eventually reference the same node, not merely nodes containing equal values.

A: 1 → 2 → 8 → 10
B: 5 → 6 → 8 → 10
Shared nodes → 8 → 10
Important distinction: Same value does not necessarily mean same node. Intersection is based on node identity/reference.

Palindrome Linked List

A powerful solution uses the middle node, reverses the second half, and compares both halves.

1 → 2 → 3 → 2 → 1
First half: 1 → 2 → 3
Reversed second half: 1 → 2 → 3
Time: O(n)   |   Extra Space: O(1)

Reorder Linked List

Reordering combines multiple linked-list patterns.

1 → 2 → 3 → 4 → 5
1 → 2 → 5 → 4 → 3

Step 1

Find the middle.

Step 2

Reverse the second half.

Step 3

Merge both halves alternately.

Pattern

Fast/slow + reverse + merge.

Interview Questions & Cheat Sheet

Why is random access O(n) in a linked list?
Nodes must be reached sequentially from the head.
How do you reverse a linked list?
Use previous, current and next references.
How do you detect a cycle?
Use Floyd's fast and slow pointer technique.
How do you find the middle node?
Move slow one step and fast two steps.
What is the difference between node value and node identity?
Two different nodes can contain the same value.
