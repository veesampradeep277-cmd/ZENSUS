Core Concept

What are Aggregate Functions?

Aggregate functions perform calculations on multiple rows and return a single summarized value.

Simple definition:

An aggregate function takes a collection of values and produces one result from that collection.

Row 1 91 marks
+
Row 2 87 marks
+
Row 3 94 marks
→
AVG() 90.67
💡
Key idea:

Without GROUP BY, an aggregate can summarize the entire selected set. With GROUP BY, the same aggregate is calculated separately for each group.

Function 01

COUNT()

COUNT is used when you want to know how many records or non-NULL values exist.

Count all rows 
SELECT COUNT(*) AS total_students
FROM students;
Result:

6 students.

COUNT(column) 

SELECT COUNT(phone) AS students_with_phone
FROM students;

COUNT(column) counts only rows where that column is non-NULL. 

SELECT COUNT(DISTINCT city) AS unique_cities
FROM students;

COUNT(DISTINCT column) counts unique non-NULL values.

Function 02

SUM()

SUM calculates the total of numeric values. 

SELECT SUM(marks) AS total_marks
FROM students;
Calculation:

91 + 82 + 87 + 76 + 89 + 94 = 519 

SELECT department,
       SUM(marks) AS total_marks
FROM students
GROUP BY department;
Function 03

AVG()

AVG calculates the arithmetic mean of non-NULL numeric values. 

SELECT AVG(marks) AS average_marks
FROM students;
Formula:

Average = Sum of values ÷ Number of non-NULL values 

SELECT department,
       AVG(marks) AS average_marks
FROM students
GROUP BY department;
⚠️
NULL matters:

AVG() normally ignores NULL values. It does not treat NULL as zero.

Functions 04 & 05

MIN() and MAX()

MIN()

Returns the smallest value in the selected set. 

SELECT MIN(marks) AS lowest_marks
FROM students;

MAX()

Returns the largest value in the selected set. 

SELECT MAX(marks) AS highest_marks
FROM students;
SELECT
    department,
    MIN(marks) AS lowest,
    MAX(marks) AS highest
FROM students
GROUP BY department;
Important

NULL and Aggregate Functions

Understanding NULL is critical for writing accurate SQL reports.

COUNT(*)

Counts rows, including rows where individual columns contain NULL.

COUNT(column)

Counts only non-NULL values in that column.

SUM()

Normally ignores NULL inputs.

AVG()

Normally averages non-NULL values only.

MIN()

NULL values do not normally become the minimum.

MAX()

NULL values do not normally become the maximum.

Unique Values

COUNT(DISTINCT)

Sometimes you don't want the number of rows. You want the number of unique values. 

SELECT COUNT(DISTINCT department)
       AS unique_departments
FROM students;
Example:

CSE, ECE and EEE are three unique departments, so the result is 3. 

SELECT COUNT(DISTINCT city)
       AS unique_cities
FROM students;
Aggregation + Grouping

Aggregate Functions with GROUP BY

GROUP BY makes aggregate functions much more powerful by calculating a separate result for every group.

Raw Rows 6 students
→
GROUP BY Department
→
COUNT() Students
→
AVG() Marks
→
Report One row/group 
SELECT
    department,
    COUNT(*) AS total_students,
    SUM(marks) AS total_marks,
    AVG(marks) AS average_marks,
    MIN(marks) AS lowest_marks,
    MAX(marks) AS highest_marks
FROM students
GROUP BY department;
Filtering

WHERE + Aggregate Functions 

SELECT
    department,
    AVG(marks) AS average_marks
FROM students
WHERE marks >= 80
GROUP BY department;
What happens?

First, WHERE removes students with marks below 80. Then GROUP BY creates department groups. Finally AVG() calculates the average of each remaining group.

Group Filtering

HAVING + Aggregate Functions 

SELECT
    department,
    AVG(marks) AS average_marks
FROM students
GROUP BY department
HAVING AVG(marks) >= 85;

WHERE

Filters individual rows before aggregation.

HAVING

Filters groups after aggregation.

Advanced Reporting

Conditional Aggregation

CASE combined with aggregate functions allows SQL to calculate multiple categories in one query. 

SELECT
    department,

    COUNT(*) AS total_students,

    SUM(
        CASE
            WHEN marks >= 80 THEN 1
            ELSE 0
        END
    ) AS high_scorers

FROM students

GROUP BY department;
SELECT
    department,

    SUM(
        CASE
            WHEN marks >= 90 THEN 1
            ELSE 0
        END
    ) AS excellent,

    SUM(
        CASE
            WHEN marks >= 75
             AND marks < 90
            THEN 1
            ELSE 0
        END
    ) AS good,

    SUM(
        CASE
            WHEN marks < 75 THEN 1
            ELSE 0
        END
    ) AS needs_improvement

FROM students

GROUP BY department;
🚀
Real-world use:

Conditional aggregation is frequently used in dashboards, business reports, sales analytics, student performance reports and user analytics.

Advanced Concepts

Aggregate functions beyond the basics

Aggregates with JOIN

Combine related tables and calculate totals or counts. 

SELECT d.name,
       COUNT(s.id)
FROM departments d
JOIN students s
ON d.id = s.department_id
GROUP BY d.name;

Aggregates with Expressions

Aggregate calculated values when the expression is meaningful for the dataset. 

SELECT SUM(quantity * price)
       AS revenue
FROM orders;

Date Aggregation

Group records by supported date parts such as year or month. 

SELECT year,
       SUM(sales)
FROM sales
GROUP BY year;

Window Functions

Window functions calculate aggregate-like values without collapsing rows. 

AVG(marks)
OVER(PARTITION BY department)
Interview Concept

Aggregate + GROUP BY vs Window Aggregate

GROUP BY

  • Collapses rows.
  • Usually one output row per group.
  • Excellent for reports and summaries.

Window Function

  • Preserves individual rows.
  • Calculates across related rows.
  • Useful for rankings and comparisons. 
SELECT
    name,
    department,
    marks,

    AVG(marks)
    OVER (
        PARTITION BY department
    ) AS department_average

FROM students;

Avoid These

Common Aggregate Function mistakes

❌ COUNT(column) vs COUNT(*)

They are not always equivalent. COUNT(column) ignores NULL values.

❌ Treating NULL as 0

NULL means missing/unknown data. It is not automatically the same as zero.

❌ Using WHERE for aggregate filters

Conditions on aggregate results generally belong in HAVING at the same query level.

❌ Forgetting GROUP BY

If you want separate aggregate results for categories, you generally need GROUP BY.

❌ Averaging the wrong values

Always understand which rows are included before calculating AVG().

❌ Assuming output order

Aggregate functions do not guarantee result order. Use ORDER BY when order matters.

Exam Preparation

5-Mark Answer

Aggregate Functions in SQL

Aggregate functions perform calculations on a set of rows and return a summarized result. The major aggregate functions are COUNT(), SUM(), AVG(), MIN() and MAX(). COUNT() counts rows or non-NULL values, SUM() calculates totals, AVG() calculates averages, MIN() returns the smallest value and MAX() returns the largest value. Aggregate functions are commonly used with GROUP BY to calculate separate summaries for different groups. 

SELECT
    department,
    COUNT(*) AS total_students,
    AVG(marks) AS average_marks,
    MAX(marks) AS highest_marks
FROM students
GROUP BY department;

Interview Preparation

Aggregate Function Interview Questions

1. What are aggregate functions?

Aggregate functions perform calculations over a set of rows and return a summarized result.

2. Name the five major aggregate functions.

COUNT(), SUM(), AVG(), MIN() and MAX().

3. What is the difference between COUNT(*) and COUNT(column)?

COUNT(*) counts rows, while COUNT(column) counts non-NULL values in that column.

4. Does AVG() include NULL values?

Normally no. AVG() calculates the average of non-NULL values.

5. Can aggregate functions be used without GROUP BY?

Yes. Without GROUP BY, an aggregate can summarize the entire selected set.

6. Can aggregate functions be used with GROUP BY?

Yes. This is one of their most common uses and produces a separate aggregate result for each group.

7. WHERE vs HAVING?

WHERE filters rows before grouping. HAVING filters groups after aggregation.

8. What is COUNT(DISTINCT column)?

It counts unique non-NULL values of the specified column.

9. Can SUM() be used with expressions?

Yes. For example, SUM(quantity * price) can calculate total revenue when quantity and price are stored per row.

10. GROUP BY vs window aggregate?

GROUP BY normally collapses rows into groups, while window aggregates calculate across related rows while preserving individual rows.
