01 • Concept

What is the WHERE clause?

WHERE tells SQL which rows should qualify for a query.

Imagine a college database containing 10,000 students.

If you ask:

SQL 
SELECT *
FROM students
WHERE marks >= 80;

SQL does not return every student. It checks the condition marks >= 80 and returns only matching rows.

ALL STUDENTS
1 Pradeep 92
2 Rahul 65
3 Anu 88
4 Ravi 72
→
WHERE marks >= 80
1 Pradeep 92
3 Anu 88
02 • Syntax

Basic WHERE syntax

GENERAL SYNTAX 
SELECT column1, column2
FROM table_name
WHERE condition;
1

SELECT

Specifies which columns you want to display.

2

FROM

Specifies the table from which data is read.

3

WHERE

Defines the condition used to filter rows.

4

Condition

An expression that evaluates to TRUE, FALSE, or UNKNOWN.

07 • Multiple Conditions

AND — all conditions must be true

Use AND when every condition must be satisfied.

SQL 
SELECT *
FROM students
WHERE department = 'CSE'
AND marks >= 80;
Think: AND = BOTH Department must be CSE AND marks must be at least 80.
08 • Multiple Conditions

OR — at least one condition must be true

SQL 
SELECT *
FROM students
WHERE department = 'CSE'
OR department = 'ECE';
Think: OR = EITHER A student can belong to CSE or ECE.
09 • Logical Operator

NOT — reverse a condition

SQL 
SELECT *
FROM students
WHERE NOT department = 'CSE';

This selects rows where the condition department = 'CSE' is not true.

Common alternative You will often see:

WHERE department <> 'CSE'
10 • Important

AND vs OR precedence

This is a common interview and exam topic.

In a condition containing both AND and OR, AND is generally evaluated before OR.

POTENTIALLY CONFUSING 
SELECT *
FROM students
WHERE department = 'CSE'
OR department = 'ECE'
AND marks >= 80;

Conceptually, this is interpreted as: 

WHERE department = 'CSE'
OR (department = 'ECE' AND marks >= 80);
Best practice Use parentheses whenever the logic matters. 
SELECT *
FROM students
WHERE
    (department = 'CSE' OR department = 'ECE')
    AND marks >= 80;
11 • Range Filtering

BETWEEN

BETWEEN checks whether a value lies within an inclusive range.

SQL 
SELECT *
FROM students
WHERE marks BETWEEN 70 AND 90;
Important BETWEEN is normally inclusive.
70 and 90 are both included. 
-- Equivalent idea

WHERE marks >= 70
AND marks <= 90;
12 • Multiple Values

IN and NOT IN

IN is useful when a column can match one of several specified values. 

SELECT *
FROM students
WHERE department IN ('CSE', 'ECE', 'EEE');

Instead of writing: 

WHERE department = 'CSE'
OR department = 'ECE'
OR department = 'EEE';

NOT IN 

SELECT *
FROM students
WHERE department NOT IN ('CSE', 'ECE');
NULL warning NOT IN can behave unexpectedly when NULL values are involved. For nullable columns, understand SQL's three-valued logic before relying on NOT IN.
13 • Pattern Matching

LIKE — search text patterns

LIKE is used when you do not know the complete text value.

%

% wildcard

Represents zero or more characters. 

WHERE name LIKE 'P%'

Names beginning with P.

_

_ wildcard

Represents exactly one character. 

WHERE name LIKE 'A_nu'

Useful LIKE patterns

Pattern Meaning
'P%' Starts with P
'%a' Ends with a
'%ra%' Contains "ra"
'_a%' Second character is a
'____' Exactly four characters
14 • Critical SQL Concept

NULL — the special case

NULL does not mean zero, empty string, or the word "NULL".

NULL

Represents missing or unknown information.

0

A numeric value.

''

An empty string in databases that support it as such.

Never use = NULL This is not the correct way to test for NULL:

WHERE city = NULL

Instead use: 

SELECT *
FROM students
WHERE city IS NULL;

Or: 

SELECT *
FROM students
WHERE city IS NOT NULL;
15 • Advanced Understanding

SQL's three-valued logic

A normal programming language often thinks in terms of TRUE and FALSE.

SQL can produce:

✓

TRUE

The row satisfies the condition.

✕

FALSE

The row does not satisfy the condition.

?

UNKNOWN

Often occurs when NULL participates in a comparison.

WHERE keeps TRUE rows Rows for which the WHERE condition evaluates to FALSE or UNKNOWN are not returned.
16 • Query Execution

Where does WHERE fit?

SQL is written in one order, but conceptually processed in a different logical order. 

SELECT department, AVG(marks)
FROM students
WHERE marks >= 60
GROUP BY department
HAVING AVG(marks) >= 75
ORDER BY AVG(marks) DESC;
1 FROM
2 WHERE
3 GROUP BY
4 HAVING
5 SELECT
6 DISTINCT
7 ORDER BY
8 LIMIT
Interview point WHERE filters rows before grouping. HAVING filters groups after GROUP BY.
17 • Combining Clauses

WHERE with SELECT

SELECT name, department, marks
FROM students
WHERE marks >= 80;

SELECT determines the columns displayed. WHERE determines which rows qualify.

18 • Combining Clauses

WHERE with ORDER BY

SELECT name, marks
FROM students
WHERE marks >= 70
ORDER BY marks DESC;

First filter the qualifying rows, then sort the result.

19 • Result Limiting

WHERE with LIMIT

SELECT *
FROM students
WHERE marks >= 80
ORDER BY marks DESC
LIMIT 3;
Dialect note LIMIT is common in MySQL, PostgreSQL and SQLite. SQL Server commonly uses TOP or OFFSET/FETCH, while standard SQL supports FETCH FIRST.
20 • Safety

WHERE with UPDATE

This is extremely important in real-world SQL. 

UPDATE students
SET marks = 95
WHERE id = 3;
⚠️ Dangerous mistake Never casually run:

UPDATE students SET marks = 95;

Without a WHERE condition, you may update every row in the table.
21 • Safety

WHERE with DELETE

DELETE FROM students
WHERE id = 8;
Critical rule Always verify your WHERE condition before DELETE.

DELETE FROM students;

can remove all rows from the table.
22 • Real-World Data

Filtering dates

Date syntax varies somewhat between database systems, so follow the conventions of your DBMS. 

SELECT *
FROM orders
WHERE order_date >= '2026-01-01';
SELECT *
FROM orders
WHERE order_date BETWEEN '2026-01-01'
                     AND '2026-01-31';
Important date/time point If a column stores timestamps, filtering through an inclusive end date can be tricky. For a full day, a half-open range such as

order_date >= '2026-01-01' AND order_date < '2026-02-01'

is often safer than assuming the end date represents the entire day.

26 • Avoid These

Common WHERE mistakes

❌ Using = NULL

WHERE city = NULL;

Use IS NULL instead.

❌ Forgetting quotes

WHERE department = CSE;

Text values normally require string quotes.

❌ Wrong AND/OR logic

WHERE A OR B AND C;

Use parentheses when the intended logic is important.

❌ Missing WHERE in UPDATE

UPDATE students
SET marks = 100;

This can affect every row.

27 • Exam Preparation

5-mark answer: WHERE clause

The WHERE clause is used in SQL to filter rows based on a specified condition. Only rows for which the condition evaluates to TRUE are returned by a SELECT query. 

SELECT *
FROM students
WHERE marks >= 80;

WHERE can use comparison operators such as =, >, <, >=, <=, <>, as well as logical operators such as AND, OR, and NOT.
