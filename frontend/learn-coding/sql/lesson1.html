2. What Is SQL?

The language used to communicate with relational databases.

SQL = Structured Query Language

SQL is a language used to interact with relational database systems. We can use SQL to create database structures, insert data, retrieve information, update records and delete records.

Think of SQL like this: You ask the database a question or give it an instruction, and the database processes that SQL statement. 
SELECT name
FROM students
WHERE department = 'CSE';

This query asks for the names of students whose department is CSE.

3. Database vs SQL

Don't confuse the language with the system.

Database SQL
Stores and manages data. Language used to communicate with the database.
Example: MySQL database server. Example: SELECT, INSERT, UPDATE.
Responsible for storing and processing data. Provides commands to interact with that data.

10. Your First SQL Statements

Start with the basic database workflow.

Create a Database 

CREATE DATABASE college;

Creates a database named college.

Select a Database 

USE college;

In systems that support USE, this selects the database for subsequent commands.

Create a Table 

CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    marks INT

Insert Data 

INSERT INTO students
VALUES (101, 'Pradeep', 88);

Read Data

FROM students;

Filter Data

13. Why Is SQL Called Declarative?

This is an important conceptual interview question.

You say WHAT you want 

SELECT name
FROM students
WHERE marks > 80;

Database decides HOW

The database engine determines how to execute the query using its optimizer, indexes, access paths and execution plan.

You describe the desired result; the database system determines an execution strategy.

14. Anatomy of a SQL Query

Learn how to read a basic SELECT statement. 

SELECT name, marks
FROM students
WHERE marks >= 80
ORDER BY marks DESC;
Part Purpose
SELECT Specifies the columns or expressions to return.
FROM Specifies the source table or tables.
WHERE Filters rows according to a condition.
ORDER BY Controls the ordering of the returned rows.

18. Common Beginner Mistakes

Avoid these from your first SQL lesson.

❌ Confusing SQL with MySQL

SQL is the language. MySQL is a database management system that supports SQL.

❌ Forgetting quotes 

-- Correct
WHERE name = 'Pradeep';

-- Usually incorrect for a string
WHERE name = Pradeep;

❌ Forgetting WHERE 

UPDATE students
SET marks = 100;

This can update every row. Always understand the scope of UPDATE and DELETE statements.

❌ Using SELECT * everywhere

SELECT * is useful for exploration, but production queries often select only the columns they actually need.

❌ Ignoring NULL

NULL represents missing/unknown data and does not behave like an ordinary value. You will learn IS NULL and IS NOT NULL.

❌ Thinking SQL is case-sensitive everywhere

Keyword case is commonly flexible, but identifier and string comparison behavior can depend on the database system and configuration.

20. Interview Questions

Questions you should be able to answer after Lesson 1.

What is SQL? +
SQL stands for Structured Query Language. It is used to interact with relational databases, including retrieving, inserting, updating and deleting data and defining database structures.
What is a database? +
A database is an organized collection of data that can be stored, managed, retrieved and modified efficiently.
What is a table? +
A table is a structured collection of rows and columns used to organize related data in a relational database.
What is the difference between SQL and MySQL? +
SQL is a language used to communicate with relational databases. MySQL is a database management system that implements SQL and provides additional database features.
What is CRUD? +
CRUD stands for Create, Read, Update and Delete. These represent the fundamental operations applications perform on stored data.
Why is SQL called declarative? +
SQL primarily describes the desired result, while the database engine determines an execution strategy for obtaining that result.
What is a row and what is a column? +
A row represents one record in a table. A column represents one attribute or field shared by the records in that table.
