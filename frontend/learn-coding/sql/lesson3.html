02 — CREATE

What is CREATE in SQL?

CREATE is a Data Definition Language (DDL) command used to create database objects.

🗃️

Database

Creates a new database that can contain tables and other database objects.

📊

Table

Creates the structure used to store rows and columns of data.

👁️

View

Creates a virtual table based on a query.

⚡

Index

Creates an index that can improve query lookup performance.

Important: CREATE mainly defines the structure of database objects. It does not normally insert the actual application records. Data insertion is covered with INSERT.

04 — CREATE DATABASE

Creating a Database

A database is a logical container that stores related database objects.

SQL 
CREATE DATABASE college;

Using the Database

MySQL 
USE college;
Remember: SQL syntax differs slightly between database systems such as MySQL, PostgreSQL, SQL Server and Oracle. Always check the dialect you are using.

Avoiding an error if the database already exists

SQL 
CREATE DATABASE IF NOT EXISTS college;
05 — CREATE TABLE

Creating a Table

Tables are the heart of relational databases. They organize information into rows and columns.

SQL 
CREATE TABLE students (
    student_id INT,
    name VARCHAR(100),
    age INT,
    email VARCHAR(150)
);

Understanding the Structure

students 📊
student_id INT
name VARCHAR
age INT
email VARCHAR
Key idea: A CREATE TABLE statement defines the schema of the table — column names, data types and constraints.

07 — Data Types

Choosing the Right Data Type

A column's data type determines what kind of values can be stored in that column.

Data Type Used For Example
INT Whole numbers 25
DECIMAL(10,2) Exact decimal values 89.50
VARCHAR(100) Variable-length text Pradeep
CHAR(2) Fixed-length text IN
DATE Date values 2026-09-11
BOOLEAN True/false values TRUE
Professional rule: Choose the smallest appropriate data type that correctly represents the data and meets your database system's requirements. Do not blindly use VARCHAR for everything.
08 — Constraints

Making Tables Reliable

Constraints are rules that protect the integrity of data.

🔑

PRIMARY KEY

Uniquely identifies each row. It cannot contain NULL values.

🚫

NOT NULL

Requires a value to be supplied for the column.

🆔

UNIQUE

Prevents duplicate values according to the database system's rules.

🎯

CHECK

Restricts values according to a condition.

🔗

FOREIGN KEY

Establishes a relationship with another table.

📌

DEFAULT

Provides a value when one is not explicitly supplied.

SQL 
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE,
    age INT CHECK (age >= 16),
    city VARCHAR(50) DEFAULT 'Guntur'
);

10 — CREATE Family

Other CREATE Statements

CREATE is not limited to databases and tables. SQL database systems support many database objects.

CREATE VIEW

SQL 
CREATE VIEW student_directory AS
SELECT student_id, first_name, email
FROM students;

A view is a stored query that behaves like a virtual table when queried.

CREATE INDEX

SQL 
CREATE INDEX idx_student_email
ON students(email);
Performance note: Indexes can make suitable queries faster, but they also consume storage and can add overhead to INSERT, UPDATE and DELETE operations. Do not create indexes blindly.

13 — Testing

How to Verify Your Table

After creating a table, inspect its structure using commands supported by your database system.

MySQL 
DESCRIBE students;

You can also query metadata or use the database system's schema browser.

Important distinction: CREATE defines structure. INSERT adds rows. SELECT retrieves rows. UPDATE modifies rows. DELETE removes rows.
14 — Common Mistakes

Mistakes Beginners Make

❌

Missing comma

Forgetting commas between column definitions causes syntax errors.

❌

Wrong data type

Storing numbers or dates as generic text can make validation and querying harder.

❌

No primary key

Many important tables should have a reliable way to identify each row.

❌

Overusing VARCHAR

Not every value should be stored as text.

Example of a syntax error: 
CREATE TABLE students (
    id INT
    name VARCHAR(100)
);
A comma is missing after INT.
