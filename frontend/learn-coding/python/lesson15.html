List Comprehensions & Lambda Functions

Learn how Python developers write concise, expressive code using list comprehensions, lambda functions and functional tools such as map(), filter(), reduce() and sorted().

FOUNDATION

Why Learn These Concepts?

Python provides several ways to write operations on collections in a concise and readable way.

Two important techniques are list comprehensions and lambda functions.

List comprehension is mainly used to create a new list from an iterable, while lambda creates a small anonymous function that can be passed to other functions.

Developer Mindset

Don't use compact syntax simply because it is shorter. Use it when it makes the code easier to understand.

LISTS

What Is List Comprehension?

A list comprehension is a concise way to create a new list by applying an expression to each item of an iterable.

The iterable can be a list, tuple, string, range, set or another iterable object.

HOW LIST COMPREHENSION WORKS
📦 Iterable [1, 2, 3, 4]
→
🔄 Loop for x in data
→
⚙️ Expression x * 2
→
📋 New List [2, 4, 6, 8]
03
VERY IMPORTANT

List Comprehension Syntax

GENERAL SYNTAX 

new_list = [expression for item in iterable if condition]
Part Meaning Example
expression What should be added to the new list. x * 2
for Iterates through the source iterable. for x in numbers
iterable Collection being processed. numbers
if condition Optional filter. if x % 2 == 0
04
EXAMPLES

Basic List Comprehensions

Square Every Number EXAMPLE 01 
numbers = [1, 2, 3, 4, 5]

squares = [x ** 2 for x in numbers]

print(squares)
Output: [1, 4, 9, 16, 25]
Create Numbers Using range() EXAMPLE 02 
numbers = [x for x in range(1, 6)]

print(numbers)
Output: [1, 2, 3, 4, 5]
Convert Strings EXAMPLE 03 
names = ["pradeep", "python", "zensus"]

upper_names = [name.upper() for name in names]

print(upper_names)
Output: ['PRADEEP', 'PYTHON', 'ZENSUS']
05
FILTERING

List Comprehension with Conditions

The optional if condition acts as a filter. Only elements satisfying the condition are included. 

new_list = [expression for item in iterable if condition]
Even Numbers EXAMPLE 01 
numbers = [1, 2, 3, 4, 5, 6]

even = [x for x in numbers if x % 2 == 0]

print(even)
Output: [2, 4, 6]
Numbers Greater Than 10 EXAMPLE 02 
numbers = [5, 12, 7, 18, 3, 20]

result = [x for x in numbers if x > 10]

print(result)
Output: [12, 18, 20]
06
CONDITIONAL EXPRESSION

If-Else in List Comprehension

Important Difference

When using if-else to choose the output, the conditional expression comes before the for loop. 

[value_if_true if condition else value_if_false
 for item in iterable]
Even or Odd EXAMPLE 
numbers = [1, 2, 3, 4, 5]

result = [
    "Even" if x % 2 == 0 else "Odd"
    for x in numbers
]

print(result)
Output: ['Odd', 'Even', 'Odd', 'Even', 'Odd']
07
ADVANCED

Nested List Comprehension

A list comprehension can contain more than one for clause.

This is useful for working with nested lists, matrices and combinations.

NESTED LOOP FLOW
🔢 Outer Loop for x in range(3)
→
🔁 Inner Loop for y in range(3)
→
📦 Tuple (x, y)
Coordinate Pairs EXAMPLE 01 
pairs = [
    (x, y)
    for x in range(3)
    for y in range(3)
]

print(pairs)
Output: [(0,0), (0,1), (0,2), (1,0), (1,1), (1,2), (2,0), (2,1), (2,2)]
Flatten a Matrix EXAMPLE 02 
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

flat = [
    value
    for row in matrix
    for value in row
]

print(flat)
Output: [1, 2, 3, 4, 5, 6, 7, 8, 9]

FUNCTIONS

What Is a Lambda Function?

A lambda function is a small anonymous function.

Unlike a normal function defined with def, lambda functions are commonly used when a short function is required temporarily.

Key Rule

A lambda function contains a single expression, and that expression's result is returned automatically.

LAMBDA CONCEPT
📥 Arguments x
→
λ Lambda lambda x
→
⚙️ Expression x * 2
→
📤 Result 20
10
VERY IMPORTANT

Lambda Syntax

GENERAL SYNTAX 

lambda arguments : expression
One Argument EXAMPLE 01 
square = lambda x: x ** 2

print(square(5))
Output: 25
Multiple Arguments EXAMPLE 02 
add = lambda a, b: a + b

print(add(10, 20))
Output: 30
Conditional Lambda EXAMPLE 03 
check = lambda x: "Positive" if x > 0 else "Non-positive"

print(check(10))
print(check(-2))
Output: Positive Non-positive
11
FUNCTIONAL PYTHON

Lambda with map()

map() applies a function to every item of an iterable.

It is commonly combined with lambda functions for short transformations. 

map(function, iterable)
Double Every Number EXAMPLE 
numbers = [1, 2, 3, 4]

result = list(
    map(lambda x: x * 2, numbers)
)

print(result)
Output: [2, 4, 6, 8]
12
FILTERING DATA

Lambda with filter()

filter() selects items for which the supplied function evaluates to true. 

filter(function, iterable)
Select Even Numbers EXAMPLE 
numbers = [1, 2, 3, 4, 5, 6]

even = list(
    filter(lambda x: x % 2 == 0, numbers)
)

print(even)
Output: [2, 4, 6]
13
AGGREGATION

Lambda with reduce()

reduce() repeatedly applies a function to the items of an iterable to produce a single accumulated result.

It is available through the functools module. 

from functools import reduce

reduce(function, iterable)
Product of Numbers EXAMPLE 
from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(
    lambda x, y: x * y,
    numbers
)

print(result)
Output: 24

CUSTOM SORTING

Lambda with sorted()

The key argument of sorted() can receive a function that determines how elements should be compared.

Sort Tuples by Age EXAMPLE 
students = [
    ("Ravi", 25),
    ("Priya", 21),
    ("Arun", 23)
]

result = sorted(
    students,
    key=lambda x: x[1]
)

print(result)
Output: [('Priya', 21), ('Arun', 23), ('Ravi', 25)]
Sort by String Length EXAMPLE 02 
words = [
    "Python",
    "AI",
    "Programming",
    "Code"
]

result = sorted(
    words,
    key=lambda x: len(x)
)

print(result)
Output: ['AI', 'Code', 'Python', 'Programming']

KNOW THE DIFFERENCE

List Comprehension vs Lambda

Feature List Comprehension Lambda
Purpose Creates a new list. Creates a small anonymous function.
Syntax [expression for x in data] lambda x: expression
Output Usually a list. Function result.
Best For Transforming/filtering collections. Short temporary functions.
Can use with map? Yes. Yes.
Can use with filter? Can perform filtering directly. Commonly used with filter().
Same Result — Two Approaches COMPARISON 
numbers = [1, 2, 3, 4]

# List comprehension
a = [x * 2 for x in numbers]

# map + lambda
b = list(map(lambda x: x * 2, numbers))

print(a)
print(b)
Both produce: [2, 4, 6, 8]

DEBUGGING

Common Mistakes

✕

Confusing filter with transformation

filter() is primarily for selecting elements, while map() transforms each element.

✕

Writing multiple statements in lambda

Lambda is designed for one expression. Use def when the logic becomes complex.

✕

Forgetting list()

In Python 3, map() and filter() return iterators. Use list() when you need an actual list.

✕

Overusing comprehensions

Extremely complex comprehensions can become difficult to read. A normal loop may be better.

✕

Confusing if filtering with if-else output

[x for x in data if condition] filters values, while [A if condition else B for x in data] chooses the output value.

PLACEMENT PREPARATION

Python Interview Questions

1. What is list comprehension?

List comprehension is a concise syntax for creating a new list from an iterable, optionally applying conditions to filter the elements.

2. What is the general syntax of list comprehension?

The general syntax is [expression for item in iterable if condition]. The condition is optional.

3. Can list comprehension contain an if condition?

Yes. An if condition can be used to filter which elements are included in the resulting list.

4. Can list comprehension contain if-else?

Yes. A conditional expression can determine which value is placed into the resulting list.

5. What is a lambda function?

A lambda is a small anonymous function created using the lambda keyword.

6. What is the syntax of lambda?

lambda arguments : expression

7. Can lambda have multiple arguments?

Yes. A lambda can accept multiple arguments, but it contains only one expression.

8. What is the difference between def and lambda?

def creates a regular named function and supports multiple statements. Lambda is generally used for short anonymous functions containing one expression.

9. What is map()?

map() applies a function to each element of an iterable and returns an iterator.

10. What is filter()?

filter() returns an iterator containing elements for which the supplied function returns true.

11. What is reduce()?

reduce() repeatedly applies a function to combine elements into a single accumulated result.

12. Which module provides reduce()?

The reduce() function is provided by Python's functools module.

13. How can lambda be used with sorted()?

A lambda can be passed to the key parameter to define custom sorting logic.

14. Which is more readable: loop or comprehension?

For simple transformations and filters, comprehensions are often more concise. For complex logic, a normal loop may be easier to understand.

15. Can lambda contain a for loop?

A lambda cannot contain statements such as a normal for loop body. For complex operations, use a normal function with def.
