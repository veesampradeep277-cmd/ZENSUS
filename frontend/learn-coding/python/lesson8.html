CORE CONCEPT

What is a List?

💡

A List stores multiple values in one variable.

A Python list is an ordered, mutable collection that can contain multiple elements. Lists can contain duplicate values and can store different data types in the same collection.

One Variable → Multiple Values
students
→
0 "Ravi"
1 "Priya"
2 "Arun"
3 "Anu"
Python 
students = ["Ravi", "Priya", "Arun", "Anu"]

print(students)
OUTPUT ['Ravi', 'Priya', 'Arun', 'Anu']

EXTRACTING DATA

List Slicing

list[start : stop : step]
start Starting index
stop Ending index — excluded
step How far to move
Examples 
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[1:4])
print(numbers[:3])
print(numbers[3:])
print(numbers[::2])
print(numbers[::-1])
OUTPUT [20, 30, 40]
[10, 20, 30]
[40, 50, 60]
[10, 30, 50]
[60, 50, 40, 30, 20, 10]
⚠️ Important

The stop index is not included. numbers[1:4] means indexes 1, 2 and 3.

ADDING DATA

Adding List Items

append()

Add to End

numbers = [1, 2, 3]

numbers.append(4)

print(numbers)
[1, 2, 3, 4]
insert()

Add at Position

numbers = [1, 3]

numbers.insert(1, 2)

[1, 2, 3]
extend()

Add Multiple

a = [1, 2]

a.extend(b)

💡 append vs extend

append() adds one object as a single element. extend() adds elements from an iterable individually.

Remove by Index

POWERFUL PYTHON

List Comprehension

⚡

A compact way to create lists

List comprehension allows you to create a new list using an expression, a loop and optionally a condition.

[expression for item in iterable if condition]
expression Value to place in the list
for Iterates through values
if Optional filtering condition
Traditional Approach 
squares = []

for number in range(1, 6):
    squares.append(number ** 2)

print(squares)
List Comprehension 
squares = [number ** 2 for number in range(1, 6)]

print(squares)
OUTPUT [1, 4, 9, 16, 25]
With Condition 
numbers = [1, 2, 3, 4, 5, 6]

even_numbers = [
    number for number in numbers
    if number % 2 == 0
]

print(even_numbers)
OUTPUT [2, 4, 6]

REFERENCES

Copying Lists

⚠️ Important Concept

Assigning one list to another variable does not create an independent list. Both variables refer to the same list object.

Problem 
a = [1, 2, 3]

b = a

b.append(4)

print(a)
print(b)
OUTPUT [1, 2, 3, 4]
[1, 2, 3, 4]
Correct Copy 
a = [1, 2, 3]

b = a.copy()

b.append(4)

print(a)
print(b)
OUTPUT [1, 2, 3]
[1, 2, 3, 4]

Remove Duplicates

DEBUGGING

Common Mistakes

❌

Forgetting zero-based indexing

items[1] accesses the second item, not the first.

❌

Using wrong index

Accessing an index outside the list can cause IndexError.

❌

Confusing append() and extend()

append([3,4]) adds one nested list, while extend([3,4]) adds two elements.

❌

Confusing remove() and pop()

remove() uses a value; pop() uses an index.

❌

Accidentally sharing a list

b = a does not create an independent copy.

❌

Modifying while iterating

Removing or adding items to a list while looping over it can produce unexpected behavior.
