What is a Variable?

A variable is a name that refers to a value or object in a Python program.

Variables allow us to store information and use that information later in our program.

Think of a variable like a labeled box.

The label is the variable name and the value stored inside the box is the data.

Python 
name = "Pradeep"
age = 19
cgpa = 8.6

Here:

  • name refers to the string "Pradeep".
  • age refers to the integer 19.
  • cgpa refers to the floating-point value 8.6.

Dynamic Typing in Python

Python is a dynamically typed language. This means you do not need to explicitly declare the data type of a variable when creating it.

Python 
x = 10
x = "Hello"
x = 3.14

The same variable name can refer to objects of different types at different points in the program.

Important:

The variable itself does not permanently have one type. The object it refers to has a type.

🔗

Multiple Assignment

Python allows multiple variables to be assigned in a single statement. 

x, y, z = 10, 20, 30

This assigns:

  • x = 10
  • y = 20
  • z = 30

Same Value to Multiple Variables 

a = b = c = 100
🔒

Constants in Python

Python does not provide a special keyword that makes a variable truly constant.

Instead, programmers use uppercase names to indicate that a value should not normally be changed. 

PI = 3.14159
MAX_USERS = 100
APP_NAME = "ZENSUS"
Convention:

Uppercase variable names communicate that the value is intended to remain constant.

🧬

What is a Data Type?

A data type defines the kind of value an object represents and determines what operations can meaningfully be performed on it.

Example:

The value 25 is an integer, while "25" is a string. 

age = 25
int 
age = "25"
str

1. Integer — int

Whole numbers without a fractional component. 

age = 19
students = 60

Integers can be positive, negative or zero.

2. Floating-Point — float

Numbers containing a fractional component. 

price = 99.50
cgpa = 8.63

Type: float

3. Complex Numbers — complex

Python supports complex numbers containing a real part and an imaginary part. 

z = 3 + 4j

The imaginary component is represented using j.

Type: complex

4. Boolean — bool

Represents logical truth values.

Boolean values are:

True Logical yes / condition satisfied
False Logical no / condition not satisfied
Type: bool

6. List — list

An ordered, mutable collection of objects. 

languages = [
    "Python",
    "Java",
    "C++"

Lists can contain multiple values and can be modified after creation.

Important properties:

Ordered • Mutable • Allows duplicate values

7. Tuple — tuple

An ordered, immutable collection. 

coordinates = (10, 20)

Important properties:

Ordered • Immutable • Allows duplicate values

Type: tuple
🧩

8. Set — set

An unordered collection of unique elements. 

numbers = {1, 2, 3, 4}
unique_numbers = {1, 2, 2, 3}

Duplicate elements are removed from a set.

Important properties:

Unique elements • Mutable • No indexing

Type: set
🗂️

9. Dictionary — dict

Stores data as key-value pairs. 

student = {
    "name": "Pradeep",
    "age": 19,
    "course": "CSE"
}

Each key is associated with a value.

Example:

"name" is the key and "Pradeep" is its value.

Type: dict
🔢

10. Range — range

Represents an immutable sequence of numbers. 

numbers = range(5)

This represents the sequence:

0, 1, 2, 3, 4
Type: range
⭕

11. None — NoneType

Represents the absence of a value.

None is commonly used when a variable does not currently contain a meaningful value.

Type: NoneType

Finding the Type of a Value

Python provides the built-in type() function to determine the type of an object. 

age = 19

print(type(age))
Terminal Output 
<class 'int'>

More Examples 

print(type(10))
print(type(10.5))
print(type("Python"))
print(type(True))
print(type([1, 2, 3]))
✅

Checking Types with isinstance()

isinstance() checks whether an object belongs to a particular type or class. 

age = 19

print(isinstance(age, int))
True

Explicit Type Conversion

Implicit Type Conversion

Python can automatically convert certain numeric values to a compatible type during an operation. 

x = 10
y = 2.5

result = x + y

print(result)
print(type(result))
12.5
<class 'float'>
Remember:

Automatic conversion does not happen for every combination of types.

Common Beginner Mistakes

❌
Starting a variable name with a number 
2name = "Python"

Identifiers cannot start with a digit.

❌
Confusing strings and numbers 
age = "19"

This is a string, not an integer.

❌
Using = when you mean comparison 
age = 20

= assigns a value. Comparison uses operators such as ==.

❌
Assuming every conversion is possible 
int("Python")

This raises a conversion error because the text does not represent an integer.
