FUNDAMENTALS

What is File Handling?

File handling is the process of interacting with files using a programming language.

Python allows you to create, open, read, write, append, and manage files stored on your computer.

💡 Key Idea

Variables store data temporarily while a file allows data to remain available even after your Python program stops running.

05
OPENING FILES

The open() Function

The open() function creates a connection between your Python program and a file.

Important Syntax

file = open("filename", "mode")
filename Name or path of the file
mode Specifies what operation you want
Example 01 Opening a File 
file = open("student.txt", "r")

print(file)

file.close()
06
ACCESS MODES

Python File Modes

Mode Meaning File Required? Important Behavior
r Read Yes Reads existing content
w Write No Creates or overwrites
a Append No Adds at the end
x Create No Fails if file exists
r+ Read + Write Yes Read and modify
w+ Write + Read No Overwrites first
a+ Append + Read No Preserves existing data
rb Read Binary Yes Reads bytes
wb Write Binary No Writes bytes
⚠️ Interview Tip

The most important modes to remember are r, w, a, x, rb, and wb.

07
READING

Reading Files

📖

read()

Reads the entire file or a specified number of characters. 

file.read()
📄

readline()

Reads one line from the file. 

file.readline()
📚

readlines()

Reads all lines and returns them as a list. 

file.readlines()
Example 02 read() 
with open("student.txt", "r") as file:
    data = file.read()

print(data)
Output → Complete contents of student.txt
Example 03 readline() 
with open("student.txt", "r") as file:

    line1 = file.readline()
    line2 = file.readline()

    print(line1)
    print(line2)
Example 04 Read Line by Line 
with open("student.txt", "r") as file:

    for line in file:
        print(line.strip())
08
WRITING

Writing to Files

The w mode is used to write data into a file.

If the file already exists, w mode replaces its existing content.

Example 05 write() 
with open("student.txt", "w") as file:

    file.write("Name: Pradeep\n")
    file.write("Course: Python\n")
    file.write("Level: Beginner")
Example 06 writelines() 
students = [
    "Rahul\n",
    "Priya\n",
    "Arjun\n"
]

with open("students.txt", "w") as file:
    file.writelines(students)
⚠️ Remember

Never use w mode when you want to preserve existing content. Use a for appending.

11
BEST PRACTICE

The with Statement

The with statement is the recommended way to work with files in normal Python programs.

It automatically closes the file when the block finishes, even if an exception occurs.

Manual Approach Recommended Approach 
file = open("data.txt", "r")

data = file.read()

file.close()
 
with open("data.txt", "r") as file:
    data = file.read()
⭐ Professional Practice

Prefer with open(...) because it makes resource management safer and cleaner.

14
BINARY DATA

Working with Binary Files

Binary files store raw bytes rather than normal human-readable text.

They are commonly used for images, PDFs, audio, videos, and other non-text data.

Example 10 Read Binary Data 
with open("image.jpg", "rb") as file:

    data = file.read()

print(len(data))
Example 11 Copy Binary File 
with open("source.jpg", "rb") as source:
    data = source.read()

with open("copy.jpg", "wb") as target:
    target.write(data)
15
FILE LOCATIONS

File Paths

📁

Relative Path

open("data.txt")

Refers to a location relative to the current working directory.

🗂️

Nested Path

open("data/students.txt")

Refers to a file inside another folder.

💻

Absolute Path

open("/project/data.txt")

Specifies the complete file location.

💡 Best Practice

For portable applications, prefer pathlib.Path for modern path handling instead of hard-coding operating-system specific paths.

File Handling Exceptions

Exception Meaning

Example 12 Handling Missing Files

    with open("students.txt", "r") as file:

STRUCTURED DATA

Working with JSON Files

JSON is widely used for storing and exchanging structured data.

Python provides the built-in json module for working with JSON.

Example 13 Write JSON 
import json

student = {
    "name": "Pradeep",
    "age": 20,
    "course": "Python"
}

with open("student.json", "w") as file:
    json.dump(student, file, indent=4)
Example 14 Read JSON 
import json

with open("student.json", "r") as file:
    student = json.load(file)

print(student["name"])
18
TABULAR DATA

Working with CSV Files

CSV stands for Comma-Separated Values.

CSV files are commonly used for student data, employee records, datasets, reports, and spreadsheet-style information.

Example 15 Write CSV 
import csv

students = [
    ["Name", "Marks"],
    ["Pradeep", 90],
    ["Rahul", 85],
    ["Priya", 95]
]

with open("students.csv", "w", newline="") as file:

    writer = csv.writer(file)

    writer.writerows(students)
Example 16 Read CSV 
import csv

with open("students.csv", "r") as file:

    reader = csv.reader(file)

    for row in reader:
        print(row)

DEBUGGING

Common File Handling Mistakes

❌

Forgetting to Close the File

Use with open() whenever possible.

❌

Using w Instead of a

w can overwrite existing content.

❌

Wrong File Path

Verify the file location and current working directory.

❌

Ignoring Exceptions

Handle expected errors such as FileNotFoundError.

❌

Reading Huge Files at Once

For large files, consider processing them line by line or in chunks.

❌

Ignoring Encoding

For text files, explicitly specifying an encoding such as UTF-8 can improve portability.

HANDS-ON

Important File Handling Programs

Program 01 Count Lines 
count = 0

with open("data.txt", "r") as file:

    for line in file:
        count += 1

print("Number of lines:", count)
Program 02 Count Words 
with open("data.txt", "r") as file:

    text = file.read()

words = text.split()

print("Number of words:", len(words))
Program 03 Copy File 
with open("source.txt", "r") as source:

    data = source.read()

with open("copy.txt", "w") as target:

    target.write(data)

print("File copied successfully")
Program 04 Search a Word 
word = input("Enter word: ")

with open("data.txt", "r") as file:

    content = file.read()

if word in content:
    print("Word found")
else:
    print("Word not found")
Program 05 Student Record 
name = input("Enter name: ")
marks = input("Enter marks: ")

with open("students.txt", "a") as file:

    file.write(f"{name} - {marks}\n")

INTERVIEW PREPARATION

Python File Handling Interview Questions

1. What is file handling in Python?

File handling is the process of creating, opening, reading, writing, appending, and managing files using Python.

2. Which function is used to open a file?

The built-in open() function is used to open a file.

3. What is the difference between r, w and a?

r reads an existing file, w writes and can overwrite existing content, while a adds content at the end.

4. What happens if a file does not exist in r mode?

Python raises a FileNotFoundError.

5. What is the difference between w and a?

w replaces existing content, whereas a preserves existing content and adds new data at the end.

6. What is the purpose of with open()?

It provides automatic resource management and closes the file when the block finishes.

7. Difference between read(), readline() and readlines()?

read() reads content, readline() reads one line, and readlines() returns multiple lines as a list.

8. What is seek()?

seek() moves the file cursor to a specified position.

9. What does tell() return?

tell() returns the current position of the file cursor.

10. What is binary file handling?

Binary file handling works with raw bytes and is commonly used for images, PDFs, audio, and video.

11. What is the difference between text and binary mode?

Text mode works with decoded text while binary mode works directly with bytes.

12. What is FileNotFoundError?

It occurs when Python tries to access a file that does not exist at the specified location.

13. Why should encoding be specified?

Explicit encoding helps Python interpret text consistently across different environments.

14. What is JSON?

JSON is a lightweight structured data format commonly used to store and exchange data between applications.

15. What is CSV?

CSV stands for Comma-Separated Values and is commonly used for tabular data.
