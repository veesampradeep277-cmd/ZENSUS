02 What is a Variable?

A variable is a named memory location used to store a value that can change during program execution.

Simple Definition

A variable is a container with a name, a data type and a value.

C 
int age = 19;

Here:

  • int → data type
  • age → variable name
  • 19 → value
  • = → assignment operator

Real-World Analogy

Think of a variable as a labeled box.

Physical Box

Label: Age

Content: 19

C Variable

Name: age

Value: 19

What happens when the value changes?

C 
int age = 19;

age = 20;

The variable age still refers to the same variable, but its stored value is changed to 20.

05 Initialization, Assignment & Reassignment

Declaration

int age;

Creates/declares a variable but does not give it a meaningful value.

Initialization

int age = 19;

Gives a value when the variable is declared.

Assignment

age = 20;

Stores a new value in an existing variable.

Reassignment

age = 21;

Changes the previously stored value.

Complete Example

C 
#include <stdio.h>

int main() {

    int age = 19;

    printf("Age = %d\n", age);

    age = 20;

    printf("New Age = %d\n", age);

    return 0;
}

06 Identifiers

Identifiers are names used for variables, functions, arrays, structures and other program elements.

✓ Valid Identifiers

  • age
  • studentName
  • total_marks
  • num1
  • _count

✗ Invalid Identifiers

  • 2age
  • student-name
  • total marks
  • float
  • @price

Important Rules

  1. Must begin with a letter or underscore.
  2. Cannot begin with a number.
  3. Can contain letters, digits and underscores.
  4. Cannot contain spaces.
  5. Cannot be a C keyword.
  6. C identifiers are case-sensitive.

Case Sensitivity

int age = 19;
int Age = 20;

printf("%d", age);   // 19
printf("%d", Age);   // 20

age and Age are two different identifiers in C.

10 Type Modifiers

Modifiers change the range or representation of integer and other applicable types.

signed

Can represent both negative and non-negative values. 

signed int temperature = -10;

unsigned

Represents only non-negative values for integer types, providing a larger positive range. 

unsigned int count = 100;

short

Specifies a short integer type. 

short int marks = 95;

long

Specifies a long integer type. 

long int population = 1000000L;

Important

Do not memorize sizes blindly. C defines minimum ranges and relationships, while actual sizes depend on the implementation. For portable programs, use sizeof() and the limits provided by headers such as <limits.h>.

11 sizeof() Operator

The sizeof operator tells you the size, in bytes, of a type or object. 

#include <stdio.h>

int main() {

    printf("char   = %zu bytes\n", sizeof(char));
    printf("int    = %zu bytes\n", sizeof(int));
    printf("float  = %zu bytes\n", sizeof(float));
    printf("double = %zu bytes\n", sizeof(double));

    return 0;
}

The result can vary between systems, except that sizeof(char) is always 1.

Why is %zu used?

sizeof produces a value of type size_t. The portable printf conversion specifier for size_t is %zu.

12 Format Specifiers

Format specifiers tell functions such as printf and scanf how a value should be interpreted.

Data printf Example Example
int %d 25
unsigned int %u 25
char %c 'A'
float %f 3.14
double %f 3.14159
string %s "ZENSUS"
size_t %zu 8

Important scanf Difference

For scanf, a pointer is generally required for ordinary variables. 

int age;

scanf("%d", &age);

The & gives the address of the variable so that scanf can store the input there.

13 char and ASCII

A char stores a character representation, while character constants such as 'A' have integer values in C's execution character set. 

#include <stdio.h>

int main() {

    char ch = 'A';

    printf("Character = %c\n", ch);
    printf("Numeric value = %d\n", ch);

    return 0;
}

On systems using ASCII, 'A' corresponds to 65. More generally, C defines a character set; ASCII is a common implementation.

15 Type Conversion

Type conversion happens when a value is converted from one data type to another.

Implicit Conversion

The compiler performs the conversion automatically according to C's conversion rules. 

int a = 10;
double b = a;

printf("%f", b);

Here, the integer value can be converted to double for the assignment.

Explicit Conversion

The programmer explicitly requests a conversion using a cast. 

double price = 99.99;

int value = (int)price;

printf("%d", value);

The fractional part is discarded when converting this positive floating value to int.

Type Casting Visualization

double

→
int

⚠ Integer Division Trap

int a = 5;
int b = 2;

printf("%d\n", a / b);

Output: 

2

Because both operands are integers, integer division is performed. 

printf("%f\n", (double)a / b);

Now the calculation uses floating-point arithmetic.

17 Overflow & Underflow

A type has a finite representable range. Going beyond that range can cause problems and, for unsigned integer arithmetic, operations are defined modulo one more than the maximum value.

Overflow

Occurs when an integer calculation attempts to produce a value outside the representable range. 

#include <limits.h>

int x = INT_MAX;

Check Limits

#include <stdio.h>
#include <limits.h>

int main() {

    printf("INT_MIN = %d\n", INT_MIN);
    printf("INT_MAX = %d\n", INT_MAX);

    return 0;
}

Exam Warning

Do not assume every overflow behaves the same way. In particular, signed integer overflow in C is undefined behavior.

18 Scope & Lifetime Basics

Scope

Scope describes where an identifier can be accessed in the source program.

Lifetime

Lifetime describes how long an object exists during program execution.

Local Variable Example

#include <stdio.h>

int main() {

    int age = 19;

    {
        int marks = 90;

        printf("%d\n", age);
        printf("%d\n", marks);
    }

    return 0;
}

The variable marks is declared inside the inner block and its identifier is scoped to that block.

21 Common Mistakes

These mistakes frequently appear in beginner programs and exams.

×
Using an undeclared variable 
age = 19;

Declare it first: int age = 19;

×
Using double quotes for char 
char grade = "A";

A character constant uses single quotes: char grade = 'A';

×
Forgetting scanf's address operator 
scanf("%d", age);

Normally: scanf("%d", &age);

×
Expecting decimal result from integer division 
int result = 5 / 2;

Result is 2, not 2.5.

×
Confusing assignment and equality 
x = 10;     // assignment
x == 10;    // comparison

25 Interview Questions

These questions help you move beyond memorization.

1. What is a variable in C?
A variable is an object with a name and a type whose stored value can generally be modified during its lifetime.
2. What is the difference between declaration and initialization?
Declaration introduces the variable and its type. Initialization gives it its initial value.
3. What is the difference between float and double?
Both represent floating-point values, but double normally provides greater precision and commonly uses more storage. Exact representation depends on the implementation.
4. What does sizeof return?
sizeof produces the size of its operand in bytes, with result type size_t.
5. What is type casting?
Type casting is an explicit conversion requested by the programmer, for example: (double)x.
6. Why does 5 / 2 produce 2?
Both operands are integers, so integer division is performed and the fractional part is not retained in the integer result.
7. Is char an integer type in C?
Yes. char is an integer type in C. Whether plain char behaves as signed or unsigned is implementation-defined.
8. What happens when signed integer arithmetic overflows?
Signed integer overflow is undefined behavior in C. This is an important distinction from unsigned integer arithmetic.
