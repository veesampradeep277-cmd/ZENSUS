02 • The Big Idea

Why do we need Dynamic Memory?

Traditional arrays have a size that is normally fixed when the array object is created. But real applications often don't know how much memory they will need beforehand.


❌ Fixed-size approach

int marks[100];

What if only 5 students exist? You reserve space for 100.

✅ Dynamic approach

int *marks;

marks = malloc(n * sizeof *marks);

Allocate memory according to the actual runtime requirement.

05 • malloc()

malloc() — Allocate memory at runtime

malloc()

malloc stands for memory allocation. It requests a block of memory containing the requested number of bytes. 

#include <stdlib.h>

int *p;

p = malloc(5 * sizeof *p);
Return value: On success, malloc returns a pointer to the allocated block. On failure, it returns NULL.

🎬 malloc() Animation

Complete malloc() example

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;

    int *p = malloc(n * sizeof *p);

    if (p == NULL)
    {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        p[i] = (i + 1) * 10;
        printf("%d ", p[i]);
    }

    free(p);

    return 0;
}
Uninitialized memory: malloc does not initialize the allocated bytes. Reading an element before storing a valid value is a bug.
06 • calloc()

calloc() — Allocate and initialize

calloc()

calloc allocates space for an array of elements and initializes all allocated bytes to zero. 

int *p;

p = calloc(5, sizeof *p);

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5;

    int *p = calloc(n, sizeof *p);

    if (p == NULL)
    {
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", p[i]);
    }

    free(p);

    return 0;
}
malloc vs calloc: malloc takes the total number of bytes. calloc takes a number of elements and the size of each element.

08 • realloc()

realloc() — Resize dynamic memory

realloc()

realloc() changes the size of a previously allocated memory block. 

int *temp = realloc(p, newSize * sizeof *p);
Critical rule: Do not directly overwrite your only pointer with realloc if failure would cause you to lose the original block.

Safe realloc pattern

int *temp;

temp = realloc(p, newSize * sizeof *p);

if (temp == NULL)
{
    /* Original p is still valid */
}
else
{
    p = temp;
}
Why temp? If realloc fails, the original block remains allocated and the original pointer can still be used or freed.

14 • Dynamic Arrays

Create arrays at runtime

Dynamic memory is particularly useful when the number of elements is known only while the program is running. 

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    if (n <= 0)
    {
        return 1;
    }

    int *arr = malloc((size_t)n * sizeof *arr);

    if (arr == NULL)
    {
        printf("Allocation failed\n");
        return 1;
    }

    for (int i = 0; i < n; i++)
    {
        scanf("%d", &arr[i]);
    }

    for (int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    free(arr);

    return 0;
}
Key connection: arr[i] works with a dynamically allocated array because the pointer returned by malloc points to contiguous storage suitable for the allocated elements.
15 • Dynamic 2D Arrays

Dynamic matrix allocation

Method 1 — Single contiguous block

int rows = 3;
int cols = 4;

int *matrix = malloc(
    (size_t)rows * cols * sizeof *matrix
);

if (matrix == NULL)
{
    return 1;
}

matrix[i * cols + j] = 50;

free(matrix);
Index formula:
matrix[i * cols + j]

This stores the entire matrix in one contiguous allocation.

Method 2 — Array of row pointers

int **matrix = malloc(rows * sizeof *matrix);

if (matrix == NULL)
{
    return 1;
}

for (int i = 0; i < rows; i++)
{
    matrix[i] = malloc(cols * sizeof *matrix[i]);

    if (matrix[i] == NULL)
    {
        /* cleanup previously allocated rows */
    }
}

/* use matrix[i][j] */

/* free each row */
for (int i = 0; i < rows; i++)
{
    free(matrix[i]);
}

free(matrix);
Important: int ** is not automatically the same thing as a pointer to a contiguous 2D array. These are different memory layouts.
16 • Dynamic Strings

Dynamic character storage

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    const char *source = "ZENSUS";

    char *name = malloc(strlen(source) + 1);

    if (name == NULL)
    {
        return 1;
    }

    strcpy(name, source);

    printf("%s\n", name);

    free(name);

    return 0;
}
Why +1? A C string needs space for its terminating '\0' character.
17 • Dynamic Structures

Allocate structures dynamically

#include <stdio.h>
#include <stdlib.h>

struct Student
{
    int roll;
    char name[50];
    float cgpa;
};

int main(void)
{
    struct Student *s =
        malloc(sizeof *s);

    if (s == NULL)
    {
        return 1;
    }

    s->roll = 101;
    s->cgpa = 8.8f;

    printf("Roll: %d\n", s->roll);
    printf("CGPA: %.2f\n", s->cgpa);

    free(s);

    return 0;
}
Remember: For a pointer to a structure, s->roll is the convenient equivalent of (*s).roll.

19 • Memory Leaks

Memory Leak — the silent problem

A memory leak occurs when dynamically allocated memory remains allocated but the program loses the ability to access and release it. 

int *p = malloc(100 * sizeof *p);

/* use p */

p = NULL;   // ❌ lost the allocation

/* original block can no longer be freed through p */

❌ Leak

Allocation still exists but pointer was lost.

✅ Correct

free(p)

Memory is explicitly released.

20 • Dangling Pointers

Dangling Pointer

int *p = malloc(sizeof *p);

*p = 50;

free(p);

/* ❌ p is now a dangling pointer */
printf("%d", *p);
Never dereference a pointer after its pointed-to storage has been released.

Safer pattern

free(p);
p = NULL;

Setting that particular pointer variable to NULL makes accidental use through that variable easier to detect. It does not magically invalidate other aliases pointing to the same released storage.

21 • Double Free

Never release the same allocation twice

int *p = malloc(sizeof *p);

free(p);

free(p);   // ❌ invalid: double free
Safer pattern: 
free(p);
p = NULL;

free(p);   // free(NULL) is safe
In C, calling free(NULL) has no effect.
22 • Use After Free

Use-after-free

int *p = malloc(sizeof *p);

*p = 100;

free(p);

/* ❌ Undefined behavior */
*p = 200;
Rule: Once storage is released, stop using it through the pointer.
23 • Allocation Failure

What if malloc() returns NULL?

int *p = malloc(1000000000ULL * sizeof *p);

if (p == NULL)
{
    printf("Allocation failed\n");
    return 1;
}
Never assume allocation always succeeds. A robust program checks the returned pointer before dereferencing it.
24 • sizeof()

The safest allocation-size pattern

int *p = malloc(n * sizeof *p);

This is preferable to manually writing sizeof(int) because the allocation remains naturally tied to the type of the pointer. 

struct Student *s =
    malloc(n * sizeof *s);
Exam tip: sizeof *p means the size of the object that p points to.
25 • Advanced Safety

Watch for size calculation overflow

When calculating the number of bytes, multiplying large values can overflow the integer type before malloc receives the result. 

size_t bytes;

if (n != 0 && size > SIZE_MAX / n)
{
    /* multiplication would overflow */
}

Production-quality code should validate sizes before performing potentially overflowing calculations.

28 • Complete Programs

Interview-ready examples

Example 1 — Sum of dynamic array

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n;

    scanf("%d", &n);

    if (n <= 0)
        return 1;

    int *a = malloc((size_t)n * sizeof *a);

    if (a == NULL)
        return 1;

    long long sum = 0;

    for (int i = 0; i < n; i++)
    {
        scanf("%d", &a[i]);
        sum += a[i];
    }

    printf("Sum = %lld\n", sum);

    free(a);

    return 0;
}

Example 2 — Dynamic array growth

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t capacity = 2;
    size_t size = 0;

    int *a = malloc(capacity * sizeof *a);

    if (a == NULL)
        return 1;

    for (int value = 10; value <= 50; value += 10)
    {
        if (size == capacity)
        {
            size_t newCapacity = capacity * 2;

            int *temp =
                realloc(a, newCapacity * sizeof *a);

            if (temp == NULL)
            {
                free(a);
                return 1;
            }

            a = temp;
            capacity = newCapacity;
        }

        a[size++] = value;
    }

    for (size_t i = 0; i < size; i++)
        printf("%d ", a[i]);

    free(a);

    return 0;
}
This is the basic idea behind a dynamically growing array. Many real libraries use more sophisticated growth strategies, but the core concept is allocation + resizing + copying/preservation.

Example 3 — calloc for counters

int *frequency = calloc(26, sizeof *frequency);

if (frequency == NULL)
{
    return 1;
}

/* frequency[0] ... frequency[25] start at zero */

free(frequency);

30 • Real World

Where is Dynamic Memory used?

🌐 Web Servers

Request data may require memory whose size is known only at runtime.

🎮 Games

Dynamic objects, entities and resources can be created and destroyed during execution.

🧠 Data Structures

Linked lists, trees, graphs and many other structures rely heavily on dynamic allocation.

📷 Image Processing

Image dimensions and buffers may vary at runtime.

📊 Databases

Runtime buffers and temporary structures often require dynamically managed storage.

⚙️ Operating Systems

Systems software constantly manages memory resources, although user-level allocation is mediated by libraries and the operating system.

32 • Common Mistakes

🚨 Mistakes students frequently make

❌
Not checking malloc()

Dereferencing NULL after allocation failure is invalid.

❌
Forgetting free()

Repeated allocations without releasing them can cause memory leaks.

❌
Using memory after free()

This creates use-after-free and undefined behavior.

❌
Double free

Calling free twice on the same allocation is invalid.

❌
Wrong sizeof expression

Prefer sizeof *p or sizeof(array[0]) when appropriate.

❌
Unsafe realloc assignment

Use a temporary pointer when you need to preserve the original allocation on failure.

❌
Assuming malloc initializes memory

malloc does not initialize the allocated bytes.

33 • Best Practices

Professional memory-management habits

  • Always check allocation results before use.
  • Use sizeof *pointer to reduce type duplication.
  • Free every allocation when ownership is finished.
  • After freeing, set the owning pointer to NULL when appropriate.
  • Do not dereference freed memory.
  • Do not free the same allocation twice.
  • Use a temporary pointer for failure-safe realloc().
  • Validate user-controlled sizes before allocation.
  • Keep ownership rules clear in larger programs.
  • Use memory-analysis tools during debugging.

36 • Interview Preparation

🎤 Interview Questions

Dynamic memory allocation is the process of requesting and releasing storage during program execution, commonly using malloc(), calloc(), realloc() and free().
malloc() accepts a number of bytes and leaves the allocated bytes uninitialized. calloc() accepts a count and element size and initializes all allocated bytes to zero.
malloc() returns NULL when it cannot satisfy the allocation request.
malloc() returns void*. In C, void* converts implicitly to an object pointer type. Adding a cast is unnecessary and can hide missing declarations in older-style code.
A memory leak occurs when allocated memory is no longer reachable by the program and therefore cannot be released normally.
A dangling pointer is a pointer whose pointed-to storage is no longer valid, for example after the allocated block has been freed.
realloc() may allocate another block, preserve the old contents up to the appropriate amount, release the old block and return the new address.
Yes. Calling free() with a null pointer has no effect.
You should not rely on malloc() for initialization. Use calloc() when you need the allocated bytes initialized to zero.
