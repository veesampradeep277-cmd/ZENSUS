3 Output Using printf()

printf() is the most commonly used function for displaying formatted output on the screen.

basic_output.c 
#include <stdio.h>

int main() {

    printf("Hello, ZENSUS!");

    return 0;
}

Understanding the statement

Part Meaning
#include <stdio.h> Provides standard input/output functions.
printf() Displays formatted output.
"Hello, ZENSUS!" String literal to display.
; Terminates the C statement.

Printing Variables

variables_output.c 
#include <stdio.h>

int main() {

    int age = 19;
    float cgpa = 8.63;

    printf("Age = %d\n", age);
    printf("CGPA = %.2f\n", cgpa);

    return 0;
}
Important pattern printf("format string", value1, value2, ...); The format specifier tells printf() how the value should be displayed.

4 Format Specifiers

Format specifiers are placeholders that tell C how to interpret and display a value.

%d Integer Example: 25
%f Floating-point Example: 12.50
%c Character Example: A
%s String Example: Hello
%lf double input Used with scanf()
%u Unsigned int Non-negative integer
%x Hexadecimal Example: FF
%o Octal Example: 17
%p Address Pointer address
Important distinction For printf(), %f is used to print a floating-point value such as a double. For scanf(), %f is used for float, while %lf is used for double.

Example

format_demo.c 
#include <stdio.h>

int main() {

    int marks = 95;
    float percentage = 95.5f;
    char grade = 'A';

    printf("Marks      : %d\n", marks);
    printf("Percentage : %.1f\n", percentage);
    printf("Grade      : %c\n", grade);

    return 0;
}

5 Input Using scanf()

scanf() reads formatted input from standard input, usually the keyboard.

integer_input.c 
#include <stdio.h>

int main() {

    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}

Why do we use &?

The & operator gives the memory address of a variable. scanf() needs that address so it knows where to store the input.

Variable
age 19
→
Memory Address
0x7ffe21 age
Remember scanf("%d", &age); means: Read an integer → find the address of age → store the integer there.

Multiple Inputs

multiple_input.c 
#include <stdio.h>

int main() {

    int a, b;

    printf("Enter two numbers: ");

    scanf("%d %d", &a, &b);

    printf("Sum = %d\n", a + b);

    return 0;
}

6 Understanding the Input Buffer

One of the most important concepts for beginners is understanding what happens to characters typed on the keyboard.

⌨️ What happens when you type?

Suppose you type 25 and press Enter.

2
5
\n
→
Input Buffer
→
scanf()

When you press Enter, the newline character \n is also placed into the input stream. Some input functions can encounter that leftover newline.

Classic beginner problem After reading an integer using scanf(), immediately using getchar() or scanf("%c", ...) may read the leftover newline instead of the character you intended.

Example of the problem

buffer_problem.c 
#include <stdio.h>

int main() {

    int age;
    char grade;

    scanf("%d", &age);
    scanf("%c", &grade);

    printf("Grade = %c", grade);

    return 0;
}

If the user enters: 

19
A

The second scanf() may consume the newline left after 19.

One common solution

buffer_solution.c 
#include <stdio.h>

int main() {

    int age;
    char grade;

    scanf("%d", &age);
    getchar();

    scanf("%c", &grade);

    printf("Grade = %c", grade);

    return 0;
}
Better practical rule For larger string input, prefer fgets() rather than trying to solve every input situation with scanf().

8 String Input

A string in C is a sequence of characters terminated by the null character '\0'.

Using scanf("%s")

string_scanf.c 
#include <stdio.h>

int main() {

    char name[30];

    printf("Enter your name: ");
    scanf("%29s", name);

    printf("Hello %s!", name);

    return 0;
}
Important For a character array used as a string, you generally do not write & before the array name in scanf("%s", name). The array expression already supplies an address to its first element. Also, %s stops at whitespace, so it cannot read a full sentence or a name containing spaces.

Using fgets()

string_fgets.c 
#include <stdio.h>

int main() {

    char name[50];

    printf("Enter your full name: ");

    fgets(name, sizeof(name), stdin);

    printf("Hello %s", name);

    return 0;
}

✓ fgets()

  • Can read spaces.
  • Receives maximum size.
  • Better suited for lines of text.
  • Useful for safer string input.

⚠ scanf("%s")

  • Stops at whitespace.
  • Must carefully limit input width.
  • Simple for one-word input.
  • Can be unsafe if width is omitted.

puts()

puts.c 
#include <stdio.h>

int main() {

    char message[] = "Welcome to ZENSUS";

    puts(message);

    return 0;
}

puts() prints a string and automatically appends a newline.

9 Escape Sequences

Escape sequences represent special characters inside C strings and character literals.

Escape Meaning Example
\n New line printf("A\nB");
\t Horizontal tab printf("A\tB");
\\ Backslash printf("\\");
\" Double quote printf("\"Hello\"");
\' Single quote printf("\'A\'");
\0 Null character String termination

Example

escape.c 
#include <stdio.h>

int main() {

    printf("Name:\tPradeep\n");
    printf("Course:\tC Programming\n");
    printf("Status:\tLearning");

    return 0;
}
Visual idea \n moves the cursor to the next line. \t moves the cursor to the next tab position.

10 Professional Output Formatting

Good programmers don't just produce correct output — they make output readable.

Decimal Precision

precision.c 
#include <stdio.h>

int main() {

    float pi = 3.1415926;

    printf("%f\n", pi);
    printf("%.2f\n", pi);
    printf("%.3f\n", pi);

    return 0;
}

Possible output:

3.141593
3.14
3.142

Width

printf("%5d", 42);

The number 42 is displayed using a minimum field width of 5 characters.

Left Alignment

printf("%-10d", 42);

Building a Student Report

student_report.c 
#include <stdio.h>

int main() {

    char name[] = "Pradeep";
    int age = 19;
    float cgpa = 8.63;

    printf("============================\n");
    printf("       STUDENT REPORT       \n");
    printf("============================\n");

    printf("Name : %-15s\n", name);
    printf("Age  : %-15d\n", age);
    printf("CGPA : %.2f\n", cgpa);

    printf("============================\n");

    return 0;
}

12 Input, Data Types & Conversion

The format specifier must match the expected data type.

different_inputs.c 
#include <stdio.h>

int main() {

    int age;
    float height;
    char grade;

    printf("Enter age: ");
    scanf("%d", &age);

    printf("Enter height: ");
    scanf("%f", &height);

    printf("Enter grade: ");
    scanf(" %c", &grade);

    printf("\nAge = %d", age);
    printf("\nHeight = %.2f", height);
    printf("\nGrade = %c", grade);

    return 0;
}
Why is there a space before %c? scanf(" %c", &grade); The leading whitespace tells scanf() to skip whitespace characters such as spaces and newlines before reading the character.

Important input combinations

Variable scanf()
int scanf("%d", &x);
float scanf("%f", &x);
double scanf("%lf", &x);
char scanf(" %c", &x);
string array scanf("%s", x);

13 Advanced: scanf() Return Value

A powerful but often ignored feature: scanf() returns the number of input items successfully matched and assigned.

scanf_return.c 
#include <stdio.h>

int main() {

    int age;

    printf("Enter age: ");

    if (scanf("%d", &age) == 1) {
        printf("Valid input: %d", age);
    } else {
        printf("Invalid input");
    }

    return 0;
}
Why this matters This lets programs detect whether the user entered the expected kind of data. For example: scanf("%d", &age) == 1 means one integer was successfully read.

14 Common Mistakes

❌ Forgetting & in scanf()

scanf("%d", age);

For an ordinary scalar variable, use: 

scanf("%d", &age);

❌ Wrong format specifier

float x;
scanf("%d", &x);

The format should match the expected type: 

scanf("%f", &x);

❌ Unsafe %s usage

char name[10];
scanf("%s", name);

A long input can exceed the array capacity. Use a width or prefer fgets().

❌ Character input after integer

scanf("%d", &age);
scanf("%c", &grade);

The newline can be consumed. Use suitable whitespace handling, such as scanf(" %c", &grade), or another appropriate input strategy.

❌ Missing newline in output

printf("Hello");
printf("World");

Both strings may appear on the same line.

❌ Confusing %f and %lf

Remember the distinction between printf() and scanf().

Imagine a simple college result system.

result.c 
#include <stdio.h>

int main() {

    int m1, m2, m3;
    float average;

    printf("Enter marks of three subjects: ");

    scanf("%d %d %d", &m1, &m2, &m3);

    average = (m1 + m2 + m3) / 3.0f;

    printf("\nAverage = %.2f\n", average);

    if (average >= 40)
        printf("Result = PASS\n");
    else
        printf("Result = FAIL\n");

    return 0;
}

Processing → arithmetic expression
Decision → if
