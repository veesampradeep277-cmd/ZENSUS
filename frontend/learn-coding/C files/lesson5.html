What is Decision Making?

A program often needs to execute different statements depending on whether a condition is true or false.

condition
?
Decision
Important: In C, a condition is considered true when its value is non-zero and false when its value is zero.

True

Any non-zero integer value is treated as true. 

if (5)
{
    printf("True");
}

False

Zero is treated as false. 

if (0)
{
    printf("This will not execute");
}

05

if Statement

The if statement executes a block only when its condition is true.

Syntax

if (condition)
{
    // statements
}

Example

#include <stdio.h>

int main()
{
    int age = 20;

    if (age >= 18)
    {
        printf("Eligible to vote");
    }

    return 0;
}
Execution: age ≥ 18 → condition becomes true → statement executes.

→
age >= 18
→

→

07

else-if Ladder

Use an else-if ladder when you need to test multiple conditions.

Grade Example

#include <stdio.h>

int main()
{
    int marks;

    scanf("%d", &marks);

    if (marks >= 90)
    {
        printf("Grade A+");
    }
    else if (marks >= 80)
    {
        printf("Grade A");
    }
    else if (marks >= 70)
    {
        printf("Grade B");
    }
    else if (marks >= 60)
    {
        printf("Grade C");
    }
    else if (marks >= 40)
    {
        printf("Grade D");
    }
    else
    {
        printf("Fail");
    }

    return 0;
}
C checks conditions from top to bottom. Once one condition becomes true, its block executes and the remaining else-if conditions are skipped.
08

Nested if

A nested if means placing one if statement inside another.

Real-World Example — Login Validation

int usernameCorrect = 1;
int passwordCorrect = 1;

if (usernameCorrect)
{
    if (passwordCorrect)
    {
        printf("Login successful");
    }
    else
    {
        printf("Wrong password");
    }
}
else
{
    printf("Wrong username");
}
Tip: Nested conditions are useful when the second condition should only be checked after the first condition succeeds.
09

switch-case Statement

switch is useful when one expression must be compared against several fixed values.

Syntax

switch (expression)
{
    case value1:
        statements;
        break;

    case value2:
        statements;
        break;

    default:
        statements;
}

Example

int day = 2;

switch(day)
{
    case 1:
        printf("Monday");
        break;

    case 2:
        printf("Tuesday");
        break;

    case 3:
        printf("Wednesday");
        break;

    default:
        printf("Invalid day");
}

Important switch Keywords

case break default
Why is break important? Without break, execution can continue into the next case. This behavior is called fall-through.

Looping / Iteration Statements

Loops repeatedly execute a block of code while a condition remains satisfied.

for Loop

Best when the number of iterations is known. 

for(int i=1; i<=5; i++)
{
    printf("%d ", i);
}

while Loop

Condition is checked before execution. 

int i = 1;

while(i <= 5)
{
    printf("%d ", i);
    i++;
}

do-while

Executes at least once because the condition is checked after the body. 

int i = 1;

do
{
    printf("%d ", i);
    i++;
}
while(i <= 5);
Interview point: A do-while loop executes its body at least once, even when the condition is initially false.

Jump Statements

break

Immediately terminates the nearest loop or switch. 

for(int i=1; i<=10; i++)
{
    if(i == 5)
        break;

    printf("%d ", i);
}
Output: 1 2 3 4

continue

Skips the current iteration and moves to the next one. 

for(int i=1; i<=5; i++)
{
    if(i == 3)
        continue;

    printf("%d ", i);
}
Output: 1 2 4 5

return

Ends a function and optionally sends a value back to the caller. 

int add(int a, int b)
{
    return a + b;
}

goto

Transfers control to a labeled statement. 

goto message;

message:
printf("Hello");
Best practice: Avoid goto in normal application code unless there is a specific reason. Structured control flow is usually clearer.

Conditions + Operators

Conditional statements become powerful when combined with relational and logical operators.

Example

int age = 20;
int marks = 85;

if (age >= 18 && marks >= 60)
{
    printf("Eligible");
}
else
{
    printf("Not Eligible");
}
The condition uses &&, meaning both conditions must be true.

Common Mistakes

✕
Using = instead of == 
if (x = 10)

Assignment and comparison are different.

✕
Missing braces

Braces make the intended block explicit and reduce bugs.

✕
Forgetting break in switch

This can cause unintended fall-through.

✕
Wrong condition order

In an else-if ladder, more specific conditions often need to be checked before broader ones.

✕
Infinite loops

Always make sure the loop condition can eventually become false.

22

Interview Questions

1. What is the difference between = and ==?

= performs assignment, while == checks equality.

2. What is the difference between if-else and switch?

if-else supports complex conditions and ranges. switch is convenient for comparing one expression against fixed constant cases.

3. Why is break used in switch?

It normally prevents execution from continuing into subsequent cases.

4. Difference between while and do-while?

while checks the condition before executing its body. do-while executes the body first and checks the condition afterward.

5. What is fall-through?

In switch, if break is omitted, execution can continue into later cases.
