07 • SWITCH

switch statement

Use switch when one expression is being matched against several constant case values. 

switch (expression)
{
    case value1:
        // statements
        break;

    case value2:
        // statements
        break;

    default:
        // statements
}

Example — Menu 

int choice = 2;

switch (choice)
{
    case 1:
        std::cout << "Start";
        break;

    case 2:
        std::cout << "Settings";
        break;

    case 3:
        std::cout << "Exit";
        break;

    default:
        std::cout << "Invalid choice";
}

08 • BREAK

Why is break important?

In a traditional switch statement, break prevents execution from continuing into subsequent cases.

With break 

switch (choice)
{
    case 1:
        std::cout << "One";
        break;

    case 2:
        std::cout << "Two";
        break;
}
Execution leaves the switch after the matching case.

Without break 

switch (choice)
{
    case 1:
        std::cout << "One";

    case 2:
        std::cout << "Two";
}
If case 1 matches, execution can continue into case 2. This is called fall-through.
09 • DEFAULT

default case

The default branch handles the situation when no case matches. 

int day = 9;

switch (day)
{
    case 1:
        std::cout << "Monday";
        break;

    case 2:
        std::cout << "Tuesday";
        break;

    default:
        std::cout << "Invalid day";
}
Good practice: Include a default case when invalid or unexpected values need to be handled.
10 • FALL-THROUGH

Understanding fall-through

A switch case can intentionally share behavior with another case. 

char grade = 'A';

switch (grade)
{
    case 'A':
    case 'B':
        std::cout << "Good performance";
        break;

    case 'C':
        std::cout << "Average";
        break;

    default:
        std::cout << "Needs improvement";
}
Here both A and B intentionally reach the same statement.

A compact way to choose between two expressions.

Example

        ? "Adult"

Use ternary for simple expressions. Avoid deeply nested ternary expressions because they reduce readability.

19 • COMMON MISTAKES

Avoid these beginner errors

!

Using = instead of == 

// Wrong idea
if (x = 5)

// Comparison
if (x == 5)

= assigns. == compares.

!

Forgetting braces 

if (age >= 18)
    std::cout << "Adult";
    std::cout << "Welcome";

Without braces, only the immediately following statement belongs to the if.

!

Wrong condition order 

if (marks >= 40)
    std::cout << "Pass";
else if (marks >= 90)
    std::cout << "Excellent";

The 90 case is never reached because 90 is already greater than or equal to 40.

!

Forgetting break in switch

Without break, execution may continue into later cases.

!

Overusing nested if statements

Deep nesting can make code hard to understand. Look for clearer conditions or early-return designs.

!

Confusing switch with range conditions

A traditional switch is designed around matching discrete case values rather than directly expressing ranges such as marks >= 80.

22 • INTERVIEW PREPARATION

Interview questions

What is a conditional statement? +
A conditional statement controls program flow by executing different code depending on whether a condition is true or false.
Difference between if and if-else? +
An if statement provides a true path only. An if-else statement provides both a true path and a false path.
What is an else-if ladder? +
It is a sequence of conditions checked from top to bottom. Once a condition is true, its block executes and the remaining ladder is skipped.
What is nested if? +
A nested if is an if statement placed inside another conditional block.
Why is break used in switch? +
It normally transfers control out of the switch after the selected case finishes, preventing unintended fall-through into subsequent cases.
What is fall-through? +
Fall-through occurs when execution continues from one switch case into subsequent cases because there is no break. It can also be intentional when several cases share the same behavior.
if-else vs switch? +
if-else is flexible for ranges and complex boolean expressions. Traditional switch is useful when matching one expression against discrete case values.
