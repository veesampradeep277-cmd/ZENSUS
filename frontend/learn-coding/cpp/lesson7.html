01 — Foundation

What is a Function?

A function is a reusable block of code designed to perform a specific task.

Imagine a calculator. Instead of writing the complete addition logic every time you need it, you can create an add() function and call it whenever you need addition.

Simple definition

A function takes input, performs a task, and may produce an output.

Why Functions?

Why do programmers use functions?

♻

Reusability

Write code once and use it many times.

🧩

Modularity

Divide a large problem into smaller manageable pieces.

🛠

Maintainability

Fix or improve one function without rewriting the entire program.

🐞

📖

Readability

Meaningful function names make programs easier to understand.

🚀

Scalability

Functions help large applications remain organized.

03 — Structure

Declaration, Definition & Calling

①

Declaration

Tells the compiler that a function exists.

②

Definition

Contains the actual implementation.

③

Call

Executes the function.

Complete Example 
// Function declaration
int add(int, int);

int main()
{
    int result = add(10, 20);

    std::cout << result;

    return 0;
}

// Function definition
int add(int a, int b)
{
    return a + b;
}
Important

If a function is defined before it is called, a separate declaration is usually unnecessary. If it is defined later, declare it before the call.

05 — Inputs

Parameters & Arguments

Parameter

A variable written in the function definition. 

int square(int n)
{
    return n * n;
}

Here n is a parameter.

Argument

The actual value supplied when calling the function. 

int result = square(5);

Here 5 is an argument.

Easy memory trick

Parameter = placeholder | Argument = actual value

07 — Parameter Passing

Pass by Value

In pass by value, the function receives a copy of the original value. 

void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    std::cout << a;

    return 0;
}
Output: 10

The function changed its local copy, not the original variable.

08 — References

Pass by Reference

A reference parameter allows a function to work directly with the original variable. 

void change(int& x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    std::cout << a;

    return 0;
}
Output: 100

The reference refers to the original variable.

Real Problem

Swap Two Numbers

void swapNumbers(int& a, int& b)
{
    int temp = a;
    a = b;
    b = temp;
}

int main()
{
    int a = 10;
    int b = 20;

    swapNumbers(a, b);

    std::cout << a << " " << b;

    return 0;
}
Output

20 10

Advanced Foundation

const Reference

A const reference lets a function access an existing object without copying it while preventing the function from modifying it through that reference. 

void printName(const std::string& name)
{
    std::cout << name;
}
Why is this useful?

It is especially useful for larger objects such as strings, vectors and custom classes when you only need to read the object.

09 — Polymorphism

Function Overloading

Multiple functions can have the same name when their parameter lists differ. 

int add(int a, int b)
{
    return a + b;
}

double add(double a, double b)
{
    return a + b;
}

int add(int a, int b, int c)
{
    return a + b + c;
}
Important interview point

Functions cannot be overloaded using only different return types.

10 — Convenience

Default Arguments

A default argument provides a value automatically when the caller does not provide that argument. 

void greet(std::string name = "Student")
{
    std::cout << "Hello " << name;
}

greet();

greet("Pradeep");
Rule

Default arguments are generally supplied from the rightmost parameter toward the left.

11 — Scope

Local & Global Variables

Local Variable

Declared inside a function or block and accessible only within its scope. 

void test()
{
    int x = 10;

    std::cout << x;
}

Global Variable

Declared outside functions and has broader scope. 

int x = 10;

void show()
{
    std::cout << x;
}
Professional advice

Avoid unnecessary global mutable variables. Prefer passing data through function parameters and return values.

Advanced

Static Local Variable

void counter()
{
    static int count = 0;

    count++;

    std::cout << count << "\n";
}

counter();
counter();
counter();
Output

2
3

A local static variable retains its value between function calls and has local scope.

12 — Advanced

Recursion

A function calling itself to solve a smaller version of the same problem.

Every recursive function needs two things

1. Base case — stops recursion.
2. Recursive case — calls the function again with a smaller problem. 

int factorial(int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}

Factorial of 4

factorial(4)
↓
4 × factorial(3)
↓
4 × 3 × factorial(2)
↓
4 × 3 × 2 × factorial(1)
↓
4 × 3 × 2 × 1 = 24
Interview Concept

Recursion vs Iteration

Feature Recursion Iteration
Technique Function calls itself Uses loops
Memory Uses call stack Usually lower overhead
Readability Elegant for some problems Often straightforward for repetitive tasks
Risk Deep recursion can exhaust the stack Infinite loops can run indefinitely
Examples Tree traversal, divide-and-conquer Counting, scanning arrays
Advanced C++

Inline Functions

The inline specifier allows a function to be defined in multiple translation units under C++'s ODR rules and is also a request related to inline expansion. Modern compilers decide optimization themselves. 

inline int square(int x)
{
    return x * x;
}
Interview warning

Do not say that inline guarantees that the compiler will physically replace the function call.

Avoid These

Common Function Mistakes

❌ Forgetting the return

int add(int a, int b)
{
    a + b;
}

A non-void function should return an appropriate value when execution reaches its end.

❌ Wrong parameter count

int add(int a, int b);

add(10);

Two required parameters were declared, but only one was supplied.

❌ Confusing value and reference

Pass-by-value changes a copy. Pass-by-reference can modify the original object.

❌ Missing base case

Recursive functions without a proper stopping condition can continue until the call stack is exhausted.

Important Questions

A function is a named, reusable block of code that performs a specific task. It can accept parameters and may return a value.
A declaration specifies the function's name, return type and parameter types. A definition provides the actual function body.
Pass by value gives the function a copy of the argument, so modifying the parameter does not modify the original argument.
Pass by reference gives the function a reference to the original object, allowing modifications to affect that object.
Function overloading allows multiple functions to have the same name but different parameter lists.
Recursion is a technique where a function calls itself to solve smaller instances of the same problem.
Interview Ready

Top Interview Questions

Q1. Can functions be overloaded by return type only?

No. The parameter list must differ in a way that allows the overloads to be distinguished.

Q2. What is the difference between parameter and argument?

A parameter is the variable declared in the function; an argument is the actual value passed during the call.

Q3. Why use const reference?

To avoid copying an object while preventing modification through the reference.

Q4. What is the base case in recursion?

The condition that stops further recursive calls.

Q5. What happens during a function call?

Control transfers to the called function, its parameters and local state are established, the body executes, and control returns to the caller.

Q6. Can a function return multiple values?

A function has one return object/value in its return statement, but multiple pieces of information can be returned through structures, pairs, tuples, or output parameters/references.
