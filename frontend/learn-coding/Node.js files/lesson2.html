07 • package.json

Understanding package.json

package.json is the identity card and configuration file of a Node.js project.

Example package.json

{
  "name": "my-node-app",
  "version": "1.0.0",
  "description": "Node application",
  "main": "app.js",

  "scripts": {
    "start": "node app.js",
    "dev": "node --watch app.js"
  },

  "dependencies": {
    "express": "^5.1.0"
  },

  "devDependencies": {
    "nodemon": "^3.1.10"
  }
}

Important Properties

name : project name
version : project version
main : entry file
scripts : commands
dependencies : production packages
devDependencies : development packages

09 • Lock File

package-lock.json

Why does Node.js create another JSON file?

📄 package.json

  • Describes your project
  • Stores dependency requirements
  • Contains scripts
  • Usually edited by developers

🔒 package-lock.json

  • Records exact dependency versions
  • Locks dependency tree
  • Helps consistent installations
  • Usually generated by npm
10 • node_modules

The node_modules Folder

This is where installed packages live.

📁 my-node-app/ ├── 📄 app.js ├── 📄 package.json ├── 🔒 package-lock.json ├── 🚫 .gitignore ├── 🔐 .env └── 📦 node_modules/     ├── 📁 express/     ├── 📁 dotenv/     └── 📁 other-packages/
Never manually edit files inside node_modules. npm manages this directory.

13 • Configuration

.env & process.env

Keep configuration and secrets outside your source code.

.env

PORT=5000
DB_NAME=student_db
JWT_SECRET=my_secret_key

Node.js

require("dotenv").config();

console.log(process.env.PORT);
console.log(process.env.DB_NAME);
Never commit real passwords, API keys, database credentials or JWT secrets to GitHub.

17 • Troubleshooting

Common Node.js Errors

❌ 'node' is not recognized

Node.js may not be installed or PATH is not configured.

Reinstall Node.js and restart the terminal.

❌ Cannot find module

A required package may not be installed.

Run npm install or install the required package.

❌ npm command failed

Check the terminal error carefully.

Verify Node/npm versions and package configuration.

20 • Interview Preparation

Node.js Setup Interview Questions

Node.js is a JavaScript runtime built on Chrome's V8 JavaScript engine. It allows JavaScript code to run outside the browser.
npm is the package manager commonly used with Node.js. It helps developers install, update and manage packages.
package.json contains project metadata, scripts and dependency information.
package-lock.json records the exact dependency tree and versions resolved by npm.
node_modules can be very large and can be recreated using package.json and package-lock.json by running npm install.
process.env provides access to environment variables available to the Node.js process.
