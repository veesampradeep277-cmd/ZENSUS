01 • FOUNDATION

What is a CSS Selector?

A CSS selector is a pattern used to select one or more HTML elements that you want to style. In simple terms, the selector tells CSS: "Which element should I style?"

E

Element

Select elements using their HTML tag, such as p, h1, div or button.

.

Class

Select elements that share a class name.

#

ID

Select a specific element using its unique ID.

02 • ANATOMY

Anatomy of a CSS Selector

A selector appears before the declaration block. The browser uses it to determine which elements should receive the declarations.

p { color : blue ; }
↑
Selector chooses all <p> elements
03 • UNIVERSAL SELECTOR

Universal Selector (*)

The universal selector is represented by an asterisk *. It selects every HTML element on the page.

*

Select Everything

Useful for applying a basic reset or global box-sizing rule.

* {
   box-sizing : border-box ;
}
04 • ELEMENT SELECTOR

Element Selector

The element selector selects HTML elements based on their tag name.

p {
   color : #333 ;
}

This selects every <p> element.

05 • CLASS SELECTOR

Class Selector

A class selector begins with a period .. It selects all elements that contain the specified class.

.card {
   padding : 20px ;
}

HTML

<div class="card" >
   Course Content
</div>

Multiple elements can share the same class.

06 • ID SELECTOR

ID Selector

An ID selector begins with #. It targets an element with a specific ID.

#main-title {
   font-size : 40px ;
}

HTML

<h1 id="main-title" >
   ZENSUS
</h1>
07 • GROUPING SELECTORS

Grouping Selectors

Use a comma to apply the same styles to multiple selectors.

h1 , h2 , p {
   font-family : Arial ;
}

The declaration applies to all three selectors.

08 • DESCENDANT SELECTOR

Descendant Selector

A space between selectors selects elements that are descendants of another element.

.card p {
   color : gray ;
}

This selects every <p> inside an element having the class card.

09 • CHILD SELECTOR

Child Selector (>)

The child combinator selects elements that are direct children of another element.

.card > p {
   color : blue ;
}

Unlike the descendant selector, the > combinator only selects direct children.

10 • ADJACENT SIBLING

Adjacent Sibling Selector (+)

The plus sign selects an element that comes immediately after another element.

h2 + p {
   margin-top : 0 ;
}

This selects the first <p> immediately following an <h2>.

11 • GENERAL SIBLING

General Sibling Selector (~)

The tilde selects all matching sibling elements that appear after the first element.

h2 ~ p {
   color : #555 ;
}
12 • ATTRIBUTE SELECTOR

Attribute Selectors

Attribute selectors allow CSS to select elements based on their HTML attributes.

[ ]

Has Attribute

input[type]

=

Exact Value

input[type="text"]

^

Starts With

a[href^="https"]

input[type="email"] {
   border : 2px solid blue ;
}
13 • PSEUDO-CLASS

Pseudo-Classes

A pseudo-class selects an element based on a special state or condition.

:

:hover

Applies when the pointer is over an element.

:

:focus

Applies when an element receives focus.

:

:first-child

Selects an element that is the first child.

button:hover {
   transform : translateY(-3px) ;
}
14 • PSEUDO-ELEMENTS

Pseudo-Elements

Pseudo-elements allow you to style a specific part of an element or insert generated content.

::

::before

Inserts generated content before an element's content.

::

::after

Inserts generated content after an element's content.

::

::first-letter

Styles the first letter of text.

.title::before {
   content : "★ " ;
}
15 • ATTRIBUTE PATTERNS

Advanced Attribute Matching

[href^="https"] /* starts with */

[href$=".pdf"] /* ends with */

[class*="card"] /* contains */

[title~="course"] /* contains word */
16 • SELECTOR COMBINATIONS

Combining Selectors

Selectors can be combined to create very precise targeting rules.

.course-card.featured {
   border : 2px solid blue ;
}
nav ul li a {
   text-decoration : none ;
}

20 • COMMON MISTAKES

Common Selector Mistakes

❌ Wrong Class Selector
card {
color: blue;
}
Without the period, CSS interprets card as an element selector.
✓ Correct Class Selector
.card {
color: blue;
}
The period identifies card as a class selector.
❌ Wrong ID Selector
main-title {
color: blue;
}
An ID selector needs the # symbol.
✓ Correct ID Selector
#main-title {
color: blue;
}
The hash symbol identifies an ID selector.

24 • SUMMARY

CSS Selectors — Summary

  • Selectors tell CSS which HTML elements should be styled.
  • The universal selector * selects all elements.
  • Element selectors target HTML tags.
  • Class selectors use the . symbol.
  • ID selectors use the # symbol.
  • Multiple selectors can be grouped with commas.
  • Descendant selectors use a space.
  • Child selectors use >.
  • Adjacent siblings use +.
  • General siblings use ~.
  • Attribute selectors target HTML attributes.
  • Pseudo-classes represent element states.
  • Pseudo-elements style specific parts or generated content.
  • Specificity determines which competing selector has greater weight.
