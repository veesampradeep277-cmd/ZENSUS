Part 01

Compile-Time Polymorphism

Compile-time polymorphism is primarily achieved in Java through method overloading.

Same method name + different parameter list

The compiler determines which overloaded method matches the arguments supplied by the caller.

1

Different Number

Methods can have different numbers of parameters.

2

Different Types

Parameter data types can be different.

3

Different Order

The order of parameter types can differ.

✕

Return Type Alone

Changing only the return type does not overload a method.

MethodOverloading.java 
class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }
}

What happened?

01

All methods have the same name: add().

02

Their parameter lists are different.

03

Java can determine the correct method from the arguments.

Example

Practical Method Overloading

Calculator.java 
class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {

        Calculator c = new Calculator();

        System.out.println(c.add(10, 20));

        System.out.println(c.add(10.5, 20.5));

        System.out.println(c.add(10, 20, 30));
    }
}

!
Important Interview Rule

You cannot overload a Java method by changing only its return type. The parameter list must be different.

InvalidOverloading.java 
class Demo {

    int calculate(int a) {
        return a;
    }

    // ERROR
    double calculate(int a) {
        return a;
    }
}

Why is this invalid?

Both methods have exactly the same parameter list:

calculate(int)

Java cannot use the return type alone to distinguish between the methods.

Part 02

Runtime Polymorphism

Runtime polymorphism occurs when a subclass overrides an inherited instance method and the method call is resolved during execution.

Dynamic Method Dispatch

A superclass reference can refer to a subclass object. When an overridden instance method is called, Java uses the actual object type to determine which implementation runs.

Reference Type → What is accessible | Object Type → Which overridden method executes
Core Mechanism

Method Overriding

Method overriding occurs when a subclass provides its own implementation of an inherited instance method.

Animal.java 
class Animal {

    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

class Cat extends Animal {

    @Override
    void sound() {
        System.out.println("Cat meows");
    }
}

What is happening?

  • Animal defines sound().
  • Dog provides another implementation.
  • Cat provides another implementation.
  • All classes share the same method name.

Best Practice

The @Override Annotation

@

@Override

The @Override annotation tells the compiler that the method is intended to override a superclass method.

It is not strictly required for overriding, but it is strongly recommended because the compiler can detect accidental signature mistakes.

Recommended 
class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}
Possible Mistake 
class Dog extends Animal {

    // Typo creates another method
    void soud() {
        System.out.println("Dog barks");
    }
}
Rules

Rules of Method Overriding

01

The subclass method must have the same method signature as the inherited instance method.

02

The overriding method cannot reduce the accessibility of the parent method.

03

A static method is hidden, not overridden.

04

A final method cannot be overridden.

05

Private methods are not overridden because they are not inherited as accessible subclass methods.

06

Constructors cannot be overridden.

Advanced Concept

Downcasting

Downcasting converts a parent reference back to a more specific child reference. It requires explicit casting and should be performed carefully.

Downcasting.java 
Animal animal = new Dog();

if (animal instanceof Dog) {

    Dog dog = (Dog) animal;

    dog.bark();
}
!

Be careful with downcasting

Casting an object to an incompatible child type can cause a ClassCastException at runtime.

Restrictions

final and Polymorphism

final method

A final method cannot be overridden by a subclass. 

final void display() {
    System.out.println("Fixed");
}

final class

A final class cannot be extended, so it cannot participate in subclass-based overriding. 

final class Vehicle {
}

Important: Static Methods

Static methods are associated with classes. If a subclass declares a static method with the same signature, the method is hidden rather than dynamically overridden.

StaticHiding.java 
class Parent {

    static void show() {
        System.out.println("Parent");
    }
}

class Child extends Parent {

    static void show() {
        System.out.println("Child");
    }
}

Placement Preparation

Interview Questions

01 What is polymorphism in Java?

Polymorphism means one entity can represent multiple forms. Java primarily demonstrates it through method overloading and method overriding.

02 What are the two main types of polymorphism?

Compile-time polymorphism and runtime polymorphism.

03 What is method overloading?

Defining multiple methods with the same name but different parameter lists.

04 What is method overriding?

Providing a subclass-specific implementation of an inherited instance method with the same signature.

05 Is inheritance required for overloading?

No. Overloading can occur within a single class.

06 Is inheritance required for overriding?

Yes. Method overriding involves a superclass and subclass relationship.

07 What is dynamic method dispatch?

It is the runtime mechanism by which an overridden instance method call is resolved according to the actual object.

08 Can static methods be overridden?

No. A static method with the same signature in a subclass hides the superclass static method.

09 Can final methods be overridden?

No. A final method cannot be overridden.

10 What is upcasting?

Assigning a subclass object to a superclass reference, such as Animal a = new Dog().

11 What is downcasting?

Explicitly converting a parent reference to a child reference when the actual object is compatible.

12 Why is @Override recommended?

It tells the compiler that overriding is intended and helps detect incorrect method signatures.

Lesson Summary

Polymorphism allows Java programs to represent different behaviors through a common interface or reference. Compile-time polymorphism is primarily achieved through method overloading, where the compiler selects a method based on its parameter list. Runtime polymorphism is achieved through method overriding, where an overridden instance method is selected according to the actual object during execution.


The key idea to remember is: same interface, different implementation.
