LESSON 05 • BEGINNER

Git Log & Viewing History

Learn how Git records project history and how to inspect previous commits using git log, git show, compact history views, file-specific history, and visual commit graphs.

git log Commit History git show --oneline Commit Graph
01 — Foundation

What Is Git History?

Every time you create a commit, Git records a version of your project in the repository.

These commits form a chronological history of the project.

Commit 1 Initial project
→
Commit 2 Add homepage
→
Commit 3 Fix navigation
→
Commit 4 Update styling

Simple idea: Git history is a record of the commits that have been created in your repository.

02 — Main Command

Using git log

The basic command for viewing commit history is:

Terminal 
git log

It displays information about previous commits.

Example Output

Example 
commit a84f91c7d2...
Author: Pradeep <pradeep@example.com>
Date:   Sat Sep 20 10:20:00 2026 +0530

    Add homepage

commit 72bd4a18f1...
Author: Pradeep <pradeep@example.com>
Date:   Fri Sep 19 18:30:00 2026 +0530

    Initial commit

The newest commit normally appears first.

03 — Understand the Output

Anatomy of a Commit

A commit contains several important pieces of information.

ID

Commit Hash

A unique identifier used to identify the commit.

A

Author

The person associated with creating the commit.

D

Date

The date and time associated with the commit.

M

Message

A short description explaining what the commit changed.

The long identifier beginning with characters such as a84f91c is commonly called the commit hash or commit ID.

04 — Visual Understanding

Understanding a Commit Timeline

Imagine that you have made several commits to your portfolio.

a84f91c Update homepage

Latest version of the project.

72bd4a1 Add projects section

Added project information to the website.

3fc91d8 Add navigation

Added the main navigation menu.

18a2e50 Initial commit

Created the initial project files.

Git history allows developers to understand how the project evolved over time.

05 — Compact History

git log --oneline

The normal git log output can contain a lot of information.

For a compact history, use:

Terminal 
git log --oneline

Example

Output 
a84f91c Update homepage
72bd4a1 Add projects section
3fc91d8 Add navigation
18a2e50 Initial commit

Each line shows a shortened commit hash followed by the commit message.

Useful habit: Use git log --oneline when you want to quickly understand recent project history.

06 — Detailed History

Viewing Detailed Commit Information

You can use git log with different options to control the information displayed.

Show Only Recent Commits

Command 
git log -3

This asks Git to show the latest three commits.

Compact Format

Command 
git log --oneline -5

This combines compact output with a limit of five commits.

07 — Commit Information

Author, Date and Commit Information

Git records information about commits, including the author, timestamp and commit message.

The long form of git log can show information similar to:

Example 
commit a84f91c7d2...

Author: Pradeep
Date:   Sat Sep 20 10:20:00 2026 +0530

    Update homepage

This is useful when you need to understand who created a particular commit and when it was created.

The author information comes from the Git identity configured on the system/repository, such as the user.name and user.email settings.

08 — File History

Viewing History of a Specific File

Sometimes you do not need the entire project history. You may want to know how one particular file changed.

You can provide a file path to git log.

Terminal 
git log -- index.html

The -- separates Git options from the path that follows.

Compact File History

Command 
git log --oneline -- index.html

This is useful when investigating the history of a particular page, component, configuration file or source file.

09 — Visual History

Viewing the Commit Graph

Git can display a visual representation of branches and commits using the --graph option.

Command 
git log --oneline --graph

Example

Example Output 
* a84f91c Update homepage
* 72bd4a1 Add projects section
* 3fc91d8 Add navigation
* 18a2e50 Initial commit

Later, when you learn branches, the graph becomes especially useful for understanding how different lines of development connect.

Tip: A popular readable command is:

Command 
git log --oneline --graph --all
10 — Inspect a Commit

Using git show

git show displays information about a particular commit.

Command 
git show

By default, Git can show information about the current commit/reference, including the changes introduced by it.

Show a Specific Commit

Command 
git show a84f91c

You can use the commit hash to inspect that particular commit.

git log helps you find commits. git show helps you inspect a specific commit.

12 — Troubleshooting

Common Mistakes When Using Git Log

01

No Commits

If the repository has no commits, there may be no useful history to display.

02

Wrong Repository

Make sure you are inside the correct Git repository.

03

Too Much Output

Use --oneline or a commit limit when the history is long.

04

Confusing Hashes

You do not need to memorize every commit hash. Use the history to locate the commit you need.

If git log seems to show unexpected history, first confirm your current repository and branch.

Lesson Takeaway

  • git log displays commit history.
  • A commit contains information such as its hash, author, date and message.
  • git log --oneline gives a compact history view.
  • git log -3 limits the output to recent commits.
  • git log -- filename displays history related to a particular file.
  • git log --oneline --graph helps visualize commit relationships.
  • git show can inspect a particular commit and the changes associated with it.
  • Git history helps developers understand how a project evolved over time.
