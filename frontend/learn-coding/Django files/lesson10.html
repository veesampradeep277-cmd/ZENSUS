Django Admin Panel

Learn how Django's built-in Admin Panel allows developers and administrators to manage database records through a powerful web interface without building a separate management dashboard from scratch.

01

What is Django Admin?

Django Admin is a built-in web-based interface provided by Django. It allows authorized users to view, create, update and delete database records through a browser.

Why Do We Need an Admin Panel?

01

Manage Data

Add, edit and delete database records without writing SQL manually.

02

Save Development Time

Django automatically creates a management interface for registered models.

03

Secure Access

Only authorized users can access administrative functionality.

04

Quick Testing

Django Admin Setup

Django projects created using startproject already include the admin configuration. 

from django.contrib import admin
from django.urls import path

urlpatterns = [
    path("admin/", admin.site.urls),
]

The URL: 

http://127.0.0.1:8000/admin/
Remember: The admin URL is normally available at /admin/, unless you change the URL configuration.

Register Models in Admin

Creating a model does not automatically mean that it appears in the Admin Panel.

We usually register the model inside the app's admin.py.

Example Model

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    email = models.EmailField()
    age = models.IntegerField()
    course = models.CharField(max_length=100)

    def __str__(self):
        return self.name

Register the Model

from django.contrib import admin
from .models import Student

admin.site.register(Student)
After registration, the Student model becomes available in the Admin Panel.
07

Understanding admin.py

The admin.py file is where we configure how our models should appear and behave inside Django Admin.

products/ │ ├── admin.py ├── apps.py ├── models.py ├── views.py ├── tests.py │ └── migrations/ └── __init__.py

Basic admin.py

from django.contrib import admin
from .models import Student

admin.site.register(Student)

For advanced customization, Django provides the ModelAdmin class.

08

Customize Display Fields

By default, Django shows a basic list of objects. We can control which fields appear in the model list. 

from django.contrib import admin
from .models import Student

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "email",
        "age",
        "course",
    )

Add Search

The search_fields option allows administrators to search records using selected model fields. 

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "email",
        "age",
        "course",
    )

    search_fields = (
        "name",
        "email",
        "course",
    )
Now an administrator can search students by name, email or course.

11

Ordering Records

Use ordering to control the default order of records. 

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "age",
        "course",
    )

    ordering = (
        "name",
    )
"name" sorts in ascending order. Use "-name" for descending order.
12

Read-Only Fields

Sometimes an administrator should be able to see a field but should not be allowed to edit it. 

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    readonly_fields = (
        "email",
    )
Example: You may want an automatically generated or verified value to be visible but not manually changed.
13

Complete ModelAdmin Customization

We can combine multiple options to create a more useful Admin Panel. 

from django.contrib import admin
from .models import Student

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "email",
        "age",
        "course",
    )

    search_fields = (
        "name",
        "email",
        "course",
    )

    list_filter = (
        "course",
    )

    ordering = (
        "name",
    )

    readonly_fields = (
        "email",
    )

What each option does

Option Purpose
list_display Controls columns shown in the list
search_fields Adds search functionality
list_filter Adds sidebar filters
ordering Controls default sorting
readonly_fields Prevents editing selected fields

Mini Project — ZENSUS Student Admin

Let's build a simple Student model and make it fully manageable through Django Admin.

Step 1 — Create Model

from django.db import models

class Student(models.Model):

    name = models.CharField(max_length=100)

    email = models.EmailField()

    age = models.IntegerField()

    course = models.CharField(max_length=100)

    def __str__(self):
        return self.name

Step 2 — Create Migrations

python manage.py makemigrations
python manage.py migrate

Step 3 — Register Model

from django.contrib import admin
from .models import Student

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):

    list_display = (
        "name",
        "email",
        "age",
        "course",
    )

    search_fields = (
        "name",
        "email",
    )

    list_filter = (
        "course",
    )

    ordering = (
        "name",
    )

Step 4 — Create Superuser

python manage.py createsuperuser

Step 5 — Run Server

python manage.py runserver

Step 6 — Open Admin

http://127.0.0.1:8000/admin/

Common Admin Mistakes

01

Model Not Registered

The model exists but does not appear in Admin because it was not registered in admin.py.

02

No Superuser

Create an administrator account using createsuperuser.

03

Forgot Migrations

Run makemigrations and migrate after changing models.

04

Wrong admin.py Import

Make sure the model is imported from the correct app.

05

Wrong URL

Check that the project urls.py includes admin.site.urls.

06

Unsafe Access

Do not treat the Admin Panel as a public-facing user dashboard.

Security reminder: The Admin Panel is powerful. Use strong passwords, proper permissions, secure deployment settings and appropriate access controls in real projects.
