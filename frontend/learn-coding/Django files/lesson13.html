What is a Serializer?

A serializer converts complex Django/Python objects into data that can be rendered into formats such as JSON.

It can also validate incoming data before converting it into Python objects or saving it through a ModelSerializer.

from rest_framework import serializers

class StudentSerializer(
    serializers.Serializer
):

        max_length=100
    )

    email = serializers.EmailField()

    course = serializers.CharField(

09

ModelSerializer

When an API works directly with a Django model, ModelSerializer can reduce repetitive serializer code.

models.py

from django.db import models

class Student(models.Model):

    name = models.CharField(
        max_length=100
    )

    email = models.EmailField()

    course = models.CharField(
        max_length=100
    )

serializers.py

from rest_framework import serializers
from .models import Student

class StudentSerializer(
    serializers.ModelSerializer
):

    class Meta:

        model = Student

        fields = [
            "id",
            "name",
            "email",
            "course"
        ]
Key idea: ModelSerializer connects serializer fields to a Django model and can provide create/update behavior based on the model.

DRF Request and Response

DRF provides a request object that makes it convenient to access parsed request data.

This is commonly used for JSON or form-like request bodies.

Building a CRUD API

CRUD means: Create, Read, Update and Delete.

C

Create

POST a new student.

R

Read

GET students.

U

Update

PUT or PATCH a student.

D

Delete

DELETE a student.

Complete Example with APIView

from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework import status

from .models import Student
from .serializers import StudentSerializer


class StudentList(APIView):

    def get(self, request):

        students = Student.objects.all()

        serializer = StudentSerializer(
            students,
            many=True
        )

        return Response(
            serializer.data
        )


    def post(self, request):

        serializer = StudentSerializer(
            data=request.data
        )

        if serializer.is_valid():

            serializer.save()

            return Response(
                serializer.data,
                status=status.HTTP_201_CREATED
            )

        return Response(
            serializer.errors,
            status=status.HTTP_400_BAD_REQUEST
        )
What happened?

GET reads database records, while POST validates incoming data through the serializer and saves a new Student when the data is valid.

Common Mistakes

01

Not Installing DRF

Run pip install djangorestframework inside the correct virtual environment.

02

Missing INSTALLED_APPS

Add rest_framework to the Django settings.

03

Forgetting Serializer

Model objects need appropriate serialization before being returned as API data.

04

Using request.POST

DRF commonly uses request.data for parsed request data.

05

Wrong URL

Check both project-level and app-level URL configuration.

06

Ignoring Validation

Always check serializer.is_valid() before saving data.

Lesson Takeaway

  • API means Application Programming Interface.
  • Django REST Framework is used to build Web APIs with Django.
  • REST APIs commonly use HTTP methods such as GET, POST, PUT, PATCH and DELETE.
  • JSON is a common format for API data.
  • Serializers convert and validate API data.
  • ModelSerializer simplifies serialization of Django models.
  • APIView provides class-based API request handling.
  • DRF commonly uses request.data for incoming parsed data.
  • Response is used to return API responses.
  • HTTP status codes communicate the result of an API request.
  • APIs can connect Django with React, mobile applications and other clients.
