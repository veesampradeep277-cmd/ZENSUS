What is a Django Template?

A Django template is usually an HTML file containing normal HTML together with Django Template Language syntax.

Think of it this way

Python View

Decides what data and page should be returned.

HTML Template

Decides how that data should appear to the user.

templates/home.html 
<!DOCTYPE html>
<html>
<head>
    <title>ZENSUS</title>
</head>

<body>

    <h1>Welcome to ZENSUS</h1>

    <p>Learn Django step by step.</p>

</body>
</html>
03

Why Do We Need Templates?

You can return HTML directly from a view, but that becomes difficult when the page contains a lot of HTML.

Not recommended for large pages 
from django.http import HttpResponse

def home(request):

    return HttpResponse(
        "<h1>Welcome</h1>"
        "<p>This is my website</p>"
    )

Templates separate the presentation layer from Python logic.

🐍
Views

Python logic and data

📄
Templates

HTML presentation

🎨
Static Files

CSS, JS, images

04

Template Folder Structure

A common Django structure is to create a templates directory inside the app.

products/ │ ├── views.py ├── models.py ├── urls.py │ └── templates/ │ └── products/ │ ├── home.html ├── product.html └── about.html
Why create a products folder inside templates?
It prevents template-name conflicts when multiple Django apps contain files with the same name.
05

Rendering a Template

Django provides the render() function to combine a template with data and return an HTTP response.

views.py 
from django.shortcuts import render

def home(request):

    return render(
        request,
        "products/home.html"
    )

06

Passing Data from View to Template

One of the most powerful features of templates is displaying dynamic data sent from the Python view.

views.py 
from django.shortcuts import render

def student(request):

    data = {
        "name": "Pradeep",
        "course": "Artificial Intelligence",
        "college": "ZENSUS Academy"
    }

    return render(
        request,
        "student.html",
        data
    )
student.html 
<h1>Student Profile</h1>

<p>Name: {{ name }}</p>

<p>Course: {{ course }}</p>

<p>College: {{ college }}</p>
{{ variable }} is called template variable syntax. Django replaces it with the value supplied by the view.

Template Filters

Filters modify or format values before displaying them.

Template filters 
{{ name|upper }}

{{ name|lower }}

{{ name|title }}

{{ message|length }}

{{ price|floatformat:2 }}

upper

Converts text to uppercase.

lower

Converts text to lowercase.

length

Returns the length of a value.

09

Template Inheritance

Real websites contain common elements such as navigation bars, footers and page layouts. Instead of copying the same HTML into every page, Django supports template inheritance.

templates/ │ ├── base.html │ ├── home.html ├── products.html └── contact.html

base.html

base.html 
<!DOCTYPE html>

<html>

<head>
    <title>ZENSUS</title>
</head>

<body>

    <nav>
        ZENSUS
    </nav>

    {% block content %}

    {% endblock %}

    <footer>
        ZENSUS Learning Platform
    </footer>

</body>

</html>

home.html

home.html 
{% extends "base.html" %}

{% block content %}

    <h1>Welcome to ZENSUS</h1>

    <p>Learn Django step by step.</p>

{% endblock %}
Important idea:
base.html provides the common layout. Child templates fill the defined blocks.

What Are Static Files?

Static files are frontend resources that are normally served separately from dynamically generated HTML.

🎨

CSS

Controls colors, spacing, layouts and design.

⚡

JavaScript

Adds interaction and browser-side behavior.

🖼️

Images

Logos, banners, icons and visual assets.

Remember: Templates are generally dynamic HTML. Static files are frontend assets such as CSS, JavaScript and images.
11

Adding CSS to Django

Django provides the static template tag for referencing static assets.

products/ │ ├── templates/ │ └── products/ │ └── home.html │ └── static/ └── products/ ├── style.css └── script.js

settings.py

settings.py 
STATIC_URL = "static/"

Template

home.html 
{% load static %}

<!DOCTYPE html>

<html>

<head>

    <link
        rel="stylesheet"
        href="{% static 'products/style.css' %}"
    >

</head>

<body>

    <h1>ZENSUS Products</h1>

</body>

</html>

Common Mistakes

❌ Template not found

Check the template folder name and the path passed to render().

❌ CSS not loading

Check {% load static %}, STATIC_URL and the static file path.

❌ Variable not showing

Make sure the variable is included in the context dictionary.

❌ Wrong static path

Check the path relative to the static directory.

❌ Forgetting extends

Child templates must use {% extends "base.html" %} when using template inheritance.

❌ CSS written in the wrong place

Keep reusable CSS in static files rather than putting everything directly into templates.

Final concept: Django views handle the server-side logic. Templates define the HTML structure and display dynamic data. Static files provide CSS, JavaScript, images and other frontend resources. Together they create the user-facing Django application.

Key points to remember

  • Templates are usually HTML files.
  • render() connects a view with a template.
  • {{ variable }} displays dynamic data.
  • {% if %} and {% for %} provide template logic.
  • Template inheritance avoids repeated HTML.
  • Static files include CSS, JavaScript and images.
  • {% load static %} loads Django's static template tag library.
  • {% static 'path/to/file' %} creates a static-file URL.
