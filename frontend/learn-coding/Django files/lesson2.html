02 • PREREQUISITES

Check Python & pip

Django is a Python framework, so Python and pip should be available on your system.

🐍

Python

Python is the programming language used to write Django applications.

📦

pip

pip is Python's package installer. It can install Django and other packages. 

python --version
python3 --version
pip --version

What are we checking?

The first command checks whether Python is available. The second is commonly used on systems where Python is invoked as python3. The third checks pip.

03 • ENVIRONMENT

Create a Virtual Environment

A virtual environment creates an isolated Python workspace for your Django project.

Why use a virtual environment?

Different projects may require different package versions. A virtual environment prevents packages from different projects from interfering with one another.

Terminal
$ mkdir django-projects
$ cd django-projects
$ python -m venv venv

# Your isolated environment is now created.

Activate the environment 

venv\Scripts\activate
source venv/bin/activate

How do you know it is active?

Your terminal usually displays the environment name, such as (venv), before the command prompt.

04 • INSTALLATION

Install & Verify Django

Once the virtual environment is active, install Django using pip. 

pip install django
⬇️

Install

pip downloads Django and installs it inside your active environment.

✅

Verify

Check that Django can be accessed from your environment. 

django-admin --version

You can also verify Django with: 

python -m django --version

06 • PROJECT STRUCTURE

Understand the Generated Files

Django automatically creates several files. Each file has a specific responsibility.

📁 myproject/
├── 📄 manage.py
└── 📁 myproject/
    ├── 📄 __init__.py
    ├── 📄 settings.py
    ├── 📄 urls.py
    ├── 📄 asgi.py
    └── 📄 wsgi.py
manage.py
Command-line control center used to manage the Django project.
settings.py
Contains project configuration such as installed apps, database and templates.
urls.py
Defines URL routes and connects URLs with views.
wsgi.py
Provides the WSGI entry point commonly used for deployment.
asgi.py
Provides the ASGI entry point and supports modern asynchronous server scenarios.
__init__.py
Marks the directory as a Python package in the traditional package model.

In a production deployment, sensitive values such as the secret key should be protected, and DEBUG should not remain enabled.

06C • URL ROUTING

urls.py

Django uses URL patterns to decide which view should handle a request. 

from django.contrib import admin
from django.urls import path

urlpatterns = [
    path("admin/", admin.site.urls),
]

Think of URLs as a traffic controller

When a browser requests a particular path, Django checks the URL patterns and determines which view should receive the request.

09 • IMPORTANT CONCEPT

Django Project vs Django App

Understanding this difference is one of the most important concepts for Django beginners.

🏢 Django Project

The complete website/application configuration.

  • settings.py
  • Main urls.py
  • ASGI / WSGI configuration
  • Overall project configuration

🧩 Django App

A modular component that provides specific functionality.

  • Users
  • Products
  • Orders
  • Payments

Easy way to remember

Project = Whole website
App = One functional part of the website

09A • APP FILES

Important App Files

views.py

apps.py

tests.py

migrations/

09B • CONFIGURE APP

Register the App

After creating an app, add it to INSTALLED_APPS in settings.py. 

INSTALLED_APPS = [
    "django.contrib.admin",
    "django.contrib.auth",
    "django.contrib.contenttypes",
    "django.contrib.sessions",
    "django.contrib.messages",
    "django.contrib.staticfiles",

    "products",
]

Why register it?

Registering the app tells Django that products is an enabled application in this project.

10 • FIRST VIEW

Create Your First View

A view receives a request and returns a response. 

from django.http import HttpResponse

def home(request):
    return HttpResponse(
        "Welcome to ZENSUS Django!"
    )

Understanding the code

HttpResponse allows the view to return a response to the browser.

The home() function receives a request object and returns text.

10A • APP ROUTING

Connect the App to a URL

Create a urls.py file inside the app. 

from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),
]

Connect the app URLs to the project 

from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("products.urls")),
]
