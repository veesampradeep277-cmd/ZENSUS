01 · Foundation

What is JSX?

JSX is a syntax extension for JavaScript commonly used with React. It lets developers describe UI using a syntax that resembles HTML while still being part of JavaScript code.

App.jsx JSX 
function App() {

    return (
        <h1>
            Hello React
        </h1>
    );
}

The important idea is that this is not an HTML file. The JSX is written inside a JavaScript module and is transformed into JavaScript that React can use.

02 · Why JSX

Why Does React Use JSX?

Readable UI

The structure of a component is easy to see because the markup is close to the logic that controls it.

Dynamic

JavaScript expressions can be placed directly inside JSX.

Component Friendly

Components can be composed using JSX just like HTML elements are nested.

03 · Syntax

JSX Syntax

JSX looks familiar if you know HTML, but it follows JavaScript and React rules. 

const element = (
    <div>
        <h1>Welcome</h1>
        <p>Learn React with ZENSUS.</p>
    </div>
);

JSX uses angle brackets for elements, but because it lives inside JavaScript, JavaScript expressions can also be embedded inside it.

04 · HTML vs JSX

HTML vs JSX

HTML JSX
class className
for htmlFor
style="color:red" style={{ color: "red" }}
Can use HTML comments Uses JavaScript-style comments inside JSX expressions
HTML attribute naming Many attributes follow JavaScript property naming conventions
Important: JSX is similar to HTML, but it is not HTML. Treat JSX as a JavaScript syntax with XML-like markup.
05 · JavaScript

JavaScript Inside JSX

One of JSX's biggest advantages is the ability to use JavaScript expressions directly inside the markup. 

const name = "Pradeep";
const age = 19;

function App() {

    return (
        <div>

            <h1>
                Hello, {name}
            </h1>

            <p>
                Age: {age}
            </p>

        </div>
    );
}
06 · Curly Braces

Curly Braces { }

Curly braces tell JSX that you want to switch from JSX markup into a JavaScript expression.

Hello, {name} JSX + JavaScript
→
Hello, Pradeep Rendered result 
const name = "Alex";

<h1>
    Hello, {name}
</h1>
Inside JSX braces you can use expressions such as variables, calculations, function calls and conditional expressions. You cannot place arbitrary JavaScript statements such as if/for directly inside the braces.

JSX Expressions

    return "ZENSUS";

Conditional Expression

    {loggedIn ? "Welcome" : "Login"}

08 · Attributes

JSX Attributes

JSX attributes provide information to elements and components. They resemble HTML attributes but follow JSX's syntax rules. 

<img
    src="profile.png"
    alt="Profile"
    width={200}
/>

String values can use quotes. JavaScript expressions are commonly passed using curly braces.

09 · className

Why className Instead of class?

In JSX, use className to assign CSS classes. 

<div className="card">
    <h2>ZENSUS</h2>
</div>
React's JSX attributes generally map to JavaScript/DOM property conventions. Therefore className is used rather than HTML's class.
10 · Comments

JSX Comments

JSX comments need to be placed inside a JavaScript expression.

    return (

12 · Multiple Elements

The Parent Element Rule

A component's returned JSX must have one root element or another valid grouping mechanism. 

// ❌ Invalid

return (
    <h1>Hello</h1>
    <p>Welcome</p>
);
// ✅ Valid

return (
    <div>
        <h1>Hello</h1>
        <p>Welcome</p>
    </div>
);
13 · Fragment

React Fragment

Sometimes you need to group multiple JSX elements without adding an extra DOM element. A Fragment solves this problem. 

return (
    <>
        <h1>ZENSUS</h1>
        <p>Learn React</p>
    </>
);

<p>

14 · Restrictions

JSX Restrictions

One Root

Return one root element or use a Fragment.

Close Tags

Every non-void element must have a closing tag.

Self Close

Elements such as img and input must be self-closed in JSX.

className

Use className for CSS classes.

Expressions

JavaScript expressions inside JSX use curly braces.

camelCase

Many JSX properties use JavaScript-style naming such as tabIndex and onClick.

15 · Styling

Inline Styles in JSX

Inline styles are supplied as a JavaScript object. CSS property names that contain hyphens generally become camelCase property names. 

<h1
    style={{
        color: "blue",
        fontSize: "32px",
        marginTop: "20px"
    }}
>
    ZENSUS
</h1>
Notice the two sets of curly braces: the outer braces enter JavaScript, while the inner braces represent the JavaScript style object.

18 · Under the Hood

JSX vs React.createElement()

JSX

const element = (
    <h1>
        Hello
    </h1>
);

Readable and convenient for describing component UI.

JavaScript API

const element =
    React.createElement(
        "h1",
        null,
        "Hello"
    );

JSX is syntax that tooling transforms into JavaScript operations React can use.

You usually write JSX rather than manually writing createElement calls. Understanding the relationship is useful because it explains why JSX is ultimately JavaScript.
19 · Common Mistakes

Common JSX Mistakes

❌ Mistake 1 — Using class 
<div class="box">Hello</div>
Use className="box".
❌ Mistake 2 — Forgetting to close tags 
<h1>Hello
Use <h1>Hello</h1>.
❌ Mistake 3 — Multiple root elements 
return (
    <h1>Hello</h1>
    <p>React</p>
);
Wrap them in a parent element or Fragment.
❌ Mistake 4 — JavaScript without braces 
<p>Hello, name</p>
Use <p>Hello, {name}</p>.
❌ Mistake 5 — Invalid style syntax 
<h1 style="color: red">Hello</h1>
In JSX, use an object: style={{ color: "red" }}.
