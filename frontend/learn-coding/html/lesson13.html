12 • HTML5

Use Modern HTML5 Features

Your project can use modern HTML elements to make the structure more meaningful and interactive.

Semantic Elements

header, nav, main, section, article, aside and footer.

Details

Create expandable information without requiring custom JavaScript.

Progress

Represent task or course progress using the progress element.

Meter

Represent a measurement within a known range.

Time

Represent dates and times semantically.

Data Attributes

Store custom metadata for scripts and application behavior.

HTML5 Example 
<section>

    <h2>
        My Learning Progress
    </h2>

    <label for="courseProgress">
        HTML Course
    </label>

    <progress
        id="courseProgress"
        value="85"
        max="100">
        85%
    </progress>

    <details>

        <summary>
            View Learning Goals
        </summary>

        <p>
            Learn semantic HTML,
            forms, tables and accessibility.
        </p>

    </details>

</section>

20 • Security

HTML Does Not Automatically Make Data Safe

A frontend form can collect data, but real applications must validate and protect that data on the server too.

Remember: Client-side validation improves user experience, but server-side validation is still required for security and correctness.

Example 
<input
    type="email"
    name="email"
    required>

The browser can check whether the field is required and whether the input resembles an email address. A backend should still validate the submitted value independently.

24 • Exam Preparation

5-Mark Answer

Explain the steps involved in creating an HTML mini project.

An HTML mini project begins with planning the website structure and identifying the required sections. A valid HTML document is then created using DOCTYPE, html, head and body. Semantic elements such as header, nav, main, section, article and footer are used to organize content. Images, links, tables, forms and multimedia can then be added according to the project's requirements. Finally, the page is tested for valid structure, accessibility, responsive behavior, working links and correct file paths.

10-Mark Answer

Explain how to develop a professional HTML website.

A professional HTML website is developed systematically. First, the requirements and page structure are planned. A valid HTML5 document is created with appropriate metadata. Semantic elements such as header, nav, main, section, article, aside and footer are used to describe the structure of the page.

Navigation links are created using the anchor element. Images are added using img with meaningful alt text. Structured data is represented using tables with appropriate headings and scope attributes. User information can be collected using accessible forms containing labels and suitable input types.

Multimedia can be integrated using audio, video, source and track elements. HTML5 elements such as details, summary, progress and time can improve the structure and user experience.

Finally, the website should be tested for accessibility, responsive behavior, broken links, missing resources, semantic structure and browser compatibility.

25 • Interview Preparation

HTML Mini Project Interview Questions

1. Why should a project use semantic HTML?
Semantic HTML communicates the meaning and structure of content to browsers, search engines and assistive technologies.
2. Why should tables not be used for page layout?
Tables represent relationships between rows and columns of data. CSS layout systems are more appropriate for designing page structure.
3. What is the purpose of alt text?
It provides a textual alternative for an image when the image cannot be perceived.
4. Why are labels important in forms?
Labels identify form controls and improve accessibility and usability.
5. What is the difference between id and class?
An id identifies a particular element, while a class can be shared by multiple elements.
6. Why use figure and figcaption?
They provide semantic grouping for self-contained content such as images, diagrams or media and their captions.
7. What is the purpose of the viewport meta tag?
It helps browsers control the layout viewport, especially on mobile devices.
8. What is the purpose of the name attribute in forms?
It identifies submitted form data so that the server can associate a value with its field.
9. Why should client-side validation not be trusted alone?
Client-side validation can be bypassed. Server-side validation is necessary for security and correctness.
10. What is the purpose of the source element?
It allows audio or video elements to specify media sources, including different formats.
11. Why are headings important?
Headings organize content hierarchically and help users and assistive technologies understand the document.
12. What is the DOM?
The DOM is the browser's object representation of the HTML document, which scripts can inspect and manipulate.
13. What is progressive enhancement?
It means starting with a solid accessible core experience and progressively adding enhanced functionality.
14. What should you test before delivering an HTML project?
Test links, images, forms, keyboard navigation, headings, responsive behavior, media, validation and semantic structure.
