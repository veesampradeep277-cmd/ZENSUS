1. What Is HTML5?

The modern foundation of web pages and web applications.

HTML5 is the modern generation of HTML that provides improved document structure, native multimedia, graphics, forms, storage and APIs for building interactive web experiences.

Think of HTML5 like this: HTML gives the browser the structure and meaning of the page. JavaScript APIs allow the page to interact with browser capabilities.

Before HTML5

Developers often depended heavily on plugins for multimedia and interactive experiences.

HTML5

Native elements and browser APIs made many common web capabilities easier to implement.

Modern Web

HTML, CSS and JavaScript work together to create application-like experiences.

📄

2. HTML5 Document Structure

The modern HTML5 doctype is intentionally simple.

HTML5 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My HTML5 Website</title>
</head>

<body>

    <h1>Welcome to HTML5</h1>

</body>

</html>
Remember: <!DOCTYPE html> tells the browser to use standards mode for modern HTML.

4. Canvas

Draw graphics using JavaScript.

The <canvas> element provides a drawing surface. JavaScript can use the Canvas API to draw shapes, text, paths, animations, images and more.

HTML + JavaScript 
<canvas id="myCanvas"
        width="500"
        height="300">
</canvas>

<script>

const canvas = document.getElementById("myCanvas");

const ctx = canvas.getContext("2d");

ctx.fillStyle = "blue";

ctx.fillRect(50, 50, 150, 100);

</script>

5. SVG — Scalable Vector Graphics

Create resolution-independent graphics.

SVG is a vector graphics format. Instead of storing graphics as pixels, SVG represents shapes using mathematical descriptions.

Canvas

Excellent for pixel-based drawing and dynamic graphics.

SVG

Excellent for scalable icons, diagrams, logos and illustrations.

Responsive

SVG can scale without becoming pixelated.

SVG 
<svg width="300"
     height="180"
     viewBox="0 0 300 180"
     role="img"
     aria-label="Blue circle">

    <circle
        cx="150"
        cy="90"
        r="60"
        fill="blue">
    </circle>

</svg>

6. Web Storage

Store data in the user's browser.

Web Storage provides simple key-value storage mechanisms: localStorage and sessionStorage.

Feature localStorage sessionStorage
Persistence Usually remains after browser restart Usually tied to the current page session/tab
API localStorage sessionStorage
Data type Strings Strings
Common use Preferences, progress Temporary session state
JavaScript 
// Save
localStorage.setItem("username", "Pradeep");

// Read
const name = localStorage.getItem("username");

// Remove one value
localStorage.removeItem("username");

// Remove everything for this origin
localStorage.clear();
Important: Web Storage stores strings. Objects normally need JSON.stringify() and JSON.parse().
JavaScript 
const student = {
    name: "Alex",
    course: "CSE"
};

localStorage.setItem(
    "student",
    JSON.stringify(student)
);

const savedStudent = JSON.parse(
    localStorage.getItem("student")
);

console.log(savedStudent.name);

7. Geolocation API

Request the user's geographic location with permission.

The Geolocation API allows a web application to request location information from the browser.

JavaScript 
if ("geolocation" in navigator) {

    navigator.geolocation.getCurrentPosition(
        function(position) {

            console.log(
                position.coords.latitude
            );

            console.log(
                position.coords.longitude
            );

        },
        function(error) {

            console.log(
                "Location unavailable."
            );

        }
    );

}
Privacy: Never assume that location is automatically available. Browsers can request permission and users can deny it.

8. Drag and Drop API

Allow users to drag elements and drop them into targets.

The Drag and Drop API uses events such as dragstart, dragover and drop.

HTML 
<div
    id="item"
    draggable="true">

    Drag Me

</div>

<div id="dropZone">
    Drop Here
</div>
JavaScript 
item.addEventListener(
    "dragstart",
    function(event) {

        event.dataTransfer.setData(
            "text/plain",
            "ZENSUS"
        );

    }
);

dropZone.addEventListener(
    "dragover",
    function(event) {

        event.preventDefault();

    }
);

dropZone.addEventListener(
    "drop",
    function(event) {

        event.preventDefault();

        console.log(
            event.dataTransfer.getData(
                "text/plain"
            )
        );

    }
);

9. Progress and Meter

Represent progress and measurements semantically.

HTML provides native elements such as <progress> and <meter>.

HTML 
<label for="courseProgress">
    Course Progress
</label>

<progress
    id="courseProgress"
    value="72"
    max="100">
    72%
</progress>


<label for="skillLevel">
    Skill Level
</label>

<meter
    id="skillLevel"
    min="0"
    max="100"
    value="80">
    80
</meter>
Difference: <progress> represents completion of a task. <meter> represents a scalar measurement within a known range.

12. Custom Data Attributes

Store custom information on HTML elements using data-*.

HTML 
<button
    id="student"
    data-student-id="101"
    data-course="CSE">

    Student

</button>
JavaScript 
const student =
    document.getElementById("student");

console.log(
    student.dataset.studentId
);

console.log(
    student.dataset.course
);
Remember: Custom attributes should normally use the data-* convention.

13. Web Workers

Perform JavaScript work in a background thread.

A Web Worker can execute JavaScript separately from the main page thread. This can help keep the user interface responsive during suitable CPU-intensive tasks.

main.js 
const worker =
    new Worker("worker.js");

worker.postMessage(
    "Start calculation"
);

worker.onmessage = function(event) {

    console.log(
        event.data
    );

};
worker.js 
self.onmessage = function(event) {

    // Perform background work

    self.postMessage(
        "Calculation complete"
    );

};
Important: Workers do not directly manipulate the DOM in the normal way. They communicate with the main thread using messages.

14. History API

Work with browser session history.

JavaScript 
history.pushState(
    { page: "dashboard" },
    "",
    "/dashboard"
);

history.back();

history.forward();

Modern web applications can use browser history APIs to create navigation experiences without requiring a complete page reload for every state change.

Important: The History API changes browser history/state. It does not automatically create a complete routing system.

19. Common HTML5 Mistakes

Avoid these problems in real projects.

❌ Mistake 1

Treating localStorage as a secure database.

❌ Mistake 2

Requesting location without explaining why it is needed.

❌ Mistake 3

Using Canvas when semantic/vector SVG is more appropriate.

❌ Mistake 4

Performing huge computations on the main thread unnecessarily.

❌ Mistake 5

Assuming every browser/device supports every API identically.

❌ Mistake 6

Embedding untrusted third-party content without considering security and permissions.

22. HTML5 Security Basics

Browser APIs do not remove the need for security.

Never trust client-side data. Values stored in localStorage, sessionStorage, form fields and other client-side mechanisms can be modified by the user.

Storage

Do not use localStorage as a place for highly sensitive secrets.

Location

Request location only when necessary and explain its purpose.

iframes

Understand origins, permissions and sandboxing for embedded content.

25. Interview Questions

Questions you should be able to answer confidently.

1. What is HTML5?

HTML5 is the modern generation of HTML that provides improved structure, multimedia, forms, graphics and browser APIs.

2. What is the HTML5 doctype?

<!DOCTYPE html> is the simple modern declaration that puts the browser into standards mode.

3. What is Canvas?

Canvas is a scriptable drawing surface used for pixel-based graphics and dynamic visualizations.

4. What is SVG?

SVG is a vector graphics format that represents graphics using scalable shapes and paths.

5. Canvas vs SVG?

Canvas is generally pixel-oriented and drawn through scripting. SVG represents vector elements that remain scalable.

6. What is localStorage?

localStorage is browser storage that stores key-value string data and normally persists across browser sessions.

7. What is sessionStorage?

sessionStorage stores key-value string data associated with the current page session.

8. Does localStorage store objects directly?

No. Objects are normally converted to strings using JSON.stringify() and converted back using JSON.parse().

9. What is the Geolocation API?

It is a browser API that allows a website to request available geographic location information from the user/device.

10. What are Web Workers?

Web Workers execute JavaScript in a background thread so that suitable computations do not block the main page thread.

11. Can a Web Worker directly manipulate the DOM?

A worker does not have normal direct access to the page DOM. It communicates with the main thread through messages.

12. What is Drag and Drop?

It is a browser interaction API that allows data and elements to be dragged and dropped through events and DataTransfer.

13. What is the History API?

The History API provides methods such as pushState() and back() for working with browser session history.

14. What is the purpose of the progress element?

It represents completion progress for a task.

15. What is the meter element?

It represents a scalar measurement within a known range.
