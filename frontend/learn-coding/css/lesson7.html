Margin & Padding

Learn how professional websites control space inside, outside, between and around elements. Master spacing systems, shorthand syntax, auto margins, negative margins, collapsing margins and responsive spacing.

1. Why Spacing Matters

Good interfaces are not only about colors and fonts. Spacing creates hierarchy and readability.

Imagine a webpage where every element touches the next element. Even if the colors and typography are perfect, the interface will feel crowded.

CSS spacing solves this problem.
Margin controls the space outside an element.
Padding controls the space inside an element.

2. Margin vs Padding

The most important distinction in this lesson.

Margin

Creates space between an element and surrounding elements.

Content
Space appears outside the border.

Padding

Creates space between the content and the element's border.

Content
Space appears inside the border. 
/* Outside */
margin: 30px;

/* Inside */
padding: 30px;

3. Padding — Internal Space

Padding increases the space between the content and border. 

.card {
    padding: 24px;
}

This is commonly used for cards, buttons, inputs, navigation items and sections.

Individual padding properties 

padding-top: 20px;

padding-right: 30px;

padding-bottom: 20px;

padding-left: 30px;

Padding affects the element's box

Under content-box, adding padding can increase the rendered outer dimensions. Using box-sizing: border-box makes dimensions easier to control. 

* {
    box-sizing: border-box;
}

4. Margin — External Space

Margin controls the space surrounding an element. 

.card {
    margin: 30px;
}

Margin is particularly useful when separating sections, cards, headings and other block-level elements.

Individual margin properties 

margin-top: 20px;

margin-right: 30px;

margin-bottom: 40px;

margin-left: 30px;

5. Four Directions

CSS lets you control every side independently.

TOP margin-top
RIGHT margin-right
BOTTOM margin-bottom
LEFT margin-left 
margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;

The same four-direction model works with padding.

7. margin: auto

Horizontal auto margins are frequently used to center a block with a defined or constrained width. 

.container {
    width: 700px;
    margin-left: auto;
    margin-right: auto;
}

The remaining horizontal space is distributed between the left and right auto margins.

Centered Element
Important: margin: auto does not magically center every element in every situation. Its behavior depends on the element's layout context, dimensions and the axis being used.

8. Negative Margins

Unlike padding, margins can be negative. A negative margin can pull an element toward or over another element. 

.card {
    margin-top: -30px;
}
Element A
Element B — Negative Margin
Negative margins are powerful, but should be used deliberately. If spacing becomes difficult to understand, consider whether a different layout technique would communicate the intended relationship more clearly.

9. Margin Collapse

Vertical margins between certain block-level elements in normal flow can collapse. 

.first {
    margin-bottom: 40px;
}

.second {
    margin-top: 60px;
}

Do not simply assume the resulting gap is always 100px. In common adjoining-margin cases, the larger margin can determine the collapsed distance.

First element
Second element
Professional debugging tip: If two vertical margins appear to behave unexpectedly, inspect the elements in DevTools and check their formatting context and neighboring margins.

10. Percentage Values

Percentage values can be used with margin and padding. Their behavior is based on the containing block's relevant dimension rules, so percentage spacing should be understood rather than treated as a universal "percentage of the element itself." 

.card {
    padding: 5%;
    margin: 5%;
}
For responsive layouts, combine percentage spacing with other responsive units such as rem, vw or clamp() when appropriate.

11. Logical Margin & Padding

Modern CSS can describe spacing by writing direction instead of physical left/right sides. 

margin-inline: auto;

padding-inline: 24px;

margin-block: 30px;

padding-block: 20px;

Logical properties are especially useful when building interfaces that may support different writing directions.

Physical vs Logical

Physical Logical
margin-left margin-inline-start
margin-right margin-inline-end
padding-left padding-inline-start
padding-right padding-inline-end
margin-top / bottom margin-block-start / end

12. Responsive Spacing

Professional websites often need smaller spacing on mobile and larger spacing on larger screens. 

section {
    padding: clamp(20px, 5vw, 70px);
}

This gives the browser a flexible spacing value with a minimum, preferred responsive value and maximum.

Responsive Section

Resize the browser window and observe how the spacing adapts smoothly.

Modern pattern: Use a controlled spacing system instead of manually writing many unrelated pixel values throughout a project.

15. Common Mistakes

❌ Using margin when internal space is required

If text needs more room inside a card, use padding. 

/* Better */
.card {
    padding: 25px;
}

❌ Using padding to separate neighboring elements

If two separate elements need distance between them, margin or a parent layout's gap may be appropriate.

❌ Random spacing values everywhere

Avoid having dozens of unrelated values such as 17px, 23px, 31px and 43px without a spacing system.

A consistent spacing scale makes interfaces easier to maintain.

❌ Forgetting margin collapse

Two vertical margins in normal block flow may collapse. Always inspect the layout before assuming the browser "ignored" a margin.

❌ Ignoring box-sizing 

* {
    box-sizing: border-box;
}

Predictable sizing becomes much easier when the project's box-sizing strategy is understood.
