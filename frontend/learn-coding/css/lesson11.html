What is CSS Grid?

Think of Grid as a coordinate system for web layouts.

CSS Grid = Two-Dimensional Layout

CSS Grid is a layout system designed to control elements across both horizontal and vertical dimensions. You can define columns and rows and then position elements precisely inside the resulting grid.

Grid Terminology

Before writing advanced Grid code, understand the vocabulary.

GC

Grid Container

The parent element whose display is set to grid.

GI

Grid Item

A direct child of the Grid container.

GL

Grid Line

The numbered boundaries that define rows and columns.

GT

Grid Track

A complete row or column between two grid lines.

GC

Grid Cell

The smallest individual unit created by a row and column intersection.

GA

Grid Area

One or more adjacent grid cells grouped together.

EX

Explicit Grid

Rows and columns explicitly defined by you.

IM

Implicit Grid

Tracks automatically created when more space is needed.

Creating a Grid Container

Everything starts with the parent.

display: grid

Once an element becomes a Grid container, its direct children become Grid items.

.container { display: grid; }

display: inline-grid

inline-grid creates a Grid container that participates in inline formatting instead of behaving like a block-level container.

The fr Unit

One of the most important concepts in modern Grid.

Fraction of Available Space

The fr unit represents a fraction of the available space in the Grid container.

grid-template-columns: 1fr 1fr 1fr;

The available space is divided into three equal portions.

Unequal Fractions

grid-template-columns: 1fr 2fr 1fr;

The middle track receives twice the flexible share of each outer track.

repeat()

Avoid writing the same track definition repeatedly.

/* Without repeat */ grid-template-columns: 1fr 1fr 1fr 1fr; /* With repeat */ grid-template-columns: repeat(4, 1fr);

minmax()

Define a minimum and maximum size for a Grid track.

The Responsive Pattern

grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));

Each column should never become smaller than approximately 220px while still being able to expand into available space.

Advanced: minmax(0, 1fr)

grid-template-columns: minmax(0, 1fr) minmax(0, 1fr);

This pattern is useful when you need flexible tracks that can shrink to zero rather than allowing their minimum content size to force unwanted overflow.

gap, row-gap & column-gap

Control the spacing between Grid tracks.

grid { gap: 20px; } grid { row-gap: 30px; column-gap: 15px; }

Useful Shortcuts

Auto Placement & grid-auto-flow

Grid can automatically place items when explicit positions are not provided.

Default

grid-auto-flow: row;

Items are automatically placed across rows.

Column Flow

grid-auto-flow: column;

Dense Packing

grid-auto-flow: dense;

Dense packing allows later items to fill earlier available spaces when possible.

Responsive CSS Grid

Create layouts that adapt without manually defining every breakpoint.

.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 20px; }

auto-fit vs auto-fill

Both can be used with repeat() and minmax().


auto-fit

Empty tracks can collapse, allowing existing items to expand.


auto-fill

The browser attempts to fill the available space with as many tracks as can fit, including potentially empty tracks.

Grid Alignment

Grid has powerful alignment controls at both container and item level.

Container Alignment

justify-content align-content place-content

These control the position of the entire Grid inside its container when extra space exists.

Item Alignment

justify-items align-items place-items

These control the alignment of Grid items inside their cells.

Individual Item

justify-self align-self place-self

CSS Grid vs Flexbox

They solve related but different layout problems.

CSS Grid

  • Two-dimensional layout
  • Rows + columns
  • Excellent for page structures
  • Excellent for card layouts
  • Precise placement
  • Named areas

Flexbox

  • Primarily one-dimensional layout
  • Row OR column
  • Excellent for navigation
  • Excellent for component alignment
  • Content-driven layouts
  • Flexible distribution

Professional Rule

Don't think of Grid and Flexbox as competitors. Modern interfaces commonly use both:

Page Layout ↓ GRID ↓ Component Layout ↓ FLEXBOX

Common Grid Mistakes

Understanding mistakes is part of becoming interview-ready.

❌ Mistake 1

Using Grid for Everything

Not every small horizontal alignment problem requires Grid. Flexbox can often be simpler.

❌ Mistake 2

Forgetting Direct Children

Grid formatting directly affects the container's direct children, not arbitrary deeply nested elements.

❌ Mistake 3

Ignoring Responsive Sizing

Hard-coded columns can become unusable on smaller screens.

✓ Better Approach

Use minmax()

Combine minmax() with auto-fit for flexible card layouts.

🧠 ZENSUS Algorithm Thinking


When the browser sees:

display: grid;

Think like this:

1. Find the Grid container ↓ 2. Identify direct Grid items ↓ 3. Create explicit rows/columns ↓ 4. Calculate track sizes ↓ 5. Create grid lines ↓ 6. Place items ↓ 7. Create implicit tracks if necessary ↓ 8. Apply gaps ↓ 9. Apply alignment ↓ 10. Render the final layout

That is the mental model you should use when debugging CSS Grid.
