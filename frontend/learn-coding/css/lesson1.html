What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe how HTML elements should be presented on a webpage.

🎨

CSS controls colors, fonts, backgrounds, borders, shadows and many other visual properties.

06 · Targeting Elements

Introduction to Selectors

A CSS selector tells the browser which HTML element or elements should be styled. We will study selectors in much greater depth in Lesson 2.

Element Selector

p {
  color: blue;
}

Targets all paragraph elements.

Class Selector

.card {
  padding: 20px;
}

Targets elements with a specific class.

ID Selector

#header {
  background: black;
}

Targets an element by its ID.

08 · CSS Integration

Three Ways to Add CSS

1

Inline CSS

CSS is written directly inside an HTML element using the style attribute.

<p style="color: blue;"> Hello CSS </p>
2

Internal CSS

CSS is placed inside a <style> element within the HTML document.

<style>
p {
  color: blue;
}
</style>
3

External CSS

CSS is stored in a separate stylesheet and linked to the HTML document.

<link rel="stylesheet" href="style.css">

External stylesheets are particularly useful when styles need to be shared across multiple webpages.

09 · Cascade & Specificity

The CSS Cascade

The cascade is the process by which the browser determines which applicable CSS declarations contribute to the final styling when multiple rules affect an element.

/* Rule 1 */
p {
  color: blue;
}

/* Rule 2 */
.important {
  color: red;
}

/* Which applies? */
Important Text
1. Relevance
2. Origin & Importance
3. Specificity
4. Source Order

Important Idea

Don't think of CSS as simply "the last rule always wins." The browser considers several parts of the cascade, including importance, origin, specificity and source order.

15 · Beginner Mistakes

Common CSS Mistakes

❌
Wrong property name

background-colour is incorrect. The standard CSS property is background-color.

❌
Missing braces

CSS declarations belong inside { }.

❌
Confusing class and ID selectors

A class normally uses ., while an ID uses #.

❌
Forgetting the stylesheet link

When using an external stylesheet, the HTML document must correctly reference it.

❌
Using !important everywhere

Overusing !important can make styles harder to maintain and debug.

17 · JNTUK Exam Preparation

🎓 Exam Preparation

5 MARKS

What is CSS? Explain its purpose.

CSS stands for Cascading Style Sheets. It is a stylesheet language used to control the presentation of HTML documents. CSS can be used to specify colors, fonts, spacing, borders, backgrounds and layouts. It separates presentation from document structure, making websites easier to maintain and style consistently.

10 MARKS

Explain CSS and the different ways of applying CSS.

CSS is a stylesheet language used to describe the presentation of HTML documents. A CSS rule generally contains a selector and declaration block. Each declaration consists of a property and a value.

CSS can be applied in three major ways:

  1. Inline CSS — written inside an HTML element.
  2. Internal CSS — written inside a <style> element.
  3. External CSS — written in a separate stylesheet and connected using the <link> element.

External stylesheets are particularly useful for larger websites because the same stylesheet can be reused across multiple HTML pages.

18 · Interview Preparation

💼 CSS Interview Questions

1. What is CSS?

CSS is a stylesheet language used to describe the presentation of HTML documents.

2. What does CSS stand for?

Cascading Style Sheets.

3. What is a CSS selector?

A selector identifies the HTML elements to which a CSS rule should apply.

4. What is a CSS property?

A property represents the characteristic that CSS is going to modify, such as color or padding.

5. What is a CSS value?

A value specifies the setting assigned to a CSS property.

6. What is a declaration?

A property-value pair such as color: blue; is a declaration.

7. What is a ruleset?

A selector together with its declaration block forms a CSS ruleset.

8. What are the three ways of applying CSS?

Inline, Internal and External CSS.

9. What is the CSS cascade?

It is the mechanism used to determine which applicable declarations contribute to an element's final styling.

10. What is specificity?

Specificity is a mechanism used by CSS to determine the relative priority of competing selectors.

11. What is inheritance?

Inheritance allows certain properties of a parent element to be inherited by descendant elements.

12. Why is external CSS useful?

It separates styling from HTML and allows styles to be reused across multiple pages.

13. What happens when CSS rules conflict?

The browser resolves the conflict through the CSS cascade, considering factors such as origin, importance, specificity and source order.

14. Is CSS a programming language?

CSS is generally classified as a stylesheet language, not a general-purpose programming language.
