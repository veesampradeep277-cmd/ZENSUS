01

What is a Greedy Algorithm?

Understand the central idea before learning individual problems.

Definition

A Greedy Algorithm solves a problem by repeatedly making the choice that appears to be the best at the current moment, without reconsidering previous choices.

Simple idea At every step:

Choose the best available option → make the decision → continue.
🎯

Local Optimum

The best decision available right now.

🌍

Global Optimum

The best possible answer for the entire problem.

⚡

Greedy Choice

A local choice that can safely lead to the optimal solution.

Important! Greedy does NOT mean: "Always choose something that looks good." A greedy strategy must have a logical or mathematical reason why the choice is safe.

Greedy Intuition

Understand greedy thinking using everyday situations.

💰 Example — Paying with Coins

Suppose the available coins are:

25
10
5
1

For amount 41, a natural strategy is: 

25 → 10 → 5 → 1

25 + 10 + 5 + 1 = 41

This uses the largest useful coin first.

📅 Example — Scheduling Meetings

Suppose several meetings compete for the same room. You want to attend as many as possible.

Greedy idea: Choose the meeting that finishes earliest.

Why? Because finishing early leaves the maximum amount of time available for future meetings.

03

Greedy Choice Property & Optimal Substructure

The two ideas behind many greedy solutions.

1. Greedy Choice Property

A globally optimal solution can be obtained by making a locally optimal choice first.

Question to ask: Can I safely make the best choice now without needing to undo it later?

2. Optimal Substructure

After making a correct choice, the remaining problem must itself contain an optimal solution.

Think: Best choice now + best solution for the remaining problem.

Example

Activity Selection demonstrates both properties. 

Choose activity with earliest finish
                ↓
Remaining activities
                ↓
Solve remaining scheduling problem
                ↓
Repeat

Activity Selection Problem

One of the most important classical greedy problems.

Problem

Given activities with start and finish times, select the maximum number of non-overlapping activities.

Greedy choice: Always choose the activity that finishes earliest.

A(1,2), B(3,5), C(0,6), D(5,7), E(8,9)

3
Select B

B starts at 3 ≥ previous finish 2.

4

D starts at 5 ≥ B's finish 5.

5

Python — Activity Selection O(n log n) 
def activity_selection(activities):

    activities.sort(key=lambda x: x[1])

    selected = []

    last_finish = -1

    for start, finish in activities:

        if start >= last_finish:

            selected.append((start, finish))

            last_finish = finish

    return selected


activities = [
    (1, 2),
    (3, 5),
    (0, 6),
    (5, 7),
    (8, 9)
]

print(activity_selection(activities))
Complexity: Sorting takes O(n log n), traversal takes O(n). Overall: O(n log n)

Fractional Knapsack

Greedy works because items can be divided.

Problem

You have a bag with limited capacity. Each item has a value and weight. You can take fractions of items. Maximize total value.

Greedy choice: Choose the item with the highest value / weight ratio first.

Item A

Value = 60

Weight = 10

Ratio = 6

Item B

Value = 100

Weight = 20

Ratio = 5

Item C

Value = 120

Weight = 30

Ratio = 4
A
60 / 10
Ratio 6
B
100 / 20
Ratio 5
C
120 / 30
Ratio 4
Capacity = 50
Python — Fractional Knapsack O(n log n) 
def fractional_knapsack(items, capacity):

    items.sort(
        key=lambda x: x[0] / x[1],
        reverse=True
    )

    total_value = 0

    for value, weight in items:

        if capacity >= weight:

            capacity -= weight
            total_value += value

        else:

            total_value += (
                value / weight
            ) * capacity

            break

    return total_value
Important interview distinction: Greedy works for Fractional Knapsack. It does NOT generally work for 0/1 Knapsack because items cannot be divided.

Job Sequencing with Deadlines

Maximize profit while completing jobs before deadlines.

Problem

Each job has:

  • Deadline
  • Profit
  • One unit of execution time

Only one job can be executed at a time.

Greedy idea: Process jobs in descending order of profit and place each job in the latest available slot before its deadline.
A
Profit 100
Deadline 2
B
Profit 19
Deadline 1
C
Profit 27
Deadline 2
D
Profit 25
Deadline 1

Python — Job Sequencing Greedy 
def job_sequencing(jobs):

    jobs.sort(
        key=lambda x: x[2],
        reverse=True
    )

    max_deadline = max(job[1] for job in jobs)

    slots = [False] * (max_deadline + 1)

    profit = 0

    for job_id, deadline, value in jobs:

        for slot in range(deadline, 0, -1):

            if not slots[slot]:

                slots[slot] = True
                profit += value
                break

    return profit

Minimum Number of Coins

Learn both the greedy success and greedy failure cases.

Greedy Example

Coins: 

[25, 10, 5, 1]

Amount = 41

Choose the largest possible coin repeatedly. 

41
↓
25
↓
16
↓
10
↓
6
↓
5
↓
1

Answer = 4 coins
But greedy is NOT universally correct. Consider: 
Coins = [1, 3, 4]
Amount = 6
Greedy: 
4 + 1 + 1 = 6

3 coins
Optimal: 
3 + 3 = 6

2 coins
Therefore: Greedy fails.
Python — Greedy Coin Change Works only for suitable coin systems 
def greedy_coins(coins, amount):

    coins.sort(reverse=True)

    count = 0

    for coin in coins:

        count += amount // coin

        amount %= coin

    return count

Minimum Platforms

A classic interval and sorting problem.

Problem

Given train arrival and departure times, find the minimum number of platforms required so that no train has to wait.

Greedy idea: Sort arrival and departure times separately and process the next event chronologically.
Python — Minimum Platforms 
def minimum_platforms(arrival, departure):

    arrival.sort()
    departure.sort()

    i = 0
    j = 0

    platforms = 0
    answer = 0

    while i < len(arrival):

        if arrival[i] <= departure[j]:

            platforms += 1
            i += 1

            answer = max(answer, platforms)

        else:

            platforms -= 1
            j += 1

    return answer

Assign Cookies

Greedy matching between two sorted arrays.

Problem

Each child has a greed factor. Each cookie has a size. A cookie satisfies a child if: 

cookie size >= child's greed
Greedy: Give the smallest cookie that can satisfy the current least-demanding child.
Python — Assign Cookies 
def find_content_children(greed, cookies):

    greed.sort()
    cookies.sort()

    child = 0

    for cookie in cookies:

        if child < len(greed) and cookie >= greed[child]:

            child += 1

    return child

Jump Game

Maintain the farthest reachable position.

Example

nums = [2, 3, 1, 1, 4]

index:
  0  1  2  3  4

value:
  2  3  1  1  4

At every position, calculate the farthest position you can reach.

Greedy state: max_reach Keep updating the farthest reachable index.
Python — Jump Game 
def can_jump(nums):

    max_reach = 0

    for i in range(len(nums)):

        if i > max_reach:
            return False

        max_reach = max(
            max_reach,
            i + nums[i]
        )

    return True

Gas Station

Understand a powerful greedy reset technique.

Core Idea

If your current fuel becomes negative while traveling from station start to station i, then none of the stations between start and i can be a valid starting point.

Greedy reset: When current fuel < 0: 
start = i + 1
current = 0
Python — Gas Station 
def can_complete_circuit(gas, cost):

    if sum(gas) < sum(cost):
        return -1

    start = 0
    fuel = 0

    for i in range(len(gas)):

        fuel += gas[i] - cost[i]

        if fuel < 0:

            start = i + 1
            fuel = 0

    return start

Partition Labels

Greedy interval expansion.

Example

s = "ababcbacadefegdehijhklij"

Answer:
[9, 7, 8]

The goal is to partition the string so that each character appears in at most one partition.

Greedy idea: Find the last occurrence of every character. Expand the current partition until all characters inside it have their last occurrence within the partition.
Python — Partition Labels 
def partition_labels(s):

    last = {}

    for i, ch in enumerate(s):
        last[ch] = i

    result = []

    start = 0
    end = 0

    for i, ch in enumerate(s):

        end = max(end, last[ch])

        if i == end:

            result.append(
                end - start + 1
            )

            start = i + 1

    return result

Huffman Coding

A major greedy algorithm used for lossless compression.

Core Idea

Characters that occur frequently should receive shorter binary codes, while less frequent characters receive longer codes.

Greedy choice: Repeatedly combine the two nodes with the smallest frequencies. 
Frequencies:

A = 5
B = 9
C = 12
D = 13
E = 16
F = 45

Pick:
5 + 9 = 14

Then:
12 + 13 = 25

Continue...

This produces a Huffman Tree.
Python — Huffman Core Idea 
import heapq

def huffman(frequencies):

    heap = list(frequencies.values())

    heapq.heapify(heap)

    while len(heap) > 1:

        first = heapq.heappop(heap)
        second = heapq.heappop(heap)

        combined = first + second

        heapq.heappush(
            heap,
            combined
        )

    return heap[0]

Greedy Algorithms in Graphs

Kruskal and Prim are classic greedy algorithms.

Kruskal's Algorithm

Sort all edges by weight. Take the smallest edge that does not create a cycle. 

Sort edges
    ↓
Smallest edge
    ↓
Cycle?
 /     \
No      Yes
↓        ↓
Take    Skip

O(E log E)

Prim's Algorithm

Start from one vertex and repeatedly select the minimum-weight edge connecting the tree to a new vertex. 

Start vertex
    ↓
Cheapest connecting edge
    ↓
Add vertex
    ↓
Repeat

O(E log V)

Important connection: You learned these algorithms in Graphs, but conceptually they are also examples of greedy decision making.

How to Prove a Greedy Algorithm

Move from coding to interview-level reasoning.

Exchange Argument

A common proof technique is to show that an optimal solution can be transformed so that it contains the greedy choice without making the solution worse.

1
Choose the greedy option.
2
Take an optimal solution.
3
Replace its first choice with the greedy choice.
4
Show that the solution remains valid or no worse.
5
Therefore the greedy choice is safe.
Activity Selection Proof Intuition Choosing the activity that finishes earliest leaves at least as much remaining time as any other first choice. Therefore an optimal solution can always be modified to use the earliest-finishing activity first.

Greedy vs Brute Force vs Dynamic Programming

Know which technique to choose.

Feature Greedy Dynamic Programming Brute Force
Decision Best current choice Compare subproblems Try everything
Reconsider choices? Usually no Yes through states Yes
Speed Usually fast Moderate Often slow
Proof required Very important Recurrence correctness Exhaustive search
Example Activity Selection 0/1 Knapsack Subset Enumeration
Classic trap: Do not solve every optimization problem greedily. 0/1 Knapsack is the classic example where greedy based on value/weight can fail.

Common Greedy Mistakes

Errors students frequently make in interviews.

❌ Mistake 1 — Assuming greedy always works

Greedy is not a universal optimization technique.

❌ Mistake 2 — Choosing randomly

A greedy choice must have a reason.

❌ Mistake 3 — Ignoring sorting

Many greedy algorithms become obvious only after sorting.

❌ Mistake 4 — Confusing local and global optimum

The best immediate choice is not automatically the best overall choice.

❌ Mistake 5 — Forgetting edge cases

Always test empty input, one item, impossible cases, duplicates and boundary conditions.

❌ Mistake 6 — Using greedy for 0/1 Knapsack

Fractional Knapsack is greedy. 0/1 Knapsack generally requires DP or another exhaustive optimization technique.
