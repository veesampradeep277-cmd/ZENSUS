01 • Foundations

What is a Tree?

A tree is a hierarchical, non-linear data structure.

A tree is a data structure used to represent hierarchical relationships between elements.

Simple idea: Instead of storing elements one after another like an array, a tree stores elements in a parent-child hierarchy.

Real-world examples

📁

File System

Folder → subfolder → files. This naturally forms a hierarchy.

🏢

Organization

CEO → managers → employees can be represented using a tree.

🌐

Web Structure

HTML elements form a hierarchical Document Object Model.

02 • Terminology

Important Tree Terminology

These terms appear constantly in DSA and interviews.

①

Root

The topmost node of a tree. A tree has exactly one root when it is non-empty.

↳

Parent

A node that directly connects to one or more child nodes.

↓

Child

A node directly connected below another node.

↔

Sibling

Nodes having the same parent are called siblings.

●

Leaf

A node that has no children.

—

Edge

The connection between two nodes.

↕

Depth

Number of edges from the root to a particular node.

↟

Height

Number of edges on the longest downward path from a node to a leaf.

◫

Subtree

A node together with all of its descendants.

Interview warning: Depth and height are not the same.

Depth → measured from the root downward.
Height → measured from the node downward to its deepest leaf.

03 • Core Concept

What is a Binary Tree?

Definition

A Binary Tree is a tree in which every node can have at most two children.

The two children are called:

Left Child
Right Child

A node may have:

  • 0 children
  • 1 child
  • 2 children

04 • Mathematical Properties

Binary Tree Properties

These formulas are useful for exams and interviews.

Maximum nodes at level L

2L

If the root is at level 0:

  • Level 0 → 1 node
  • Level 1 → 2 nodes
  • Level 2 → 4 nodes
  • Level 3 → 8 nodes

Maximum nodes for height h

2h+1 − 1

If height starts from 0.

Example: height = 2

23 − 1 = 7

Edges in a tree

Edges = Nodes − 1

Example: If a tree has 7 nodes:

7 − 1 = 6 edges

Minimum height

To store n nodes with minimum possible height, nodes should be distributed as evenly as possible.

h ≈ ⌈log₂(n + 1)⌉ − 1

This is why balanced trees can provide efficient operations.

07 • Most Important

Binary Tree Traversals

Traversal means visiting every node of a tree exactly once in a specific order.

Master this tree:

1
↙          ↘
2          3
↙ ↘          ↙ ↘
4   5        6   7
DFS

Preorder Traversal

Visit: Root → Left → Right

1 → 2 → 4 → 5 → 3 → 6 → 7

Memory trick: Root comes first.

DFS

Inorder Traversal

Visit: Left → Root → Right

4 → 2 → 5 → 1 → 6 → 3 → 7

In a BST, inorder produces values in sorted order.

DFS

Postorder Traversal

Visit: Left → Right → Root

4 → 5 → 2 → 6 → 7 → 3 → 1

Memory trick: Root comes last.

BFS

Level Order Traversal

Visit nodes level by level from top to bottom.

1 → 2 → 3 → 4 → 5 → 6 → 7

Usually implemented using a queue.

```
```
Algorithms

Traversal Algorithms

Preorder Algorithm

Algorithm Root → Left → Right
``` 
PREORDER(root):

    if root is NULL:
        return

    visit(root)

    PREORDER(root.left)

    PREORDER(root.right)
```

Inorder Algorithm

Algorithm Left → Root → Right
``` 
INORDER(root):

    if root is NULL:
        return

    INORDER(root.left)

    visit(root)

    INORDER(root.right)
```

Postorder Algorithm

Algorithm Left → Right → Root
``` 
POSTORDER(root):

    if root is NULL:
        return

    POSTORDER(root.left)

    POSTORDER(root.right)

    visit(root)
```

Level Order Algorithm

Algorithm BFS
``` 
LEVEL_ORDER(root):

    if root is NULL:
        return

    create queue

    enqueue(root)

    while queue is not empty:

        node = dequeue()

        visit(node)

        if node.left exists:
            enqueue(node.left)

        if node.right exists:
            enqueue(node.right)
```

08 • Deep Understanding

Recursion Behind Tree Traversals

Tree traversal and recursion are closely connected.

Why recursion works

Every subtree is itself a smaller tree. Therefore, the same traversal logic can be applied repeatedly.

Key idea:

A tree problem can often be solved by asking:

"Can I solve this for the left subtree and the right subtree?"

Base Case

Python Critical
``` 
if root is None:
    return
```

Without a proper base case, recursion would continue indefinitely.

Preorder Call-Stack Example

Consider:

1 → 2 → 4 → 5 → 3 → 6 → 7
  1. Start at node 1.
  2. Visit 1.
  3. Go to the left subtree.
  4. Visit 2.
  5. Go to node 4.
  6. Node 4 has no children, so return.
  7. Back at node 2, visit node 5.
  8. Return to node 1.
  9. Process the right subtree.
Think recursively: "Do the same thing for the left subtree, then do the same thing for the right subtree."

09 • BFS

Level Order Traversal

Level order is Binary Tree Breadth-First Search.

Why a Queue?

A queue follows:

FIFO — First In, First Out

We process the earliest discovered node first. This naturally allows us to process the tree level by level.

Example

Queue: [1]

Remove 1 → add 2, 3
Queue: [2, 3]

Remove 2 → add 4, 5
Queue: [3, 4, 5]

Continue...

Python Level Order

Python BFS
``` 
from collections import deque


def level_order(root):

    if root is None:
        return

    queue = deque([root])

    while queue:

        node = queue.popleft()

        print(node.data, end=" ")

        if node.left:
            queue.append(node.left)

        if node.right:
            queue.append(node.right)
```

Python Patterns

Common Recursive Solutions

Count Nodes

Python O(n)
``` 
def count_nodes(root):

    if root is None:
        return 0

    left_count = count_nodes(root.left)

    right_count = count_nodes(root.right)

    return 1 + left_count + right_count
```

Find Height

Python Recursive DFS
``` 
def height(root):

    if root is None:
        return -1

    left_height = height(root.left)

    right_height = height(root.right)

    return 1 + max(
        left_height,
        right_height
    )
```
Convention note: Some textbooks define height using edges, where an empty tree has height −1 and a leaf has height 0. Others define height using nodes, where an empty tree may have height 0 and a leaf height 1. Always check which convention the problem uses.

12 • Important Distinction

Binary Tree vs Binary Search Tree

Feature Binary Tree Binary Search Tree
Maximum children 2 2
Ordering rule None Left < Root < Right
Inorder sorted? No Yes, under the standard BST ordering
Searching May require O(n) O(h) in a standard BST
Purpose Hierarchical structure Ordered searching

Binary Tree

10
↙   ↘
20   5

This is a valid binary tree even though 20 is greater than the root.

BST

10
↙   ↘
5    20

The ordering rule is satisfied: values on the left are smaller and values on the right are larger.

Never make this mistake:

Every BST is a binary tree.
But every binary tree is not a BST.

14 • Avoid These

Common Binary Tree Mistakes

!
Confusing height and depth

Depth is measured from the root to a node. Height is measured downward from a node.

!
Confusing Binary Tree with BST

A binary tree does not automatically have an ordering property.

!
Wrong traversal order

Remember: Pre = Root first, In = Root in the middle, Post = Root last.

!
Missing the base case

Recursive tree functions must handle the null / empty subtree case.

!
Forgetting one subtree

Many recursive solutions require processing both left and right subtrees.

!
Using stack when BFS is required

Level-order traversal normally requires a queue.
