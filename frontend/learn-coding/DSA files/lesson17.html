Sliding Window

🪟

When should you think Sliding Window?

Look for: subarray, substring, contiguous, longest, shortest, maximum, minimum.

Generic Sliding Window

left = 0

for right in range(len(arr)):

    # expand window
    add(arr[right])

    while window_is_invalid():

        # shrink window
        remove(arr[left])
        left += 1

    update_answer()
Time O(n)
Space O(k)
EASY

Maximum Sum Subarray of Size K

Given an array, find the maximum sum of any contiguous subarray of size K. 

def max_sum(arr, k):
    window_sum = sum(arr[:k])
    answer = window_sum

    for right in range(k, len(arr)):
        window_sum += arr[right]
        window_sum -= arr[right - k]

        answer = max(answer, window_sum)

    return answer

MEDIUM

Two Sum in a Sorted Array

def two_sum_sorted(arr, target):

    left = 0
    right = len(arr) - 1

    while left < right:

        total = arr[left] + arr[right]

        if total == target:
            return [left, right]

        elif total < target:
            left += 1

        else:
            right -= 1

    return []
Time O(n)
Space O(1)

Binary Search Patterns

First / Last Position

Find boundaries of duplicate values.

Search despite rotation.

Binary Search on Answer

Search the range of possible answers.

Binary Search Template

left = 0
right = len(arr) - 1

while left <= right:

    mid = left + (right - left) // 2

    if arr[mid] == target:
        return mid

    elif arr[mid] < target:
        left = mid + 1

    else:
        right = mid - 1

return -1

Monotonic Stack

📚

Recognition Signal

Look for: next greater, next smaller, previous greater, previous smaller.

← PUSH / POP →

Next Greater Element

def next_greater(arr):

    stack = []
    answer = [-1] * len(arr)

    for i in range(len(arr)):

        while stack and arr[i] > arr[stack[-1]]:
            index = stack.pop()
            answer[index] = arr[i]

        stack.append(i)

    return answer

INTERVIEW NAVIGATION

Which Pattern Should I Use?

What does the problem look like?

🪟 Contiguous Range?

Subarray / substring / longest / shortest

→ Sliding Window

👥 Sorted / Pair?

Two values, palindrome, in-place

→ Two Pointers

🔍 Search Space?

Sorted data or monotonic answer

→ Binary Search

🧮 Fast Lookup?

Frequency, duplicate, complement

→ HashMap / Set

📚 Next Greater?

Greater / smaller element relationship

→ Monotonic Stack

🌳 Hierarchical?

Parent-child structure

→ Tree DFS / BFS

🗺️ Connectivity?

Nodes, edges, components

→ Graph / DSU

🔄 All Possibilities?

Choices, combinations, permutations

→ Backtracking

💰 Repeated Subproblems?

Min / max / count / possibility

→ Dynamic Programming

🏆 Top K?

Kth largest / smallest / priority

→ Heap
