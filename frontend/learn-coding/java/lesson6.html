03 · LOOP TYPES

Types of Loops in Java

Java provides several looping constructs for different programming situations.

01

for Loop

Best when you know how many times the loop should run.

for(initialization; condition; update)
Best for counted repetition
02

Best when the number of iterations is not known in advance.

while(condition)
Condition checked first
03

do-while Loop

Executes the body first and checks the condition afterward.

do { } while(condition);
Executes at least once
04

Enhanced for

Simplifies iteration through arrays and collections.

for(type item : collection)
Clean collection iteration

The while Loop

A while loop checks its condition before executing the loop body.

YES
Print i

↺ Check again
NO → END
Java 
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}

Execution

  1. Initialize i = 1
  2. Check i <= 5
  3. Print the value
  4. Increment i
  5. Repeat until condition becomes false

Important

10 · LOOP CONTROL

The break Statement

break immediately terminates the nearest loop and transfers control to the statement after it.

1 2 3 4 STOP 5 6
Java 
for (int i = 1; i <= 10; i++) {

    if (i == 5) {
        break;
    }

    System.out.println(i);
}
Output: 1 2 3 4
11 · LOOP CONTROL

The continue Statement

continue skips the current iteration and proceeds with the next iteration.

1
2
3 SKIP
4
5
Java 
for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        continue;
    }

    System.out.println(i);
}
Output: 1 2 4 5

13 · IMPORTANT

Infinite Loops

An infinite loop occurs when its termination condition never becomes false.

∞

Condition remains TRUE

Danger Example 
int i = 1;

while (i <= 10) {
    System.out.println(i);
    // i++ is missing
}
⚠ Common Problem

Always make sure that the variables controlling the loop can eventually make the condition false.

15 · DEBUGGING

Common Loop Mistakes

01

Forgetting the update

The loop variable never changes and the loop can become infinite.

while (i < 10) { }
02

Off-by-one error

Using < instead of <=, or vice versa, can produce the wrong number of iterations.

03

Wrong semicolon

An accidental semicolon after a loop condition can create unexpected behavior.

while (i < 5);
04

Changing the wrong variable

Make sure the variable being updated is the one controlling the loop condition.

16 · INTERVIEW PREP

Interview Questions

What is a loop? +

A loop repeatedly executes a block of code while a condition is satisfied.

What is the difference between while and do-while? +

while checks the condition before execution, whereas do-while checks the condition after execution.

What does break do? +

break terminates the nearest enclosing loop.

What does continue do? +

continue skips the current iteration and proceeds with the next iteration.

When should you use an enhanced for loop? +

It is useful when you want to process each element of an array or collection without manually managing an index.
