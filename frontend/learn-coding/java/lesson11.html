PART 01

What is a Class?

A class is a blueprint or template from which objects can be created.

C

Class = Blueprint

A Java class defines the structure and behavior that objects created from it can have. A class can contain fields, methods, constructors, nested classes and interfaces.

Think about a building blueprint. The blueprint describes the structure, but the blueprint itself is not the actual building. Objects are the actual instances created from the class.
CLASS STRUCTURE

Anatomy of a Java Class

A class normally combines data and behavior into one logical unit.

Student.java 
class Student {

    String name;
    int age;

    void study() {
        System.out.println(name + " is studying");
    }
}

Break it down

class Student Declares a class named Student.
String name Stores the student's state.
int age Another piece of object state.
study() Defines behavior of the object.

OBJECT INITIALIZATION

Constructors and Objects

Constructors are commonly used to initialize an object's state when the object is created.

ConstructorExample.java 
class Student {

    String name;
    int age;

    Student(String name, int age) {

        this.name = name;
        this.age = age;
    }
}

class Main {

    public static void main(String[] args) {

        Student s1 =
            new Student("Pradeep", 19);

        System.out.println(s1.name);
        System.out.println(s1.age);
    }
}

What happens?

new Student(...) Creates a new Student object.
Student(...) Constructor initializes the object.
this.name Refers to the current object's field.
✓

Constructors are not inherited by subclasses, although a subclass can invoke a superclass constructor using super().

PART 03

What is Inheritance?

Inheritance allows a new class to derive from an existing class and reuse accessible members.

I

Inheritance = Reuse + Extension

Instead of writing the same functionality repeatedly, a child class can inherit common functionality from a parent class and then add its own specialized behavior.

Java syntax:
class Child extends Parent
INHERITANCE TERMINOLOGY

Learn the language of inheritance

P

Parent / Superclass

The existing class whose accessible members are inherited.

C

Child / Subclass

The class that extends another class.

E

extends

Keyword used by a class to inherit from another class.

S

super

Used to access members and constructors of the immediate parent class.

FIRST INHERITANCE EXAMPLE

Parent → Child

BasicInheritance.java 
class Animal {

    void eat() {

        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {

    void bark() {

        System.out.println("Dog is barking");
    }
}

public class Main {

    public static void main(String[] args) {

        Dog d = new Dog();

        d.eat();
        d.bark();
    }
}

↓
extends Dog inherits eat()
↓
CHILD bark() Own behavior

INHERITED / ACCESSIBLE

Common functionality

ACCESS CONTROL

Inheritance and access modifiers

Inheritance does not mean that every parent member becomes directly accessible everywhere.

AccessExample.java 
class Parent {

    public int a = 10;

    protected int b = 20;

    int c = 30;

    private int d = 40;
}


class Child extends Parent {

    void show() {

        System.out.println(a);
        System.out.println(b);
        System.out.println(c);

        // System.out.println(d);
        // Not directly accessible
    }
}
Modifier Basic inheritance visibility
public Accessible wherever permitted by Java's access rules.
protected Accessible within the same package and through subclass access rules.
default Accessible within the same package.
private Direct access is restricted to the declaring class.

TYPE 04

Multiple Inheritance

Java does not allow a class to extend two classes at the same time.

NOT ALLOWED

Two parent classes 

class A {
    void show() {}
}

class B {
    void show() {}
}

// Not valid Java

class C extends A, B {
}

If both parent classes provide the same method, Java would face ambiguity about which implementation should be inherited.

JAVA SOLUTION

Multiple Interfaces 

interface A {
    void showA();
}

interface B {
    void showB();
}

class C implements A, B {

    public void showA() {
        System.out.println("A");
    }

    public void showB() {
        System.out.println("B");
    }
}

Java supports a class implementing multiple interfaces.

ADVANCED STRUCTURE

Hybrid Inheritance

Hybrid inheritance combines multiple inheritance structures. In Java, such designs can be achieved using classes together with interfaces.

Animal
Dog
Pet
↓
ServiceDog
!
Exam point

Do not write that Java supports multiple inheritance through classes. Java supports multiple interface implementation instead.

PART 05

The super Keyword

The super keyword refers to the immediate superclass and is especially important when working with inheritance.

01

super.variable

Access a parent field when the child has a field with the same name.

02

super.method()

Call a parent method from a child class.

03

super()

Invoke the constructor of the immediate parent class.

04

Resolve conflicts

Helps distinguish parent members from child members.

SUPER — CASE 01

Accessing a parent variable

SuperVariable.java 
class Parent {

    int value = 100;
}

class Child extends Parent {

    int value = 200;

    void display() {

        System.out.println(value);

        System.out.println(super.value);
    }
}

public class Main {

    public static void main(String[] args) {

        Child c = new Child();

        c.display();
    }
}
value Child = 200
vs
super.value Parent = 100
SUPER — CASE 02

Calling a parent method

SuperMethod.java 
class Animal {

    void sound() {

        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {

        super.sound();

        System.out.println("Dog barks");
    }
}
Animal sound Dog barks
SUPER — CASE 03

Calling a parent constructor

SuperConstructor.java

    Person(String name) {

class Student extends Person {

PART 07

Method Overriding

A subclass can provide its own implementation of an inherited method.

MethodOverriding.java 
class Animal {

    void sound() {

        System.out.println(
            "Animal makes a sound"
        );
    }
}

class Dog extends Animal {

    @Override
    void sound() {

        System.out.println(
            "Dog barks"
        );
    }
}

public class Main {

    public static void main(String[] args) {

        Dog d = new Dog();

        d.sound();
    }
}
PARENT

Animal

sound() → Animal makes a sound

CHILD

Dog

sound() → Dog barks

OVERRIDING RULES

Important rules to remember

01

Same method signature

The overriding method must correspond to the inherited method according to Java's overriding rules.

02

Use @Override

The annotation helps the compiler verify that you intended to override a method.

03

Constructors cannot be overridden

Constructors belong to object initialization and are not inherited.

04

final methods cannot be overridden

A final method prevents subclasses from replacing its implementation.

IMPORTANT CONCEPT

Upcasting

A subclass object can be referenced using a superclass reference.

Upcasting.java 
class Animal {

    void sound() {
        System.out.println("Animal");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Dog");
    }

    void bark() {
        System.out.println("Bark");
    }
}

public class Main {

    public static void main(String[] args) {

        Animal a = new Dog();

        a.sound();

        // a.bark();
        // Not directly accessible through
        // the Animal reference.
    }
}
Remember: Animal a = new Dog(); means the reference type is Animal while the actual object is a Dog.

COMMON MISTAKES

Mistakes Java beginners often make

01

Confusing class and object

A class is the blueprint; an object is an instance created from that blueprint.

02

Forgetting new

Declaring Student s1 does not create the object. Instantiation is normally performed using new.

03

Thinking constructors are inherited

Constructors are not inherited. Parent constructors can be invoked using super().

04

Confusing overriding with overloading

Overriding works between superclass and subclass methods; overloading uses different parameter lists.

05

Writing multiple class inheritance

Java does not allow class C extends A, B. Use interfaces when a class needs to implement multiple contracts.

06

Misusing super

super refers to the immediate superclass, not an arbitrary ancestor.

INTERVIEW PREP

Frequently asked questions

Q1 What is the difference between a class and an object?

A class is a blueprint or template that defines fields and behavior. An object is an instance created from that class.

Q2 What keyword is used for inheritance in Java?

The extends keyword is used when one class inherits from another class.

Q3 What is the difference between superclass and subclass?

The superclass is the class being inherited from, while the subclass is the class that inherits from it.

Q4 Does Java support multiple inheritance?

Java does not support multiple inheritance through classes. A class can, however, implement multiple interfaces.

Q5 What is the purpose of super?

super can refer to members of the immediate superclass and can invoke the superclass constructor.

Q6 Are constructors inherited?

No. Constructors are not inherited. A subclass constructor can invoke a superclass constructor using super().

Q7 What is method overriding?

Method overriding occurs when a subclass provides its own implementation of an inherited method.

Q8 What is upcasting?

Upcasting is treating a subclass object as an instance of its superclass type, such as Animal a = new Dog().

Q9 What is the IS-A relationship?

It represents an inheritance relationship. For example, Dog IS-A Animal.

Q10 Why does Java avoid multiple class inheritance?

Multiple inheritance through classes can create ambiguity when different parent classes provide conflicting implementations. Java uses interfaces to support multiple type relationships instead.
