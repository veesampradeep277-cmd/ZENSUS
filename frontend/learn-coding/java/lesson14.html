CORE CONCEPT

What is an Interface?

I

Interface = Contract

An interface in Java is a reference type that defines a contract that implementing classes agree to follow.

Think of it like this: An interface tells a class what it must do, while the implementing class decides how to do it.
KEY IDEA

What vs How

This is one of the most important ideas behind interfaces.

WHAT

Interface

Defines what operations should be available.

pay() withdraw() print()
→
HOW

Implementation

The implementing class provides the actual behavior.

UPI payment ATM withdrawal Printer logic
WHY INTERFACES?

Why do we need interfaces?

01

Abstraction

Hide implementation details and expose only the required behavior.

02

Loose Coupling

Code can depend on an interface instead of a specific implementation.

03

Multiple Interfaces

A class can implement multiple interfaces, giving Java multiple inheritance of type.

04

Polymorphism

An interface reference can refer to different implementing objects.

SYNTAX

Creating an Interface

BasicInterface.java 
interface Animal {

    void sound();

    void move();
}

class Dog implements Animal {

    @Override
    public void sound() {
        System.out.println("Dog barks");
    }

    @Override
    public void move() {
        System.out.println("Dog runs");
    }
}

INTERFACE METHODS

Abstract Methods in Interfaces

Traditional interface methods are abstract and must be implemented by concrete classes.

Interface 
interface Vehicle {

    void start();

    void stop();

    void accelerate();
}
Implementation 
class Car implements Vehicle {

    public void start() {
        System.out.println("Car started");
    }

    public void stop() {
        System.out.println("Car stopped");
    }

    public void accelerate() {
        System.out.println("Car accelerating");
    }
}
INTERFACE MEMBERS

Variables in Interfaces

Fields declared in an interface are implicitly public, static and final.

Constants.java 
interface MathConstants {

    int MAX_VALUE = 100;

    double PI = 3.14159;
}

class Test {

    public static void main(String[] args) {

        System.out.println(MathConstants.MAX_VALUE);

        System.out.println(MathConstants.PI);
    }
}
Interface fields behave as: public static final constants.
MULTIPLE INHERITANCE

Implementing Multiple Interfaces

Java does not allow a class to extend multiple classes, but a class can implement multiple interfaces.

MultipleInterfaces.java 
interface Camera {

    void takePhoto();
}

interface GPS {

    void getLocation();
}

class Smartphone implements Camera, GPS {

    public void takePhoto() {

        System.out.println("Photo captured");
    }

    public void getLocation() {

        System.out.println("Location detected");
    }
}

JAVA 8+

Default Methods

A default method provides an implementation inside an interface.

DefaultMethod.java 
interface Vehicle {

    void start();

    default void horn() {

        System.out.println("Beep beep!");
    }
}

class Car implements Vehicle {

    public void start() {

        System.out.println("Car started");
    }
}

class Main {

    public static void main(String[] args) {

        Car car = new Car();

        car.start();

        car.horn();
    }
}
Output Car started Beep beep!
JAVA 8+

Static Methods in Interfaces

Static interface methods belong to the interface itself and are called using the interface name.

StaticInterfaceMethod.java 
interface Calculator {

    static int square(int n) {

        return n * n;
    }
}

class Main {

    public static void main(String[] args) {

        int result =
            Calculator.square(5);

        System.out.println(result);
    }
}
Output 25
JAVA 9+

Private Methods in Interfaces

Private methods can be used inside an interface to reuse common implementation logic.

PrivateMethod.java 
interface Logger {

    default void info(String message) {

        print("INFO: " + message);
    }

    default void error(String message) {

        print("ERROR: " + message);
    }

    private void print(String message) {

        System.out.println(message);
    }
}

INTERFACE + POLYMORPHISM

Interface Reference

An interface reference can point to an object of any class that implements that interface.

InterfacePolymorphism.java 
interface Payment {

    void pay();
}

class UPI implements Payment {

    public void pay() {

        System.out.println("Paid using UPI");
    }
}

class Card implements Payment {

    public void pay() {

        System.out.println("Paid using Card");
    }
}

class Main {

    public static void main(String[] args) {

        Payment payment;

        payment = new UPI();

        payment.pay();

        payment = new Card();

        payment.pay();
    }
}
Output Paid using UPI Paid using Card
FUNCTIONAL INTERFACE

Functional Interfaces

A functional interface contains exactly one abstract method. It can be used with lambda expressions.

FunctionalInterface.java 
@FunctionalInterface
interface Greeting {

    void sayHello();
}

class Main {

    public static void main(String[] args) {

        Greeting greeting =
            () -> System.out.println("Hello!");

        greeting.sayHello();
    }
}
Common examples from Java's standard library include functional interfaces such as Runnable, Comparator, Predicate, Function and Consumer.

IMPORTANT RULES

Interface Rules You Must Remember

RULE 01

You cannot directly create an object of an interface.

RULE 02

A class uses implements to implement an interface.

RULE 03

A class can implement multiple interfaces.

RULE 04

Interface fields are implicitly public, static and final.

RULE 05

AVOID THESE

Common Mistakes

01

Trying to instantiate an interface

❌ Wrong 

Payment p = new Payment();

✓ Correct 

Payment p = new UPI();
02

Using extends instead of implements

For a class implementing an interface, use implements. 

class Dog implements Animal {
}
03

Forgetting to implement methods

A concrete class must implement the required abstract methods.

04

Confusing interface with abstract class

Remember: interface = contract and abstract class = partially implemented base class.

INTERVIEW PREPARATION

Frequently Asked Questions

1. What is an interface in Java?

An interface is a reference type that defines a contract that implementing classes agree to follow.

2. Can we create an object of an interface?

No. An interface cannot be directly instantiated. However, an interface reference can refer to an implementing class object.

3. Can a class implement multiple interfaces?

Yes. Java allows a class to implement multiple interfaces.

4. Can an interface extend another interface?

Yes. An interface can extend one or more interfaces.

5. Can an interface have a constructor?

No. Interfaces do not have constructors because they cannot be instantiated directly.

6. What is a functional interface?

A functional interface has exactly one abstract method and can be used with lambda expressions.

7. What is the difference between extends and implements?

A class uses extends to inherit from a class. A class uses implements to implement an interface. An interface uses extends to inherit from another interface.

8. Why can a class implement multiple interfaces?

Java allows multiple inheritance of type through interfaces while avoiding many of the complexities associated with multiple class inheritance.
