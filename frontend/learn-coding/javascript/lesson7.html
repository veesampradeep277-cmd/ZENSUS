02 • Fundamentals

What is a Function?

A function is a reusable block of code designed to perform a specific task.

Think of a function like a machine. You give it input, it performs a task, and it may produce an output.

INPUT

Number: 10
FUNCTION
process()
OUTPUT

Result: 100
Basic Function 
function square(number) {
    return number * number;
}

console.log(square(10)); // 100
💡 Core idea Define the function once and call it whenever you need that behavior.

04 • Parameters & Arguments

Parameters vs Arguments

Parameters are placeholders. Arguments are the actual values supplied when the function is called.

Parameter

A variable written in the function definition. 

function greet(name) {
    console.log(name);
}

Argument

The actual value passed to the function. 

greet("Pradeep");
Easy way to remember Parameter = placeholder
Argument = actual value
Multiple Parameters 
function add(a, b) {
    return a + b;
}

console.log(add(10, 20)); // 30
console.log(add(5, 7));   // 12
05 • Default Parameters

Default Values

Default parameters allow a function to use a fallback value when an argument is not provided.

Example 
function greet(name = "Student") {
    return "Hello " + name;
}

console.log(greet("Pradeep"));
console.log(greet());
⚠️ Important Default parameters are used when the argument is undefined, not generally when it is null.
06 • Return Values

The return Statement

return sends a value back to the code that called the function.

Return Example 
function multiply(a, b) {
    return a * b;
}

const result = multiply(6, 7);

console.log(result); // 42
What happens after return? When JavaScript reaches return, the current function execution ends immediately.
Early Return 
function checkAge(age) {

    if (age < 18) {
        return "Not eligible";
    }

    return "Eligible";
}

console.log(checkAge(20));
07 • Function Forms

Declaration vs Expression

JavaScript provides multiple ways to create functions.

Function Declaration

function add(a, b) {
    return a + b;
}

Named function declaration. Function declarations are hoisted.

Function Expression

const add = function(a, b) {
    return a + b;
};

A function is stored inside a variable.

Interview point Function declarations can be called before their declaration because of hoisting. Function expressions assigned to let or const cannot be used before initialization.
08 • Anonymous Functions

Functions Without Names

An anonymous function does not have its own function name.

Anonymous Function 
const greet = function() {
    console.log("Hello!");
};

greet();

Anonymous functions are frequently used as callbacks and function expressions.

09 • Modern JavaScript

Arrow Functions

Arrow functions provide a shorter syntax for writing functions and have important differences in how this works.

Traditional Function 
const add = function(a, b) {
    return a + b;
};
Arrow Function 
const add = (a, b) => {
    return a + b;
};

Implicit Return

const add = (a, b) => a + b;

console.log(add(10, 20));

Single Parameter

const square = n => n * n;

No Parameters

const greet = () => "Hello!";
💡 Important difference Arrow functions do not have their own this, arguments, super, or new.target bindings. They are especially useful for callbacks and lexical this.

11 • Scope

Function Scope & Block Scope

Scope determines where a variable can be accessed.

Global Scope

const appName = "ZENSUS";

function show() {
    console.log(appName);
}

show();

Function Scope

function test() {
    const message = "Hello";
    console.log(message);
}

test();

// console.log(message); // Error

Block Scope

if (true) {

    let age = 19;
    const name = "Student";

    console.log(age);
}

// age is not accessible here
Best practice Prefer const by default, use let when reassignment is required, and avoid var in modern JavaScript unless you specifically understand its function-scoped behavior.
12 • First-Class Functions

Functions Are Values

In JavaScript, functions can be stored, passed and returned just like other values.

Store

const greet = function() {
    return "Hello";
};

Pass

function run(fn) {
    fn();
}

run(greet);

Return

function create() {
    return function() {
        return "Hi";
    };
}
Definition A language treats functions as first-class values when functions can be assigned to variables, passed as arguments and returned from other functions.
13 • Callbacks

Callback Functions

A callback is a function passed to another function so that it can be called later or at a specific point.

Basic Callback 
function greet(name, callback) {

    console.log("Hello " + name);

    callback();
}

function finish() {
    console.log("Task completed!");
}

greet("Pradeep", finish);

Callback Flow

Main Function
→
Receives Callback
→
Executes Callback
→
Complete
setTimeout(function() {
    console.log("Executed after 2 seconds");
}, 2000);

Callbacks are foundational to browser events, timers and asynchronous JavaScript.

14 • Higher-Order Functions

Functions That Work With Functions

A higher-order function takes a function as an argument, returns a function, or both. 

function calculate(a, b, operation) {
    return operation(a, b);
}

function add(x, y) {
    return x + y;
}

function multiply(x, y) {
    return x * y;
}

console.log(calculate(5, 3, add));
console.log(calculate(5, 3, multiply));

map()

Transforms every element.

[1,2,3].map(x => x * 2);

filter()

Selects matching elements.

[1,2,3,4]
.filter(x => x % 2 === 0);

reduce()

Combines values into one result.

[1,2,3,4]
.reduce((a,b) => a+b, 0);
15 • Modern Functions

Rest Parameters & Spread Syntax

Rest Parameter

Collects remaining arguments into an array. 

function sum(...numbers) {

    return numbers.reduce(
        (total, number) => total + number,
        0
    );
}

console.log(sum(10, 20, 30, 40));

Spread Syntax

Expands an iterable into individual values when calling a function. 

function add(a, b, c) {
    return a + b + c;
}

const numbers = [10, 20, 30];

console.log(add(...numbers));
Remember Rest collects values. Spread expands values.
16 • Arguments Object

The arguments Object

Traditional non-arrow functions can access an arguments object containing the arguments passed to the function. 

function showArguments() {

    console.log(arguments);

    for (let i = 0; i < arguments.length; i++) {
        console.log(arguments[i]);
    }
}

showArguments("A", "B", "C");
Modern recommendation Prefer rest parameters such as (...args) when you need a real array of variable arguments. Arrow functions do not have their own arguments object.
17 • IIFE

Immediately Invoked Function Expression

An IIFE is a function expression that is executed immediately after it is created. 

(function() {

    console.log("I run immediately!");

})();
(() => {

    console.log("Arrow IIFE");

})();

IIFEs were historically used to create private scopes before modern modules became the standard approach.

18 • Advanced

Recursion

Recursion occurs when a function calls itself to solve a smaller version of the same problem.

Factorial 
function factorial(n) {

    if (n === 0) {
        return 1;
    }

    return n * factorial(n - 1);
}

console.log(factorial(5)); // 120

Recursive Thinking

factorial(5)
↓
5 × factorial(4)
↓
4 × factorial(3)
↓
3 × factorial(2)
↓
2 × factorial(1)
↓
Base Case → 1
⚠️ Base case is mandatory Without a stopping condition, recursion can continue until the call stack is exhausted.
19 • Functional Thinking

Pure vs Impure Functions

Pure Function ✅

Same input → same output, and no observable side effects. 

function add(a, b) {
    return a + b;
}

Impure Function ⚠️

Depends on or modifies external state. 

let total = 0;

function addToTotal(value) {
    total += value;
}
Why pure functions are valuable They are easier to test, reason about, reuse and debug.
20 • Nested Functions

Functions Inside Functions

function outer() {

    function inner() {
        console.log("Inside inner function");
    }

    inner();
}

outer();

Nested functions can access variables from their surrounding scope. This behavior leads directly to closures.

21 • Advanced JavaScript

Closures

A closure occurs when a function remembers and can access variables from its lexical outer scope even after the outer function has finished executing. 

function createCounter() {

    let count = 0;

    return function() {

        count++;

        return count;
    };
}

const counter = createCounter();

console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3

Closure Visualization

createCounter()
→
count = 0
→
inner function
→
remembers count
Interview definition A closure is the combination of a function and the lexical environment in which that function was created.
22 • Execution Model

Function Hoisting

Function declarations are hoisted during JavaScript's setup/execution model. 

greet();

function greet() {
    console.log("Hello!");
}

The above works because greet is a function declaration.

Function Expression

sayHello();

const sayHello = function() {
    console.log("Hello");
};
⚠️ This does not work A variable declared with const is in the temporal dead zone until initialization is complete.
23 • Advanced Foundation

this, call(), apply() & bind()

These concepts become important when functions are used as object methods or when you explicitly control function invocation.

this in a Method

const student = {

    name: "Pradeep",

    greet() {
        console.log("Hello " + this.name);
    }

};

student.greet();

call()

function greet() {
    console.log("Hello " + this.name);
}

const user = {
    name: "Student"
};

greet.call(user);

apply()

function add(a, b) {
    return a + b;
}

console.log(
    add.apply(null, [10, 20])
);

bind()

const boundGreet = greet.bind(user);

boundGreet();
Interview warning Arrow functions use lexical this and do not create their own dynamic this binding.
24 • Terminology

Function vs Method

Function

function greet() {
    console.log("Hi");
}

greet();

A function can exist independently.

Method

const user = {

    greet() {
        console.log("Hi");
    }

};

user.greet();

A function used as a property of an object is commonly called a method.

34 • Common Mistakes

Errors Students Commonly Make

❌ Forgetting to call a function

function greet() {
    console.log("Hello");
}

// Nothing happens yet.

Correct: greet();


❌ Confusing return with console.log

function add(a, b) {
    console.log(a + b);
}

const result = add(2, 3);

console.log(result); // undefined

console.log() displays something. return sends a value back.


❌ Calling with missing arguments

function add(a, b) {
    return a + b;
}

console.log(add(10)); // NaN

❌ Infinite recursion

function count() {
    count();
}

// count(); // Do not do this

❌ Accidentally returning undefined

function test() {

    if (true) {
        return "Success";
    }

    // no return here
}

Explain JavaScript Functions.

A function in JavaScript is a reusable block of code designed to perform a particular task. Functions improve code reusability, modularity and maintainability.

37 • Interview Preparation

Important Interview Questions

A reusable block of code that performs a specific task.

2. Parameter vs argument?

Parameter is the placeholder in a definition; argument is the actual value passed during a call.

3. What is a callback?

A function passed to another function to be invoked later or at a particular point.

4. What is a higher-order function?

A function that accepts functions, returns a function, or both.

5. What is closure?

A function retaining access to variables from its lexical outer scope.

6. What is recursion?

A technique where a function calls itself until a base condition is reached.

Arrow functions have lexical this and do not have their own arguments object.

An Immediately Invoked Function Expression that runs immediately after creation.

40 • Mini Project

Student Result Analyzer

Use functions to build a small result-processing system.

Requirements

  • Function to calculate total marks.
  • Function to calculate average.
  • Function to determine grade.
  • Function to determine pass/fail.
  • Display final result.
function calculateTotal(marks) {

    return marks.reduce(
        (total, mark) => total + mark,
        0
    );
}

function calculateAverage(marks) {

    return calculateTotal(marks) / marks.length;
}

function getGrade(average) {

    if (average >= 90) return "A+";
    if (average >= 80) return "A";
    if (average >= 70) return "B";
    if (average >= 60) return "C";
    if (average >= 50) return "D";

    return "F";
}

const marks = [85, 90, 78, 92, 88];

const total = calculateTotal(marks);
const average = calculateAverage(marks);
const grade = getGrade(average);

console.log("Total:", total);
console.log("Average:", average);
console.log("Grade:", grade);

Functions in 60 Seconds

  • Function: reusable block of code.
  • Parameter: placeholder variable.
  • Argument: actual value passed.
  • return: sends value back.
  • Declaration: named function definition.
  • Expression: function stored in a value.

  • Callback: function passed to another function.
