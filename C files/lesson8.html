02 • Foundation

What is an Array?

An array is a collection of elements of the same data type stored in contiguous memory locations.

Without an array

C 
int mark1 = 85;
int mark2 = 90;
int mark3 = 78;
int mark4 = 92;
int mark5 = 88;

Managing many variables becomes repetitive and difficult.

With an array

C 
int marks[5] = {85, 90, 78, 92, 88};

One variable name can represent multiple related values.

Core idea: An array gives one common name to multiple values of the same type, and each value is accessed using an index.

10 • Searching

Linear Search

Linear search checks elements one by one until the target is found.

Algorithm

Start
Set i = 0
i < n ?
arr[i] == target?
i++

C implementation

C 
int arr[] = {10, 25, 30, 45, 50};
int target = 30;
int found = -1;

for(int i = 0; i < 5; i++) {

    if(arr[i] == target) {
        found = i;
        break;
    }
}

printf("Index = %d", found);
Complexity: Linear search has O(n) worst-case time complexity.
Interview Problem

Find the Second Largest Element

C 
#include <stdio.h>
#include <limits.h>

int main() {

    int arr[] = {10, 45, 20, 67, 34};
    int n = 5;

    int largest = INT_MIN;
    int second = INT_MIN;

    for(int i = 0; i < n; i++) {

        if(arr[i] > largest) {
            second = largest;
            largest = arr[i];
        }
        else if(arr[i] > second && arr[i] != largest) {
            second = arr[i];
        }
    }

    printf("Largest = %d\n", largest);
    printf("Second Largest = %d", second);

    return 0;
}
Interview note: If the question asks for the second distinct largest element, duplicates of the largest value must not become the answer.

11 • Sorting

Sorting Arrays

Sorting arranges array elements in ascending or descending order.

Bubble Sort

Compare adjacent elements and swap them when they are in the wrong order.

C 
for(int i = 0; i < n - 1; i++) {

    for(int j = 0; j < n - i - 1; j++) {

        if(arr[j] > arr[j + 1]) {

            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}
Complexity: Basic bubble sort has O(n²) worst-case time complexity.

Bubble Sort

Repeatedly swaps adjacent elements.

O(n²)

Selection Sort

Selects the minimum element each round.

O(n²)

Insertion Sort

Builds the sorted portion one element at a time.

O(n²)

15 • Advanced

Arrays and Pointers

Arrays and pointers are closely related in C. Understanding this relationship is essential for advanced C and DSA.

C 
int arr[3] = {10, 20, 30};

printf("%p\n", (void*)arr);
printf("%p\n", (void*)&arr[0]);

printf("%d\n", *(arr + 1));
Important concept: In many expressions, the array name converts to a pointer to its first element. However, an array is not itself a pointer.
Array Size

Finding Number of Elements

C 
int arr[] = {10, 20, 30, 40, 50};

int n = sizeof(arr) / sizeof(arr[0]);

printf("Elements = %d", n);
Very important: This common technique works for an actual array in the same scope. When an array is passed to a function, it is typically adjusted to a pointer parameter, so sizeof cannot be used there to recover the original element count.
Functions + Arrays

Passing Arrays to Functions

C 
#include <stdio.h>

void printArray(int arr[], int n) {

    for(int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
}

int main() {

    int numbers[] = {10, 20, 30, 40, 50};

    int n = sizeof(numbers) / sizeof(numbers[0]);

    printArray(numbers, n);

    return 0;
}
Best practice: Pass the array and its size separately when a function needs to know how many elements it can safely process.

Array Manipulation

Insertion and Deletion

Insertion concept

To insert an element in the middle while preserving order, elements after the insertion point are shifted right.

C 
for(int i = n; i > pos; i--) {
    arr[i] = arr[i - 1];
}

arr[pos] = value;
n++;

Deletion concept

To delete an element, elements after it are shifted left.

C 
for(int i = pos; i < n - 1; i++) {
    arr[i] = arr[i + 1];
}

n--;

Common Array Mistakes

!
Using index n For an array of size n, valid indexes are 0 to n-1.
!
Off-by-one error Using i <= n instead of i < n.
!
Reading uninitialized automatic arrays Local arrays without an initializer contain indeterminate values.
!
Writing beyond the array Accessing outside the valid range causes undefined behavior.
!
Wrong scanf syntax Use &arr[i] for an integer element with scanf.
!
Confusing size and last index An array of 5 elements has last index 4.
!
Assuming arrays grow automatically A normal C array has a fixed size after its storage is created.
!
Using sizeof incorrectly in functions Array parameters are adjusted to pointers.

Interview Preparation

Frequently Asked Questions

1. Why does C use zero-based indexing?

It aligns naturally with offset-based memory addressing: the first element is at offset zero from the beginning of the array.

2. Is an array a pointer?

No. An array and pointer are different types. In many expressions, an array name converts to a pointer to its first element.

3. What happens out of bounds?

Accessing outside the valid array range results in undefined behavior.

4. Why is array access O(1)?

The address of an element can be calculated directly from the base address and index.

5. Can an array size change automatically?

A normal array's storage size does not dynamically grow. Dynamic memory allocation is used when runtime resizing is required.

6. Why pass array size to a function?

Because the function parameter normally receives a pointer-like representation and does not retain the original array's size.
