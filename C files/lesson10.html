What is a Pointer?

The fundamental idea

A pointer is a variable that stores an address.

Normal variables store values. A pointer stores the memory address of another object.

Think like this:

Variable → stores data
Pointer → stores the address of data
Basic example 
int x = 10;

int *p = &x;

Visual Model

VARIABLE x
10
Address: 1000
→
POINTER p
1000
p stores address of x

Memory & Addresses

Understand what the pointer actually stores

Memory is divided into locations

Every object stored in memory occupies one or more bytes. Each byte has an address.

The addresses above are illustrative. Actual addresses depend on the program's execution environment.

The Address-of Operator — &

& operator 
int x = 50;

printf("%p", (void *)&x);

&x means: "give me the address of x."

For portable pointer-address output with printf, use %p and cast the pointer to void *.

05

Dereferencing — *

The most important pointer operation

* means "access the object at this address"

Example 
int x = 10;

int *p = &x;

printf("%d", *p);
Result: 10

p → contains the address of x
*p → accesses the value stored at that address

Change a Variable Through a Pointer

Modify through pointer 
int x = 10;

int *p = &x;

*p = 100;

printf("%d", x);
Output: 100

& vs *

Operator Meaning Example
& Address of &x
* Dereference / access pointed object *p
06

Complete Pointer Example

Put everything together

Complete program 
#include <stdio.h>

int main(void) {

    int x = 25;

    int *p = &x;

    printf("Value of x      = %d\n", x);
    printf("Address of x    = %p\n", (void *)&x);
    printf("Value of p      = %p\n", (void *)p);
    printf("Value of *p     = %d\n", *p);

    *p = 50;

    printf("New value of x  = %d\n", x);

    return 0;
}
07

NULL Pointer

Representing "points to nothing"

NULL 
int *p = NULL;

A null pointer is a pointer value that does not point to an object or function.

Never dereference NULL:

*p = 10;

is invalid when p == NULL.

Always Check When Appropriate

Safe check 
if(p != NULL) {
    printf("%d", *p);
}
08

Wild & Dangling Pointers

Two dangerous pointer states

Wild Pointer

int *p;

*p = 10;

p is uninitialized and does not point to a valid known object.

Dangling Pointer

int *p = malloc(sizeof *p);

free(p);

/* p is now dangling */

After freeing memory, the pointer value may still remain, but the object it referred to no longer exists.

10

Pointer Size

Do not assume all pointers have the same representation

sizeof() 
printf("%zu\n", sizeof(int *));
printf("%zu\n", sizeof(char *));
printf("%zu\n", sizeof(double *));

Pointer sizes are implementation-dependent. On many modern 64-bit systems they are commonly 8 bytes, but C does not require that exact size.

Important: The size of a pointer is not the same thing as the size of the object it points to.

Pointer Arithmetic

Move through objects and arrays

Basic Operations

Pointer arithmetic 
p++;
p--;
p + 2;
p - 2;

When a pointer points into an array, adding one advances it to the next element, not simply to the next byte.

Example

Array traversal with pointer 
int a[] = {10, 20, 30, 40};

int *p = a;

printf("%d\n", *p);

p++;

printf("%d\n", *p);
Output:
10
20

Why Does p + 1 Move by Different Amounts?

int *

p + 1 moves to the next int.
char *

p + 1 moves to the next char.

The compiler uses the pointed-to type to scale pointer arithmetic.

Pointer Difference

Subtract pointers 
int a[] = {10,20,30,40,50};

int *p = &a[1];
int *q = &a[4];

printf("%td", q - p);

When two pointers point into the same array (or one past it), their difference gives the number of elements between them.

12

Pointers and Arrays

One of the most important relationships in C

Array Name and First Element

Relationship 
int a[5] = {10,20,30,40,50};

printf("%d\n", a[0]);

printf("%d\n", *a);
Both access the first element: 10.

Key Identity

Equivalent indexing 
a[i] == *(a + i)

Array indexing is closely connected to pointer arithmetic.

But Array ≠ Pointer

This is a very common interview question.
Array Pointer
Represents an array object. Is a variable that stores an address.
Cannot be assigned to another array. Can be reassigned to point elsewhere.
sizeof(array) gives total array size in its scope. sizeof(pointer) gives pointer size.

Pointers and Functions

How functions can modify caller objects

Pass Address to a Function

Swap using pointers 
#include <stdio.h>

void swap(int *a, int *b) {

    int temp = *a;

    *a = *b;
    *b = temp;
}

int main(void) {

    int x = 10;
    int y = 20;

    swap(&x, &y);

    printf("%d %d", x, y);

    return 0;
}
Output: 20 10

Important: C Uses Pass-by-Value

C always passes function arguments by value. When you pass &x, the function receives a copy of the address. Dereferencing that copied pointer lets the function access the original object.

Interview answer: C does not have true pass-by-reference parameters. Pointers are used to achieve reference-like behavior.
16

Arrays as Function Parameters

Why pointers appear everywhere in C functions

Array parameter 
void printArray(int a[], int n) {

    for(int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
}

In a function parameter list, an array parameter is adjusted to a pointer parameter.

Equivalent parameter form 
void printArray(int *a, int n);
Because the function receives a pointer, it does not automatically know the original array length. Pass the length separately.
17

sizeof() — Array vs Pointer

One of the biggest interview traps

In the same scope 
int a[5];

printf("%zu", sizeof(a));

Here sizeof(a) is the total size of the array object.

Inside function parameter 
void test(int a[]) {

    printf("%zu", sizeof(a));
}

Here a is adjusted to a pointer parameter, so sizeof(a) gives the size of the pointer, not the original array.

Pointer to Pointer — **

Two levels of indirection

Basic Example

Double pointer 
int x = 10;

int *p = &x;

int **pp = &p;
x = 10
←
p = &x
←
pp = &p
x → value
p → address of x
pp → address of p

Dereferencing Levels

One vs two levels 
*p      // gives x

**pp    // gives x

Double Pointer in a Function

Modify a pointer itself 
void changePointer(int **p, int *newAddress) {

    *p = newAddress;
}

A pointer-to-pointer is useful when a function needs to modify the caller's pointer variable.

Void Pointer — void *

Generic object pointer

Generic pointer 
int x = 10;

void *p = &x;

printf("%d", *(int *)p);
A void * can hold the address of an object of any object type. Before dereferencing it, convert it to an appropriate object-pointer type.
Standard C does not allow pointer arithmetic directly on void *, because void has no size.
20

const and Pointers

Very important for professional C programming

1. Pointer to const

const int * 
int x = 10;
int y = 20;

const int *p = &x;

p = &y;

/* *p = 30;  // not allowed */

You can change where p points, but you cannot modify the pointed-to object through p.

2. Const Pointer

int * const 
int x = 10;

int * const p = &x;

*p = 20;

/* p = &y;  // not allowed */

The pointer itself cannot point somewhere else, but the pointed-to object can be modified.

3. Const Pointer to Const

Both protected 
const int * const p = &x;

Neither the pointer nor the pointed-to value can be changed through this declaration.

Dynamic Memory & Pointers

Runtime memory allocation

malloc()

Allocate memory 
#include <stdlib.h>

int *p = malloc(5 * sizeof *p);

if(p == NULL) {
    return 1;
}

malloc() allocates a block of uninitialized storage and returns a pointer to it, or NULL if allocation fails.

calloc()

Allocate and zero-initialize bytes 
int *p = calloc(5, sizeof *p);

calloc() allocates space for an array of elements and initializes all allocated bytes to zero.

realloc()

Resize allocation 
int *temp = realloc(p, 10 * sizeof *p);

if(temp != NULL) {
    p = temp;
}
Always use a temporary pointer with realloc() when failure must preserve the original allocation.

free()

Release memory 
free(p);

p = NULL;
Dynamic memory must eventually be released when it is no longer needed.

Dynamic Array Example

Combine pointers with malloc()

Complete program 
#include <stdio.h>
#include <stdlib.h>

int main(void) {

    int n;

    scanf("%d", &n);

    int *a = malloc((size_t)n * sizeof *a);

    if(a == NULL) {
        return 1;
    }

    for(int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    for(int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }

    free(a);

    return 0;
}

Function Pointers

Advanced and interview-important

A pointer can point to a function

Basic function pointer 
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {

    int (*fp)(int, int) = add;

    printf("%d", fp(10, 20));

    return 0;
}
Output: 30

Function Pointer as Callback

A powerful C programming technique

Callback example

void calculate(
    int a,
    int b,
    int (*operation)(int, int)

    printf("%d", operation(a, b));
}

    return x + y;
}

int main(void) {

    calculate(10, 20, add);

}

Pointers and 2D Arrays

Important advanced concept

2D array parameter 
#define COLS 3

void printMatrix(int a[][COLS], int rows) {

    for(int i = 0; i < rows; i++) {

        for(int j = 0; j < COLS; j++) {

            printf("%d ", a[i][j]);
        }

        printf("\n");
    }
}

For a multidimensional array parameter, the compiler needs the later dimensions to calculate addressing correctly.

Equality

    ...

    ...

Equality and inequality comparisons can be used to check whether pointers have the same pointer value, including checking for null.

Common Pointer Mistakes

Memorize these before interviews

❌ Uninitialized pointer

int *p;
*p = 10;

The pointer does not point to a valid object.

❌ Dereferencing NULL

int *p = NULL;

*p = 10;

Never dereference a null pointer.

❌ Wrong type

int x = 10;

float *p = &x;

Incompatible pointer types should not be used this way.

❌ Use after free

free(p);

printf("%d", *p);

The pointed-to allocation has already been released.

❌ Returning address of local variable

int *bad(void) {

    int x = 10;

    return &x;
}

x ceases to exist when the function returns.

❌ Out-of-bounds pointer

int a[3];

int *p = a;

printf("%d", *(p + 5));

Pointer arithmetic must stay within the valid array range (or one-past position when permitted).

34

Pointer Safety Rules

Professional habits

  1. Initialize pointers before using them.
  2. Use NULL when a pointer should represent no object.
  3. Check allocation results from malloc()/calloc().
  4. Do not dereference NULL.
  5. Do not dereference dangling pointers.
  6. Do not access outside array bounds.
  7. Free dynamically allocated memory exactly when ownership requires it.
  8. After free(), avoid using the old pointer; setting it to NULL can help prevent accidental reuse.
  9. Use the correct pointer type.
  10. Use const when pointed-to data should not be modified.

Interview Questions

Questions you should answer without hesitation

Q1. What is a pointer?

A pointer is an object that stores a pointer value, typically the address of another object or function.

Q2. What is *p?

It dereferences p, accessing the object to which p points, provided p points to a valid object.

Q3. What is &x?

It obtains the address of x.

Q4. Is an array a pointer?

No. An array is an array object. In many expressions its name converts to a pointer to its first element.

Q5. Why does p++ depend on pointer type?

Pointer arithmetic advances by the size of the pointed-to type.

Q6. What is a double pointer?

A pointer whose pointed-to object is itself a pointer.

Q7. What is void *?

A generic object pointer that can hold the address of an object of any object type.

Q8. What is a dangling pointer?

A pointer whose referenced object no longer exists or is no longer valid to access.

Q9. Does C use pass-by-reference?

No. C passes arguments by value. Pointers allow functions to access or modify caller objects.

Q10. What is a function pointer?

A pointer value that can refer to a function and be used to call it.

  3. Find minimum using pointers.

  5. Calculate sum using pointers.
