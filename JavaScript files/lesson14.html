03 · VARIABLES

let and const

The modern way to declare variables.

let

Use let when the variable needs to be reassigned. 

let score = 50;

score = 80;

console.log(score);

const

Use const when the variable binding should not be reassigned. 

const name = "Pradeep";

console.log(name);

// name = "Rahul"; // TypeError
Best Practice Prefer const by default. Use let only when reassignment is actually required.

Block Scope

if (true) {

    let a = 10;
    const b = 20;

    console.log(a);
    console.log(b);
}

// a and b cannot be accessed here.

05 · FUNCTIONS

Arrow Functions

A shorter function syntax with important this behavior.

Traditional Function

function add(a, b) {
    return a + b;
}

Arrow Function

const add = (a, b) => {
    return a + b;
};

Implicit Return

const square = n => n * n;

console.log(square(5));
Important: this Arrow functions do not create their own this. They use the surrounding lexical this.
06 · FUNCTIONS

Default Parameters

Provide fallback values directly in function parameters.

function greet(name = "Student") {
    return `Hello, ${name}!`;
}

console.log(greet("Pradeep"));
console.log(greet());

Rest Parameters

function sum(...numbers) {

    return numbers.reduce(
        (total, n) => total + n,
        0
    );
}

console.log(sum(10, 20, 30, 40));

The ...numbers syntax collects multiple arguments into an array.

07 · DATA EXTRACTION

Destructuring

Extract values from arrays and objects using concise syntax.

Array Destructuring

const scores = [90, 85, 78];

const [first, second, third] = scores;

console.log(first);
console.log(second);
console.log(third);

Object Destructuring

const student = {
    name: "Pradeep",
    age: 19,
    branch: "CSE"
};

const {name, age, branch} = student;

console.log(name);
console.log(branch);

Renaming Variables

const student = {
    name: "Pradeep",
    marks: 92
};

const {
    name: studentName,
    marks: score
} = student;

console.log(studentName);
console.log(score);

Skipping Array Values

const colors = ["red", "green", "blue"];

const [, second] = colors;

console.log(second);
08 · COLLECTIONS

Rest & Spread Operators

Same syntax, different jobs depending on context.

Spread — Expand

const a = [1, 2, 3];
const b = [4, 5, 6];

const result = [...a, ...b];

console.log(result);

Rest — Collect

function show(first, ...others) {

    console.log(first);
    console.log(others);
}

show(10, 20, 30, 40);
Easy Memory Trick Spread expands. Rest collects.

Object Spread

const user = {
    name: "Pradeep",
    role: "Student"
};

const updatedUser = {
    ...user,
    role: "Developer"
};

console.log(updatedUser);

Enhanced Object Literals

ES6 made object creation cleaner.

When property names and variable names are identical, ES6 allows shorthand property syntax.

10 · ITERATION

for...of

Iterate directly over values of iterable objects.

const languages = [
    "JavaScript",
    "Python",
    "Java"
];

for (const language of languages) {
    console.log(language);
}

Compared with for...in

const languages = ["JS", "Python", "Java"];

for (const index in languages) {
    console.log(index);
}

for (const value of languages) {
    console.log(value);
}
Rule Use for...of when you want values. Use for...in mainly for enumerable property keys.
11 · COLLECTIONS

Map and Set

Specialized collections introduced in ES6.

Map

A Map stores key-value pairs. Keys can be values of many types. 

const students = new Map();

students.set("101", "Pradeep");
students.set("102", "Rahul");

console.log(students.get("101"));

console.log(students.has("102"));

console.log(students.size);

Set

A Set stores unique values. 

const numbers = new Set();

numbers.add(10);
numbers.add(20);
numbers.add(10);

console.log(numbers);

console.log(numbers.has(20));

Remove Duplicates Using Set

const numbers = [1, 2, 2, 3, 4, 4, 5];

const unique = [...new Set(numbers)];

console.log(unique);
12 · OOP

Classes

ES6 introduced a cleaner syntax for object-oriented programming.

class Student {

    constructor(name, marks) {
        this.name = name;
        this.marks = marks;
    }

    introduce() {
        return `I am ${this.name}`;
    }

    isPassed() {
        return this.marks >= 40;
    }
}

const student = new Student("Pradeep", 92);

console.log(student.introduce());
console.log(student.isPassed());
Important JavaScript classes are built on top of JavaScript's prototype-based object model. The class syntax provides a cleaner abstraction.

Inheritance

class Animal {

    speak() {
        return "Animal makes a sound";
    }
}

class Dog extends Animal {

    speak() {
        return "Dog barks";
    }
}

const dog = new Dog();

console.log(dog.speak());

Modules

Split large applications into reusable files.

15 · ASYNCHRONOUS JAVASCRIPT

async / await

Write asynchronous code in a more readable style.

function getUser() {

    return Promise.resolve({
        name: "Pradeep"
    });
}

async function showUser() {

    try {

        const user = await getUser();

        console.log(user.name);

    } catch (error) {

        console.log(error);
    }
}

showUser();
Think of it this way await pauses the async function until the Promise settles, without blocking the JavaScript thread itself.
16 · MODERN SYNTAX

Optional Chaining & Nullish Coalescing

Safer access to potentially missing data.

Optional Chaining ?.

const user = {
    profile: {
        name: "Pradeep"
    }
};

console.log(user.profile?.name);

console.log(user.address?.city);

If a value before ?. is nullish, the expression returns undefined instead of throwing because of that missing property.

Nullish Coalescing ??

const username = null;

const result =
    username ?? "Guest";

console.log(result);

?? uses the fallback only when the left side is null or undefined.

?? vs ||

const score = 0;

console.log(score || 100);
// 100

console.log(score ?? 100);
// 0
Interview Point || treats values such as 0, "" and false as falsy. ?? only falls back for null and undefined.
16.5 · MODERN JAVASCRIPT

Useful Modern Array Syntax

ES6 works especially well with functional array methods.

M

map()

Transform every element.

const nums = [1,2,3];

const result =
    nums.map(n => n * 2);
F

filter()

Select elements matching a condition.

const nums = [1,2,3,4];

const even =
    nums.filter(n => n % 2 === 0);
R

reduce()

Combine values into one result.

const nums = [1,2,3];

const total =
    nums.reduce(
        (a,b) => a + b,
        0
    );
17 · ADVANCED

Iterators & Generators

Advanced tools for controlling iteration.

Generator Function

function* numbers() {

    yield 1;
    yield 2;
    yield 3;
}

const generator = numbers();

console.log(generator.next());
console.log(generator.next());
console.log(generator.next());
console.log(generator.next());

A generator can pause at yield and continue later. Each call to next() returns an object containing value and done.

Advanced Topic Iterators and generators are useful to understand deeply when working with custom data structures, lazy sequences and JavaScript internals.

20 · DEBUGGING

Common ES6 Mistakes

Learn these early and avoid unnecessary bugs.

❌ Using var everywhere

var score = 10;

Prefer let or const in modern code.

❌ Confusing Rest and Spread

const copy = [...numbers]; // spread

function test(...args) {}  // rest

❌ Expecting arrow functions to have their own this

Arrow functions capture this lexically.

❌ Misunderstanding ??

0 ?? 100
// 0

Nullish coalescing is not the same as logical OR.

❌ Mutating arrays accidentally

const copy = [...original];

Spread creates a shallow copy, not a deep copy.

❌ Forgetting try/catch with await

async function load() {

    try {
        const data = await getData();
    } catch (error) {
        console.log(error);
    }
}

22 · INTERVIEW PREPARATION

Important Interview Questions

1. Difference between let, const and var?

var is function-scoped and has older hoisting semantics. let and const are block-scoped and have a temporal dead zone before initialization. const prevents reassignment of its binding.

2. What is an arrow function?

A concise function syntax introduced in ES6. Arrow functions do not have their own this, arguments, super, or new.target.

3. What is destructuring?

A syntax for unpacking values from arrays or properties from objects into variables.

4. Difference between Map and Object?

Map is a dedicated key-value collection with explicit collection methods and keys that can be values of different types. Objects are general-purpose property containers.

5. What is a Set?

A collection that stores unique values.

6. What is the difference between Promise and async/await?

Promises provide the underlying asynchronous abstraction. async/await provides syntax for writing Promise-based asynchronous code in a more sequential style.

7. What does the spread operator do?

It expands an iterable or enumerable object into individual elements/properties depending on context.

8. What does optional chaining do?

It safely continues property access when an intermediate value is nullish, returning undefined rather than failing because of that missing value.
