What Is an Object?

An object is a collection of related data and functionality represented using key-value pairs.

Objects are perfect for representing real-world entities such as students, users, products, cars, bank accounts, and orders.

name
→
"Pradeep"
age
→

→

JavaScript 
const student = {
    name: "Pradeep",
    age: 19,
    branch: "CSE",
    isStudent: true
};
Think of it like this: An object is like a real-world record. The key describes what information we have, while the value contains the actual information.

04

Creating Objects

1. Object Literal — Most Common

const user = {
    name: "Alice",
    age: 22,
    city: "Hyderabad"
};

2. Using new Object()

const user = new Object();

user.name = "Alice";
user.age = 22;
Best practice: Object literals are generally preferred for ordinary object creation because they are shorter and easier to read.

3. Object.create()

const personPrototype = {
    greet() {
        return "Hello!";
    }
};

const person = Object.create(personPrototype);

person.name = "Alice";

console.log(person.greet());

Object.create() allows you to create an object with a specified prototype.

05

Accessing Object Properties

JavaScript provides two major ways.

Dot Notation

const student = {
    name: "Pradeep",
    age: 19
};

console.log(student.name);
console.log(student.age);

Bracket Notation

console.log(student["name"]);
console.log(student["age"]);
When should you use brackets? Bracket notation becomes essential when the property name is stored in a variable or contains characters that cannot be used normally with dot notation. 
const key = "name";

console.log(student[key]);

Add, Update & Delete Properties

Add

08

Objects Can Contain Functions

A function stored inside an object is commonly called a method. 

const student = {
    name: "Pradeep",

    greet: function() {
        return "Hello " + this.name;
    }
};

console.log(student.greet());

Modern Method Syntax

const student = {
    name: "Pradeep",

    greet() {
        return `Hello ${this.name}`;
    }
};

console.log(student.greet());
Key idea: Objects can store both data and behavior.

13

Object Property Shorthand

If a variable and property have the same name, JavaScript allows a shorter syntax. 

const name = "Pradeep";
const age = 19;
const branch = "CSE";

const student = {
    name,
    age,
    branch
};

Instead of writing: 

const student = {
    name: name,
    age: age,
    branch: branch
};
14

Computed Property Names

Property names can be dynamically calculated using square brackets. 

const field = "username";

const user = {
    [field]: "pradeep123"
};

console.log(user.username);
Useful for: Dynamic forms, API payloads, configuration objects, reducers, and many advanced JavaScript applications.

Object Destructuring

Extract properties into variables.

    name: "Pradeep",
    age: 19,
    branch: "CSE"
};

const { name, age, branch } = student;

console.log(name);
console.log(age);
console.log(branch);

Rename During Destructuring

const {
    name: studentName,
    age: studentAge
} = student;

console.log(studentName);
console.log(studentAge);

Default Values

const {
    name,
    country = "India"
} = student;

console.log(country);

17

Object Spread Operator

The spread operator ... can copy enumerable properties from one object into another. 

const user = {
    name: "Pradeep",
    age: 19
};

const copy = {
    ...user
};

console.log(copy);

Merge Objects

const personal = {
    name: "Pradeep",
    age: 19
};

const academic = {
    branch: "CSE",
    cgpa: 8.63
};

const student = {
    ...personal,
    ...academic
};
Important: Object spread creates a shallow copy. Nested objects are not deeply cloned.
18

Rest Properties

const student = {
    name: "Pradeep",
    age: 19,
    branch: "CSE",
    city: "Guntur"
};

const {
    name,
    ...remaining
} = student;

console.log(name);
console.log(remaining);

Here, remaining collects the rest of the properties.

20

Looping Through Objects

for...in

const student = {
    name: "Pradeep",
    age: 19,
    branch: "CSE"
};

for (const key in student) {
    console.log(key, student[key]);
}

Using Object.entries()

for (const [key, value] of Object.entries(student)) {
    console.log(key, value);
}
Modern approach: Object.entries() combined with for...of is often a clear way to process both keys and values.
21

Optional Chaining

Optional chaining ?. lets you safely access nested properties when an intermediate value may be nullish. 

const user = {
    profile: {
        name: "Pradeep"
    }
};

console.log(user.profile?.name);
console.log(user.address?.city);

Instead of throwing an error when address is undefined, the second expression produces undefined.

22

Nullish Coalescing with Objects

const user = {
    name: "Pradeep"
};

const city = user.city ?? "Unknown";

console.log(city);

The ?? operator uses the right side only when the left side is null or undefined.

Property Descriptors

Advanced object control.

JavaScript properties have attributes such as:

value

The property's stored value.

writable

Whether the value can be changed.

enumerable

Whether it appears in common enumeration.

configurable

Whether the descriptor/property can generally be reconfigured or deleted. 

const user = {
    name: "Pradeep"
};

console.log(
    Object.getOwnPropertyDescriptor(user, "name")
);

Object.defineProperty()

const user = {};

Object.defineProperty(user, "name", {
    value: "Pradeep",
    writable: false,
    enumerable: true,
    configurable: false

console.log(user.name);

This provides low-level control over property descriptors.

27

Objects and References

Objects are reference values. Assigning an object variable to another variable does not create an independent copy. 

const user1 = {
    name: "Pradeep"
};

const user2 = user1;

user2.name = "Rahul";

console.log(user1.name);
Result: user1.name also becomes "Rahul" because both variables refer to the same object.
28

Shallow Copy

Spread

const original = {
    name: "Pradeep",
    age: 19
};

const copy = {
    ...original
};

Object.assign()

const copy = Object.assign({}, original);

Both commonly create shallow copies of the object's enumerable own properties.

29

Deep Copy — Important Concept

A shallow copy does not recursively copy nested objects. 

const original = {
    name: "Pradeep",

    address: {
        city: "Guntur"
    }
};

const copy = {
    ...original
};

copy.address.city = "Hyderabad";

console.log(original.address.city);

structuredClone()

const deepCopy = structuredClone(original);
Modern option: structuredClone() can deep-clone many structured data types. It is not a universal clone for every JavaScript value, so understand its supported data model before relying on it.

Objects and Classes

Classes provide a convenient syntax for creating objects with shared structure and behavior. 

class Student {

    constructor(name, branch) {
        this.name = name;
        this.branch = branch;
    }

    introduce() {
        return `I am ${this.name}`;
    }
}

const student =
    new Student("Pradeep", "CSE");

console.log(student.introduce());

Classes will become much easier after you understand objects, prototypes, and this.

🚨 Common Mistakes

❌ Wrong Dynamic Access

const key = "name";

student.key;

This looks for a property literally named key.

Use: 

student[key];

❌ Confusing Copy

const b = a;

This does not create an independent object.

❌ Forgetting this

const user = {
    name: "A",
    greet() {
        return name;
    }
};

Use: 

return this.name;

❌ Assuming spread is deep

Object spread performs a shallow copy.

38

Professional Best Practices

  • Use meaningful property names.
  • Keep objects focused on one responsibility.
  • Prefer const when the object variable does not need reassignment.
  • Use object shorthand when appropriate.
  • Use destructuring to make data extraction readable.
  • Avoid unnecessarily deep nested objects.
  • Understand reference behavior before copying objects.
  • Use immutable update patterns when working with state-heavy applications.
  • Do not overuse Object.freeze() without understanding shallow immutability.
39

Performance & Design Thinking

Objects are fundamental to JavaScript, but good object design matters more than simply knowing syntax.

Small Objects

Keep frequently used structures simple and understandable.

Avoid Unnecessary Copies

Large object copies can consume memory and time.

Stable Structure

Consistent object shapes can help JavaScript engines optimize execution.

Readable Data Models

Good object structure makes APIs and application state easier to maintain.

🚀 Mini Project — Student Profile Manager

Combine objects, arrays, methods, destructuring, and DOM-ready thinking. 

const student = {

    id: 101,

    name: "Pradeep",

    branch: "CSE",

    skills: [
        "Python",
        "JavaScript",
        "SQL"
    ],

    marks: {
        python: 90,
        javascript: 88,
        sql: 92
    },

    getAverage() {

        const values =
            Object.values(this.marks);

        return values.reduce(
            (sum, mark) => sum + mark,
            0
        ) / values.length;
    },

    introduce() {

        return `
        I am ${this.name}.
        I study ${this.branch}.
        My average is ${this.getAverage()}.
        `;
    }
};

console.log(student.introduce());
