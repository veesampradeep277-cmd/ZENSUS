02 • Fundamentals

What is an Array?

An array is an ordered collection of values.

Instead of creating separate variables for many related values, an array lets us store them together.

Without Array 
const mark1 = 85;
const mark2 = 92;
const mark3 = 78;
const mark4 = 90;
With Array 
const marks = [85, 92, 78, 90];
03 • Indexing

Indexes & Length

JavaScript arrays use zero-based indexing.

85 index 0
92 index 1
78 index 2
90 index 3

The first element is at index 0, not 1. 

const marks = [85, 92, 78, 90];

console.log(marks[0]); // 85
console.log(marks[1]); // 92
console.log(marks[3]); // 90

console.log(marks.length); // 4
⚠️ Important formula Last valid index = array.length - 1

07 • Traversal

Traversing an Array

Traversal means visiting each element of an array.

Classic for Loop

const numbers = [10, 20, 30, 40];

for(let i = 0; i < numbers.length; i++) {

    console.log(numbers[i]);

}

for...of

for(const number of numbers) {
    console.log(number);
}

forEach()

numbers.forEach(function(number) {
    console.log(number);
});
Interview tip Use a classic for loop when you need the index or precise loop control. Use for...of for simple value traversal.

Essential Array Methods

09 • Add & Remove

push, pop, shift, unshift 

const numbers = [20, 30];

numbers.push(40);

console.log(numbers);
// [20, 30, 40]

numbers.pop();

console.log(numbers);
// [20, 30]

numbers.unshift(10);

console.log(numbers);
// [10, 20, 30]

numbers.shift();

console.log(numbers);
// [20, 30]
Method Position Action Mutates?
push() End Add Yes
pop() End Remove Yes
unshift() Beginning Add Yes
shift() Beginning Remove Yes
10 • Extraction

slice()

slice() extracts a portion of an array without modifying the original array. 

const numbers = [10, 20, 30, 40, 50];

const result = numbers.slice(1, 4);

console.log(result);
// [20, 30, 40]

console.log(numbers);
// [10, 20, 30, 40, 50]
Remember: The start index is included, but the end index is excluded.
11 • Modification

splice()

splice() can add, remove or replace elements and changes the original array. 

const fruits = [
    "Apple",
    "Banana",
    "Mango"
];

fruits.splice(1, 1, "Orange");

console.log(fruits);

// ["Apple", "Orange", "Mango"]

Syntax: array.splice(start, deleteCount, item1, item2, ...)

14 • Functional Thinking

reduce()

reduce() processes an array and combines its elements into a single accumulated result. 

const numbers = [10, 20, 30, 40];

const total = numbers.reduce(
    (sum, number) => sum + number,
    0
);

console.log(total);

// 100
accumulator = 0
↓
0 + 10 = 10
↓
10 + 20 = 30
↓
30 + 30 = 60
↓
60 + 40 = 100
Interview idea Think of reduce() as: many values → one result.
15 • Sorting

Sorting Arrays

JavaScript's default sort compares values as strings. For numbers, provide a comparison function. 

const numbers = [10, 2, 30, 5];

numbers.sort();

console.log(numbers);

// Not numeric ordering:
// [10, 2, 30, 5] may be ordered lexicographically

Correct Numeric Sort

const numbers = [10, 2, 30, 5];

numbers.sort(
    (a, b) => a - b
);

console.log(numbers);

// [2, 5, 10, 30]

Descending Order

numbers.sort(
    (a, b) => b - a
);

16 • Advanced Searching

find(), findIndex(), some(), every()

find()

Returns the first element satisfying a condition. 

const result = [5, 12, 8]
    .find(x => x > 10);

// 12
findIndex()

Returns the index of the first matching element. 

const index = [5, 12, 8]
    .findIndex(x => x > 10);

// 1
some()

Checks whether at least one element satisfies a condition. 

[1, 3, 8]
.some(x => x % 2 === 0);

// true
every()

Checks whether all elements satisfy a condition. 

[2, 4, 6]
.every(x => x % 2 === 0);

// true

18 • Modern JavaScript

Array Destructuring

Destructuring extracts values from an array into variables. 

const colors = [
    "Red",
    "Green",
    "Blue"
];

const [first, second, third] = colors;

console.log(first);
console.log(second);
console.log(third);

Skipping Values

const numbers = [10, 20, 30];

const [first, , third] = numbers;

console.log(first); // 10
console.log(third); // 30

Rest with Destructuring

const numbers = [
    10,
    20,
    30,
    40
];

const [first, ...remaining] = numbers;

console.log(first);
// 10

// [20, 30, 40]
19 • Spread Syntax

Spread with Arrays 

const first = [1, 2, 3];
const second = [4, 5, 6];

const combined = [
    ...first,
    ...second
];

console.log(combined);

// [1, 2, 3, 4, 5, 6]

Copy an Array

const original = [10, 20, 30];

const copy = [...original];
Important Spread creates a shallow copy. Nested objects or arrays still require deeper copying when independent nested state is needed.
20 • References

Copying Arrays Correctly

Reference Copy ❌

const a = [10, 20, 30];

const b = a;

b[0] = 100;

console.log(a);

// [100, 20, 30]

Both variables refer to the same array object.

Shallow Copy ✅

const a = [10, 20, 30];

const b = [...a];

b[0] = 100;

console.log(a);
// [10, 20, 30]

32 • Common Mistakes

Mistakes You Must Avoid

❌ Mistake 1 — Starting index at 1 

const arr = ["A", "B", "C"];

console.log(arr[1]);
// B

// First element is arr[0]

❌ Mistake 2 — Wrong numeric sort 

const numbers = [10, 2, 30];

numbers.sort();

console.log(numbers);

Use: numbers.sort((a, b) => a - b)


❌ Mistake 3 — Confusing slice and splice

slice() extracts without modifying the original array.

splice() changes the original array.


❌ Mistake 4 — Accidentally sharing an array 

const a = [1, 2, 3];

const b = a;

b.push(4);

console.log(a);
// [1, 2, 3, 4]

Use a shallow copy when appropriate: const b = [...a]


❌ Mistake 5 — Forgetting return in map() 

const result = numbers.map(number => {
    number * 2;
});

console.log(result);

// [undefined, undefined, ...]

Correct: 

const result = numbers.map(
    number => number * 2
);

35 • Interview Preparation

Important Interview Questions

1. What is an array?

An ordered collection of values accessed using indexes.

2. What is zero-based indexing?

The first array element is at index 0.

3. Difference between slice and splice?

slice() returns a portion without changing the original; splice() modifies the original.

4. Difference between map and forEach?

map() returns a new array. forEach() is primarily used for iteration and does not create a transformed array from its return value.

5. What does filter() return?

A new array containing elements that pass the condition.

6. What does reduce() do?

It combines array elements into an accumulated result.

7. Why does [10, 2, 30].sort() behave unexpectedly?

Default sort compares values as strings. Use (a, b) => a - b for numeric ascending order.

8. What is a shallow copy?

A new outer array is created, while nested object/array references remain shared.

9. What is array destructuring?

A syntax for extracting array elements into variables.

10. What is an array of objects?

An array whose elements are objects, commonly used for API and application data.

Student Marks Analyzer

const marks = [
    85,
    92,
    76,
    88,
    95
];

const total = marks.reduce(
    (sum, mark) => sum + mark,

);
