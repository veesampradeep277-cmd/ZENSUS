Example: Student Model 

class Student:

    def __init__(self, name, roll_no, branch):
        self.name = name
        self.roll_no = roll_no
        self.branch = branch

    def display(self):
        return (
            f"{self.roll_no} - "
            f"{self.name} - "
            f"{self.branch}"
        )


student = Student(
    "Pradeep",
    "CSE101",
    "CSE"
)

print(student.display())
CSE101 - Pradeep - CSE
Development Rule

Build the project feature by feature. Do not try to write the entire application in one block of code.

INPUT SAFETY

Input Validation

Real applications should not assume that users always enter correct information. 

def get_age():

    while True:

        try:

            age = int(input("Enter age: "))

            if age < 0:
                raise ValueError(
                    "Age cannot be negative"
                )

            return age

        except ValueError as error:

            print("Invalid input:", error)
VALIDATE

Make sure required values are not empty.

QUALITY ASSURANCE

Testing Your Python Project

Testing helps determine whether individual parts of the application behave as expected. Python provides the built-in unittest framework for creating automated tests.

Testing Flow
Test Case Define scenario
→
Execute Run code
→
Assert Compare result
→
Result Pass / Fail

unittest Example 

import unittest


def add(a, b):
    return a + b


class TestCalculator(unittest.TestCase):

    def test_add(self):

        result = add(10, 20)

        self.assertEqual(
            result,
            30
        )


if __name__ == "__main__":
    unittest.main()
Assertion Purpose
assertEqual() Check whether two values are equal
assertTrue() Check whether a condition is true
assertFalse() Check whether a condition is false
assertRaises() Check whether an expected exception occurs

PROBLEM SOLVING

Debugging Your Application

01

Read the error message

Start with the traceback. Identify the file, line number and exception type.

02

Reproduce the problem

Determine exactly what input or sequence of actions causes the error.

03

Isolate the problem

Reduce the issue to the smallest possible piece of code.

04

Fix the root cause

Do not simply hide the error. Understand why it occurred and correct the underlying problem.

05

Test again

Confirm that the fix works and has not introduced another problem.

def calculate_grade(average):

    if average >= 90:
        return "A"

    elif average >= 75:
        return "B"

    elif average >= 60:
        return "C"

    elif average >= 40:
        return "D"

    return "F"
