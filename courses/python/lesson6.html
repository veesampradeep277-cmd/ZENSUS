What is a Loop?

🔁

Repeat Instructions

A loop allows you to execute the same block of code repeatedly without writing it again and again.

⏱️

Save Time

Instead of manually performing repetitive tasks, loops automate the process.

🧠

Build Logic

Loops are one of the most important tools for solving programming problems.

💡 Real-World Example

Imagine you have to print "Hello" 100 times. Without a loop, you would need 100 print statements. With a loop, you can accomplish it with only a few lines.

The range() Function

The range() function generates a sequence of numbers that is commonly used with for loops.

01

range(stop)

range(5)

Generates numbers from 0 up to, but not including, 5.

02

range(start, stop)

range(2, 7)

Starts from 2 and stops before 7.

2 3 4 5 6

CONDITION BASED

The while Loop

CONCEPT

Repeat while condition is true

A while loop checks a condition before every iteration. If the condition becomes false, the loop stops.

initialize → condition → execute → update 
i = 1

while i <= 5:
    print(i)
    i += 1
OUTPUT 1 2 3 4 5
01 Initialize i = 1
↓
02 Check i ≤ 5?
↓
03 Execute print(i)
↓
04 Update i += 1
↻
🚨 Infinite Loop Warning

If the condition never becomes false, the while loop can continue forever. 

i = 1

while i <= 5:
    print(i)

# i never changes!

09
CONTROL

Loop Control Statements

🛑

break

Immediately terminates the loop. 

for i in range(10):
    if i == 5:
        break
    print(i)
Output: 0 1 2 3 4
⏭️

continue

Skips the current iteration and continues with the next iteration. 

for i in range(5):
    if i == 2:
        continue
    print(i)
Output: 0 1 3 4
⏸️

pass

Does nothing. It is used as a placeholder where code will be added later. 

for i in range(5):
    pass
No output
10
VISUALIZATION

break vs continue

🛑

break

Completely stops the loop.

1 2 3 STOP 4 5
⏭️

continue

Skips one iteration but keeps the loop running.

11
ELSE WITH LOOPS

Loop else

🔢

for...else

for i in range(3):
    print(i)
else:
    print("Done")

The else block runs when the loop completes normally.

🔄

while...else

i = 1

while i <= 3:
    print(i)
    i += 1
else:
    print("Done")

The else block executes after the while condition becomes false.

💡 Important: If the loop is terminated using break, the else block does not execute.

AVOID THESE

Common Loop Mistakes

01

Forgetting to update while condition

i = 1

while i <= 5:
    print(i)
❌ Infinite loop 
i = 1

while i <= 5:
    print(i)
    i += 1
✅ Correct
02

Wrong range boundary

for i in range(1, 5):
    print(i)
❌ Prints 1 to 4 
for i in range(1, 6):
    print(i)
✅ Prints 1 to 5
03

Incorrect indentation

for i in range(5):
print(i)
for i in range(5):
    print(i)
04

Using break when continue is needed

Remember:

break → Stop entire loop continue → Skip current iteration
