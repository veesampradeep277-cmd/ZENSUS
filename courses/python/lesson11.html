CORE CONCEPT

What is a Module?

A module is a Python file containing reusable code such as functions, classes, variables and executable statements.

A module normally has the .py extension.

Think of a Module as a Toolbox

calculator.py Module
→
Functions add(), subtract()
→
main.py Uses the module

Write reusable functionality once and import it wherever it is needed.

03
WHY THEY MATTER

Why Do We Use Modules?

01

02

Maintainability

03

05

Large applications become easier to structure.

04
BUILD YOUR FIRST MODULE

Creating a Module

01 calculator.py 
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b


def multiply(a, b):
    return a * b


def divide(a, b):
    return a / b
Important:

Once this file is saved as calculator.py, Python can treat it as a module named calculator.

05
IMPORT SYSTEM

Importing a Module

Basic Syntax

import module_name

Example

import calculator

print(calculator.add(10, 5))
print(calculator.subtract(10, 5))
Output 15
5

When using import calculator, functions are accessed through the module name: 

calculator.add()
calculator.subtract()
06
SELECTIVE IMPORT

from ... import

Instead of importing the complete module, you can import only specific functions, classes or variables.

02 Specific import 
from calculator import add

result = add(20, 30)

print(result)
Difference 
import calculator

calculator.add(10, 20)
from calculator import add

add(10, 20)

IMPORTANT CONCEPT

Module Namespace

A module has its own namespace. This means names defined inside one module do not automatically overwrite names in another module. 

# math_tools.py

value = 100


# main.py

value = 50

import math_tools

print(value)
print(math_tools.value)
Output 50
100

PROJECT ORGANIZATION

What is a Package?

A package is a directory used to organize related Python modules into a structured hierarchy.

Packages are especially useful when applications become larger and contain many modules.

Module vs Package

Module One .py file
→
Package Directory of modules
→
Application Multiple packages
13
SPECIAL PACKAGE FILE

Understanding __init__.py

__init__.py is a special file associated with Python packages. It can initialize package state and expose selected names.

In modern Python, namespace packages can exist without __init__.py, but it remains widely used for regular packages and package initialization.

07 Package structure 
mypackage/
│
├── __init__.py
├── calculator.py
└── greetings.py
What can __init__.py contain?
  • Initialization code
  • Package-level variables
  • Selected imports
  • Package metadata

PROJECT ARCHITECTURE

Professional Package Structure

08 Example project 
student_app/
│
├── main.py
│
├── users/
│   ├── __init__.py
│   ├── authentication.py
│   └── profile.py
│
├── courses/
│   ├── __init__.py
│   ├── python.py
│   └── java.py
│

    ├── __init__.py
    ├── helpers.py
    └── validators.py

This approach separates different responsibilities instead of putting the entire application into one massive Python file.

USING PACKAGES

Importing From a Package

09 Import a module 
from users import authentication

authentication.login("admin", "1234")

from users.authentication import login

login("admin", "1234")
Remember the pattern:

16
NESTED ORGANIZATION

Sub-Packages

A package can contain another package. Such nested packages are called sub-packages. 

application/
│
├── users/
│   ├── __init__.py
│   └── authentication/
│       ├── __init__.py
│       ├── login.py
│       └── register.py
│
└── main.py

Sub-packages help organize very large applications into logical layers.

17
PACKAGE NAVIGATION

Relative Imports

Current Package

from . import helpers

Parent Package

from .. import utilities
Meaning

A single dot refers to the current package. Two dots move toward the parent package.

18
IMPORT SEARCH

Understanding sys.path

Python uses a module search path to determine where it should look for modules and packages.

The search locations can be inspected using sys.path. 

import sys

for path in sys.path:
    print(path)
Interview Point:

If Python cannot locate a module in its search path, you may encounter ModuleNotFoundError.

VERY IMPORTANT

__name__ and __main__

Python provides the special variable __name__.

When a file is executed directly, __name__ is typically "__main__".

15 main.py 
def greet():
    print("Hello from Python")


if __name__ == "__main__":
    greet()
Why use this?

It allows a file to contain reusable definitions while also supporting code that should run only when the file is executed directly.

Execution Flow

Run directly python main.py
→
__name__ "__main__"
→
Run main code Condition = True

AVOID THESE

Common Mistakes

01

Wrong Module Name

File is named calculator.py but code tries import calculators.

02

Wrong File Location

Python cannot find the module because it is outside the expected import path.

03

Using Module Prefix Incorrectly

from math import sqrt

math.sqrt(25)   # incorrect in this context
04

Using import * Everywhere

Wildcard imports can make code harder to read and may create naming conflicts.

05

Confusing Module and Package

A module is generally a Python file; a package organizes modules into directories.

06

Incorrect Relative Import

Relative imports depend on package context and should be used with proper package structure.

07

Installing the Wrong Package

Always verify the package name before installing third-party dependencies.

08

Circular Imports

Avoid designing modules that depend on each other in a circular chain.

PLACEMENT PREPARATION

Python Modules & Packages Interview Questions

1. What is a module in Python?

A module is a Python file containing reusable definitions and statements such as functions, classes and variables.

2. What is a package?

A package is a directory used to organize related Python modules into a hierarchical structure.

3. What is the difference between a module and package?

A module is generally a single Python file, while a package is a directory structure used to organize multiple modules.

4. What does import do?

The import statement makes a module available to the current program so its names can be used.

5. Difference between import and from import? 
import math
math.sqrt(25)


from math import sqrt
sqrt(25)
6. What is an alias?

An alias is an alternate name assigned to an imported module using the as keyword. 

import pandas as pd
7. What is __init__.py?

It is a special package file that can initialize package state, define package-level names and expose selected modules or objects.

8. What is sys.path?

It is the list of locations Python searches when looking for modules and packages.

9. What is ModuleNotFoundError?

It occurs when Python cannot locate the requested module in the available import search path.

10. What is __name__?

__name__ is a special variable that identifies the module's execution context.

11. What does if __name__ == "__main__" mean?

It checks whether the file is being executed directly rather than being imported as a module.

12. What are third-party modules?

Modules/packages created outside Python's standard library that can be installed separately.

13. What is pip?

pip is the standard package-management tool commonly used to install and manage Python packages.

14. What is a circular import?

A circular import occurs when modules depend on each other directly or indirectly, creating an import cycle.

15. What is a relative import?

A relative import references modules relative to the current package using dots such as . and ...

16. Why should wildcard imports be avoided?

Wildcard imports can make it unclear where names came from and can cause naming conflicts.
