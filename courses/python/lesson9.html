BIG PICTURE

Python Collection Types

Python provides several built-in collection types for organizing multiple values. In this lesson we focus on Tuple, Set and Dictionary.

Type Syntax Ordered Mutable Duplicates Main Use
List [] Yes Yes Yes General collection
Tuple () Yes No Yes Fixed data
Set {} No defined indexing Yes No Unique values
Dictionary {key:value} Yes* Yes No duplicate keys Key-value data

* Dictionaries preserve insertion order in modern Python versions.

COLLECTION TYPE 01

Python Tuples

What is a Tuple?

A tuple is an ordered and immutable collection of Python objects.

Unlike a list, a tuple cannot be modified after it has been created.

Tuple Structure
0 "Python"
1 "Java"
2 "C++"

Ordered + Indexed + Immutable

IMPORTANT CONCEPT

Tuple Immutability

numbers = (10, 20, 30)

numbers[0] = 100
TypeError: 'tuple' object does not support item assignment

Why use tuples?

  • Data should not accidentally change.
  • Useful for fixed records.
  • Can represent coordinates.
  • Can be used as dictionary keys when appropriate.
  • Useful for returning multiple values from functions.

COLLECTION TYPE 02

Python Sets

What is a Set?

A set is a collection of unique elements. It does not provide positional indexing like a list or tuple.

Sets are especially useful when duplicate values must be removed or when mathematical set operations are required.

Duplicate Removal
[1, 2, 2, 3, 4, 4]
→
set()
→
{1, 2, 3, 4}

MATHEMATICAL OPERATIONS

Set Operations

∪

Union

All elements from both sets.

A | B
∩

Intersection

Elements common to both sets.

A & B
−

Difference

Elements present in A but not B.

A - B
△

Symmetric Difference

Elements in either set, but not both.

A ^ B 
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(A | B)
print(A & B)
print(A - B)
print(A ^ B)

{3, 4}
{1, 2}
{1, 2, 5, 6}

COLLECTION TYPE 03

Python Dictionaries

What is a Dictionary?

A dictionary stores information using key-value pairs.

Instead of accessing data by numeric position, we use meaningful keys.

Key → Value Relationship
name → "Pradeep"
age → 20
branch → "CSE"

PYTHONIC PROGRAMMING

Dictionary Comprehension

Dictionary comprehension provides a compact way to create dictionaries from an iterable. 

squares = {
    x: x * x
    for x in range(1, 6)
}

print(squares)
{ 1: 1, 2: 4, 3: 9, 4: 16, 5: 25 }

With Condition

even_squares = {
    x: x * x
    for x in range(1, 11)
    if x % 2 == 0
}

DECISION GUIDE

List vs Tuple vs Set vs Dictionary

Question Choose Why?
Need an ordered, changeable collection? List Flexible and indexed.
Need fixed ordered data? Tuple Immutable collection.
Need only unique values? Set Duplicates are removed.
Need key-based lookup? Dictionary Stores key-value pairs.

AVOID THESE

Common Mistakes

01

Confusing () with (10)

(10) is an integer expression. (10,) is a tuple.

02

Using {} for an empty set

{} creates an empty dictionary. Use set() for an empty set.

03

Trying to index a set

Sets do not provide positional indexing.

04

Duplicate dictionary keys

Dictionary keys must be unique. Reusing a key replaces its previous value.

05

Modifying a tuple

Tuples are immutable. Use a list if frequent modification is required.

06

Using remove() incorrectly

remove() expects a value, while pop() works by position in lists and by key in dictionaries.
