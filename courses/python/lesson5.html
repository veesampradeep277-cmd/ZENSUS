What is Control Flow?

Control flow determines the order in which statements in a program are executed.

Normally, Python executes statements from top to bottom.

But real programs need to make decisions, repeat tasks and sometimes skip or stop execution.

1 Start
↓
2 Decision
↓
3 Action
↓
4 Result
💡 Think of it like this:

Control flow is like a GPS for your program. It decides where the program should go next.

The if Statement

The if statement executes a block of code only when a condition is true.

Syntax 
if condition:
    statement
EXAMPLE

Check whether a student passed

If marks are greater than or equal to 40, the student has passed.

marks ≥ 40 → Pass 
marks = 75

if marks >= 40:
    print("Pass")
Output: Pass

How the if statement works

marks ≥ 40?
YES
Print "Pass"
NO
Nothing happens

if - elif - else

Use elif when you need to check multiple conditions.

Syntax 
if condition1:
    statement1
elif condition2:
    statement2
elif condition3:
    statement3
else:
    statement4
EXAMPLE

Student Grade Calculator

Different marks produce different grades.

A 90 - 100
B 75 - 89
C 60 - 74
D 40 - 59
F Below 40 
marks = 85

if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 60:
    grade = "C"
elif marks >= 40:
    grade = "D"
else:
    grade = "F"

print(grade)
Output: B
Python checks conditions from top to bottom
1 marks >= 90
↓
2 marks >= 75
↓
✓ B is selected

Nested if Statement

A nested if means placing one conditional statement inside another.

REAL-WORLD EXAMPLE

College Exam Eligibility

A student must have sufficient attendance before checking their marks.

    else:

    print("Not eligible")
Output: Eligible and Passed

Combining Conditions

Python allows multiple conditions to be combined using logical operators.

and

AND

Both conditions must be true. 

age = 20
has_id = True

if age >= 18 and has_id:
    print("Allowed")
Output: Allowed
or

OR

At least one condition must be true. 

day = "Saturday"

if day == "Saturday" or day == "Sunday":
    print("Weekend")
Output: Weekend
not

NOT

Reverses a Boolean condition. 

logged_in = False

if not logged_in:
    print("Please login")
Output: Please login

The range() Function

range() generates a sequence of numbers commonly used with for loops.

Jumping Statements

Jump statements change the normal execution of loops.

🛑

break

Immediately terminates the loop. 

for i in range(1, 10):

    if i == 5:
        break

    print(i)
Output: 1 2 3 4
⏭️

continue

Skips the current iteration and continues with the next iteration. 

for i in range(1, 6):

    if i == 3:
        continue

    print(i)
Output: 1 2 4 5
⏸️

pass

Does nothing. It is used as a placeholder when code is required syntactically. 

for i in range(5):

    if i == 3:
        pass

    print(i)
Output: 0 1 2 3 4

Real-World Example

Let's combine conditions and loops to build a simple login attempt system.

🔐

Login Attempt System

A user gets three chances to enter the correct password. 

correct_password = "python123"

for attempt in range(3):

    password = input("Enter password: ")

    if password == correct_password:
        print("Login successful!")
        break

    else:
        print("Incorrect password")

else:
    print("Account locked")
Important:

The else associated with a loop executes when the loop finishes normally, without encountering break.

19

Common Mistakes

These are mistakes beginners frequently make while learning control flow.

01

Using = instead of ==

❌ Wrong 
if age = 18:
✓ Correct 
if age == 18:

= assigns a value, while == compares values.

02

Forgetting the colon

❌ Wrong 
if age >= 18
    print("Adult")
✓ Correct 
if age >= 18:
    print("Adult")
03

Incorrect indentation

❌ Wrong 
if age >= 18:
print("Adult")
✓ Correct 
if age >= 18:
    print("Adult")
04

Infinite while loop

❌ Wrong 
number = 1

while number <= 5:
    print(number)

The variable is never updated, so the condition remains true forever.

✓ Correct 
number = 1

while number <= 5:
    print(number)
    number += 1
05

Wrong range assumption

range(1, 5)

This produces:

1 → 2 → 3 → 4

The stop value 5 is excluded.

06

Confusing break and continue

break Stops loop
continue Skips iteration
