Using the end of a dynamic array as the top allows efficient append and removal operations.
Manual Stack 
class Stack:

    def __init__(self):
        self.items = []

    def push(self, value):
        self.items.append(value)

    def pop(self):

        if not self.items:
            return None

        return self.items.pop()

    def peek(self):

        if not self.items:
            return None

        return self.items[-1]

    def is_empty(self):
        return len(self.items) == 0

CLASSIC STACK PATTERN

Balanced Parentheses

When you encounter an opening bracket, remember it. When you encounter a closing bracket, compare it with the most recent unmatched opening bracket.

( push
[ push
] pop
) pop
Python 
def is_valid(s):

    stack = []

    pairs = {
        ')': '(',
        ']': '[',
        '}': '{'
    }

    for ch in s:

        if ch in "([{":

            stack.append(ch)

        else:

            if not stack:
                return False

            if stack[-1] != pairs[ch]:
                return False

            stack.pop()

    return not stack
Time: O(n)   |   Space: O(n)

IMPLEMENTATION

Queue Implementation

In Python, deque provides efficient insertion and removal operations at both ends.

Python — collections.deque 
from collections import deque

queue = deque()

queue.append(10)
queue.append(20)
queue.append(30)

print(queue.popleft())

print(queue[0])
append: O(1)   |   popleft: O(1)
Avoid repeatedly removing the first element of a normal Python list when efficient queue behavior is required.

IMPORTANT PATTERN

BFS Using Queue

Breadth-first search uses a queue to process nodes in breadth-first order.

START
↓
ENQUEUE
↓
DEQUEUE
↓
PROCESS
↓
ENQUEUE UNVISITED
↺
Python 
from collections import deque

def bfs(graph, start):

    queue = deque([start])

    visited = {start}

    while queue:

        node = queue.popleft()

        print(node)

        for neighbor in graph[node]:

            if neighbor not in visited:

                visited.add(neighbor)

                queue.append(neighbor)
Typical graph traversal complexity: O(V + E)

AVOID THESE

Common Mistakes

01

Empty Stack

Calling pop or peek without handling an empty structure.

02

Wrong Queue End

Inserting and removing from the same end when FIFO behavior is required.

03

O(n) Front Removal

Choosing an inefficient representation for repeated queue removals.

04

Monotonic Confusion

Removing candidates without understanding which candidates remain useful.

BFS on graphs can revisit nodes without appropriate tracking.

01. What is the difference between Stack and Queue?
A stack follows LIFO, while a queue follows FIFO.
02. What is stack overflow?
In a bounded implementation, overflow refers to attempting to insert when no capacity is available.
03. What is stack underflow?
It occurs when a removal operation is attempted on an empty stack.
04. What is a monotonic stack?
A stack maintained in increasing or decreasing order to efficiently solve certain ordering problems.
05. Why does BFS use a queue?
A queue processes discovered nodes in the order they enter the frontier, producing breadth-first exploration.
06. What is a deque?
A double-ended queue that supports insertion and deletion at both ends.
