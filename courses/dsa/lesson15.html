01

What is Dynamic Programming?

The fundamental idea behind DP

Dynamic Programming is an optimization technique

Dynamic Programming (DP) solves a complex problem by dividing it into smaller subproblems, solving each subproblem once, and storing its result so that the same work is not repeated.

Simple idea: Don't solve the same problem twice.
🧩

Break

Divide a large problem into smaller overlapping subproblems.

💾

Store

Save answers of subproblems so they can be reused.

⚡

Reuse

Avoid repeated calculations and improve time complexity.

Key Definition: DP = Recurrence + State + Stored Results
02

Why Do We Need Dynamic Programming?

Understanding repeated work

Example: Fibonacci

Consider:

F(n) = F(n - 1) + F(n - 2)

If we calculate Fibonacci recursively, many values are calculated again and again.

F(5)
↓
F(4)
F(3)
↓
F(3)
F(2)
F(2)
F(1)
Problem: F(3), F(2), and other states are repeatedly calculated.

DP Solution: Calculate each state once and store it.
03

The Two Properties of DP

The foundation of recognizing DP problems

🔁

1. Overlapping Subproblems

The same smaller problem appears multiple times during computation.

Fibonacci is the classic example.
🏆

2. Optimal Substructure

The optimal solution of the larger problem can be constructed from optimal solutions of its smaller subproblems.

Shortest path and knapsack are common examples.

How to recognize a DP problem?

  1. Can the problem be divided into smaller states?
  2. Do the same states appear repeatedly?
  3. Can an answer be built from previous answers?
  4. Is the question asking for min, max, count, existence, or number of ways?

Start With Recursion

Most DP solutions begin with a recursive idea

Step 1 — Define the recursive relationship

For Fibonacci:

dp(n) = dp(n - 1) + dp(n - 2)
Python — Recursive Fibonacci O(2ⁿ) 
def fib(n):
    if n <= 1:
        return n

    return fib(n - 1) + fib(n - 2)
Problem: Exponential time because the same states are recalculated repeatedly.
05

Memoization — Top Down DP

Recursion + cache

What is Memoization?

Memoization stores the result of each state when it is calculated for the first time.

Formula: Memoization = Recursion + Cache

Without Cache

F(3)
F(3) again
F(3) again
→

With Cache

F(3)
Cache[3] = 2
Reuse 2
Python — Memoization O(n) 
def fib(n, dp):

    if n <= 1:
        return n

    if dp[n] != -1:
        return dp[n]

    dp[n] = fib(n - 1, dp) + fib(n - 2, dp)

    return dp[n]


n = 10
dp = [-1] * (n + 1)

print(fib(n, dp))
Complexity: Time = O(n)
Space = O(n) for cache + recursion stack.
06

Tabulation — Bottom Up DP

Solve smaller states first

What is Tabulation?

Tabulation solves the problem iteratively by starting from the base cases and building the answer toward the final state.

Formula: Tabulation = Iteration + DP Table
0 dp[0]
1 dp[1]
1 dp[2]
2 dp[3]
3 dp[4]
5 dp[5]
? dp[6]
Python — Tabulation O(n) 
def fib(n):

    if n <= 1:
        return n

    dp = [0] * (n + 1)

    dp[1] = 1

    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]
07

Space Optimization

Store only what is actually required

Sometimes the current DP state depends only on a few previous states.

dp[i] depends only on dp[i-1] and dp[i-2]

Therefore, storing the entire array is unnecessary.

prev2 2
→
prev1 3
→
current 5
Python — O(1) Space O(n) / O(1) 
def fib(n):

    if n <= 1:
        return n

    prev2 = 0
    prev1 = 1

    for i in range(2, n + 1):

        current = prev1 + prev2

        prev2 = prev1
        prev1 = current

    return prev1

Fibonacci — Your First DP Problem

The classic introduction to DP

State

Let:

dp[i] = Fibonacci number at position i

Transition

dp[i] = dp[i-1] + dp[i-2]

Base Cases

dp[0] = 0     dp[1] = 1
Complete Python Solution O(n) 
def fibonacci(n):

    if n <= 1:
        return n

    a = 0
    b = 1

    for _ in range(2, n + 1):
        a, b = b, a + b

    return b


print(fibonacci(10))

Climbing Stairs

A fundamental 1D DP pattern

Problem

You are climbing a staircase with n steps. You can climb either 1 step or 2 steps at a time. How many distinct ways can you reach the top?

1
2
3
4
5
🧑‍💻
dp[n] = dp[n-1] + dp[n-2]
This problem has the same recurrence as Fibonacci. The important skill is recognizing the pattern.
Python — Climbing Stairs O(n) Time • O(1) Space 
def climb_stairs(n):

    if n <= 2:
        return n

    one = 1
    two = 2

    for _ in range(3, n + 1):

        current = one + two

        one = two
        two = current

    return two

0/1 Knapsack

One of the most important DP patterns

Problem

Given items with weights and values, choose items so that the total weight does not exceed capacity while maximizing total value.

0/1 means: Every item can either be selected once or not selected.
Item A Weight: 2 Value: 12
Item B Weight: 1 Value: 10
Item C Weight: 3 Value: 20

State

dp[i][w] = maximum value using first i items with capacity w

Transition

dp[i][w] = max( dp[i-1][w], value[i] + dp[i-1][w-weight[i]] )
Python — 0/1 Knapsack O(n × W) 
def knapsack(weights, values, capacity):

    n = len(weights)

    dp = [[0] * (capacity + 1)
          for _ in range(n + 1)]

    for i in range(1, n + 1):

        for w in range(capacity + 1):

            if weights[i - 1] <= w:

                take = (
                    values[i - 1]
                    + dp[i - 1][w - weights[i - 1]]
                )

                skip = dp[i - 1][w]

                dp[i][w] = max(take, skip)

            else:

                dp[i][w] = dp[i - 1][w]

    return dp[n][capacity]

Coin Change

Minimum and counting DP

Example

Coins:

₹1
₹2
₹5

Find the minimum number of coins required to make a target amount.

dp[amount] = min(dp[amount - coin] + 1)
Python — Coin Change O(amount × coins) 
def coin_change(coins, amount):

    dp = [float('inf')] * (amount + 1)

    dp[0] = 0

    for current in range(1, amount + 1):

        for coin in coins:

            if coin <= current:

                dp[current] = min(
                    dp[current],
                    dp[current - coin] + 1
                )

    if dp[amount] == float('inf'):
        return -1

    return dp[amount]

Python — Unique Paths O(m × n) 
def unique_paths(m, n):

    dp = [[1] * n for _ in range(m)]

    for i in range(1, m):

        for j in range(1, n):

            dp[i][j] = (
                dp[i - 1][j]
                + dp[i][j - 1]
            )

    return dp[m - 1][n - 1]

Longest Common Subsequence

One of the most important string DP problems

Example

String A:

A B C D

String B:

A C D
LCS = A C D
Length = 3

Transition

If characters match: dp[i][j] = 1 + dp[i-1][j-1]

Otherwise: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
Python — LCS O(m × n) 
def lcs(a, b):

    m = len(a)
    n = len(b)

    dp = [[0] * (n + 1)
          for _ in range(m + 1)]

    for i in range(1, m + 1):

        for j in range(1, n + 1):

            if a[i - 1] == b[j - 1]:

                dp[i][j] = dp[i - 1][j - 1] + 1

            else:

                dp[i][j] = max(
                    dp[i - 1][j],
                    dp[i][j - 1]
                )

    return dp[m][n]

Longest Increasing Subsequence

Sequence DP

Example

10 9 2 5 7 8 3
One LIS is: 2 → 5 → 7 → 8
Length = 4
dp[i] = longest increasing subsequence ending at i
Python — LIS O(n²) Dynamic Programming 
def lis(nums):

    n = len(nums)

    dp = [1] * n

    for i in range(n):

        for j in range(i):

            if nums[j] < nums[i]:

                dp[i] = max(
                    dp[i],
                    dp[j] + 1
                )

    return max(dp)
Advanced: LIS can also be solved in O(n log n) using binary search / patience sorting.

Edit Distance

String transformation DP

Problem

Find the minimum number of operations needed to convert one string into another.

Insert
Delete
Replace
If characters match: dp[i][j] = dp[i-1][j-1]

Otherwise: dp[i][j] = 1 + min( insert, delete, replace )
Python — Edit Distance O(m × n) 
def edit_distance(a, b):

    m = len(a)
    n = len(b)

    dp = [[0] * (n + 1)
          for _ in range(m + 1)]

    for i in range(m + 1):
        dp[i][0] = i

    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):

        for j in range(1, n + 1):

            if a[i - 1] == b[j - 1]:

                dp[i][j] = dp[i - 1][j - 1]

            else:

                dp[i][j] = 1 + min(
                    dp[i - 1][j],
                    dp[i][j - 1],
                    dp[i - 1][j - 1]
                )

    return dp[m][n]

Common DP Mistakes

Mistakes beginners frequently make

❌ Mistake 1 — Choosing the wrong state

If the state does not contain enough information, the transition cannot correctly solve the problem.

❌ Mistake 2 — Wrong base cases

A wrong base case can make the entire DP table incorrect.

❌ Mistake 3 — Confusing subsequence and substring

A subsequence does not need to be contiguous. A substring must be contiguous.

❌ Mistake 4 — Wrong iteration direction

In knapsack-style problems, loop direction can determine whether an item is used once or repeatedly.

❌ Mistake 5 — Immediately memorizing formulas

Understand the state and transition first. Formula memorization alone does not build DP skill.
