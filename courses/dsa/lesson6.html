What is Hashing?

Hashing is a technique used to map a key to a location where its associated information can be stored or retrieved efficiently.

Simple Definition

Hashing converts a key into a hash value, which is then used to determine where the key should be stored inside a hash table.

Why It Matters

Searching a normal list may require checking many elements. Hash-based structures can provide average O(1) lookup.

Hashing Mental Model

↓
HASH FUNCTION hash(key)
↓
BUCKET INDEX 5
↓
VALUE 10

HashMap Complexity

Hash-based lookup is usually very fast, but O(1) should be understood as an average-case complexity, not a guarantee for every possible implementation state.

COLLISIONS

What is a Collision?

A collision occurs when different keys map to the same bucket.

KEY A CAT
↘
BUCKET 3
CAT → 10
DOG → 20
↗
KEY B DOG

Collision does not mean failure

A hash table needs a strategy for storing and finding multiple entries that map to the same bucket.

SIGNATURE PATTERN

Two Sum Pattern

Two Sum is one of the most important examples of how hashing converts an O(n²) pair search into an average O(n) solution.

GIVEN
2 7 11 15
Target = 9
Current 2
→
Needed 9 − 2 = 7
→
HashMap 7 not found
→
Store 2
Current 7
→
Needed 9 − 7 = 2
→
HashMap 2 FOUND ✓
Python 
def two_sum(nums, target):

    seen = {}

    for i, x in enumerate(nums):

        needed = target - x

        if needed in seen:
            return [seen[needed], i]

        seen[x] = i

    return []
Java 
int[] twoSum(int[] nums, int target) {

    HashMap<Integer, Integer> map
        = new HashMap<>();

    for (int i = 0; i < nums.length; i++) {

        int needed = target - nums[i];

        if (map.containsKey(needed)) {
            return new int[]{
                map.get(needed), i
            };
        }

        map.put(nums[i], i);
    }

    return new int[]{};
}
Time O(n) average
Space O(n)

DEBUGGING

Common Hashing Mistakes

01 Assuming HashMap is always O(1)

Remember that O(1) is the average lookup expectation.

02 Using HashMap when HashSet is enough

If only existence matters, a set may be simpler.

03 Using the wrong key

Your key must represent the information you need to identify or group.

04 Overwriting useful information

Decide whether you need first index, latest index, frequency, or another stored value.

05 Ignoring duplicates

Frequency and duplicate problems require explicit duplicate handling.

06 Forgetting prefix initialization

Prefix-sum counting problems often depend on the initial zero-prefix state.

07 Mishandling negative numbers

Prefix-sum reasoning must work for negative values too.

08 Assuming iteration order

Do not assume a map preserves an order unless the specific implementation guarantees it.

INTERVIEW PREPARATION

Hashing Interview Questions

What is hashing?
Hashing maps keys to hash values and helps hash-based structures organize information for efficient average-case lookup.
What is a hash function?
A function that converts a key into a hash value used by a hash-table implementation to locate a bucket.
What is a collision?
A collision occurs when different keys map to the same bucket.
How can collisions be handled?
Common strategies include chaining and open addressing.
Why is HashMap lookup considered O(1) on average?
A well-distributed hash table can usually locate the relevant bucket directly, making lookup constant on average.
HashMap or HashSet?
Use HashMap when you need key-value information; use HashSet when you mainly need membership or uniqueness.
How does HashMap optimize Two Sum?
It stores previously seen values and checks the required complement instead of testing every pair.
What is a frequency map?
A map where each key represents an item and its value stores the item's frequency.
