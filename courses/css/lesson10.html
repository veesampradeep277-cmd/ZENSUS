CSS Flexbox

Master one-dimensional CSS layout. Learn how Flexbox distributes space, aligns items, controls direction, creates responsive layouts and powers professional navigation bars, cards, dashboards and components.

1. What is Flexbox?

Flexbox is a one-dimensional layout system for arranging elements along a row or column.

Flexbox allows a parent element to control the layout of its direct children. 

.container {
    display: flex;
}

Once an element becomes a flex container, its direct children become flex items.

2. Flex Container vs Flex Items

Flex Container

The element receiving: 

display: flex;

It controls the layout direction, alignment, wrapping and spacing of its direct children.

Flex Items

The direct children of a flex container. 

.container {
    display: flex;
}

.item {
    /* flex item */
}
Think of the parent as the layout manager and the children as the participants.

8. align-content

align-content controls the distribution of multiple flex lines when wrapping occurs. 

.container {

    display: flex;

    flex-wrap: wrap;

    align-content:
        space-between;
}
Important distinction: align-items aligns items within a flex line.

align-content distributes the flex lines themselves when there is extra cross-axis space.

9. gap

The gap property creates consistent spacing between flex items. 

.container {

    display: flex;

    gap: 20px;
}

You can also specify row and column gaps separately. 

.container {

    row-gap: 20px;

    column-gap: 30px;
}

10. flex-grow

flex-grow determines how a flex item can receive available extra space relative to other growing items. 

.item {
    flex-grow: 1;
}

For example: 

.item1 {
    flex-grow: 1;
}

.item2 {
    flex-grow: 2;
}

.item3 {
    flex-grow: 1;
}

The available positive free space is distributed according to the grow factors, subject to the flex sizing algorithm.

11. flex-shrink

flex-shrink controls how flex items participate in distributing negative free space when the container is too small. 

.item {
    flex-shrink: 1;
}

The default value is 1. 

.item {
    flex-shrink: 0;
}

This can prevent a flex item from shrinking through the flex-shrink factor, although min-size constraints still matter.

12. flex-basis

flex-basis defines the initial main-size contribution of a flex item before remaining free space is distributed. 

.item {

    flex-basis:
        200px;
}

With a horizontal flex direction, this commonly relates to the item's initial width.

With a vertical flex direction, it relates to the item's initial main-axis size instead.

13. The flex Shorthand

The flex property is shorthand for: 

flex-grow
flex-shrink
flex-basis

Example: 

.item {
    flex: 1 1 200px;
}

A common pattern is: 

.item {
    flex: 1;
}

This is commonly used when you want flexible items to share available space.

Do not memorize shorthand blindly. First understand grow → shrink → basis.

14. order

The order property changes the visual ordering of flex items. 

.item {
    order: 2;
}

Items are laid out from lower order values to higher order values. Items with the same order follow source order.

19. Common Flexbox Mistakes

❌ Mistake 1 — Using justify-content for everything

Always ask which axis you are controlling.

Main axis → usually justify-content

Cross axis → usually align-items

❌ Mistake 2 — Forgetting flex-direction

When you change from row to column, the main and cross axes change.

❌ Mistake 3 — Using margins everywhere for spacing

For spacing between flex items, prefer gap when appropriate. 

.container {
    display: flex;
    gap: 20px;
}

❌ Mistake 4 — Not understanding flex-basis

flex-basis participates in the flex sizing algorithm along the main axis. It is not simply a universal replacement for width.

❌ Mistake 5 — Using Flexbox when Grid is more appropriate

Flexbox is primarily one-dimensional. Grid is designed for two-dimensional row-and-column layouts.

🔥 Flexbox vs Positioning

Positioning → Place something precisely relative to a reference.

Flexbox → Arrange and distribute items along one dimension.

Grid → Arrange items across rows and columns. 

POSITIONING
    ↓
Precise placement

FLEXBOX
    ↓
One-dimensional layout

GRID
    ↓
Two-dimensional layout
