01 • Foundation

What is a Constructor?

The function responsible for initializing an object.

📌 Definition

A constructor is a special member function that is automatically called when an object is initialized.

💡
Think of it like a setup machine. When an object is created, the constructor prepares its initial state.

For example, when a Student object is created, its constructor can initialize the student's name, age and roll number.

🏠 Real-World Analogy

Imagine ordering a new house.

  • The class is the house blueprint.
  • The object is the actual house.
  • The constructor performs the initial setup.
Student s1("Pradeep", 19);

The constructor receives the supplied values and initializes s1.

03 • Core Rules

Constructor Rules

Remember these rules for exams and interviews.

1️⃣ Same Name

A constructor normally has the same name as its class.

2️⃣ No Return Type

Constructors do not have a return type, not even void.

3️⃣ Automatic Call

It is called automatically as part of object initialization.

4️⃣ Can Overload

A class can have multiple constructors with different parameter lists.

5️⃣ Cannot be Virtual

Constructors cannot be virtual because the object is still being initialized.

6️⃣ Can be Explicit

explicit can prevent unwanted implicit conversions.

⚠️
Important: A constructor is not a normal function that you call using object.constructor(). It participates in object initialization.
04 • Constructor Type

Default Constructor

A constructor that can be called without arguments.

What is a Default Constructor?

A default constructor is a constructor that can be invoked with no arguments.

default_constructor.cpp 
#include <iostream>
using namespace std;

class Student {
public:
    Student() {
        cout << "Default constructor called\n";
    }
};

int main() {
    Student s1;
}
💡
Important distinction If you do not declare a user-declared constructor, C++ may implicitly declare a default constructor. Once you declare constructors that prevent default construction, an object may no longer be constructible without arguments unless you provide a suitable default constructor.

User-Defined Default Constructor

You can explicitly define a constructor that initializes an object's members with your chosen default values.

Student.cpp 
class Student {

private:
    string name;
    int age;

public:

    Student()
        : name("Unknown"), age(0) {
    }
};

Now every default-created Student begins with:

  • Name = Unknown
  • Age = 0
05 • Constructor Type

Parameterized Constructor

Initialize objects using values supplied during creation.

Concept

A parameterized constructor accepts one or more arguments. This allows every object to start with different data.

parameterized.cpp 
class Student {

public:

    Student(string n, int a) {
        name = n;
        age = a;
    }

private:
    string name;
    int age;
};

Creating Objects

main.cpp 
Student s1("Pradeep", 19);
Student s2("Rahul", 20);

The two objects receive different initial values.

06 • Best Practice

Constructor Initializer List

The professional way to initialize data members.

Why use an initializer list?

An initializer list initializes members before the constructor body executes.

recommended.cpp 
class Student {

    string name;
    int age;

public:

    Student(string n, int a)
        : name(n), age(a) {
    }
};

⚡ Efficient

Members are initialized directly instead of being initialized first and assigned later.

🔒 Required

Needed for const members and reference members.

🎯 Clear

Makes initialization intent explicit and readable.

const Members

A const data member must be initialized during object construction. 

class Account {

    const int id;

public:

    Account(int value)
        : id(value) {
    }
};

Reference Members

Reference members must also be initialized in the initializer list. 

class Wrapper {

    int& ref;

public:

    Wrapper(int& x)
        : ref(x) {
    }
};
07 • Flexible Initialization

Constructor with Default Arguments

Constructor parameters can have default values, allowing the constructor to be called with fewer arguments.

default_arguments.cpp 
class Box {

    int length;
    int width;

public:

    Box(int l = 10, int w = 5)
        : length(l), width(w) {
    }
};

Box a;
Box b(20);
Box c(20, 30);
⚠️
Be careful when combining default arguments with overloaded constructors. Some calls can become ambiguous.

09 • Object Context

The this Pointer in Constructors

Inside a non-static member function, including a constructor, this refers to the current object. 

class Student {

    string name;
    int age;

public:

    Student(string name, int age) {

        this->name = name;
        this->age = age;
    }
};
🎯
Why this->? The parameter and data member have the same names. this->name clearly refers to the current object's member.
10 • Copy Semantics

Copy Constructor

Create a new object using an existing object.

Definition

A copy constructor initializes a new object from another object of the same class.

copy_constructor.cpp 
class Student {

    string name;
    int age;

public:

    Student(string n, int a)
        : name(n), age(a) {
    }

    Student(const Student& other)
        : name(other.name), age(other.age) {
    }
};

Student s1("Pradeep", 19);

Student s2 = s1;
💡
Common form: ClassName(const ClassName& other)

12 • Resource Management

Shallow Copy vs Deep Copy

🔗 Shallow Copy

A shallow copy duplicates member values as they are. For an owning raw pointer, this can result in two objects referring to the same dynamically allocated resource. 

class Data {
public:
    int* value;
};
⚠️
If both objects think they own the same raw pointer, resource-management bugs such as double deletion can occur.

🧬 Deep Copy

A deep copy creates a separate resource and copies the underlying value. 

class Data {

    int* value;

public:

    Data(int v)
        : value(new int(v)) {
    }

    Data(const Data& other)
        : value(new int(*other.value)) {
    }
};

In modern C++, prefer RAII types such as std::string, std::vector and smart pointers whenever possible instead of managing raw ownership manually.

13 • Modern C++

Move Constructor

Transfer resources instead of unnecessarily copying them.

A move constructor typically has the form T(T&&). It initializes a new object by transferring resources from an rvalue object.

move_constructor.cpp 
class Buffer {

    int* data;

public:

    Buffer(int value)
        : data(new int(value)) {
    }

    Buffer(Buffer&& other) noexcept
        : data(other.data) {

        other.data = nullptr;
    }

    ~Buffer() {
        delete data;
    }
};
⚡
Key idea: Copy = duplicate resource. Move = transfer resource ownership.

After moving, the source object remains valid, but its exact state is generally not something your program should assume unless the type documents it.

14 • Advanced Constructors

Delegating Constructors

A delegating constructor calls another constructor of the same class from its initializer list. 

class Box {

    int length;
    int width;

public:

    Box()
        : Box(10, 10) {
    }

    Box(int l, int w)
        : length(l), width(w) {
    }
};
🎯
This reduces duplicated initialization logic and gives multiple constructors a single main initialization path.

explicit Constructor

A single-argument constructor can otherwise participate in implicit conversions. explicit prevents such unintended conversions. 

class Number {

public:

    explicit Number(int value) {
    }
};

Number n1(10);

// Prevents unintended implicit conversion:
// Number n2 = 10;

= default and = delete

class Demo {

public:

    Demo() = default;

    Demo(int) = delete;
};

= default requests the compiler-generated implementation where appropriate.

= delete explicitly disables a constructor.

15 • Static Data

Static Members and Constructors

Static data belongs to the class rather than to individual objects. A constructor can update a static counter when an object is created. 

class Student {

public:

    inline static int count = 0;

    Student() {
        ++count;
    }
};

Student a;
Student b;

cout << Student::count;
📌
The static member is shared. It is not separately initialized as part of every object's member initialization.

17 • Critical Concept

Constructor Execution Order

The order is determined by the class structure, not by the order written in the initializer list.

Virtual Bases*
Direct Bases
Members
Constructor Body

For the beginner-level rule: base class → data members → constructor body. 

class Demo {

    int first;
    int second;

public:

    Demo()
        : second(2), first(1) {

        cout << "Body\n";
    }
};
⚠️
Even though second appears first in the initializer list, first is initialized first because members are initialized in their declaration order.

Constructor Timeline

1. Storage/Object Begins

The object's initialization process starts.

2. Base Classes

Base-class subobjects are constructed first.

3. Data Members

Members initialize in declaration order.

4. Constructor Body

Finally, the constructor body executes.

18 • Object Lifetime

Constructor and Destructor Relationship

A constructor initializes an object. A destructor performs cleanup when the object's lifetime ends. 

class Demo {

public:

    Demo() {
        cout << "Constructor\n";
    }

    ~Demo() {
        cout << "Destructor\n";
    }
};

Object Lifetime
Destruction
🔄
Destruction generally happens in the reverse order of construction. For derived objects, the derived part is destroyed before its base-class part.

21 • Debugging

Common Constructor Mistakes

❌ Giving a Return Type

// Wrong

void Student() {
}

A constructor has no return type.

❌ Wrong Initializer Order

Writing members in a different initializer-list order does not change their actual initialization order.

❌ Forgetting const/reference Initialization

Const and reference members must be initialized properly, normally through the initializer list.

❌ Confusing Copy and Assignment

Student b = a; initializes a new object, whereas b = a; assigns to an existing object.

❌ Dangerous Raw Pointer Copy

Blindly copying an owning raw pointer can make multiple objects refer to the same resource.

❌ Constructor Ambiguity

Default arguments and overloaded constructors can sometimes create multiple equally valid matches.

A constructor is a special member function that is automatically involved in object initialization.

Characteristics:
  • Same name as the class.

  • Called during object initialization.

  • Can use initializer lists.

Student()

The appropriate constructor is selected based on the arguments used during object initialization.

Here s2 is a newly initialized object and s1 is the source object.

26 • Mini Project

Student Profile System

🎓 Build a Constructor-Based Student System

Create a small C++ program that demonstrates different constructor concepts in one practical application.

1. Default constructor
2. Parameterized constructor
3. Constructor overloading
4. Copy constructor
5. Initializer list
6. Static student counter
mini_project.cpp 
#include <iostream>
using namespace std;

class Student {

    string name;
    int age;

public:

    inline static int count = 0;

    // Default constructor
    Student()
        : name("Unknown"), age(0) {
        ++count;
    }

    // Parameterized constructor
    Student(string n, int a)
        : name(n), age(a) {
        ++count;
    }

    // Copy constructor
    Student(const Student& other)
        : name(other.name), age(other.age) {
        ++count;
    }

    void display() const {
        cout << "Name: " << name << '\n';
        cout << "Age : " << age << '\n';
    }
};

int main() {

    Student s1;

    Student s2("Pradeep", 19);

    Student s3 = s2;

    s1.display();
    s2.display();
    s3.display();

    cout << "Objects created: "
         << Student::count;

    return 0;
}
