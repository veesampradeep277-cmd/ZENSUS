02 • Output

Displaying Output in C++

C++ commonly uses std::cout to send output to the standard output stream, normally the console.

output.cpp 
#include <iostream>

int main()
{
    std::cout << "Hello, ZENSUS!";

    return 0;
}

Understanding the statement

  • 1 #include <iostream>
    Gives access to standard input/output facilities.
  • 2 std::cout
    Refers to the standard output stream.
  • 3 <<
    The insertion operator sends data into the output stream.
  • 4 "Hello, ZENSUS!"
    This is a string literal.

04 • Formatting

Escape Sequences

Escape sequences represent special characters inside character and string literals.

Sequence Meaning Example
\n New line "Hello\nWorld"
\t Horizontal tab "A\tB"
\\ Backslash "C:\\Users"
\" Double quote "He said \"Hi\""
\' Single quote '\\''
\r Carriage return Special cursor movement

Using '\n'

std::cout
    << "Hello\n";

std::cout
    << "World";

Using std::endl

std::cout
    << "Hello"
    << std::endl;

std::cout
    << "World";
Best practice: \n is generally preferred when you only need a new line. std::endl also flushes the output stream, which can be useful when flushing is actually required.

07 • Strings

std::getline()

Use std::getline() when you want to read an entire line, including spaces.

Problem with cin

std::string name;

std::cin >> name;
Example: If the user enters:

Venkata Pradeep

cin >> name reads only the first whitespace-delimited word: Venkata.

Solution: getline()

std::string name;

std::getline(std::cin, name);

std::cout
    << name;
Now:

Input: Venkata Pradeep

Entire line is stored.

Important: cin followed by getline()

A common beginner problem occurs when formatted extraction with std::cin >> is followed immediately by std::getline(). 

int age;
std::string name;

std::cin >> age;

std::getline(std::cin, name);
The newline left in the input stream can be consumed by getline(), causing an apparently empty string.

Common solution 

int age;
std::string name;

std::cin >> age;

std::getline(std::cin >> std::ws, name);

std::ws consumes leading whitespace before getline() starts reading.

09 • Professional Output

Output Formatting

Fixed Decimal Places

double price = 99.98765;

std::cout
    << std::fixed
    << std::setprecision(2)
    << price;
99.99

Required Header

#include <iomanip>

Formatting tools such as std::fixed and std::setprecision() are provided through <iomanip>.

Creating Table-Like Output

#include <iomanip>

std::cout
    << std::setw(15)
    << "Name"
    << std::setw(10)
    << "Age"
    << "\n";

std::setw() controls the minimum field width for the next formatted output item.

Character vs String Input

char grade = 'A';

Character uses single quotes. 

std::string name =
    "Pradeep";

String literal uses double quotes.

What Happens if the User Enters Wrong Input?

C++ stream extraction can enter a failed state when the input cannot be interpreted as the requested type. 

int age;

std::cin >> age;

If the user enters:

Enter age: hello

The extraction operation fails.
Later lessons can build proper input validation loops using std::cin.fail(), clear() and ignore().

12 • Debugging

Common Beginner Mistakes

✕
Forgetting <iostream>

If you use standard stream objects such as std::cin and std::cout, include <iostream>.

✕
Using << with cin

Output normally uses <<, while input extraction uses >>.

✕
Using cin for a full name

std::cin >> name stops at whitespace. Use std::getline() for complete lines.

✕
Mixing cin and getline incorrectly

Handle the remaining newline/whitespace appropriately, for example with std::ws.

✕
Missing semicolon

Statements such as std::cout << "Hello"; require a semicolon.

✕
Wrong quotes

Characters use single quotes: 'A'. Strings use double quotes: "Hello".

University Preparation

Exam-Oriented Questions

Input is the process of providing data to a program. Output is the process of displaying or producing information from a program. C++ provides stream-based facilities such as std::cin and std::cout.
std::cin >> variable;

Example: 
int age;
std::cin >> age;
It extracts formatted input from the standard input stream.
std::cout << expression;

It inserts data into the standard output stream.
std::cin >> performs formatted extraction and, for strings, normally reads one whitespace-delimited token.

std::getline() reads characters up to the delimiter, usually the newline, and can therefore capture spaces in a line.

Placement Preparation

Interview Questions

std::cin is the standard input stream object commonly used for reading formatted input from the console.

std::cout is the standard output stream object commonly used for writing output to the console.
The insertion operator << inserts data into an output stream. It can be chained to send multiple values to std::cout.
The extraction operator >> extracts formatted data from an input stream and stores it in a variable.
Both can produce a new line. std::endl also flushes the output stream. \n only represents the newline character, so it is generally preferable when no explicit flush is needed.
Use std::getline() when you need to read an entire line, especially when the input can contain spaces.
std::ws is a stream manipulator that consumes leading whitespace from an input stream. It is often useful when switching from formatted extraction to getline().
