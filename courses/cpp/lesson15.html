1. What is STL?

The Standard Template Library is one of the most important parts of modern C++.

STL = Standard Template Library. It provides reusable, generic components for storing data and performing common operations efficiently.

Think of STL as a ready-made toolbox: instead of manually implementing a dynamic array, stack, queue, sorting algorithm or balanced search tree, you can use well-tested library components.
Containers

Store collections of objects.

Algorithms

Operate on ranges of elements.

Iterators

Connect containers and algorithms.

2. STL Architecture

The central idea: containers hold data, iterators describe ranges, algorithms process those ranges.

Container
stores data
→
Iterator
points into range
→
Algorithm
processes range
→
Result
The classic STL pattern
vector<int> a = {4, 1, 7, 2};

sort(a.begin(), a.end());

for (auto it = a.begin(); it != a.end(); ++it) {
    cout << *it << ' ';
}

Important: a.begin() points to the first element and a.end() points one position past the last element. The range [begin, end) includes the first iterator but excludes the end iterator.

3. STL Containers

Choose the container based on the operation you need, not simply because it is popular.

FamilyContainersTypical use
Sequencearray, vector, deque, list, forward_listOrdered collections
Associativeset, multiset, map, multimapSorted keys / ordered lookup
Unorderedunordered_set, unordered_multiset, unordered_map, unordered_multimapAverage O(1) hash lookup

Interview rule: never say “unordered_map is always O(1).” Its lookup is average-case O(1), while the worst case can be O(n).

4. Sequence Containers

These containers represent elements in a sequence.

📦 vector — dynamic array

Best default choice for most array-like problems. Contiguous storage, fast random access and efficient insertion at the end.

vector<int> v = {10, 20, 30};

v.push_back(40);
v.pop_back();

cout << v[1];
cout << v.size();

Random access: O(1) • push_back: amortized O(1) • insertion/erase in middle: O(n).

🧱 array — fixed-size array

std::array wraps a fixed-size array with STL-friendly methods.

array<int, 4> a = {4, 2, 8, 1};

sort(a.begin(), a.end());

cout << a.front();
cout << a.back();

Size is fixed at compile time; contiguous storage; random access O(1).

↔️ deque — double-ended queue

Supports efficient insertion and removal at both ends.

deque<int> d;

d.push_front(10);
d.push_back(20);
d.pop_front();
d.pop_back();

Random access is O(1); front/back insertion and removal are efficient.

🔗 list — doubly linked list

Useful when frequent insertion/erasure at known positions matters more than random access.

list<int> l = {1, 2, 4};

auto it = next(l.begin(), 2);
l.insert(it, 3);

l.remove(2);

No random access; insertion/erase at a known iterator is O(1).

⚖️ vector vs deque vs list

Propertyvectordequelist
Random accessO(1)O(1)No
Memory layoutContiguousSegmentedNode-based
Fast front insertionNoYesYes
Fast back insertionYesYesYes
Cache friendlinessExcellentGoodUsually poorer
For most competitive programming and interview array problems, start with vector unless the problem clearly demands another structure.

5. Ordered Associative Containers

These containers maintain elements according to an ordering, typically implemented with balanced trees.

🌳 set

Stores unique keys in sorted order.

set<int> s = {5, 2, 5, 1};

s.insert(4);
s.erase(2);

if (s.count(4))
    cout << "Found";

insert/find/erase: O(log n). Duplicate values are ignored.

🌳 multiset

Stores sorted keys and allows duplicates.

multiset<int> ms = {2, 2, 4, 1};

cout << ms.count(2);

Useful when sorted duplicates matter.

🗺️ map

Stores unique keys mapped to values, sorted by key.

map<string, int> marks;

marks["Alice"] = 92;
marks["Bob"] = 85;

cout << marks["Alice"];

find/insert/erase: O(log n). Keys are unique.

🗺️ multimap

Allows multiple entries with the same key.

multimap<string, int> mm;

mm.insert({"CSE", 91});
mm.insert({"CSE", 88});

Use when one key can have multiple associated values.

6. Unordered Containers

Hash-based containers prioritize fast average-case lookup rather than sorted order.

    freq[x]++;

cout << freq[5];

unordered_set

unordered_set<int> seen;

seen.insert(10);

if (seen.count(10))
    cout << "Present";

7. Container Adapters

Adapters provide a restricted interface built on an underlying container.

🥞 stack

LIFO — Last In, First Out.

stack<int> st;

st.push(10);
st.push(20);

cout << st.top();
st.pop();

🚶 queue

FIFO — First In, First Out.

queue<int> q;

q.push(10);
q.push(20);

cout << q.front();
q.pop();

🏆 priority_queue

Returns the highest-priority element at the top. Default is a max-heap.

priority_queue<int> pq;

pq.push(5);
pq.push(20);
pq.push(10);

cout << pq.top(); // 20

Min-heap with priority_queue

priority_queue<int, vector<int>, greater<int>> minHeap;

minHeap.push(30);
minHeap.push(10);
minHeap.push(20);

cout << minHeap.top(); // 10

8. Iterators

Iterators provide a generalized way to traverse container elements.

Basic iterator

vector<int> v = {10, 20, 30};

for (auto it = v.begin(); it != v.end(); ++it) {
    cout << *it << ' ';
}

Reverse iterator

for (auto it = v.rbegin(); it != v.rend(); ++it) {
    cout << *it << ' ';
}
ExpressionMeaning
begin()Iterator to first element
end()One-past-last iterator
rbegin()Reverse iterator at last element
rend()Reverse one-past range boundary
cbegin()Const iterator to beginning
cend()Const iterator to end
Modern C++: prefer range-based for loops when you only need to visit elements.

9. STL Algorithms — Your Interview Superpower

Most algorithms operate on iterator ranges such as [begin, end).

🔃 sort

sort(v.begin(), v.end());

sort(v.begin(), v.end(), greater<int>());

Average/worst complexity for std::sort is O(n log n).

🔎 find

auto it = find(v.begin(), v.end(), 10);

if (it != v.end())
    cout << "Found";

For a vector, linear search: O(n).

📊 count

int c = count(v.begin(), v.end(), 5);

Counts matching values in O(n).

🔁 reverse

reverse(v.begin(), v.end());

Reverses a range in O(n).

🎯 min/max

cout << *min_element(v.begin(), v.end());
cout << *max_element(v.begin(), v.end());

Linear scan: O(n).

➕ accumulate

#include <numeric>

long long sum =
    accumulate(v.begin(), v.end(), 0LL);

Common for sums and folds: O(n).

10. Lambda Functions & Custom Comparators

Lambdas make STL algorithms dramatically more flexible.

Lambda anatomy

auto square = [](int x) {
    return x * x;
};

cout << square(5);

General form: [capture](parameters) -> return_type { body }. The return type is often deduced.

Sort in descending order

sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;
});

Sort pairs by second value

vector<pair<int,int>> v = {
    {1, 50}, {2, 20}, {3, 40}
};

sort(v.begin(), v.end(), [](const auto& a, const auto& b) {
    return a.second < b.second;
});
Comparator rule: return true when the first argument should come before the second according to your ordering. Do not write a comparator that violates strict weak ordering.

13. High-Value STL Problem-Solving Patterns

These patterns appear repeatedly in coding tests and interviews.

Pattern 1 — Frequency map

unordered_map<int,int> freq;

for (int x : a)
    freq[x]++;

Use for frequency counting, duplicates and occurrence problems.

Pattern 2 — Sort + two pointers

sort(a.begin(), a.end());

int l = 0, r = (int)a.size() - 1;

while (l < r) {
    // two-pointer logic
}

Pattern 3 — Binary search bounds

sort(a.begin(), a.end());

auto first = lower_bound(a.begin(), a.end(), x);
auto after = upper_bound(a.begin(), a.end(), x);

int frequency = after - first;

Pattern 4 — Custom heap

using P = pair<int,int>;

priority_queue<
    P,
    vector<P>,
    greater<P>
> pq;

Pattern 5 — Remove duplicates

sort(a.begin(), a.end());

a.erase(
    unique(a.begin(), a.end()),
    a.end()
);

unique does not erase elements from the container by itself.

Pattern 6 — Set for uniqueness

unordered_set<int> seen;

for (int x : a) {
    if (seen.count(x)) {
        // duplicate
    }
    seen.insert(x);
}

16. Common STL Mistakes

These errors appear frequently in beginner code and interviews.

❌ Using [] to test map existence

m[key] can insert a missing key for maps and unordered_maps.

// Better for checking:
if (m.find(key) != m.end()) {
    // exists
}

❌ Dereferencing end()

end() is not an element. Never dereference it.

❌ Forgetting sort before binary search

Algorithms such as lower_bound and upper_bound require a sorted range in their normal use.

❌ Thinking unique removes everything

unique() rearranges consecutive duplicates toward the end; pair it with erase when you need a smaller vector.

❌ Assuming unordered containers preserve order

Do not rely on iteration order of unordered_map/unordered_set.

❌ Invalidating iterators

Some container modifications invalidate iterators. Learn the invalidation rules before keeping iterators across insertions/erasures.

18. Interview Questions

Click each question to reveal the answer.

Why is vector usually preferred over list? +
vector provides contiguous storage, O(1) indexing and generally excellent cache locality. list is useful when frequent insertion/erasure at known iterators is the actual requirement.
set vs unordered_set? +
set keeps keys sorted and typically offers O(log n) operations. unordered_set uses hashing and offers average O(1) lookup, without sorted order.
map vs unordered_map? +
map maintains keys in sorted order and typically uses O(log n) operations. unordered_map uses hashing with average O(1) lookup but no sorted order.
What is an iterator? +
An iterator is an object used to traverse or refer to positions in a container range. STL algorithms use iterators to work generically across many containers.
What is the difference between lower_bound and upper_bound? +
lower_bound returns the first position whose value is not less than x. upper_bound returns the first position whose value is greater than x.
What is a lambda? +
A lambda is an anonymous function expression that can be created locally, optionally capturing surrounding variables, and is commonly used as an STL algorithm predicate or comparator.
What is a priority_queue by default? +
A max-heap: the largest element according to the comparator is at the top by default.
What does [begin, end) mean? +
It is a half-open range that includes begin and excludes end. This convention makes empty ranges natural and simplifies range composition.

🚀 Mini Project — Student Result Analyzer

Build a console program that stores student marks, calculates statistics, ranks students and identifies top performers.

struct Student {
    string name;
    vector<int> marks;

    double average() const {
        if (marks.empty()) return 0;
        return accumulate(marks.begin(), marks.end(), 0.0)
             / marks.size();
    }
};

vector<Student> students;

sort(students.begin(), students.end(),
     [](const Student& a, const Student& b) {
         return a.average() > b.average();
     });

Upgrade: add a map for subject-wise statistics and a priority_queue for top performers.
