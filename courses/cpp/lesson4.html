Master Operators

Operators are the symbols that tell C++ to perform an operation. From simple arithmetic to logical decisions, comparisons, bit manipulation and conditional expressions, operators are fundamental to almost every C++ program.

Beginner Friendly Interactive Interview Ready DSA Foundation 
#include <iostream>

int main()
{
    int a = 10;
    int b = 3;

    std::cout << a + b << '\n';
    std::cout << a > b << '\n';
    std::cout << (a > 5 && b < 5);

    return 0;
}

09 • INCREMENT & DECREMENT

++ and --

Prefix

int x = 5;

++x;

First changes x, then produces the updated value.

Postfix

int x = 5;

x++;

Produces the current value first, then increments x. 

int a = 5;

int x = ++a;  // a = 6, x = 6

int b = 5;

int y = b++;  // y = 5, b = 6
Interview favorite: Know the difference between ++x and x++ when the expression's value is used.

Operator Name Example Purpose
& AND 5 & 3 1 only when both bits are 1

Important: Bitwise operators are different from logical operators. & works on bits, while && works with logical truth values.

16 • SHORT-CIRCUIT EVALUATION

One of the most important logical concepts

AND — &&

false && something()

If the left side is already false, the entire AND expression must be false, so the right side does not need to be evaluated.

OR — ||

true || something()

If the left side is already true, the entire OR expression must be true, so the right side does not need to be evaluated.

Short-circuiting is important when the second condition has side effects or accesses something that must be valid.

22 • MINI PROJECT

Student result calculator

Combine arithmetic, relational and logical operators.

#include <iostream>

int main()
{
    int marks1 = 85;
    int marks2 = 78;
    int marks3 = 91;

    int total = marks1 + marks2 + marks3;

    double average = total / 3.0;

    bool passed =
        marks1 >= 35 &&
        marks2 >= 35 &&
        marks3 >= 35;

    std::cout << "Total: " << total << '\n';
    std::cout << "Average: " << average << '\n';

    if (passed)
        std::cout << "Result: PASS";
    else
        std::cout << "Result: FAIL";

    return 0;
}
This small program uses +, /, >= and &&.
23 • COMMON MISTAKES

Errors beginners frequently make

!

= vs ==

// Assignment
x = 5;

// Comparison
x == 5;

= assigns a value. == compares values.

!

Integer division

int result = 5 / 2;

Result is 2, not 2.5. Use a floating operand when decimal division is required. 

double result = 5.0 / 2;
!

Confusing logical and bitwise operators

&&   // logical AND
&    // bitwise AND
!

Ignoring precedence

2 + 3 * 4

Multiplication happens before addition. Parentheses can make the intended order obvious.

!

Overcomplicated expressions

Extremely long expressions can become difficult to read. Break complicated calculations into meaningful variables.

24 • INTERVIEW PREPARATION

Interview questions

What is an operator? +
An operator is a symbol or operator construct that tells C++ to perform an operation involving one or more operands.
Difference between = and ==? +
= is the assignment operator, while == checks whether two values are equal.
What is the difference between ++x and x++? +
Prefix increment changes the value before its value is used in the surrounding expression. Postfix increment uses the old value first and then increments the object.
What is short-circuit evaluation? +
For logical AND and OR, C++ can avoid evaluating the right operand when the left operand already determines the result.
Difference between & and &&? +
& is bitwise AND, while && is logical AND.
What is operator precedence? +
Operator precedence determines which operators are grouped first in an expression. Parentheses can explicitly control grouping.
