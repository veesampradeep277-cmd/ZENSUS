01 • Foundation

What is a Pointer?

A pointer is a variable that stores the memory address of another object or function.

Simple definition A pointer does not normally store the actual value. It stores the location where that value can be found.

Real-world analogy

Imagine your house has a location such as: House No. 42. Your friend does not need to carry your entire house. They only need its address to find it.

02 • Memory model

Variables Live in Memory

When you create a variable, the program stores it somewhere in memory. That location has an address.

The first statement prints the value. The second uses & to obtain the variable's address.

03 • Core operators

The Two Symbols You Must Understand

& — Address-of

Gets the address of an object.

Address 
int x = 50;

std::cout << &x;

Think: "Where is x stored?"

* — Dereference

Accesses the object referred to by a pointer.

Dereference 
int x = 50;
int* p = &x;

std::cout << *p;

Think: "Go to that address and get the value."

06 • Dereferencing

Changing a Value Through a Pointer

A pointer can be used to modify the object it points to, provided that the object is modifiable.

modify.cpp 
int x = 10;

int* p = &x;

*p = 50;

std::cout << x;
Output 50

Why? Because *p refers to the same object as x.

08 • Safety

What is nullptr?

nullptr represents a null pointer value. It means the pointer is not currently pointing to an object or function.

safe_pointer.cpp 
int* p = nullptr;

if (p == nullptr) {
    std::cout << "Pointer is null\n";
}
Never dereference a null pointer 
// Dangerous

09 • Advanced basics

Pointer Arithmetic

Pointer arithmetic is especially useful when working with arrays. If p points to an element of an array, moving to p + 1 moves to the next element of that array.

pointer_arithmetic.cpp 
int arr[] = {10, 20, 30, 40};

int* p = arr;

std::cout << *p << '\n';

p++;

std::cout << *p << '\n';

Output: 

10
20
Important Pointer arithmetic is scaled by the pointed-to type. For example, adding 1 to an int* moves to the next int element, not simply one raw byte.

Common operations

Operation Meaning
p + 1 Next element
p - 1 Previous element
p++ Move to next element
p-- Move to previous element
p2 - p1 Distance between pointers into the same array

11 • Functions

Passing Pointers to Functions

A pointer parameter can allow a function to modify an existing object supplied by the caller.

function_pointer.cpp 
void changeValue(int* p) {
    *p = 100;
}

int main() {

    int x = 10;

    changeValue(&x);

    std::cout << x;

    return 0;
}

The function receives the address of x. Dereferencing the pointer accesses the original object.

Call by value vs pointer parameter

By value

void change(int x) {
    x = 100;
}

Changes only the local copy.

Using pointer

void change(int* x) {
    *x = 100;
}

Can modify the caller's object.

12 • Advanced

Pointer to Pointer

A pointer can itself have an address. A pointer to pointer stores the address of another pointer.

double_pointer.cpp 
int x = 50;

int* p = &x;

int** pp = &p;

std::cout << x << '\n';
std::cout << *p << '\n';
std::cout << **pp << '\n';
x
50
←
p
&x
←
pp
&p
Remember

p → address of x

*p → value of x

pp → address of p

*pp → p

**pp → x

13 • Dynamic memory

Dynamic Memory Allocation

C++ provides new to dynamically create objects and delete to release memory obtained with new.

dynamic.cpp 
int* p = new int(25);

std::cout << *p << '\n';

delete p;

p = nullptr;

Dynamic array

dynamic_array.cpp 
int n = 5;

int* arr = new int[n];

for (int i = 0; i < n; i++) {
    arr[i] = i + 1;
}

delete[] arr;

arr = nullptr;
Important pairing rule

Memory allocated with new should be released with delete.

Memory allocated with new[] should be released with delete[].

Modern C++ note

In modern C++, prefer standard containers such as std::vector and smart pointers such as std::unique_ptr where appropriate, rather than manually managing memory whenever possible.

14 • Important interview topic

Const and Pointers

The position of const changes what is protected.

Pointer to const

int x = 10;

const int* p = &x;

// *p = 20;   // Not allowed through p

x = 20;       // x itself can still change

Const pointer

int x = 10;
int y = 20;

int* const p = &x;

*p = 30;

// p = &y;   // Not allowed

Const pointer to const

int x = 10;

const int* const p = &x;

// *p = 20;   // Not allowed
// p = nullptr; // Not allowed
Syntax Can change value through pointer? Can change pointer itself?
const int* p No Yes
int* const p Yes No
const int* const p No No

16 • Debugging

Common Pointer Mistakes

A local pointer that has not been initialized does not safely point to a valid object. 

int* p;

// *p = 10;  // Undefined behavior

Prefer initializing it, often to nullptr if it has no target yet. 

int* p = nullptr;

// *p = 10;  // Invalid

A dangling pointer refers to an object whose lifetime has ended. 

int* p = new int(10);

delete p;

// p now does not point to a live int object.

Setting p = nullptr after deletion is a useful defensive practice.

A memory leak can occur when dynamically allocated memory is no longer reachable and has not been released. 

int* p = new int(100);

// Forgot to delete p
int* arr = new int[5];

// delete arr;     // Wrong
delete[] arr;      // Correct

21 • Mini project

Mini Project — Swap Two Numbers Using Pointers

One of the classic pointer problems is swapping two values through their addresses.

swap.cpp 
#include <iostream>

void swapNumbers(int* a, int* b) {

    int temp = *a;

    *a = *b;

    *b = temp;
}

int main() {

    int x = 10;
    int y = 20;

    std::cout << "Before: "
              << x << " "
              << y << '\n';

    swapNumbers(&x, &y);

    std::cout << "After: "
              << x << " "
              << y << '\n';

    return 0;
}
Output 
Before: 10 20
After: 20 10
22 • Interview preparation

Pointer Interview Questions

A pointer is an object that stores an address or another pointer value and can be used to access the object it points to.
In the pointer context, & can obtain an object's address, while * can dereference a pointer to access the referred object. Their meaning depends on context.
nullptr is the C++ null pointer literal. It represents a null pointer value.
A dangling pointer refers to an object whose lifetime has ended.
A memory leak can occur when dynamically allocated memory is no longer reachable and has not been released.
Pointer arithmetic allows a pointer into an array to move between elements using operations such as +, -, ++ and --.
A double pointer, such as int**, stores the address of another pointer.

26 • Rapid revision

One-Minute Pointer Revision

Pointer: stores an address/value that can be used to refer to an object.

&x: address of x.

p: address/value stored in pointer p.

*p: object referred to by p.

nullptr: null pointer value.

p + 1: next element when p points into an array.

int**: pointer to pointer.

new: dynamically creates an object.

delete: releases a single object obtained from new.

delete[]: releases an array obtained from new[].

Dangling pointer: points to an object whose lifetime has ended.

Memory leak: allocated memory is not properly released and becomes unreachable.
