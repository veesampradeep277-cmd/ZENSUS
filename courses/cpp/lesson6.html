01 • Foundation

What is a Loop?

A loop repeatedly executes a block of statements while a condition or repetition rule allows it.

Without a loop ❌

std::cout << 1 << '\n';
std::cout << 2 << '\n';
std::cout << 3 << '\n';
std::cout << 4 << '\n';
std::cout << 5 << '\n';
Repetitive, lengthy and difficult to maintain.

With a loop ✅

for (int i = 1; i <= 5; i++)
{
    std::cout << i << '\n';
}
One compact structure performs the same task repeatedly.
Real World

Think of a loop like repetition in daily life

A loop is similar to saying: “Keep doing this until the condition changes.”

📚 Study

Read one chapter → check whether the syllabus is complete → continue if chapters remain.

🏃 Exercise

Perform one repetition → increase the count → stop when the target repetitions are reached.

💻 Programming

Execute statements → test condition → repeat until the condition becomes false.

02 • Visual Concept

How does a loop actually work?

Every loop follows the fundamental idea: initialize → check → execute → update → check again.

1. Initialize i = 1
→
2. Condition i ≤ 5?
→
3. Body print i
→
4. Update i++
Key idea: After the update, control goes back to the condition. When the condition becomes false, the loop ends.
03 • For Loop

The for Loop

Use a for loop when the repetition structure is clearly controlled by initialization, condition and update.

Syntax

for (initialization; condition; update)
{
    // statements
}
1

Initialization

Runs once before the loop begins.

2

Condition

Checked before every iteration.

3

Body

Runs when the condition is true.

4

Update

Changes the loop variable after each iteration.

Example

for (int i = 1;
     i <= 5;
     i++)
{
    std::cout << i << ' ';
}
Output: 1 2 3 4 5
Best use: counting, arrays, ranges and known repetitions.

04 • While Loop

The while Loop

A while loop repeats as long as its condition remains true.

Syntax

while (condition)
{
    // statements
}
The condition is checked before every iteration.

Example

int i = 1;

while (i <= 5)
{
    std::cout << i << ' ';
    i++;
}
Output: 1 2 3 4 5

Execution Flow

Initialize i = 1
→
Condition i ≤ 5?
→
Body print i
→
Update i++
05 • Do-While

The do-while Loop

The body executes first and the condition is checked afterward. Therefore, it executes at least once.

Syntax

do
{
    // statements
}
while (condition);
Notice the semicolon ; after the while condition.

Example

int i = 1;

do
{
    std::cout << i << ' ';
    i++;
}
while (i <= 5);
Output: 1 2 3 4 5

Special Property

int x = 10;

do
{
    std::cout << x;
}
while (x < 5);
Even though x < 5 is false, the body executes once because the condition is checked afterward.

07 • Loop Control

break and continue

🛑 break

Immediately terminates the nearest enclosing loop or switch. 

for (int i = 1; i <= 10; i++)
{
    if (i == 5)
        break;

    std::cout << i << ' ';
}
Output: 1 2 3 4

⏭️ continue

Skips the remaining body of the current iteration and proceeds with the next iteration. 

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
        continue;

    std::cout << i << ' ';
}
Output: 1 2 4 5
08 • Advanced Basics

Nested Loops

A nested loop is a loop placed inside another loop. The inner loop completes its iterations for every outer iteration.

Example

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        std::cout << "* ";
    }

    std::cout << '\n';
}

Execution

Outer i 1 → 2 → 3
→
Inner j 1 → 2 → 3
→
Print * * *
For each outer-loop iteration, the inner loop runs completely.

13 • Core Patterns

Counter & Accumulator Patterns

Many DSA problems are built from these two fundamental loop patterns.

Counter Pattern

int count = 0;

for (int i=1; i<=10; i++)
{
    if (i % 2 == 0)
        count++;
}
count records how many values satisfy a condition.

Accumulator Pattern

int sum = 0;

for (int i=1; i<=10; i++)
{
    sum += i;
}
sum continuously accumulates a result.
14 • Important

Infinite Loops

An infinite loop never reaches a terminating condition. 

while (true)
{
    std::cout << "Running...";
}
This is intentionally infinite. 
int i = 1;

while (i <= 5)
{
    std::cout << i;

    // Missing i++
}
Problem: i never changes, so the condition remains true.
15 • Logic

Important Loop Questions

When does it stop?

The loop stops when its condition becomes false, or when control exits through break.

Can a loop execute zero times?

Yes. for and while can execute zero times if their initial condition is false.

Which executes at least once?

The do-while loop because its condition is evaluated after the body.

16 • Debugging

Common Beginner Mistakes

!

Forgetting the update

Without i++, a loop may never terminate.

!

Off-by-one error

Confusing < with <= can cause one extra or one fewer iteration.

!

Wrong update direction

Starting at 1 and using i-- while checking i <= 10 can create an infinite loop.

!

Extra semicolon

for (...); 
{
    std::cout << "Hello";
}

The semicolon creates an empty loop body.

17 • Exam Preparation

Exam-Ready Answers

A loop is a control structure used to repeatedly execute a block of statements while a specified condition remains true or according to a defined iteration rule.
The for loop contains initialization, condition and update expressions. Initialization is executed once, the condition is checked before every iteration, the body executes when the condition is true, and the update occurs after the body.
A while loop checks its condition before executing the body, so it may execute zero times. A do-while loop checks its condition after executing the body, so it executes at least once.
A nested loop is a loop placed inside another loop. The inner loop is executed for every iteration of the outer loop.

Test Yourself

1. Which loop is best when the number of iterations is clearly known?

A for loop naturally groups initialization, condition and update, making it convenient for count-controlled repetition.

2. Which loop executes its body at least once?

3. What does break do inside a loop?

break immediately exits the nearest enclosing loop.

4. What does continue do?

continue skips the remaining statements of the current iteration and proceeds toward the next iteration.
