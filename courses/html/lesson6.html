01 • Fundamentals

What is an HTML List?

An HTML list is a collection of related items presented together in a structured format.


Lists are useful whenever several pieces of information belong to the same group.

Real-world examples Navigation menus, shopping items, programming steps, course topics, skills, ingredients, FAQs and feature lists can all be represented using lists.

03 • Unordered Lists

The <ul> Element

Use an unordered list when the order of items is not important.

Basic Syntax

HTML 
<ul>
    <li>Python</li>
    <li>Java</li>
    <li>C++</li>
</ul>

Output

  • Python
  • Java
  • C++

Important Rule

The direct children of <ul> should normally be <li> elements.

Remember <ul> creates the list. <li> creates each item.
04 • Ordered Lists

The <ol> Element

Use an ordered list when the sequence or ranking of items matters.

Example

HTML 
<ol>
    <li>Open the website</li>
    <li>Create an account</li>
    <li>Choose a course</li>
    <li>Start learning</li>
</ol>

Output

  1. Open the website
  2. Create an account
  3. Choose a course
  4. Start learning

When to use <ol>

  • Step-by-step tutorials
  • Rankings
  • Instructions
  • Procedures
  • Ordered processes

When NOT to use <ol>

Do not use ordered lists just because you want numbers visually. The sequence should have semantic meaning.

05 • Ordered List Controls

start, reversed and type

start

Changes the starting number of an ordered list.

HTML 
<ol start="5">
    <li>Item A</li>
    <li>Item B</li>
    <li>Item C</li>
</ol>
  1. Item A
  2. Item B
  3. Item C

reversed

Makes the numbering count downwards.

HTML 
<ol reversed>
    <li>Third</li>
    <li>Second</li>
    <li>First</li>
</ol>

type

The type attribute can control the traditional marker style of an ordered list.

Value Marker Example
1 Numbers 1, 2, 3
A Uppercase letters A, B, C
a Lowercase letters a, b, c
I Uppercase Roman I, II, III
i Lowercase Roman i, ii, iii
06 • Description Lists

The <dl>, <dt> and <dd> Elements

Description lists represent terms and their corresponding descriptions or values.

HTML 
<dl>

    <dt>HTML</dt>
    <dd>Structures web pages.</dd>

    <dt>CSS</dt>
    <dd>Styles web pages.</dd>

    <dt>JavaScript</dt>
    <dd>Adds behavior and interactivity.</dd>

</dl>
HTML
Structures web pages.
CSS
Styles web pages.
JavaScript
Adds behavior and interactivity.
Where can description lists be useful? Glossaries, terminology pages, FAQs, metadata, product specifications and key-value information.
07 • Structure

Nested Lists

A nested list is a list placed inside another list item.

HTML 
<ul>

    <li>
        Programming

        <ul>
            <li>Python</li>
            <li>Java</li>
            <li>C++</li>
        </ul>

    </li>

    <li>
        Web Development

        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>

    </li>

</ul>
  • Programming
    • Python
    • Java
    • C++
  • Web Development
    • HTML
    • CSS
    • JavaScript
Important nesting rule Put the nested list inside the relevant <li>. Do not place it directly as a sibling of <li>.
08 • CSS Styling

Customize List Markers with CSS

list-style-type

Controls the marker style.

CSS 
ul {
    list-style-type: square;
}

ol {
    list-style-type: upper-roman;
}

list-style-position

Controls whether markers appear inside or outside the list item's main box.

CSS 
ul {
    list-style-position: inside;
}

list-style

The shorthand property combines multiple list-style settings.

CSS 
ul {
    list-style: square inside;
}
09 • Modern Styling

Creating Custom List Markers

Modern CSS allows you to design custom markers using pseudo-elements such as ::before.

CSS 
ul.custom li::before {
    content: "✓";
    color: green;
    font-weight: bold;
    margin-right: 10px;
}

13 • Accessibility

Lists and Accessibility

Semantic lists help assistive technologies understand the relationship between related items.

Use semantic elements

Use <ul>, <ol> and <li> instead of manually typing bullet symbols.

Navigation lists

Place navigation lists inside <nav> when they represent navigation.

Do not fake lists

Avoid creating lists with repeated <div> elements and manually typed bullets.

Meaning matters

Choose unordered or ordered lists based on meaning, not only appearance.

14 • SEO & Structure

Why Semantic Lists Matter

Search engines and assistive technologies can better understand structured content when appropriate semantic HTML elements are used.


  • Clear document structure
  • Better accessibility
  • More meaningful HTML
  • Easier maintenance
  • Better content organization

16 • Debugging

Common Mistakes Students Make

!

Using <li> without a list container

List items should belong to an appropriate list structure.

!

Using <ol> when order has no meaning

Choose the semantic element according to the meaning of the content.

!

Typing bullets manually

Avoid using characters such as • or - as a replacement for semantic list markup.

!

Incorrect nested list structure

The nested list belongs inside the relevant <li>.

!

Using HTML attributes for visual styling

Prefer CSS for modern presentation and design.

18 • Exam Preparation

5-Mark Answer

Explain HTML Lists.

HTML lists are used to organize related information. HTML provides three main types of lists: unordered lists, ordered lists and description lists.


An unordered list uses the <ul> element and contains list items using <li>. An ordered list uses <ol> when the sequence of items is important.


A description list uses <dl>, <dt> and <dd> to represent terms and their descriptions.

19 • Interview Preparation

Important Interview Questions

1. What is an HTML list?

An HTML list is a semantic structure used to group related items.

2. What is the difference between <ul> and <ol>?

<ul> represents an unordered list where order is not important. <ol> represents an ordered list where sequence matters.

3. What is the purpose of <li>?

<li> represents an individual list item.

4. What is a description list?

A description list represents terms and their associated descriptions using <dl>, <dt> and <dd>.

5. Can lists be nested?

Yes. A list can be placed inside an <li> to create hierarchical content.

6. What does the start attribute do?

It specifies the starting value of an ordered list.

7. What does reversed do?

It makes an ordered list count in descending order.

8. What is list-style-type?

It is a CSS property used to control list marker styles.

9. Why should we use semantic lists?

They provide meaningful structure and improve accessibility and maintainability.

10. Can a list contain links?

Yes. Navigation menus commonly use links inside list items.

11. Can a list item contain other HTML elements?

Yes. An <li> can contain text, links, images, paragraphs, nested lists and other appropriate content.

12. How can list markers be customized?

CSS properties such as list-style-type and custom pseudo-elements can be used.

13. Should bullets be typed manually?

No. Semantic list elements should be used when the content is actually a list.

14. Where are lists used in real websites?

Navigation menus, documentation, product features, instructions, FAQs, course modules and search results.
