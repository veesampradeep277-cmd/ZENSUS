What is HTML?

HTML = HyperText Markup Language

HTML is the standard markup language used to structure documents on the Web.

It tells the browser what different pieces of content represent.

Chapter 2 • History

The History and Evolution of HTML

Understanding history helps you understand why HTML looks the way it does today.

1989 — The Web is proposed

Tim Berners-Lee, working at CERN, proposed a system for sharing information using hypertext over a network.

1990 — First Web implementation

Berners-Lee developed the first Web browser/editor, Web server, and early technologies that became HTTP, HTML and URLs.

1991 — HTML becomes public

An early description of HTML and a list of HTML tags became publicly available.

1993 — Web standardization begins

HTML continued evolving as the World Wide Web rapidly gained users.

1995 — HTML 2.0

HTML 2.0 provided an important formal baseline for the rapidly expanding Web.

1997 — HTML 3.2

HTML 3.2 standardized several features that had become common, including tables.

1997–1999 — HTML 4 / HTML 4.01

HTML 4 introduced important improvements around forms, scripting, accessibility, internationalization and the separation of structure from presentation.

2000 — XHTML

XHTML reformulated HTML using XML rules and encouraged stricter syntax.

2004 — WHATWG

The Web Hypertext Application Technology Working Group began practical work on the continuing evolution of the Web platform.

2008–2014 — HTML5 era

HTML5 introduced and standardized many capabilities associated with modern Web applications, including semantic elements, audio, video, canvas and richer Web features.

Today — HTML Living Standard

Modern HTML is best understood as a continuously updated standard rather than a frozen version. WHATWG maintains the HTML Living Standard.

Historical note There was not a single official "HTML 1.0" specification equivalent to later numbered specifications. Early HTML evolved through proposals, implementations and specifications.

The Web Trio

HTML vs CSS vs JavaScript

H

HTML

Defines the structure and meaning of content.

Think: Skeleton Headings, paragraphs, links, images, forms, sections and more.
C

CSS

Controls presentation, layout, colors, spacing and visual design.

Think: Appearance Colors, fonts, layouts, responsive design and animations.
JS

JavaScript

Provides logic, behavior and interaction.

Think: Behavior Events, calculations, APIs, validation and dynamic updates.
Easy analogy HTML is the skeleton, CSS is the design/clothing, and JavaScript provides behavior and interaction.
Chapter 4 • Document Structure

Anatomy of an HTML Document

Standard HTML Template 

<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width,
                   initial-scale=1.0">

    <title>
        My First Page
    </title>

</head>

<body>

    <h1>
        Hello, HTML!
    </h1>

    <p>
        My first webpage.
    </p>

</body>

</html>

Four important parts

DOCTYPE Standards mode
html Root element
head Metadata
body Page content

<head> contains metadata and information about the document.

<body> contains the document content displayed or used by the page.

Understanding DOCTYPE 

<!DOCTYPE html>

This declaration tells the browser to use standards-oriented HTML parsing and rendering behavior. It is not an HTML element.

Debugging

Common Beginner Mistakes

❌ Forgetting DOCTYPE

Start documents with the standard DOCTYPE declaration.

❌ Incorrect Nesting

Keep opening and closing elements properly nested.

❌ Missing alt Text

Give meaningful images appropriate alternative text.

❌ Styling with HTML

HTML describes structure. CSS handles visual presentation.

❌ Using Headings for Size

Heading levels represent hierarchy, not just font sizes.

❌ Thinking HTML is Programming

HTML is a markup language. JavaScript provides general programming behavior in the browser.

Developer mindset Don't memorize hundreds of tags at once. Learn what a tag means, where it belongs, and why you would use it.
