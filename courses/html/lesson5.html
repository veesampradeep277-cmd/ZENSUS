01 • Fundamentals

What is an HTML Image?

Images make websites more informative, engaging and visually understandable. HTML provides the <img> element for embedding an image resource.

Unlike elements such as paragraphs, the <img> element does not have a closing tag.

Basic Image 
<img
    src="student.jpg"
    alt="Student studying at a desk">
🖼️ Browser renders the image here

<img>

Embeds an image resource into the document.

src

Specifies the image resource URL.

alt

Provides alternative text for the image.

02 • Attributes

Important Image Attributes

src

Tells the browser where the image resource is.

alt

Describes the image when appropriate.

width

Specifies the intended rendered width.

height

Specifies the intended rendered height.

loading

Provides a hint about when the browser should load the image.

srcset / sizes

Help provide responsive image candidates. 

<img
    src="campus.jpg"
    alt="College campus building"
    width="800"
    height="500"
    loading="lazy">
03 • Image Dimensions

Width and Height

The width and height attributes can describe the intended dimensions of an image in CSS pixels. 

<img
    src="profile.jpg"
    alt="Student profile photo"
    width="400"
    height="400">
Performance tip: Providing image dimensions can help the browser reserve space before the image finishes loading, reducing unexpected layout movement.

CSS vs HTML dimensions

HTML dimensions provide intrinsic/layout information, while CSS is commonly used to control the visual presentation and responsive sizing. 

<img
    src="hero.jpg"
    alt="ZENSUS learning dashboard"
    width="1200"
    height="700"
    class="hero-image">

<style>

.hero-image {
    width: 100%;
    height: auto;
}

</style>
04 • File Paths

Understanding Image Paths

One of the most common beginner problems is an image not appearing because the path is incorrect.

Same Folder 

<img
    src="student.jpg"
    alt="Student">

Inside a Folder 

<img
    src="images/student.jpg"
    alt="Student">

Parent Folder 

<img
    src="../images/student.jpg"
    alt="Student">

Complete URL 

<img
    src="https://example.com/images/student.jpg"
    alt="Student">
Debugging rule: If an image is not showing, first check the filename, extension, folder location, capitalization and path.
05 • Accessibility

The Most Important Image Attribute: alt

The alt attribute provides alternative text for an image. It is important for accessibility and also acts as fallback text when the image cannot be displayed.

❌ Poor 

<img
    src="student.jpg"
    alt="image">

"image" does not explain useful content.

✅ Better 

<img
    src="student.jpg"
    alt="Student solving a coding problem">

The alternative text communicates meaningful information.

Decorative Images

If an image is purely decorative and adds no information, an empty alt value is often appropriate. 

<img
    src="decorative-line.svg"
    alt="">
Never write: "Image of..." or "Picture of..." unless that wording genuinely adds useful information. Screen readers already know they encountered an image.
06 • Image Semantics

Figure and Figcaption

Use <figure> when an image or other content is a self-contained piece that can be referenced separately from the main flow.

Use <figcaption> to provide a caption. 

<figure>

    <img
        src="architecture.jpg"
        alt="Modern university library building"
        width="900"
        height="600">

    <figcaption>
        ZENSUS Campus Learning Center
    </figcaption>

</figure>
Remember: alt describes the image for accessibility; figcaption is visible content associated with the figure.
07 • Image Formats

Common Image Formats

JPEG / JPG

Commonly useful for photographs and complex images where lossy compression is acceptable.

PNG

Useful when lossless quality or transparency is important.

SVG

Vector format that is especially useful for logos, icons and illustrations.

GIF

Supports simple animations and limited-color graphics.

WebP

Modern web image format with support for lossy and lossless compression.

AVIF

Modern image format designed for efficient compression and high visual quality.

08 • Responsive Web

Responsive Images

A modern website may be opened on a phone, tablet, laptop or large desktop. Sending the same huge image to every device can waste bandwidth.

📱 → 💻 → 🖥️
Responsive Image
Mobile Tablet Desktop

srcset

The srcset attribute lets you provide multiple image candidates. 

<img
    src="photo-800.jpg"
    srcset="
        photo-400.jpg 400w,
        photo-800.jpg 800w,
        photo-1200.jpg 1200w
    "
    alt="Student working on a laptop">

sizes

The sizes attribute describes how much space the image is expected to occupy under different viewport conditions. 

<img
    src="photo-800.jpg"
    srcset="
        photo-400.jpg 400w,
        photo-800.jpg 800w,
        photo-1200.jpg 1200w
    "
    sizes="
        (max-width: 600px) 100vw,
        (max-width: 1000px) 80vw,
        700px
    "
    alt="Student working on a laptop">
Concept: srcset provides candidates. sizes helps the browser determine which candidate is appropriate for the expected display size.
09 • Art Direction

The picture Element

The <picture> element is useful when you need different image resources under different conditions, such as art direction or format selection. 

<picture>

    <source
        media="(max-width: 600px)"
        srcset="mobile-banner.jpg">

    <source
        media="(min-width: 601px)"
        srcset="desktop-banner.jpg">

    <img
        src="desktop-banner.jpg"
        alt="ZENSUS learning platform">

</picture>

The final <img> acts as the fallback and provides the alternative text.

10 • Performance

Image Performance

Images are often among the largest resources downloaded by a webpage. Poor image handling can make websites slow.

⚡ Compress

Avoid unnecessarily large files.

📐 Correct Size

Do not serve a huge image when a smaller candidate is sufficient.

💤 Lazy Loading

Consider lazy loading images that are below the initial viewport. 

<img
    src="article-image.jpg"
    alt="Students learning together"
    width="800"
    height="500"
    loading="lazy"
    decoding="async">
Important: Do not blindly add lazy loading to every image. Important above-the-fold images may need to load eagerly so the initial page remains fast and visually stable.
11 • Loading

loading Attribute

The loading attribute gives the browser a hint about when an image should be loaded.

eager

Requests that the image be loaded without deferring it due to lazy-loading behavior. 

<img
    src="hero.jpg"
    alt="ZENSUS homepage"
    loading="eager">

lazy

Hints that loading may be deferred until the image is near the viewport. 

<img
    src="article.jpg"
    alt="Coding practice"
    loading="lazy">
12 • Accessibility

Professional Image Accessibility

  • Always decide deliberately what the alt value should be.
  • Use concise, meaningful descriptions for informative images.
  • Use alt="" for genuinely decorative images.
  • Do not place important text only inside an image.
  • Make sure images do not prevent users from understanding the page.
  • If an image is interactive, ensure the surrounding interaction is accessible. 
<figure>

    <img
        src="algorithm.png"
        alt="Flowchart showing the steps of a binary search">

    <figcaption>
        Binary search divides the search range repeatedly.
    </figcaption>

</figure>
13 • Image + Link

Making Images Clickable

Images can be placed inside anchor elements when clicking the image should navigate somewhere. 

<a href="course.html">

    <img
        src="html-course.jpg"
        alt="HTML course">

</a>
If the image itself is the meaningful clickable content, make sure its alternative text communicates the link's purpose rather than merely saying "image."

17 • Debugging Lab

Why Is My Image Not Showing?

1. Check the path

Is the image actually inside the folder referenced by src?

2. Check the filename

Verify spelling and capitalization.

3. Check extension

jpg, jpeg, png, webp, svg and other extensions must match the actual file.

4. Check DevTools

Browser developer tools can reveal failed resource requests. 

project/
│
├── index.html
│
├── lesson5.html
│
└── images/
    ├── student.jpg
    ├── campus.png
    └── logo.svg

If the HTML file is in the project root and the image is inside the images folder: 

<img
    src="images/student.jpg"
    alt="Student studying">
18 • Common Mistakes

Mistakes Every Beginner Should Avoid

❌ Missing alt 

<img src="student.jpg">

❌ Wrong path 

<img
src="student-photo.jpg"
alt="Student">

❌ Huge unoptimized image

Sending unnecessarily large images wastes bandwidth.

❌ Fake alt text 

<img
src="campus.jpg"
alt="image image image campus college">

❌ Layout using width alone

Always consider the image's aspect ratio and responsive behavior.

❌ Important text only inside images

Real text is generally more accessible, searchable and responsive.

19 • Professional Pattern

Professional Image Example 

<figure>

    <picture>

        <source
            media="(max-width: 600px)"
            srcset="images/campus-mobile.webp">

        <source
            srcset="
                images/campus-800.webp 800w,
                images/campus-1200.webp 1200w
            "
            sizes="
                (max-width: 900px) 90vw,
                800px
            ">

        <img
            src="images/campus-800.webp"
            alt="ZENSUS student learning center"
            width="800"
            height="500"
            loading="lazy"
            decoding="async">

    </picture>

    <figcaption>
        ZENSUS Student Learning Center
    </figcaption>

</figure>
This combines several professional techniques: responsive candidates, art direction, alternative text, dimensions, lazy loading, decoding hints and semantic figure content.
20 • Exam Preparation

5-Mark Answer: HTML Images

HTML uses the <img> element to embed images in webpages. The src attribute specifies the image source and alt provides alternative text. 

<img
    src="student.jpg"
    alt="Student studying HTML"
    width="500"
    height="300">

HTML also supports image-related features such as width and height, responsive image candidates using srcset and sizes , the <picture> element and semantic <figure> and <figcaption> . Proper image optimization and alternative text improve accessibility and performance.

22 • Interview Preparation

Important Interview Questions

1. What is <img>?

It is the HTML element used to embed an image resource.

2. What is src?

It specifies the URL of the image resource.

3. Why is alt important?

It provides alternative text and is important for accessibility and fallback content.

4. Why use width and height?

They provide image dimensions and help the browser reserve layout space.

5. What is srcset?

It provides multiple image resource candidates.

6. What is sizes?

It describes the expected display size of a responsive image under different conditions.

7. What is picture?

It provides conditional image sources for use cases such as art direction and format selection.

8. What is lazy loading?

It allows suitable images to be deferred until they are near the viewport.

9. Figure vs img?

img embeds an image; figure groups self-contained content such as an image with an optional caption.

10. What is figcaption?

It provides a caption associated with a figure.

11. How do you make an image clickable?

Place the image inside an anchor element.

12. Why optimize images?

Large images can increase network usage and slow page loading.

13. What is a decorative image?

An image that adds no meaningful information to the content.

14. JPEG vs PNG?

JPEG is commonly used for photographs; PNG is useful when lossless quality or transparency is important.
