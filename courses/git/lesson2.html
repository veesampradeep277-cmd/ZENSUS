Installing Git & Git Configuration

Install Git on your computer, verify that it works correctly, configure your Git identity, choose useful defaults, and prepare your development environment for Git and GitHub projects.

01

What Do You Need Before Installing Git?

Git is available for major desktop operating systems. Before installation, make sure you have access to a terminal or command-line application.

🪟

Windows

Git for Windows provides Git and common Unix-style command-line tools.

🐧

Linux

Git can usually be installed through the distribution's package manager.

🍎

macOS

Git can be installed using available developer tools or package management options.

Important: The exact installation screens can differ between operating system versions. The Git commands used after installation are largely the same.

What Happens During Installation?

  • Git executable files are installed.
  • Git command-line functionality becomes available.
  • Git-related tools may be added to your system path.
  • You can then execute commands such as git status.
Once Git is installed successfully, the next step is not immediately to create a repository. First, verify Git and configure your identity.
03

Installing Git on Windows

On Windows, Git is commonly installed through Git for Windows.

Step 1 — Obtain the Installer

Download the Git for Windows installer from the official Git website.

Look for the official Git distribution rather than downloading unverified copies from random websites.

Step 2 — Run the Installer

Open the downloaded installer and follow the setup wizard.

Step 3 — Installation Options

The installer provides several configuration options. For a beginner, the recommended approach is usually to keep the standard defaults unless you have a specific reason to change them.

Step 4 — Open Git Bash

After installation, you can use Git Bash or another terminal that can execute Git commands.

Git Bash 
$ git --version

Expected Result

Example 
git version 2.x.x

The exact version number depends on the Git version installed on your computer.

Configure Your Git Identity

After installing Git, configure the name and email that Git will associate with your commits.

Think of this as telling Git: "Who is creating these commits?"

Configure Name

Terminal 
git config --global user.name "Your Name"

Configure Email

Terminal 
git config --global user.email "you@example.com"

These commands configure the identity globally for your user account on that computer.

08

Setting Your Git Username

Use:

Terminal 
git config --global user.name "Pradeep"

Replace Pradeep with the name you want Git to record with your commits.

Check It

Terminal 
git config --global user.name

Example Output

Output 
Pradeep
This is the Git commit author name. It is not necessarily the same thing as your GitHub username.
09

Setting Your Git Email

Configure the email associated with your commits.

Terminal 
git config --global user.email "you@example.com"

Check It

Terminal 
git config --global user.email

Why Does This Matter?

Git stores author information inside commits. When repositories are shared, this information helps identify who created a particular commit.

If you plan to publish projects on GitHub, use an email identity that you are comfortable associating with your commits and configure your GitHub account accordingly.
10

Configure the Default Branch Name

Modern Git workflows commonly use main as the primary branch name.

You can configure Git so that newly initialized repositories use main as their initial branch name.

Terminal 
git config --global init.defaultBranch main

Why Configure This?

  • Keeps your new repositories consistent.
  • Matches the common branch naming convention.
  • Makes collaboration easier when a team expects main.
After configuring this setting, running git init in a new project will use the configured initial branch name.
11

Understanding Git Configuration

Git uses configuration settings to control its behavior.

View Configuration

Terminal 
git config --list

View Global Configuration

Terminal 
git config --global --list

Get One Specific Value

Terminal 
git config --global user.name

Git's configuration system lets you customize many parts of its behavior.

12

Git Configuration Levels

Git configuration can exist at different scopes.

Level Option Scope
System --system Applies to the system
Global --global Applies to your user account
Local --local Applies to one repository

Global Example

Global 
git config --global user.name "Your Name"

Local Repository Example

Local 
git config --local user.name "Project Name"
Important: A repository-specific configuration can override a global setting for that repository.
13

Verify Your Complete Configuration

After configuring Git, check your settings.

Terminal 
git config --global --list

You may see entries similar to:

Example 
user.name=Pradeep
user.email=you@example.com
init.defaultbranch=main

Individual Checks

Name
git config --global user.name
Email
git config --global user.email
Default Branch
git config --global init.defaultBranch
If these values are correct, your basic Git configuration is ready.
14

Configuring a Default Editor

Git sometimes opens a text editor for commit messages or other operations.

You can configure which editor Git should use.

Example: Visual Studio Code

Terminal 
git config --global core.editor "code --wait"

The exact command depends on which editor you have installed and how it is exposed through your system's command line.

Why Does Git Need an Editor?

Some Git operations may require you to enter or modify text such as commit messages.

If you are a beginner and use git commit -m "message", you can usually provide the commit message directly without opening an editor.

Common Installation & Configuration Problems

Problem Possible Cause What to Check
git is not recognized Git may not be installed or may not be available in PATH Install Git and reopen the terminal
Wrong username Incorrect Git configuration Run git config --global user.name
Wrong email Incorrect Git configuration Run git config --global user.email
Old branch name Default branch not configured Check init.defaultBranch
Configuration differs by project Local repository setting overrides global setting Check local configuration

Important Windows Tip

After installing Git, if an already-open terminal cannot find the git command, close that terminal and open a new one.

Do not immediately reinstall Git if the command is not recognized. First restart the terminal and check whether Git is available.
