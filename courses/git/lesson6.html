Branches & Branch Management

Learn how Git branches allow you to work on new features, experiments, and fixes without disturbing your main codebase. You will learn how to create, switch, rename, list, and delete branches.

1. What Is a Git Branch?

A branch is an independent line of development in a Git repository.

It allows developers to work on different changes separately while keeping the existing code safe.

Simple definition: A Git branch is a separate path where you can develop changes without directly changing another branch.

Independent Work

Work on a feature without disturbing the main code.

Safe Experiment

Try new ideas without risking the stable version.

Team Development

Multiple developers can work on different features.

2. Why Do We Use Branches?

Imagine that your application is already working correctly. You need to add a login system.

You could directly change the main code, but if something goes wrong, the stable application may also be affected.

Instead, create a separate branch: 

git switch -c login-feature

Now you can work on the login feature separately.

main Stable application
→
login-feature New login work

3. Understanding the Main Branch

Most Git projects have a primary branch called main.

Older projects may use master, but main is now a common default name.

Important: The name of the main branch is just a branch name. Git does not technically make main more powerful than another branch.

Teams commonly use the main branch for code that represents the primary or stable version of a project.

4. Visualizing Branches

Suppose your project has three commits on the main branch. You then create a feature branch.

main: A ───── B ───── C
            \ D ───── E    feature-login

The feature branch started from commit C. New commits D and E belong to that branch.

The main branch can continue independently.

5. The git branch Command

The git branch command is used to work with local branches. 

git branch

This displays the branches in your repository.

Git places an asterisk * next to the currently active branch. 

* main
  login-feature
  payment-feature
The * means that you are currently working on that branch.

6. Creating a Branch

To create a new branch, use: 

git branch feature-login

This creates the branch, but it does not switch you to it.

Example

git branch feature-login
git branch

You may see: 

* main
  feature-login

The branch exists, but you are still on main.

7. Switching Branches

To move from one branch to another, use git switch. 

git switch feature-login

Git changes your working directory to match the selected branch. 

Switched to branch 'feature-login'

Check the current branch

git branch

Now you should see: 

  main
* feature-login

8. Create and Switch to a Branch in One Command

Instead of creating a branch and switching separately, you can do both with one command. 

git switch -c feature-login

Here:

  • switch → change branches
  • -c → create a new branch
  • feature-login → branch name
Result: The branch is created and you immediately move to it.

Older Git syntax

You may also see: 

git checkout -b feature-login

This is an older but still widely encountered Git command. For modern Git workflows, git switch is clearer.

9. Listing Branches

Use: 

git branch

Example: 

  feature-login
  payment
* main
  profile-page

The asterisk tells you which branch is currently active.

Show the current branch

git branch --show-current

Example output: 

feature-login

10. Renaming a Branch

You may need to rename a branch when the name is incorrect or when your team's naming convention changes.

Rename the current branch

git branch -m new-name

Rename a specific branch

git branch -m old-name new-name

Example: 

git branch -m login login-feature

11. Deleting a Branch

After a feature has been completed and merged into another branch, the old feature branch may no longer be needed.

To safely delete a local branch: 

git branch -d feature-login

The -d option asks Git to perform a safe deletion.

Be careful with -D:
git branch -D feature-login forcefully deletes the branch even when Git detects that its commits may not have been merged.

Use force deletion only when you are sure the work is no longer needed.

12. Important Branch Commands

Command Purpose
git branch List local branches
git branch feature Create a branch
git switch feature Switch to a branch
git switch -c feature Create and switch
git branch --show-current Show current branch
git branch -m new-name Rename current branch
git branch -d feature Safely delete branch
git branch -D feature Force delete branch

13. Typical Branch Workflow

A common development workflow looks like this:

main Stable code
→
Create Branch feature-login
→
Develop Make changes
→
Commit Save changes

For example: 

git switch main

git switch -c feature-login

# edit files

git add .

git commit -m "Add login feature"
Important: Merging branches will be covered in the next lesson. For now, focus on creating and managing branches.

14. How Git Thinks About a Branch

Internally, a branch is essentially a lightweight reference that points to a commit.

You do not need to understand Git internals deeply yet. Think of a branch as a label pointing to a commit.

Commit A ─── Commit B ─── Commit C
                 ↑ main

When you create a new branch from the current commit, the new branch initially points to the same commit.

As you make new commits, the branch pointer moves forward.

15. Common Branch Mistakes

Mistake 1 — Creating but not switching

git branch feature-login

This only creates the branch.

You still need: 

git switch feature-login

Mistake 2 — Working on the wrong branch

Always check: 

git branch

before making important changes.

Mistake 3 — Deleting an unfinished branch

Avoid using -D unless you are certain that the branch's work can be discarded.

Mistake 4 — Using unclear branch names

Prefer meaningful names such as: 

feature-login
feature-payment
fix-navbar
fix-authentication
docs-readme

19. Lesson Takeaway

Git branches allow you to work on different versions or features of a project independently.

  • A branch represents a separate line of development.
  • git branch lists local branches.
  • git branch feature creates a branch.
  • git switch feature switches branches.
  • git switch -c feature creates and switches.
  • git branch --show-current shows the current branch.
  • git branch -m renames a branch.
  • git branch -d safely deletes a branch.
  • git branch -D force deletes a branch.
  • Always check your current branch before making important changes.
