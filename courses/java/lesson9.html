05 • CRITICAL CONCEPT

String Immutability

One of the most important concepts in Java Strings.

🔒

Strings are Immutable

Once a String object is created, its contents cannot be changed.

String methods that appear to modify a String actually return a new String.
Example 
String text = "hello";

text.toUpperCase();

System.out.println(text);
hello
Correct Approach 
String text = "hello";

text = text.toUpperCase();

System.out.println(text);
HELLO
✓

Always remember: methods such as toUpperCase(), replace() and substring() return a new String.

equals()

22 • PERFORMANCE

String vs StringBuilder

Choosing the right tool matters when repeatedly building text.

String

Immutable

Every modification produces a new String. 

String text = "";

text += "Java";
text += " is";
text += " powerful";
SB

StringBuilder

Mutable sequence designed for repeated modifications. 

StringBuilder sb =
    new StringBuilder();

sb.append("Java");
sb.append(" is");
sb.append(" powerful");
⚡

For many repeated String modifications, StringBuilder is generally the better choice in single-threaded code.

23 • AVOID THESE

Common String Mistakes

01

Using == for content comparison

❌ a == b

Use equals() when comparing String contents.

02

Forgetting String immutability

❌ text.toUpperCase();

Assign the returned String if you need the changed value.

03

Wrong substring indexes

❌ substring(1, 10)

Make sure your indexes are within the valid range.

04

Ignoring case sensitivity

"Java".equals("java") → false

Use equalsIgnoreCase() when case should not matter.

24 • INTERVIEW PREP

Java String Interview Questions

Test whether you really understand the concept.

01 Why is String immutable in Java?

String immutability provides benefits such as safe sharing, predictable behavior and compatibility with the String pool. Once created, the String's character sequence does not change.

02 What is the difference between == and equals()?

== compares object references, while equals() compares String content.

03 Why does String use double quotes?

Java String literals are represented using double quotation marks, while character literals use single quotation marks.

04 What does substring(1, 4) mean?

It starts at index 1 and stops before index 4. Therefore index 1, 2 and 3 are included.

05 String vs StringBuilder?

String is immutable, while StringBuilder provides a mutable character sequence suitable for repeated modifications.
