CORE CONCEPT

What is Input & Output?

I/O

Input → Processing → Output

Input is the data supplied to a program. Processing is the work performed by the program, and output is the result produced by the program.

In a console application, the keyboard is commonly used as input and the terminal/console is commonly used to display output.

OUTPUT METHOD

print()

print

Prints without automatically moving to a new line

The print() method writes the supplied value to the output stream without adding a new line at the end.

PrintExample.java 
public class Main {
    public static void main(String[] args) {

        System.out.print("Hello ");
        System.out.print("Java");

    }
}
OUTPUT Hello Java
Remember: print() does not automatically create a new line.

FORMATTED OUTPUT

printf()

Use printf() when you need more control over how values are displayed.

%

Formatted Output

Format strings use placeholders such as %s, %d, %f, and %.2f.

%s String Text values
%d Integer Whole numbers
%f Floating Point Decimal values
%.2f Precision Two decimal places
FormattedOutput.java 
public class Main {
    public static void main(String[] args) {

        String name = "Pradeep";
        int age = 20;
        double marks = 87.4567;

        System.out.printf("Name: %s%n", name);
        System.out.printf("Age: %d%n", age);
        System.out.printf("Marks: %.2f%n", marks);

    }
}

Taking Input with Scanner

Scanner is a convenient class for reading input from sources such as the keyboard.

It belongs to the java.util package, so we normally import it before using it.

ScannerExample.java 
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your name: ");

        String name = sc.nextLine();

VERY IMPORTANT

next() vs nextLine()

next()

Reads one token

Stops when it encounters whitespace.

Input: Venkata Pradeep
Reads: Venkata
nextLine()

Reads the complete line

Continues until the line terminator.

Input: Venkata Pradeep
Reads: Venkata Pradeep
Common interview question

Why does nextLine() sometimes appear to skip input after nextInt()?

Because numeric Scanner methods consume the numeric token but the line separator may remain for the subsequent nextLine().

ALTERNATIVE INPUT

BufferedReader

BufferedReader is another common approach for reading character input efficiently, especially when reading complete lines.

BR

java.io.BufferedReader

BufferedReader reads text using a buffer and provides the readLine() method for reading a complete line.

BufferedInput.java 
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {

    public static void main(String[] args)
            throws IOException {

        BufferedReader br =
            new BufferedReader(
                new InputStreamReader(System.in)
            );

        System.out.print("Enter your name: ");

        String name = br.readLine();

        System.out.println("Hello, " + name);
    }
}

Scanner

Easy to use and convenient for beginners. Provides methods for reading different primitive types.

BufferedReader

Useful for efficient character input and line-oriented reading.

REAL WORLD PROJECT

Student Result Calculator

Let's combine variables, input, processing and output into one complete Java program.

INPUT Student Marks Java Scanner
→
PROCESS Calculate Average Arithmetic
→
OUTPUT Display Result System.out
StudentResult.java 
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter student name: ");
        String name = sc.nextLine();

        System.out.print("Enter Java marks: ");
        double java = sc.nextDouble();

        System.out.print("Enter Python marks: ");
        double python = sc.nextDouble();

        System.out.print("Enter DBMS marks: ");
        double dbms = sc.nextDouble();

        double average =
            (java + python + dbms) / 3;

        System.out.println("\n===== RESULT =====");

        System.out.println("Student: " + name);

        System.out.printf(
            "Average: %.2f%n",
            average
        );

        sc.close();
    }
}
EXAMPLE OUTPUT 
Enter student name: Pradeep
Enter Java marks: 85
Enter Python marks: 90
Enter DBMS marks: 82

===== RESULT =====
Student: Pradeep
Average: 85.67

DEBUGGING

Common Beginner Mistakes

!

Forgetting the Scanner import

Scanner belongs to the java.util package. 

import java.util.Scanner;
!

Using the wrong Scanner method

For example, using nextInt() when the user is expected to enter a decimal value.

!

Confusing next() and nextLine()

next() reads a token, while nextLine() reads the remaining line.

!

Forgetting type compatibility

Input methods should match the expected data type.

!

Forgetting to close Scanner

When appropriate, close resources that your program opens. 

sc.close();

INTERVIEW PREP

Java I/O Interview Questions

01 What is System.out in Java?

System.out represents Java's standard output stream and is commonly used to display information on the console.

02 What is the difference between print() and println()?

print() outputs the value without automatically moving to a new line, while println() outputs the value and then moves to a new line.

03 What is Scanner?

Scanner is a class from java.util used to read input from sources such as the keyboard.

04 What is the difference between next() and nextLine()?

next() reads a single token separated by whitespace, whereas nextLine() reads the complete line.

05 What is printf() used for?

printf() is used for formatted output using format specifiers and supplied arguments.

06 What is BufferedReader?

BufferedReader is a character-input class that buffers input and provides convenient line-oriented reading through readLine().
