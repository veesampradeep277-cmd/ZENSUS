01 · FUNDAMENTALS

What is an Array?

[]

Definition

An array is an object that stores a fixed number of values of the same type. Each value is called an element, and every element is accessed using an index.

Array = Fixed number of elements + Same data type + Index-based access
🗄️

Think of an Array Like a Row of Lockers

Imagine five lockers arranged in a row. Every locker has a number and stores one item. An array works similarly: every element has an index and stores one value.

20 · COMMON MISTAKES

Mistakes Beginners Make

01

Using an invalid index

int[] arr = new int[5];

System.out.println(arr[5]);

❌ ArrayIndexOutOfBoundsException

Last valid index is 4.

02

Using <= instead of <

for (int i = 0; i <= arr.length; i++)

This eventually attempts to access an invalid index. Use i < arr.length.

03

Confusing length with last index

If length is 5, the last index is length - 1, which is 4.

04

Comparing arrays using ==

arr1 == arr2

This checks whether the references refer to the same array object, not whether their contents are equal. Use Arrays.equals() for content comparison.

05

Trying to resize an array

Java arrays have a fixed length after creation. Use a collection such as ArrayList when a dynamically sized structure is required.

21 · INTERVIEW PREP

Interview Questions

01 What is an array?

An array is a fixed-length object that stores elements of a declared type and provides index-based access.

02 Why does array indexing start from 0?

Java defines the first element of an array at index 0. Therefore, for an array of length N, valid indexes range from 0 to N - 1.

03 Can the size of an array be changed?

No. Once an array is created, its length is fixed.

04 What is the difference between length and index?

Length represents the number of elements. Index represents the position of an element.

05 What is a 2D array?

A two-dimensional array is an array whose components are themselves arrays. It is commonly used to represent tables and matrices.

06 What happens when an invalid index is accessed?

Java throws an ArrayIndexOutOfBoundsException.

07 What is the difference between an array and ArrayList?

An array has a fixed length. ArrayList is a resizable collection designed for dynamically changing numbers of elements.
