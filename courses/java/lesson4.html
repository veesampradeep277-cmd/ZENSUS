The ternary operator provides a compact way to choose between two values based on a condition.

Operator Precedence

When an expression contains multiple operators, Java follows precedence rules to determine which operation is performed first.

10 + 5 * 2
STEP 1 5 × 2 Multiplication first
↓
STEP 2 10 + 10 Addition next
↓
RESULT 20
1 ++ -- Postfix / Unary

Use parentheses when an expression could be difficult to understand. It makes your intention explicit.

REAL-WORLD APPLICATION

Student Result Calculator

Let's combine arithmetic, comparison, logical, assignment, and ternary operators in one practical example.

INPUT Marks 82
→
CALCULATE Total / Average + / %
→
COMPARE Passed? >= 40

StudentResult.java 
int marks = 82;

boolean passed = marks >= 40;

String grade =
    marks >= 90 ? "A+" :
    marks >= 80 ? "A" :
    marks >= 70 ? "B" :
    marks >= 60 ? "C" :

DEBUGGING

Common Beginner Mistakes

01

Confusing = and ==

= assigns a value while == compares values.

✕ if (age = 18)
✓ if (age == 18)
02

Integer Division

Integer division removes the fractional part.

10 / 3 → 3
03

Misunderstanding %

The modulus operator returns the remainder, not the percentage.

10 % 3 → 1
04

Confusing Prefix and Postfix

++x increments before the value is used, while x++ uses the current value first.

05

Ignoring Precedence

Multiplication and division are evaluated before addition and subtraction.

10 + 5 * 2 → 20

INTERVIEW PREPARATION

Java Operator Questions

What is an operator? +

An operator is a symbol or keyword that performs an operation on one or more operands.

What is the difference between = and ==? +

= is the assignment operator, while == is the equality comparison operator.

What does % do? +

The modulus operator returns the remainder after integer or floating-point division.

What is the ternary operator? +

The ternary operator ? : is a conditional operator that selects one of two expressions.

What is operator precedence? +

Operator precedence determines the order in which operators in an expression are evaluated.

What are logical operators? +

Java's logical operators include &&, ||, and !.
