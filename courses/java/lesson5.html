The if-else Statement

05

When the condition is true, the if block executes. Otherwise, the else block executes.

    // true block

    // false block

05 · MULTIPLE CHOICES

The switch Statement

08

A switch statement allows a program to select one execution path from multiple possible cases.

SELECT → MATCH → EXECUTE
day = 2
SWITCH Compare selector
case 1 Monday
case 2 Tuesday ✓
case 3 Wednesday
default Other
Example · Day Selection 
int day = 2;

switch (day) {

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid day");
}
OUTPUT Tuesday

INTERVIEW PREP

Frequently Asked Questions

14
What is a conditional statement? +

A conditional statement controls program execution based on whether a condition evaluates to true or false.

What is the difference between if and if-else? +

An if statement executes a block only when its condition is true. An if-else statement provides an alternative block when the condition is false.

When should you use switch? +

switch is useful when you need to choose among multiple fixed values of a selector.

What happens if break is omitted? +

In a traditional switch statement, execution can continue into subsequent case blocks until another break or the end of the switch is reached.
