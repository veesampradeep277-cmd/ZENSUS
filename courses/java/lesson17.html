What is File Handling?

Understanding persistent data

📂

Definition

File handling is the process of creating, reading, writing, modifying and deleting data stored in files.

Java provides several classes and APIs for working with files through packages such as java.io and java.nio.file.

🏠

Real-World Analogy

Think of a file like a notebook. You can create it, write information into it, read the information later, update it and finally remove it.

The File Class

Working with file and directory paths

The File class from java.io represents a file or directory path. It allows you to inspect and manipulate filesystem entries.

FileExample.java 
import java.io.File;

class FileExample {
    public static void main(String[] args) {

        File file = new File("student.txt");

        System.out.println(file.getName());
        System.out.println(file.getPath());
        System.out.println(file.exists());
    }
}
💡 Remember: A File object represents a pathname. Creating a File object does not automatically create the physical file.

Creating a File

Using createNewFile()

CreateFile.java 
import java.io.File;
import java.io.IOException;

class CreateFile {

    public static void main(String[] args)
            throws IOException {

        File file = new File("student.txt");

        if (file.createNewFile()) {
            System.out.println("File created successfully.");
        } else {
            System.out.println("File already exists.");
        }
    }
}
OUTPUT 
File created successfully.

Writing Data to a File

FileWriter

FileWriter is used to write character data into a file.

WriteFile.java 
import java.io.FileWriter;
import java.io.IOException;

class WriteFile {

    public static void main(String[] args)
            throws IOException {

        FileWriter writer =
            new FileWriter("student.txt");

        writer.write("Welcome to ZENSUS!");
        writer.write("\nLearn Java File Handling.");

        writer.close();

        System.out.println("Data written successfully.");
    }
}
💡 Important: Always close the writer after completing the operation, or use try-with-resources.
08

Appending Data

Add data without overwriting existing content

AppendFile.java 
import java.io.FileWriter;
import java.io.IOException;

class AppendFile {

    public static void main(String[] args)
            throws IOException {

        FileWriter writer =
            new FileWriter("student.txt", true);

        writer.write("\nNew student added.");

        writer.close();
    }
}
⚠️ Remember: The second argument true enables append mode. Without it, existing content can be overwritten.

Reading a File

FileReader

ReadFile.java 
import java.io.FileReader;
import java.io.IOException;

class ReadFile {

    public static void main(String[] args)
            throws IOException {

        FileReader reader =
            new FileReader("student.txt");

        int character;

        while ((character = reader.read()) != -1) {

            System.out.print((char) character);
        }

        reader.close();
    }
}

BufferedReader

Efficient character reading

BufferedReader reads text efficiently by buffering characters and provides the convenient readLine() method.

BufferedRead.java 
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

class BufferedRead {

    public static void main(String[] args)
            throws IOException {

        BufferedReader reader =
            new BufferedReader(
                new FileReader("student.txt")
            );

        String line;

        while ((line = reader.readLine()) != null) {
            System.out.println(line);
        }

        reader.close();
    }
}

Reading with Scanner

Simple file reading

ScannerFile.java 
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

class ScannerFile {

    public static void main(String[] args)
            throws FileNotFoundException {

        File file = new File("student.txt");

        Scanner scanner = new Scanner(file);

        while (scanner.hasNextLine()) {

            String line = scanner.nextLine();

            System.out.println(line);
        }

        scanner.close();
    }
}

Try-with-Resources

The recommended resource-management approach

Try-with-resources automatically closes resources that implement AutoCloseable.

SafeFileRead.java 
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

class SafeFileRead {

    public static void main(String[] args) {

        try (
            BufferedReader reader =
                new BufferedReader(
                    new FileReader("student.txt")
                )
        ) {

            String line;

            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }

        } catch (IOException e) {

            System.out.println(
                "File error: " + e.getMessage()
            );
        }
    }
}
⭐ Best Practice: Prefer try-with-resources when working with streams, readers, writers and other closeable resources.

Modern File Handling with NIO

java.nio.file

Modern Java applications often use the java.nio.file API because it provides a powerful and convenient approach to filesystem operations.

NIOExample.java 
import java.nio.file.Files;
import java.nio.file.Path;
import java.io.IOException;

class NIOExample {

    public static void main(String[] args)
            throws IOException {

        Path path = Path.of("student.txt");

        Files.writeString(
            path,
            "Welcome to ZENSUS!"
        );

        String content =
            Files.readString(path);

        System.out.println(content);
    }
}
Path

Represents a filesystem path.

Files.writeString()

Writes text to a file.

Files.readString()

Reads text from a file.

Files.exists()

Checks whether a path exists.

Serialization

Saving Java objects

💾

What is Serialization?

Serialization is the process of converting an object's state into a byte stream so that it can be stored or transmitted.

Deserialization

Deserialization reconstructs an object from the stored byte stream.

21

Serialization Example

ObjectOutputStream

Student.java 
import java.io.Serializable;

class Student implements Serializable {

    int id;
    String name;

    Student(int id, String name) {

        this.id = id;
        this.name = name;
    }
}
Serialize.java 
import java.io.FileOutputStream;
import java.io.ObjectOutputStream;
import java.io.IOException;

class Serialize {

    public static void main(String[] args)
            throws IOException {

        Student student =
            new Student(101, "Pradeep");

        try (
            ObjectOutputStream output =
                new ObjectOutputStream(
                    new FileOutputStream("student.dat")
                )
        ) {

            output.writeObject(student);
        }

        System.out.println("Object saved.");
    }
}
22

Deserialization

Restoring objects from a file

Deserialize.java 
import java.io.FileInputStream;
import java.io.ObjectInputStream;
import java.io.IOException;

class Deserialize {

    public static void main(String[] args)
            throws Exception {

        try (
            ObjectInputStream input =
                new ObjectInputStream(
                    new FileInputStream("student.dat")
                )
        ) {

            Student student =
                (Student) input.readObject();

            System.out.println(student.id);
            System.out.println(student.name);
        }
    }
}

Copying Files

Using Files.copy()

CopyFile.java 
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.io.IOException;

class CopyFile {

    public static void main(String[] args)
            throws IOException {

        Path source =
            Path.of("student.txt");

        Path destination =
            Path.of("student-copy.txt");

        Files.copy(
            source,
            destination,
            StandardCopyOption.REPLACE_EXISTING
        );

        System.out.println("File copied.");
    }
}

Common Mistakes

Problems beginners frequently make

01

Forgetting to close resources

Always close readers and writers or use try-with-resources.

02

Wrong file path

Check whether the relative path points to the expected directory.

03

Overwriting accidentally

Use append mode when you need to preserve existing content.

04

Ignoring exceptions

File operations can fail because of permissions, missing files and other I/O problems.

05

Using the wrong stream

Choose character-oriented APIs for text and byte-oriented APIs for raw binary data.

06

Assuming File creates the file

new File() creates a pathname object, not necessarily a physical file.
