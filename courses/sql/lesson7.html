01 • Core Concept

What is ORDER BY?

ORDER BY is an SQL clause used to sort the rows returned by a query according to one or more columns or expressions.

Without ORDER BY

A database does not guarantee that rows will be returned in the order you expect.

SQL 
SELECT name, marks
FROM students;
Important Never rely on the physical or insertion order of rows. If you need a specific order, explicitly use ORDER BY.

With ORDER BY

SQL sorts the final result according to your specified sorting rule.

SQL 
SELECT name, marks
FROM students
ORDER BY marks DESC;
Result Students with higher marks appear first.
02 • Syntax

ORDER BY syntax

The basic structure is simple, but it becomes powerful when multiple sorting rules are combined.

GENERAL SYNTAX 
SELECT column1, column2
FROM table_name
ORDER BY column_name ASC;
DESCENDING 
SELECT column1, column2
FROM table_name
ORDER BY column_name DESC;
Remember ASC means ascending order. DESC means descending order. If neither is specified, ASC is normally the default direction for ORDER BY.

05 • Ascending

ASC — Ascending order

ASC arranges values from lower to higher.

SQL 
SELECT name, marks
FROM students
ORDER BY marks ASC;

Result conceptually becomes:

Sorted marks

  1. Rahul — 76
  2. Priya — 84
  3. Kiran — 88
  4. Arjun — 91
  5. Ananya — 95
Memory trick ASC = Ascending = A → Z = Small → Large
06 • Descending

DESC — Descending order

DESC reverses the direction and places larger values first.

SQL 
SELECT name, marks
FROM students
ORDER BY marks DESC;

Result

  1. Ananya — 95
  2. Arjun — 91
  3. Kiran — 88
  4. Priya — 84
  5. Rahul — 76
Memory trick DESC = Descending = Z → A = Large → Small
07 • Multi-Level Sorting

ORDER BY multiple columns

Multiple columns allow you to create a primary, secondary, and even tertiary sorting rule.

SQL 
SELECT name, department, marks
FROM students
ORDER BY department ASC, marks DESC;
Department
Primary sort
→
Marks
Secondary sort
→
Final Result
How it works SQL first sorts by department. When two rows have the same department, it then sorts those rows by marks DESC.
08 • Tie Breaking

Why multiple columns matter

Suppose several students have exactly the same marks. A second column can break the tie.

SQL 
SELECT name, marks
FROM students
ORDER BY marks DESC, name ASC;

Interpretation

  1. Highest marks first.
  2. If marks are equal, names are sorted alphabetically.
Important The second column does not rearrange every row independently. It is used to break ties created by the previous sorting key.
09 • Text Sorting

Sorting text values

ORDER BY can sort character/string columns too.

A → Z

SQL 
SELECT name
FROM students
ORDER BY name ASC;

Z → A

SQL 
SELECT name
FROM students
ORDER BY name DESC;
Database note Exact text sorting behavior can depend on the database's collation and locale settings, especially for uppercase, lowercase, accents, and non-English characters.
10 • Date Sorting

Sorting dates

Dates can be sorted chronologically.

Oldest → Newest 
SELECT order_id, order_date
FROM orders
ORDER BY order_date ASC;
Newest → Oldest 
SELECT order_id, order_date
FROM orders
ORDER BY order_date DESC;
Real-world use E-commerce websites frequently use this concept for: newest orders, recent transactions, latest posts, and historical reports.
11 • Aliases & Expressions

ORDER BY calculated values

You can sort using expressions and, in many SQL systems, aliases defined in the SELECT list.

Calculated column 
SELECT name,
       marks,
       marks + 5 AS bonus_marks
FROM students
ORDER BY bonus_marks DESC;
Why this is useful You do not always sort by a stored column. You can sort by a calculated value such as price × quantity, salary + bonus, or a computed score.
12 • Advanced Syntax

Ordering by column position

Some SQL systems allow ORDER BY to reference the position of a selected expression.

Example 
SELECT name, marks
FROM students
ORDER BY 2 DESC;
Should you use this? It can work, but explicit column names or expressions are usually easier to understand and maintain.
13 • NULL Values

How ORDER BY handles NULL

NULL represents an unknown or missing value. Its position when sorting depends on the database system and query syntax.

Common SQL syntax 
SELECT name, marks
FROM students
ORDER BY marks DESC;

Explicit NULLS LAST

Supported by some systems 
ORDER BY marks DESC NULLS LAST;

Important

Do not assume every database places NULL values in exactly the same position for ASC and DESC.

15 • Top Results

ORDER BY + limiting results

A common real-world pattern is sorting results and then returning only the top few rows.

MySQL / PostgreSQL / SQLite

SELECT name, marks
FROM students
ORDER BY marks DESC
LIMIT 3;

SQL Server

SELECT TOP 3 name, marks
FROM students
ORDER BY marks DESC;

Standard-style option

SELECT name, marks
FROM students
ORDER BY marks DESC
FETCH FIRST 3 ROWS ONLY;
Database dialects differ LIMIT, TOP, and FETCH FIRST are not interchangeable syntax in every database. Always check the SQL dialect you are using.

18 • Query Processing

Where does ORDER BY fit?

The order you write SQL clauses is not exactly the same as the conceptual logical processing order.

Written query

SELECT name, marks
FROM students
WHERE marks >= 80
ORDER BY marks DESC;

Conceptual logical order

FROM
→
WHERE
→
SELECT
→
ORDER BY
Exam point ORDER BY is conceptually applied after filtering and projection in the simplified logical query-processing model. Actual database engines may optimize the physical execution.
19 • Common Mistakes

ORDER BY mistakes to avoid

❌ Mistake 1 — Forgetting DESC

ORDER BY marks;

This normally means ascending order, not highest first. 

ORDER BY marks DESC;

❌ Mistake 2 — Wrong clause order

SELECT name
FROM students
ORDER BY marks DESC
WHERE marks > 80;

WHERE belongs before ORDER BY.

❌ Mistake 3 — Assuming row order

Never assume that rows will appear in insertion order unless you explicitly request a sort.

❌ Mistake 4 — Confusing WHERE and ORDER BY

WHERE filters rows. ORDER BY sorts the rows that remain.

20 • Comparison

WHERE vs ORDER BY

WHERE
  • Filters rows
  • Decides which rows remain
  • Uses conditions
  • Example: marks > 80
ORDER BY
  • Sorts rows
  • Decides result order
  • Uses ASC / DESC
  • Example: marks DESC

23 • Exam Preparation

5-mark answer

ORDER BY clause in SQL

The ORDER BY clause is used to sort the rows returned by an SQL query according to one or more columns or expressions. By default, sorting is generally ascending. The ASC keyword specifies ascending order, while DESC specifies descending order. 

SELECT name, marks
FROM students
ORDER BY marks DESC;

Multiple columns can also be specified. In that case, the first column is the primary sorting key and subsequent columns are used to resolve ties.
