What is Input & Output?

Every useful program needs a way to receive information and a way to communicate results.

Input is information supplied to a program.

Processing is the work JavaScript performs on that information.

Output is the result produced by the program.

Getting Input with prompt()

The browser's prompt() function can ask the user for a value.

The simplest browser-based input method is prompt().

JavaScript 
let name =
prompt("Enter your name:");

console.log(name);
Important:

prompt() normally returns the user's input as a string.

Convert prompt input 
let age =
Number(prompt("Enter your age:"));

console.log(age);

05

Output with alert()

The alert() function displays a browser dialog box.

JavaScript 
alert("Welcome to ZENSUS!");
When should you use alert()?

It is useful for simple demonstrations, notifications, and learning. Modern production websites usually prefer custom UI components instead of repeated browser alerts.

06

Output on the Web Page

Real websites usually display JavaScript results directly inside HTML elements.

textContent

Use textContent when you want to insert text safely into an HTML element.

JavaScript 
let message =
    "Welcome Student!";

document.getElementById("output")
    .textContent = message;

innerHTML

innerHTML allows HTML markup to be inserted into an element.

JavaScript 
document.getElementById("output")
    .innerHTML =
    "<strong>Welcome!</strong>";
Best Practice:

Prefer textContent when you only need to display plain text. Be careful with innerHTML when inserting user-controlled content because unsafe HTML can create security problems.

07

HTML Input + JavaScript

This is one of the most important patterns for building real web applications.

HTML 
<input id="nameInput" type="text">

<button onclick="showName()">
    Submit
</button>

<p id="result"></p>
JavaScript 
function showName() {

    let name =
        document.getElementById(
            "nameInput"
        ).value;

    document.getElementById(
        "result"
    ).textContent = "Hello " + name;
}

Remember the three important properties


value → gets data from an input element

textContent → displays plain text

innerHTML → displays HTML content

Why Input Becomes a String

Understanding this concept prevents one of the most common beginner JavaScript mistakes.

User Input "10"
→
JavaScript String
→
Number() 10
The Problem 
let a = "10";
let b = "20";

console.log(a + b);

// "1020"
Correct Approach 
let a =
    Number("10");

let b =
    Number("20");

console.log(a + b);

// 30
09

Converting Input to Numbers

Method Purpose Example
Number() Converts a value to a number. Number("25") → 25
parseInt() Parses an integer from a string. parseInt("25") → 25
parseFloat() Parses a floating-point number. parseFloat("25.5") → 25.5
Examples 
Number("100");

parseInt("100px");

parseFloat("12.75");

Input Validation

Never assume that user input is valid. Real applications must validate data.

✓ Valid Input

Age = 20

Marks = 85

Email format is valid

✕ Invalid Input

Age = -5

Marks = 150

Empty name

Validation Example 
let age =
    Number(prompt("Enter age:"));

if (isNaN(age)) {

    console.log(
        "Please enter a valid number."
    );

}

document.write() — Understand It, Don't Depend on It

JavaScript also provides document.write(), but modern web development usually avoids it.

Example 
document.write(
    "Hello World"
);

⚠ Why should beginners be careful?

Calling document.write() after the page has loaded can replace the entire document.


For modern applications, prefer DOM methods such as textContent, innerHTML, or other DOM APIs.

Common Mistakes

❌ Mistake 1 — Forgetting type conversion

Wrong 
let a = "10";
let b = "20";

console.log(a + b);

// "1020"

❌ Mistake 2 — Reading the wrong element

Make sure the ID used in getElementById() matches the HTML element.

❌ Mistake 3 — Assuming input is always valid

Users can enter empty strings, invalid numbers, negative values, or unexpected data.

❌ Mistake 4 — Using alert() for everything

Alerts interrupt the user experience. Modern applications generally use custom interface components for feedback.

16

Interview Questions

INTERVIEW 01

What does prompt() return?

It normally returns the user's input as a string, or null if the user cancels the dialog.

INTERVIEW 02

How do you convert a string to a number?

Common approaches include Number(), parseInt(), and parseFloat(), depending on the desired behavior.

INTERVIEW 03

Difference between textContent and innerHTML?

textContent treats the value as text, while innerHTML parses the assigned value as HTML markup.

INTERVIEW 04

Why is document.write() discouraged?

Using it after page loading can replace the current document, so modern applications generally use DOM APIs.

INTERVIEW 05

What is the Input → Process → Output model?

A program receives data, performs operations on it, and produces a result.

INTERVIEW 06

Why validate user input?

Validation prevents invalid or unexpected data from causing incorrect behavior.
