What is an Operator?

An operator is a special symbol or keyword used to perform an operation on one or more values.

Think of variables as containers containing data. Operators tell JavaScript what to do with that data.

05

Comparison Operators

Comparison operators compare two values and always produce a Boolean value: true or false.

Operator Meaning Example
== Equal value 5 == "5"
=== Equal value and type 5 === "5"
!= Not equal 5 != 10
!== Not equal value or type 5 !== "5"
> Greater than 10 > 5
< Less than 5 < 10
>= Greater than or equal 10 >= 10
<= Less than or equal 5 <= 10
Interview Rule:

Prefer === and !== because they compare both the value and the data type.

Important Difference 
console.log(5 == "5");
// true

console.log(5 === "5");
// false

// === checks VALUE + DATA TYPE

Logical Operators

Logical operators allow us to combine multiple conditions.

&&

AND

Returns true only when both conditions are true.

||

OR

Returns true when at least one condition is true.

!

NOT

Reverses a Boolean value.

Truth Table

A B A && B A || B
true true true true
true false false true
false true false true
false false false false
Real-world Example 
let age = 20;
let hasID = true;

let canEnter =
    age >= 18 && hasID;

console.log(canEnter);

// true
07

Unary Operators

Unary operators work with only one operand.

Increment and Decrement

JavaScript 
let count = 5;

count++;

console.log(count);

// 6

count--;

console.log(count);

// 5

Prefix vs Postfix

++x → Increment first, then use the value.

x++ → Use the current value first, then increment.

Ternary Operator

The ternary operator is a shorter way to write simple if-else logic.

Condition
?
True Value
:
False Value
Example 
let age = 20;

let message =
    age >= 18
    ? "Eligible to vote"
    : "Not eligible";

console.log(message);

Interview Preparation

Important JavaScript operator questions commonly asked in interviews.

QUESTION 01

What is the difference between == and ===?

== compares values after possible type conversion, while === compares both value and type.

QUESTION 02

What does the modulus operator do?

It returns the remainder after division.

QUESTION 03

What is short-circuit evaluation?

JavaScript may stop evaluating logical expressions when the final result is already known.

QUESTION 04

What is the ternary operator?

A compact conditional operator written using ? and :.
