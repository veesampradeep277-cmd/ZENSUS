02 • Fundamentals

What Is a Conditional Statement?

A conditional statement allows JavaScript to execute different blocks of code depending on a condition.

Core idea: A condition produces a Boolean result — true or false.
Basic condition 
let age = 20;

if (age >= 18) {
    console.log("Eligible to vote");
}
Condition Boolean Decision Execution
03 • Decision Making

1. The if Statement

The simplest way to make a decision.

Syntax

JavaScript
if (condition) {
    // code executes when condition is true
}

Example

let temperature = 35;

if (temperature > 30) {
    console.log("It is hot outside.");
}
Since 35 > 30 is true, the code inside the if block executes.
04 • Two-Way Decision

2. if...else

Choose between two possible paths.

Concept

If the condition is true, the if block runs. Otherwise, the else block runs. 

let age = 16;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

Real-World Example

let passwordCorrect = true;

if (passwordCorrect) {
    console.log("Login successful");
} else {
    console.log("Invalid password");
}
Remember: else does not have its own condition. It represents every remaining case.
05 • Multiple Decisions

3. else if

Use it when more than two possibilities exist.

let marks = 82;

if (marks >= 90) {
    console.log("Grade A+");
} else if (marks >= 80) {
    console.log("Grade A");
} else if (marks >= 70) {
    console.log("Grade B");
} else if (marks >= 60) {
    console.log("Grade C");
} else {
    console.log("Needs Improvement");
}
Important: JavaScript checks the conditions from top to bottom. Once it finds a true condition, the remaining else-if blocks are skipped.
06 • Advanced Conditions

4. Nested if Statements

An if statement inside another if statement.

Nested conditions are useful when one decision depends on another decision. 

let age = 22;
let hasId = true;

if (age >= 18) {

    if (hasId) {
        console.log("Entry allowed");
    } else {
        console.log("ID required");
    }

} else {
    console.log("Underage");
}
Best practice: Avoid deeply nested conditions. If the nesting becomes difficult to read, simplify the logic or create functions.
07 • Conditions

Comparison Operators

Operator Meaning Example
> Greater than age > 18
< Less than age < 18
>= Greater than or equal marks >= 40
<= Less than or equal age <= 60
=== Strict equality role === "admin"
!== Strict inequality status !== "blocked"
Prefer === and !== in modern JavaScript because they avoid unexpected type conversion.
08 • Logic Building

Logical Operators

AND

&&

True only when both conditions are true. 

age >= 18 && hasId
OR

||

True when at least one condition is true. 

isAdmin || isTeacher
NOT

!

Reverses a Boolean value. 

!isLoggedIn

Real-World Example

let age = 20;
let hasId = true;

if (age >= 18 && hasId) {
    console.log("Entry allowed");
}
09 • Advanced Logic

Short-Circuit Evaluation

AND — &&

If the first part is falsy, JavaScript does not need to evaluate the remaining part. 

let user = null;

if (user && user.name) {
    console.log(user.name);
}

OR — ||

If the first part is truthy, JavaScript can stop evaluating the remaining expression. 

let username = "";

let displayName = username || "Guest";

console.log(displayName);
10 • JavaScript Behavior

Truthy and Falsy Values

JavaScript can convert values to Boolean context.

Common Falsy Values

false 0 -0 0n "" null undefined NaN 
let username = "";

if (username) {
    console.log("Username exists");
} else {
    console.log("Username is empty");
}

Common Truthy Values

"hello" 42 -10 [] {} true
Empty arrays [] and empty objects {} are truthy in JavaScript.
11 • Multiple Fixed Choices

5. switch Statement

Useful when comparing one value against several fixed cases.

Syntax

switch (expression) {

    case value1:
        // code
        break;

    case value2:
        // code
        break;

    default:
        // fallback
}

Example — Traffic Light

let signal = "green";

switch (signal) {

    case "red":
        console.log("Stop");
        break;

    case "yellow":
        console.log("Get Ready");
        break;

    case "green":
        console.log("Go");
        break;

    default:
        console.log("Unknown signal");
}
Why break? Without break, JavaScript can continue executing the following cases. This is called fall-through.
12 • Important Behavior

switch Fall-Through

Without break

let day = 1;

switch (day) {

    case 1:
        console.log("Monday");

    case 2:
        console.log("Tuesday");

    default:
        console.log("Other");
}

With break

let day = 1;

switch (day) {

    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    default:
        console.log("Other");
}
13 • Concise Decisions

6. Ternary Operator

A compact alternative for simple two-way decisions.

Syntax

condition ? valueIfTrue : valueIfFalse;

Example

let age = 20;

let status = age >= 18
    ? "Adult"
    : "Minor";

console.log(status);
Best use: Use ternary when the decision is short and easy to understand.
Avoid extremely complicated nested ternary expressions. Readability is more important than writing fewer lines.

19 • Debugging

Common Mistakes

❌ Mistake 1 — Assignment instead of comparison

// Wrong
if (age = 18) {
}

// Correct
if (age === 18) {
}

❌ Mistake 2 — Forgetting break 

switch (role) {

    case "admin":
        console.log("Admin");
        break;

}

❌ Mistake 3 — Wrong condition order 

// Bad ordering
if (marks >= 40) {
    console.log("Pass");
} else if (marks >= 90) {
    console.log("Excellent");
}
The second condition can never be reached for marks 90+, because the first condition already catches them.

❌ Mistake 4 — Using == unnecessarily 

// Prefer
if (value === 10) {
}

❌ Mistake 5 — Too much nesting

Deeply nested conditions are difficult to understand, test and maintain.

20 • Exam Preparation

5-Mark Answer

Conditional Statements in JavaScript

Conditional statements are used to execute different blocks of code based on whether a condition is true or false. JavaScript provides if, if...else, else if, switch and ternary operator for decision making.

The if statement executes a block when its condition is true. The if...else statement provides two possible paths. else if handles multiple conditions. switch is useful for comparing one expression with multiple fixed values. The ternary operator provides a short form for simple two-way decisions.

22 • Interview Preparation

Interview Questions

1. What is a conditional statement?

A statement that chooses code execution based on a condition.

2. Difference between == and ===?

== allows type coercion, while === performs strict comparison.

3. When should you use switch?

When comparing one value against several fixed cases.

4. Why is break used in switch?

To stop execution from continuing into subsequent cases.

5. What is a ternary operator?

A concise conditional expression using ? and :.

6. What are falsy values?

Values that become false when evaluated in Boolean context.

7. What is short-circuit evaluation?

JavaScript stops evaluating a logical expression when the result is already known.

8. Can switch use strings?

Yes. switch can compare strings, numbers and other values using strict matching semantics.
