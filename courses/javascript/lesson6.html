01 • Fundamentals

What is a loop?

A loop repeatedly executes a block of code while a condition or iteration rule allows it.

Imagine this problem

Suppose you want to print numbers from 1 to 100.

Without a loop 
console.log(1);
console.log(2);
console.log(3);
// ...
console.log(100);

This is repetitive, difficult to maintain and doesn't scale.

With a loop 
for (let i = 1; i <= 100; i++) {
    console.log(i);
}
Core idea: Write the instructions once, then let JavaScript repeat them.

02 • for Loop

The for loop

The most common choice when you know the initialization, condition and update.

Basic syntax

JavaScript 
for (initialization; condition; update) {
    // code to repeat
}

Example

Print 1 to 5 
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Execution:

i = 1
→
i <= 5 ?
→
print i
→
i++

Initialization

Runs once before the loop begins. 

let i = 1;

Condition

Checked before every iteration. 

i <= 5

Body

Runs when the condition is true. 

console.log(i);

Update

Changes the loop variable. 

i++;
03 • while Loop

The while loop

Use a while loop when repetition depends mainly on a condition and the number of iterations may not be known in advance.

Syntax

while (condition) {
    // code
}

Example

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
Important: Always make sure something inside the loop eventually makes the condition false. Otherwise, you may create an infinite loop.
04 • do...while

The do...while loop

A do...while loop executes its body at least once.

Syntax 
do {
    // code
} while (condition);

Example

let number = 10;

do {
    console.log(number);
    number++;
} while (number < 5);

Although number < 5 is false, the body still executes once.

Best mental model: do first → check later
05 • for...of

The for...of loop

Use for...of when you want the values of an iterable.

Array example

const languages = [
    "JavaScript",
    "Python",
    "C++"
];

for (const language of languages) {
    console.log(language);
}

String example

const word = "ZENSUS";

for (const letter of word) {
    console.log(letter);
}
Key idea: for...of gives you the actual values.
06 • for...in

The for...in loop

Use for...in to iterate over enumerable property keys. 

const student = {
    name: "Pradeep",
    branch: "CSE",
    year: 2
};

for (const key in student) {
    console.log(key);
    console.log(student[key]);
}
Important: Do not normally use for...in for arrays when your goal is to process array values. For arrays, prefer: for...of, traditional for, or array methods such as forEach().
Choose the right loop

Loop comparison

Loop Best use Condition Main idea
for Known/reasonable iteration structure Before iteration Initialization → condition → update
while Condition-driven repetition Before iteration Repeat while true
do...while Must execute at least once After iteration Execute → check
for...of Iterable values Per value Value-focused iteration
for...in Object property keys Per enumerable key Key-focused iteration
07 • Loop Control

break and continue

Loops become powerful when you can control their execution.

🛑

break

Immediately exits the nearest loop. 

for (let i = 1; i <= 10; i++) {

    if (i === 5) {
        break;
    }

    console.log(i);
}

Output: 1 2 3 4

⏭️

continue

Skips the current iteration and continues with the next iteration. 

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}

Output: 1 2 4 5

Remember: break = stop the loop
continue = skip this iteration

What about return?

function findNumber(numbers) {

    for (const number of numbers) {

        if (number === 7) {
            return true;
        }
    }

    return false;
}

return exits the entire function, not merely the loop.

08 • Nested Loops

Loops inside loops

A nested loop is a loop placed inside another loop. It is commonly used for grids, matrices and patterns.

Example: 3 × 3 grid

for (let row = 1; row <= 3; row++) {

    for (let col = 1; col <= 3; col++) {

        console.log(row, col);
    }
}
Outer Loop
Row 1
→
Inner Loop
Col 1,2,3
→
Outer Loop
Row 2
→
Inner Loop
Col 1,2,3
Complexity preview: If both loops run approximately n times, the total work can be approximately O(n²). But always analyze the actual number of iterations; not every nested loop is automatically O(n²).
Pattern Thinking

Nested loops for patterns

Triangle pattern

for (let row = 1; row <= 5; row++) {

    let line = "";

    for (let col = 1; col <= row; col++) {
        line += "* ";
    }

    console.log(line);
}

Output:

* * * * * * * * * * * * * * *
Pattern strategy: Think in terms of rows and columns. Outer loop → rows
Inner loop → work inside each row

Safety Check

Infinite loops

❌ Dangerous

let i = 1;

while (i <= 5) {
    console.log(i);
}

The value of i never changes, so the condition remains true.

✅ Correct

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

The update eventually makes the condition false.

Real-world Iteration

Loop through arrays

Traditional for

const scores = [80, 90, 75];

for (let i = 0; i < scores.length; i++) {

    console.log(scores[i]);
}

for...of

const scores = [80, 90, 75];

for (const score of scores) {

    console.log(score);
}

forEach()

const scores = [80, 90, 75];

scores.forEach(score => {
    console.log(score);
});
Modern JavaScript: For simple array iteration, for...of and forEach() are often expressive. Use a traditional for when you need the index or explicit loop control.

Avoid These

Common loop mistakes

1

Forgetting the update

A while loop that never changes its counter can become infinite.

2

Off-by-one errors

Be careful with < versus <=. 

for (let i = 0; i < 5; i++) {
    // 0,1,2,3,4
}
3

Wrong loop for arrays

Avoid using for...in when you actually need array values.

4

Changing the wrong variable

Make sure the variable controlling the condition is updated correctly.

5

Too much nesting

Deeply nested loops can become difficult to understand and may increase computational cost.

6

Ignoring scope

Prefer let or const over var in modern JavaScript.

Performance

Loops and time complexity

Single loop

for (let i = 0; i < n; i++) {
    console.log(i);
}

Approximately O(n) iterations.

Nested loop

for (let i = 0; i < n; i++) {

    for (let j = 0; j < n; j++) {
        console.log(i, j);
    }
}

Approximately O(n²) operations.

Important: Don't optimize loops based only on appearance. Analyze how many times each operation actually executes.

Interview Preparation

Frequently asked questions

1. Difference between for and while?

Use for when the loop structure naturally contains initialization, condition and update. Use while when the condition itself is the main driver of repetition.

2. Difference between for...of and for...in?

for...of iterates iterable values. for...in iterates enumerable property keys.

3. What is an infinite loop?

A loop that never reaches its termination condition or whose condition remains true indefinitely.

4. What does break do?

It immediately exits the nearest enclosing loop or switch statement.

5. What does continue do?

It skips the rest of the current iteration and moves to the next iteration.

6. Can loops be nested?

Yes. Nested loops are commonly used for matrices, grids and pattern problems.

7. Why avoid for...in with arrays?

Because it iterates enumerable property keys rather than directly giving array values, and the ordering/ properties behavior isn't the intended abstraction for normal array iteration.

8. What is an off-by-one error?

A boundary mistake where a loop executes one time too many or one time too few.

Exam Preparation

5-mark answer

Explain loops in JavaScript.

Loops are control structures used to execute a block of code repeatedly based on a condition or iteration rule. JavaScript provides several loop structures including for, while, do...while, for...of and for...in.

The for loop is useful when initialization, condition and update are known. The while loop repeatedly executes while a condition is true. The do...while loop executes its body at least once. for...of iterates iterable values, while for...in iterates enumerable object property keys.

JavaScript also provides break and continue for controlling loop execution. Loops reduce code duplication and are widely used in arrays, searching, data processing and web applications.

Mini Project

Student Marks Analyzer

Use loops to build a small data-processing application.

Requirements

  • Store student marks in an array.
  • Print every mark.
  • Calculate total marks.
  • Calculate average marks.
  • Find highest mark.
  • Find lowest mark.
  • Count students who passed.
  • Count students who failed.
Starter solution 
const marks = [78, 92, 65, 88, 45];

let total = 0;
let highest = marks[0];
let lowest = marks[0];

for (const mark of marks) {

    total += mark;

    if (mark > highest) {
        highest = mark;
    }

    if (mark < lowest) {
        lowest = mark;
    }
}

const average = total / marks.length;

console.log("Total:", total);
console.log("Average:", average);
console.log("Highest:", highest);
console.log("Lowest:", lowest);
