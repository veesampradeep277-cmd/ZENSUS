01 • Foundation

What is a Variable?

A variable is a named binding that allows a program to work with a value. Instead of repeatedly writing a value directly, we give it a meaningful name.

🧠 Simple idea Think of a variable as a labeled place in your program that lets you refer to a value.

Example

JavaScript 
let age = 19;

console.log(age);

Here:

  • let → declaration keyword
  • age → variable name
  • = → assignment operator
  • 19 → value

03 • Naming

Variable Naming Rules

Choosing meaningful names makes code easier to understand, debug and maintain.

✅ Valid Names

let age = 19;

let studentName = "Pradeep";

let _score = 95;

let $price = 100;

❌ Invalid Names

// Cannot start with a number
let 1name = "X";

// Spaces are not allowed
let student name = "X";

// Reserved keywords cannot be identifiers
let class = 10;
⭐ Best Practice Prefer descriptive names such as studentName, totalMarks and isLoggedIn rather than names such as x or abc when the meaning matters.
04 • Declarations

let vs const vs var

JavaScript provides three historical declaration keywords: let, const and var. Modern JavaScript generally prefers const by default and let when reassignment is needed.

Feature let const var
Can reassign? Yes No Yes
Block scoped? Yes Yes No
Can redeclare same scope? No No Yes
Modern preference Common Preferred default Usually avoid in new code

let 

let score = 80;

score = 95;

console.log(score);

const 

const pi = 3.14159;

console.log(pi);
Important: const prevents reassignment of the binding. It does not make every object or array property immutable. 
const student = {
    name: "Pradeep"
};

student.name = "Rahul";

console.log(student.name);

The object can still be mutated because the binding itself was not reassigned.

var 

var city = "Guntur";

city = "Vijayawada";

console.log(city);
Interview Rule: In modern JavaScript, prefer const when you don't need reassignment. Use let when reassignment is required. Understand var because you will encounter it in older codebases and interview questions.
05 • Scope Preview

What is Scope?

Scope determines where a variable can be accessed.

Global Scope

A binding accessible from a broad/global context, subject to the environment and module rules.

Function Scope

Variables declared with var are scoped to their function.

Block Scope

Variables declared with let and const are scoped to blocks. 

{
    let message = "Inside block";

    console.log(message);
}

// message is not accessible here

07 • Classification

Primitive vs Object Values

Primitive Values

Primitive values represent single, non-object values. They are immutable values.

Objects

Objects can represent collections and structured data. Arrays and functions are also objects in JavaScript's type system.

    name: "Pradeep",

09 • Developer Tool

The typeof Operator

The typeof operator returns a string indicating the type of a value according to JavaScript's runtime rules. 

console.log(typeof "Hello");
// "string"

console.log(typeof 42);
// "number"

console.log(typeof true);
// "boolean"

console.log(typeof undefined);
// "undefined"
⚠️ Famous JavaScript Interview Question typeof null returns "object". This is a long-standing historical behavior of JavaScript. It does not mean that null is actually an object.

10 • Number Type

Understanding Number

JavaScript uses the Number type for ordinary numeric values. It can represent integers and floating-point values. 

let age = 19;

let price = 499.99;

let temperature = 36.5;

console.log(age);
console.log(price);
console.log(temperature);

Special Number Values

NaN

Means "Not-a-Number" and commonly appears when a numeric operation cannot produce a meaningful numeric result. 

console.log(
    "hello" * 5
);

Infinity

Represents positive infinity. 

console.log(
    1 / 0
);

Safe Integers

Number has a limited range of integers that can be represented exactly. 

Number.MAX_SAFE_INTEGER
11 • Advanced Foundation

BigInt

BigInt represents integers larger than the safe integer range of Number. 

const bigNumber =
    9007199254740993n;

console.log(bigNumber);

console.log(
    typeof bigNumber
);

// "bigint"
Important: You cannot freely mix BigInt and Number in arithmetic operations. Convert deliberately when working between them.
12 • Text Data

Strings

A string represents text. JavaScript supports single quotes, double quotes and template literals. 

let a = 'Hello';

let b = "JavaScript";

let c = `ZENSUS`;

Template Literals

Template literals are enclosed by backticks and allow interpolation using ${...}. 

const name = "Pradeep";

console.log(message);
13 • Logic Data

Boolean

A Boolean represents one of two logical values: true or false. 

let isLoggedIn = true;

let hasPermission = false;

console.log(isLoggedIn);

true

Represents a logical condition that is true.

false

Represents a logical condition that is false.

14 • Important Difference

null vs undefined

Beginners often confuse these values. They are related to "absence of a value", but they communicate different ideas.

undefined

Usually means a variable exists but no value has been assigned, or a value is unavailable. 

let score;

console.log(score);

// undefined

null

Usually represents an intentional absence of an object value. 

let selectedUser = null;

console.log(selectedUser);
Easy memory trick: undefined → "No value has been provided."
null → "I intentionally set this to no object value."
15 • Advanced Primitive

Symbol

A Symbol is a primitive value that is guaranteed to be unique. 

const id1 = Symbol("id");

const id2 = Symbol("id");

console.log(id1 === id2);

// false

Even though both symbols have the same description, the symbols themselves are different unique values.

16 • Core JavaScript Behavior

Dynamic Typing

JavaScript is dynamically typed. A variable does not need a fixed declared type and can later refer to a value of another type. 

let value = 100;

console.log(typeof value);
// number

value = "Hello";

console.log(typeof value);
// string

value = true;

console.log(typeof value);
// boolean
⚡ Watch the variable change type
value = 100
typeof → number

Type conversion means converting a value from one type to another. Explicit conversion is usually easier to understand and control.

String "100"
→

→
Boolean true

String()

    String(value);

console.log(result);

// "100"

Number() 

const value = "100";

const result =
    Number(value);

console.log(result);

// 100

Boolean() 

console.log(
    Boolean(1)
);

// true

console.log(
    Boolean(0)
);

// false
⚠️ Important Conversion rules can contain surprising cases. Don't guess — understand the specific operation and use explicit conversion when clarity matters.
18 • Interview Concept

Type Coercion

Type coercion happens when JavaScript automatically converts values during certain operations. 

console.log(
    "10" + 5
);

// "105"

console.log(
    "10" - 5
);

// 5
Why? The + operator can perform string concatenation, while - performs numeric subtraction and therefore may convert operands to numbers.

20 • Professional Coding

Variable Best Practices

Prefer const

Use const when reassignment is not required.

Use let when needed

Use let when a binding needs reassignment.

Use meaningful names

totalMarks is easier to understand than x.

Avoid unnecessary globals

Keep variables in the smallest appropriate scope.

Don't use var in new code

Learn it for compatibility and interviews, but modern code generally uses let and const.

Understand the data

Know whether your value is text, number, Boolean, object, array or another type.

21 • Debugging

Common Beginner Mistakes

✕
Reassigning a const variable

const age = 19; age = 20; causes an error because the binding cannot be reassigned.

✕
Assuming "100" is a number

"100" is a string. 100 is a number.

✕
Confusing null and undefined

They represent different concepts and should not be treated as identical.

✕
Forgetting dynamic typing

A variable can later refer to a value of a different type.

✕
Trusting typeof blindly

Remember special cases such as typeof null === "object".

22 • Exam Preparation

Exam-Ready Answers

5-Mark Question

Question: Explain variables and data types in JavaScript.

Answer: A variable is a named binding used to work with a value in a JavaScript program. Modern JavaScript provides let and const, while var is an older declaration mechanism. JavaScript supports primitive values such as string, number, bigint, boolean, undefined, symbol and null, along with objects such as arrays and ordinary objects. JavaScript is dynamically typed, so a variable can later refer to a value of another type.

10-Mark Question

Question: Explain JavaScript variables and data types with examples.

A variable is a named binding that allows a program to work with data. JavaScript provides let, const and the older var declaration.

let allows reassignment and is block scoped. const prevents reassignment of the binding and is also block scoped. var is function scoped and is generally avoided in new code.

JavaScript primitive types include String, Number, BigInt, Boolean, Undefined, Null and Symbol. Objects are used to represent structured data and collections such as arrays and ordinary objects.

JavaScript is dynamically typed. Therefore, the same variable can refer to values of different types at different times.

The typeof operator can be used to inspect the runtime type of many values. JavaScript also supports explicit type conversion using functions such as String(), Number() and Boolean().

24 • Interview Preparation

Interview Questions

1. What is a variable in JavaScript?
A variable is a named binding used by a program to work with a value.
2. Difference between let and const?
Both are block scoped. let allows reassignment of the binding, while const does not.
3. Why is var generally avoided in modern JavaScript?
var has function scope and historical behaviors that can make code harder to reason about. Modern code generally prefers let and const.
4. What are JavaScript primitive types?
String, Number, BigInt, Boolean, Undefined, Null and Symbol.
5. What is dynamic typing?
JavaScript variables do not have a permanently fixed declared type and can refer to values of different types.
6. What does typeof null return?
It returns "object". This is a historical behavior of JavaScript.
7. What is the difference between null and undefined?
undefined commonly indicates that no value has been assigned or is unavailable, while null is commonly used to intentionally represent the absence of an object value.
8. What is type coercion?
Type coercion is automatic conversion of values during certain JavaScript operations.
