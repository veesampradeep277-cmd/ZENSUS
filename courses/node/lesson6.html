02 · Core Concept

What is the File System?

A file system is the mechanism used by an operating system to organize and store data in files and directories.


Node.js provides the built-in fs module to allow JavaScript programs to interact with that filesystem.

Important: The fs module is built into Node.js. You do not need to install it using npm.

03 · Getting Started

Importing the fs Module

Node.js provides two common module-system styles. In CommonJS applications, use require().

CommonJS 
const fs = require('fs');

You can also access the promise-based API:

Promise API 
const fs = require('fs').promises;
For modern asynchronous code using async/await, the promise API is often convenient.

05 · Read

Reading a File

One of the most common filesystem operations is reading data from a file.

readFile()

The asynchronous readFile() method reads the contents of a file without blocking the JavaScript thread while the filesystem operation is in progress.

read-file.js 
const fs = require('fs');

fs.readFile('message.txt', 'utf8', (err, data) => {

    if (err) {
        console.error(err);
        return;
    }

    console.log(data);
});
Why 'utf8'?
Without an encoding such as utf8, Node.js returns a Buffer. Specifying utf8 gives you a string.

readFileSync()

The synchronous version waits until the operation finishes before continuing. 

const fs = require('fs');

const data = fs.readFileSync('message.txt', 'utf8');

console.log(data);
Synchronous filesystem operations can block the event loop. They may be acceptable for startup scripts or simple command-line tools, but should be used carefully in request-handling server code.
06 · Write

Writing to a File

writeFile()

writeFile() creates a file if it does not exist. If the file already exists, its contents are replaced by default. 

const fs = require('fs');

const content = 'Welcome to ZENSUS Node.js';

fs.writeFile('welcome.txt', content, (err) => {

    if (err) {
        console.error(err);
        return;
    }

    console.log('File written successfully');
});
Remember:
writeFile() normally replaces existing file contents. If you want to add content without replacing it, use appendFile().
07 · Update

Appending Data

appendFile() adds data to the end of an existing file. 

const fs = require('fs');

fs.appendFile(
    'logs.txt',
    'New request received\n',
    (err) => {

        if (err) {
            console.error(err);
            return;
        }

        console.log('Log added');
    }
);
Common use: Logging application events, requests, errors and activity history.
08 · Delete

Deleting Files

Node.js provides unlink() for deleting a file asynchronously. 

const fs = require('fs');

fs.unlink('old-data.txt', (err) => {

    if (err) {
        console.error(err);
        return;
    }

    console.log('File deleted');
});
Always verify the path before deleting files. Filesystem operations can be destructive.

11 · Path Module

What is the Path Module?

The built-in path module provides utilities for working with filesystem paths.


Instead of manually concatenating strings such as folder + '/' + file, the path module provides safer and platform-aware methods. 

const path = require('path');

const filePath = path.join(
    'data',
    'users',
    'profile.json'
);

console.log(filePath);
The exact path separator can differ between operating systems. Using path utilities helps your application construct paths correctly for the current platform.
12 · Essential APIs

Important Path Methods

path.join() BUILD
Joins path segments using the platform's separator and normalizes the resulting path.
path.resolve() ABSOLUTE
Resolves path segments into an absolute path.
path.basename() FILE
Returns the last portion of a path.
path.dirname() PARENT
Returns the directory portion of a path.
path.extname() EXTENSION
Returns the extension of the final path component.
path.parse() ANALYZE
Breaks a path into root, directory, basename, extension and name.

path.join()

const path = require('path');

const result = path.join(
    'projects',
    'node',
    'data.txt'
);

console.log(result);

path.basename()

const path = require('path');

const result = path.basename(
    '/projects/node/data.txt'
);

console.log(result);

// data.txt

path.dirname()

const path = require('path');

const result = path.dirname(
    '/projects/node/data.txt'
);

console.log(result);

// /projects/node

path.extname()

const path = require('path');

console.log(
    path.extname('report.pdf')
);

// .pdf

path.parse()

const path = require('path');

const result = path.parse(
    '/projects/node/report.pdf'
);

console.log(result);

The returned object contains properties such as root, dir, base, ext and name.

13 · Important Difference

path.join() vs path.resolve()

Concept path.join() path.resolve()

Result Normalized path Absolute normalized path

const path = require('path');

console.log(
    path.join('data', 'users', 'file.txt')
);

console.log(
    path.resolve('data', 'users', 'file.txt')
);
14 · Real-World Node.js

Understanding __dirname

In a CommonJS module, __dirname contains the absolute path of the directory containing the current JavaScript file. 

const path = require('path');

const filePath = path.join(
    __dirname,
    'data',
    'users.json'
);

console.log(filePath);
This pattern is useful when your application needs to refer to files relative to the current source file rather than depending on the directory from which the Node process was launched.

18 · Practical Project

Mini Project — File Notes Manager

Combine fs and path to build a simple notes storage system.

Project Structure

📁 notes-app/
├── 📄 app.js
└── 📁 notes/
    └── 📄 notes.txt

Implementation

const fs = require('fs');
const path = require('path');

const notesDirectory = path.join(
    __dirname,
    'notes'
);

const notesFile = path.join(
    notesDirectory,
    'notes.txt'
);

if (!fs.existsSync(notesDirectory)) {
    fs.mkdirSync(notesDirectory);
}

fs.appendFile(
    notesFile,
    'Learn Node.js File System\n',
    (err) => {

        if (err) {
            console.error(err);
            return;
        }

        console.log('Note saved successfully');
    }
);
What happened?
1. Imported fs and path.
2. Built the directory path.
3. Built the notes file path.
4. Checked whether the directory exists.
5. Created it when necessary.
6. Appended the note to the file.
19 · Reliability

Error Handling in File Operations

Filesystem operations can fail for many reasons:

  • File does not exist
  • Incorrect path
  • Permission denied
  • Directory does not exist
  • Invalid operation
  • File is unavailable
fs.readFile('data.txt', 'utf8', (err, data) => {

    if (err) {

        console.error(
            'Unable to read file:',
            err.message
        );

        return;
    }

    console.log(data);
});
Never assume that a file operation will always succeed. Production applications should handle filesystem errors deliberately.
20 · Modern Node.js

fs/promises with async/await

Node.js provides a promise-based filesystem API that works naturally with async/await. 

const fs = require('fs/promises');

async function readData() {

    try {

        const data = await fs.readFile(
            'message.txt',
            'utf8'
        );

        console.log(data);

    } catch (error) {

        console.error(
            'Read failed:',
            error.message
        );
    }
}

readData();
This style avoids deeply nested callbacks and makes asynchronous filesystem code easier to read.
21 · Interview Preparation

Professional Interview Questions

What is the fs module? +
The fs module is a built-in Node.js module that provides APIs for interacting with files and directories.
What is the difference between readFile() and readFileSync()? +
readFile() is asynchronous and allows Node.js to continue processing other JavaScript work while the filesystem operation is pending. readFileSync() blocks execution until the operation completes.
What does writeFile() do? +
writeFile() writes data to a file. It creates the file if needed and normally replaces its existing contents.
What is the path module used for? +
The path module provides utilities for constructing, resolving and analyzing filesystem paths.
What is path.join()? +
path.join() combines multiple path segments into one normalized path using the platform's path separator.
What is path.resolve()? +
path.resolve() processes path segments from right to left until it constructs an absolute path.
What does path.extname() return? +
It returns the extension of the last portion of a path, such as ".js" or ".json".
Why are fs and path commonly used together? +
path helps construct the correct filesystem location, while fs performs operations such as reading or writing at that location.
