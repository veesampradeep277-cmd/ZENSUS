01 · Foundation

What You Need to Learn React

React itself runs in the browser, but modern React development uses a collection of tools that make development, dependency management, module loading and production builds much easier.

HTML

Understand the structure of web pages and how elements are represented in the DOM.

CSS

JavaScript

Important: You do not need to master every advanced JavaScript feature before starting React. Learn the fundamentals first and deepen your JavaScript knowledge while building projects.
02 · Environment

Node.js

What is Node.js?

Node.js is a JavaScript runtime that allows JavaScript code to execute outside the browser. In React development, Node.js provides the environment required by many development tools.

JavaScript Programming language
→
Node.js JavaScript runtime
→
Development Tools Vite, npm, etc.

Why does React need Node.js?

A React application normally uses tools that run during development and build time. Node.js allows those tools to execute on your computer.

  • Running the Vite development server
  • Installing packages
  • Managing dependencies
  • Building optimized production files
  • Running development scripts
03 · Package Management

npm

What is npm?

npm is the package manager commonly used with Node.js. It allows you to install, update and manage JavaScript packages used by your project.

Terminal npm 
npm --version

# Check installed npm version

npm install

Installs dependencies defined by your project. 

npm install

npm run dev

Runs the development script defined in package.json. 

npm run dev

08 · Architecture

React Project Folder Structure

Understanding the project structure is one of the most important skills for becoming comfortable with React.

📁 my-react-app/
├── 📁 node_modules/
├── 📁 public/
├── 📁 src/
│ ├── App.jsx
│ ├── main.jsx
│ ├── App.css
│ └── index.css
├── index.html
├── package.json
├── package-lock.json
└── vite.config.js
Think of the project like a house: src contains the main application code, public contains public static assets, node_modules contains installed packages, and package.json describes the project's dependencies and scripts.

10 · Configuration

package.json

Think of package.json as the project's identity card. It tells npm important information about the project.

package.json 
{
  "name": "my-react-app",

  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },

  "dependencies": {
    "react": "...",
    "react-dom": "..."
  },

  "devDependencies": {
    "@vitejs/plugin-react": "...",
    "vite": "..."
  }
}

scripts

Defines commands such as npm run dev and npm run build.

dependencies

Packages required by the application at runtime.

11 · Dependency Resolution

package-lock.json

When npm resolves dependencies, many packages may depend on other packages. The lock file records the resolved dependency tree so installations can be reproduced consistently.

package.json What we want
→
npm Resolves packages
→
package-lock.json Resolved tree
Do not manually edit package-lock.json unless you have a specific reason and understand the dependency-resolution implications.
12 · Dependencies

node_modules

What lives inside node_modules?

The folder contains packages installed for your project, including React, React DOM, Vite and their dependency trees.

Your Project package.json
npm install Dependency resolution
node_modules Installed packages
React + Vite Development
Do not upload node_modules to Git. It can be recreated from the project's dependency files using npm install.

14 · Static Assets

public

The public folder is intended for static assets that need to be served directly without being imported through the JavaScript module graph. 

public/
├── logo.svg
├── favicon.ico
└── robots.txt

For many application assets, importing them from src is also common and allows the build tool to process them.

15 · HTML Entry

index.html

A React application still needs an HTML document. React does not replace HTML itself; instead, React renders the application's UI inside a DOM element.

index.html 
<body>

  <div id="root"></div>

  <script type="module"
          src="/src/main.jsx">
  </script>

</body>
The root element acts as the mounting point for the React application.
16 · Entry Point

main.jsx

main.jsx is typically the JavaScript entry point that starts React and tells React where to render the application. 

import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import './index.css'
import App from './App.jsx'

createRoot(document.getElementById('root'))
  .render(
    <StrictMode>
      <App />
    </StrictMode>
  )
17 · Component

App.jsx

App.jsx usually contains the root component of the application. 

function App() {

      <h1>Hello React</h1>

    </main>
  )
}

export default App

20 · How Everything Connects

React Application Architecture

Browser Loads index.html
Vite Serves modules
main.jsx Starts React
App.jsx Root component
DOM #root

The mental model

The browser receives the HTML document. The module script points to the React entry file. The entry file creates a React root and renders the component tree into the root DOM element.

22 · Build Lifecycle

Development vs Production

Development

  • Run npm run dev
  • Fast feedback
  • Development server
  • Helpful error information
  • Designed for coding

Production

  • Run npm run build
  • Optimized assets
  • Minified output
  • Designed for deployment
  • Served by a production host

24 · Troubleshooting

Common Setup Errors

❌ npm is not recognized

Usually means Node.js is not installed correctly or the terminal's PATH has not been refreshed. 

node --version
npm --version

❌ Cannot find module

Your dependencies may not have been installed. 

npm install

❌ Wrong directory

The terminal must be inside the React project folder. 

cd my-react-app
npm run dev

❌ Port already in use

Another process may already be using the development server port. Vite can normally select another available port.

❌ Blank page

Check browser console errors, the root element, imports and the React entry file.

❌ JSX syntax error

Check closing tags, JavaScript expressions and component syntax.
