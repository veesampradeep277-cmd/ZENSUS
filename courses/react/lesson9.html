01. Rendering Lists

Modern applications rarely display just one item. Social feeds, products, courses, messages, notifications and search results are usually collections of data.

React lets you take an array and transform every item into JSX. The most common JavaScript tool for this is map().

02. JavaScript map()

Before mastering React lists, you must understand JavaScript map().

map() creates a new array by transforming every element of an existing array. 

const numbers = [1, 2, 3, 4];

const doubled = numbers.map(
    number => number * 2
);

console.log(doubled);

// [2, 4, 6, 8]

04. Arrays in JSX

JSX allows JavaScript expressions inside curly braces. That means an array can be transformed into JSX directly. 

const skills = [
    "HTML",
    "CSS",
    "JavaScript",
    "React"
];

return (
    <div>

        {skills.map(skill => (
            <span key={skill}>
                {skill}
            </span>
        ))}

    </div>
);
Remember:

You normally don't write a normal JavaScript for loop directly inside JSX. Instead, transform your data into elements using methods such as map().

05. Keys

A key is a special React attribute that gives each item in a rendered list a stable identity. 

const users = [
    { id: 101, name: "Asha" },
    { id: 102, name: "Rahul" },
    { id: 103, name: "Priya" }
];

return (
    <div>

        {users.map(user => (
            <div key={user.id}>
                {user.name}
            </div>
        ))}

    </div>
);
EVERY ITEM NEEDS AN IDENTITY
KEY 101
KEY 102
KEY 103
React uses these identities when reconciling the list.

06. Why Keys Matter

React uses keys to determine which list items have changed, been added, removed or moved.

Imagine the original list: 

A
B
C

Now the application inserts X at the beginning: 

X
A
B
C

Stable keys help React understand that A, B and C are still the same logical items.

Data Identity

id:101 A
id:102 B
id:103 C

After Insert

id:999 X
id:101 A
id:102 B
id:103 C
Key principle:

A key should represent the identity of the data item, not simply its current position in the array.

07. Unique Keys

Keys must be unique among the siblings in the same list.

Good key

{users.map(user => (
    <UserCard
        key={user.id}
        user={user}
    />
))}

Bad key

{users.map(user => (
    <UserCard
        key={user.name}
        user={user}
    />
))}

The second example can fail if two users have the same name.

Best practice:

Use a stable unique identifier from your data such as a database ID.

08. Index as Key

You can technically use the array index as a key: 

{items.map((item, index) => (
    <div key={index}>
        {item.name}
    </div>
))}

But this becomes dangerous when list items can be inserted, removed, reordered or edited.

Why?

An index describes the item's current position—not the item's identity. If the order changes, the same index may now represent a completely different item.

When can an index be acceptable?

  • The list is static.
  • The list never changes order.
  • Items are never inserted or removed.
  • Items do not have their own stable IDs.

Even then, a stable unique ID is generally preferable when available.

10. Nested Lists

Sometimes one list contains another list. For example, a course may contain multiple topics. 

const courses = [

    {
        id: 1,

        topics: [

        ]
    },

    {
        id: 2,
        name: "Python",
        topics: [
            "Variables",
            "Functions",
            "OOP"
        ]
    }

];

Rendering nested data

{courses.map(course => (

    <section key={course.id}>

        <h2>
            {course.name}
        </h2>

        <ul>

            {course.topics.map(topic => (

                <li key={topic}>
                    {topic}
                </li>

        </ul>

    </section>

))}
Important:

Each mapped sibling list needs an appropriate key. Nested lists don't remove the need for keys.

11. List Components

For larger applications, don't place an entire list inside one giant component. Create reusable components. 

function CourseCard({ course }) {

    return (

        <article>

            <h3>
                {course.title}
            </h3>

            <p>
                {course.level}
            </p>

        </article>

    );

}

Then: 

function CourseList({ courses }) {

    return (

        <div>

            {courses.map(course => (

                <CourseCard
                    key={course.id}
                    course={course}
                />

            ))}

        </div>

    );

}
Professional React pattern:

List component manages the collection.
Item component manages one item.

12. Adding Items

When adding an item to a React state array, create a new array rather than mutating the existing one. 

const [items, setItems] = useState([]);

function addItem() {

    const newItem = {
        id: Date.now(),
        name: "React"
    };

    setItems(prevItems => [
        ...prevItems,
        newItem
    ]);

}

Add Items — Live Demo

Why spread?

... creates a new array while preserving the existing items. This follows React's immutable update pattern.

13. Removing Items

Use filter() to create a new array without the item you want to remove. 

setItems(prevItems =>
    prevItems.filter(
        item => item.id !== id
    )
);

Remove Items — Live Demo

Mental model:

Keep everything → remove the matching item → create a new array.

14. Updating Items

Use map() when you want to replace or modify one item while keeping the others. 

setItems(prevItems =>

    prevItems.map(item =>

        item.id === id

        ? {
            ...item,
            completed: !item.completed
        }

        : item

    )

);

Update Items — Live Demo

Remember the three major array operations:
  • map() → transform / update
  • filter() → remove
  • [...array, newItem] → add

15. Filtering Lists

filter() creates a new array containing only elements that satisfy a condition. 

const completedCourses =
    courses.filter(
        course => course.completed
    );

Important:

Filtering does not modify the original array. It creates a new array.

16. Sorting Lists

JavaScript's sort() can arrange list items based on a comparison function. 

const sortedCourses = [...courses].sort(
    (a, b) => a.title.localeCompare(b.title)
);
Important:

sort() mutates the array it is called on. When working with React state, make a copy first.

18. Common List Mistakes

❌ Missing key

items.map(item => (
    <div>{item.name}</div>
))

Every rendered list item should have an appropriate key.

❌ Random keys

key={Math.random()}

A random key changes between renders and defeats stable identity.

❌ Using index unnecessarily

key={index}

Avoid this when items can change order or be inserted or removed.

❌ Mutating state

items.push(newItem);

Don't directly mutate React state arrays. Create a new array.

❌ Mutating before sort

items.sort(...)

Copy the array first: 

[...items].sort(...)

❌ Forgetting return

items.map(item => {
    <div>
        {item.name}
    </div>
})

With braces, explicitly return the JSX. 

items.map(item => {
    return <div>
        {item.name}
    </div>;
})
