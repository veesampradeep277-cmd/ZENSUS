01 • Foundation

What is React?

React is a JavaScript library for building user interfaces. It allows developers to create interfaces from small, reusable components and update the screen when application data changes.

⚛

JavaScript Library

React provides tools for building the user interface layer of web applications.

🧩

Component Based

Interfaces are divided into independent and reusable pieces called components.

🔄

Dynamic UI

React updates the interface when application state changes.

App.jsx 
function Welcome() {
    return <h1>Welcome to ZENSUS!</h1>;
}

function App() {
    return (
        <Welcome />
    );
}

03 • History

History of React

React emerged from the need to manage complex interfaces more systematically.

2011 — Early Development

React was developed at Facebook to address challenges involved in building complex user interfaces.

2013 — Open Source

React was publicly introduced as an open-source JavaScript library.

React Ecosystem Growth

React became widely used alongside tools for routing, state management, development and full-stack applications.

04 • Problem

Problems with Traditional Web Development

Large interactive applications can become difficult to maintain when UI updates, application data and DOM manipulation are tightly coupled.

🔗

Complex DOM Manipulation

Developers may need to locate elements and manually change their content, attributes or styles.

🧠

State Synchronization

Keeping different parts of an interface synchronized with changing application data can become difficult.

♻️

Repeated UI Code

Without reusable component patterns, similar interface structures may be repeated across an application.

🛠️

Maintenance

As an application grows, tightly connected UI logic can become harder to understand and modify safely.

05 • Comparison

React vs Traditional JavaScript

Vanilla JavaScript

const button =
    document.querySelector("#btn");

button.addEventListener("click", () => {

    document.querySelector("#count")
        .textContent = "1";

});

The developer explicitly selects DOM elements and modifies them.

React

function Counter() {

    const [count, setCount] =
        useState(0);

    return (
        <button
            onClick={() => setCount(count + 1)}
        >
            {count}
        </button>
    );
}

The UI is described from state, while React manages the necessary updates.

08 • Core Principle

Declarative UI

Declarative programming describes what the UI should look like for a particular state rather than manually specifying every DOM operation required to reach that state.

State

isLoggedIn = true
→

UI

Declarative Example 
function App() {

    const isLoggedIn = true;

    return (
        <div>
            {isLoggedIn
                ? <h2>Welcome, Student!</h2>
                : <h2>Please Login</h2>
            }
        </div>
    );
}

10 • Rendering Concept

Virtual DOM

The Virtual DOM is an in-memory representation of the UI. React uses its rendering process to determine what changes need to be reflected in the browser DOM.

15 • Evaluation

Advantages of React

Reusable Components

Components encourage reuse and help organize complex interfaces.

Declarative UI

Developers describe UI states rather than manually coordinating every DOM update.

Large Ecosystem

React works with a broad collection of libraries, frameworks and development tools.

Component Composition

Small components can be combined to create larger application interfaces.

Developer Tools

Development tools can help inspect components, props, state and rendering behavior.

Flexible Architecture

React can be combined with different tools depending on the needs of an application.

16 • Considerations

Limitations of React

Additional Tools

React itself focuses on the UI layer, so applications may require additional solutions for routing, data management and other concerns.

Fast-Moving Ecosystem

React and its surrounding ecosystem evolve over time, requiring developers to keep their knowledge current.

JavaScript Knowledge

Effective React development requires a solid understanding of JavaScript fundamentals.

Architecture Decisions

Flexible tooling means developers must make decisions about project structure and supporting libraries.

18 • Summary

Key Takeaways

  • React is a JavaScript library focused on building user interfaces.
  • React applications are constructed from reusable components.
  • JSX provides a convenient syntax for describing UI.
  • Props allow components to receive data from their parents.
  • State represents data that can change during an application's lifetime.
  • React follows a declarative approach to describing UI.
  • React's rendering system determines what UI changes need to be committed.
  • React can be combined with routing, state management and other tools.
  • Strong JavaScript fundamentals are important before going deep into React.
