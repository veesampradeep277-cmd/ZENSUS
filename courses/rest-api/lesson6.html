JSON & Data Exchange

Learn how applications exchange structured data using JSON, understand objects, arrays and data types, and see exactly how JSON moves between a frontend, REST API and backend.

01

What is JSON?

JSON stands for JavaScript Object Notation. It is a lightweight text format used to represent and exchange structured data between applications.

Simple definition:

JSON is a standard way of writing data so that different applications can understand and exchange it.
Simple JSON 
{
    "name": "Pradeep",
    "age": 21,
    "course": "REST API"
}

Although JSON originated from JavaScript notation, it is now used widely by applications written in Python, Java, C#, JavaScript, Go, PHP and many other languages.

02

Why is JSON Used?

🌐

Cross-Platform

Different programming languages can read and generate JSON.

⚡

JSON is compact and convenient for transferring structured data over networks.

👀

Readable

Developers can easily understand JSON data.

🔗

API Friendly

REST APIs commonly use JSON for request and response data.

Basic JSON Structure

JSON mainly represents information using two structures: objects and arrays.

Object

{
"name": "Pradeep",
"age": 21
}

Objects contain key-value pairs.

Array

[
"Python",
"Django",
"REST API"
]

Arrays contain ordered collections of values.

04

JSON Objects

A JSON object is enclosed inside curly braces { }. It contains key-value pairs.

JSON Object 
{
    "id": 101,
    "name": "Pradeep",
    "email": "pradeep@example.com",
    "active": true
}

Key and Value

In the example above:

  • "name" is the key.
  • "Pradeep" is its value.
  • "age" could be another key.
  • 21 could be its numeric value.
A JSON object uses a colon : between a key and its value, and commas , between multiple pairs.
05

JSON Arrays

A JSON array is enclosed inside square brackets [ ].

Array of Strings 
[
    "Python",
    "Django",
    "REST API",
    "React"
]

Arrays can also contain objects. This is extremely common in REST APIs.

Array of Objects 
[

07

Important JSON Rules

  • JSON object keys must use double quotes.
  • String values use double quotes.
  • Key and value are separated using :.
  • Multiple items are separated using ,.
  • Objects use { }.
  • Arrays use [ ].
  • JSON does not allow comments.
  • JSON does not allow trailing commas after the final item.
Valid JSON 
{
    "name": "Pradeep",
    "age": 21,
    "active": true
}
Invalid JSON 
{
    name: 'Pradeep',
    age: 21,
}
Why is it invalid?

The keys and string value use single quotes or no quotes, and there is a trailing comma after the final property.

Nested JSON

JSON objects and arrays can be placed inside other objects and arrays. This is called nested JSON.

Nested Object 
{
    "id": 101,
    "name": "Pradeep",
    "course": {
        "name": "REST API",
        "duration": "15 Lessons",
        "level": "Beginner"
    }
}

Array Inside Object

Nested Array 
{
    "name": "Pradeep",
    "skills": [
        "Python",
        "Django",
        "REST API",
        "React"
    ]
}

Objects Inside Arrays

JSON Request

A client can send JSON data to a REST API, commonly with methods such as POST, PUT or PATCH.

Example POST Request Body 
{
    "name": "Pradeep",
    "email": "pradeep@example.com",
    "age": 21,
    "course": "REST API"
}

The server receives the JSON, validates it, processes it and may store the information in a database.

→

11

JSON Response

After processing the request, the API can return a JSON response.

Example API Response 
{
    "success": true,
    "message": "Student created successfully",
    "data": {
        "id": 101,
        "name": "Pradeep",
        "course": "REST API"
    }
}

The frontend can then use the returned data to update the user interface.

Typical flow:

Request JSON → Validate → Process → Store → Response JSON
12

Content-Type: application/json

The Content-Type header tells the receiving application what type of data is being transmitted.

JSON HTTP Request 
POST /api/students/ HTTP/1.1
Host: example.com
Content-Type: application/json

{
    "name": "Pradeep",
    "age": 21
}

For a JSON request body, the common media type is:

application/json

This tells the server that the body contains JSON data.

JSON Response Header 
HTTP/1.1 200 OK
Content-Type: application/json
13

JSON Parse & Stringify

When working with JavaScript, JSON text and JavaScript objects can be converted between each other.

📥

JSON.parse()

Converts JSON text into a JavaScript value.

📤

JSON.stringify()

Converts a JavaScript value into JSON text.

JSON.parse() 
const jsonText = '{"name":"Pradeep","age":21}';

const student = JSON.parse(jsonText);

console.log(student.name);
console.log(student.age);
JSON.stringify() 
const student = {
    name: "Pradeep",
    age: 21
};

const jsonText = JSON.stringify(student);

console.log(jsonText);
Remember:

JSON text → JavaScript object = JSON.parse()

JavaScript object → JSON text = JSON.stringify()

Lesson Takeaway

  • JSON stands for JavaScript Object Notation.
  • JSON is widely used for exchanging structured data between applications.
  • JSON objects use curly braces { }.
  • JSON arrays use square brackets [ ].
  • JSON supports strings, numbers, booleans, null, objects and arrays.
  • JSON object keys use double quotes.
  • JSON can contain nested objects and arrays.
  • REST APIs commonly use JSON for request and response bodies.

  • JavaScript uses JSON.stringify() to convert a JavaScript value into JSON text.
