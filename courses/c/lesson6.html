What is a Loop?

A loop repeatedly executes a block of statements while a specified condition is satisfied.

One instruction → repeated work

04

for Loop

The for loop combines initialization, condition checking and update in one compact structure.

Syntax 

for(initialization; condition; update)
{
    // loop body
}

Example 

#include <stdio.h>

int main()
{
    for(int i = 1; i <= 5; i++)
    {
        printf("%d ", i);
    }

    return 0;
}
Output: 1 2 3 4 5

for Loop Execution

Initialize i = 1
↓
i ≤ 5?
TRUE ↓
Execute Body
↓
i++
↩ Check Condition
FALSE → EXIT
05

Three Parts of a for Loop

1. Initialization

Establishes the starting value. 

int i = 1;

2. Condition

Determines whether another iteration should occur. 

i <= 5;

3. Update

Changes the loop variable after an iteration. 

i++;
Execution order: Initialization → Condition → Body → Update → Condition → Body → Update ...
06

while Loop

The while loop checks its condition before executing the body.

Syntax 

while(condition)
{
    // statements
}

Example 

int i = 1;

while(i <= 5)
{
    printf("%d ", i);
    i++;
}
Important: If the condition is false initially, a while loop may execute zero times.
07

do-while Loop

A do-while loop executes the body first and checks the condition afterward. 

do
{
    // statements
}
while(condition);

Example 

int i = 1;

do
{
    printf("%d ", i);
    i++;
}
while(i <= 5);
Key property: The body executes at least once.

Perfect Real-World Example — Menu 

int choice;

do
{
    printf("\n1. Deposit");
    printf("\n2. Withdraw");
    printf("\n3. Exit");

    scanf("%d", &choice);

}
while(choice != 3);

This is useful when the user must see the menu at least once.

Nested Loops

A nested loop is a loop placed inside another loop. The inner loop completes its iterations for every iteration of the outer loop. 

for(int i = 1; i <= 3; i++)
{
    for(int j = 1; j <= 3; j++)
    {
        printf("* ");
    }

    printf("\n");
}
* * *
* * *
* * *
Key idea: If the outer loop executes 3 times and the inner loop executes 3 times per outer iteration, the inner body executes 3 × 3 = 9 times.

13

break & continue

break

Immediately terminates the nearest loop. 

for(int i=1; i<=10; i++)
{
    if(i == 5)
        break;

    printf("%d ", i);
}
Output: 1 2 3 4

continue

Skips the rest of the current iteration and proceeds to the next iteration. 

for(int i=1; i<=5; i++)
{
    if(i == 3)
        continue;

    printf("%d ", i);
}
Output: 1 2 4 5
Important: In a for loop, after continue, control proceeds to the loop's iteration expression/update before the next condition check.

Infinite Loops

An infinite loop continues forever because its terminating condition never becomes false.

Example 

while(1)
{
    printf("Running...");
}
Warning: Infinite loops can consume CPU resources or prevent a program from progressing if they are not intentional.

Accidental Infinite Loop 

int i = 1;

while(i <= 5)
{
    printf("%d", i);

    /* i never changes */
}

Intentional Infinite Loop 

while(1)
{
    /* server/event loop */

    if(stop)
        break;
}

Common Mistakes

✕
Forgetting the update

If the loop variable never changes, the condition may never become false.

✕
Wrong boundary condition

Confusing < with <= can produce off-by-one errors.

✕
Semicolon after loop 
for(int i=0; i<5; i++);

That semicolon makes the loop body empty.

✕
Confusing break and continue

break exits the loop; continue skips the current iteration.

✕
Wrong nested-loop variable

Accidentally updating the outer loop variable inside the inner loop can cause incorrect behavior.

Loop Complexity Foundation

One Loop 

for(i=0; i<n; i++)
{
    // O(n)
}

Two Nested Loops 

for(i=0; i<n; i++)
{
    for(j=0; j<n; j++)
    {
        // O(n²)
    }
}

Three Nested Loops 

for(i=0; i<n; i++)
{
    for(j=0; j<n; j++)
    {
        for(k=0; k<n; k++)
        {
            // O(n³)
        }
    }
}
DSA connection: Understanding how many times a loop executes is the first step toward understanding time complexity.

Interview Questions

1. What is the difference between while and do-while?

while checks its condition before executing the body, whereas do-while executes the body first and checks the condition afterward.

2. Can a for loop omit any of its three expressions?

Yes. Initialization, condition and update expressions can be omitted individually, although a missing condition can result in an infinite loop.

3. What is a nested loop?

A loop inside another loop. The inner loop runs through its iterations for each iteration of the outer loop.

4. What is an infinite loop?

A loop whose termination condition never becomes false, causing it to continue indefinitely unless externally interrupted or internally terminated.

5. What is an off-by-one error?

A common programming error where a loop executes one time too many or one time too few because of an incorrect boundary condition.

6. What is the time complexity of two nested loops?

If both loops independently execute approximately n times, the total work is O(n²).
