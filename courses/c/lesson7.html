Why Do We Need Functions?

Functions make programs modular, readable and reusable.

❌ Without Functions

Imagine writing the same calculation 10 times. The program becomes long, repetitive and difficult to maintain.

Problem:
Repetition → difficult maintenance → more bugs → poor readability

✅ With Functions

Write a task once and call it whenever you need it.

Idea:
Write once → reuse many times → cleaner program

Real-World Analogy

Think of a calculator. Instead of rebuilding the addition mechanism every time you add two numbers, the calculator has a reusable operation.

The 4 Basic Types of Functions

Classified according to arguments and return value.

1

No Arguments + No Return Value

The function receives nothing and returns nothing.

C 
void greet()
{
    printf("Hello ZENSUS!");
}

int main()
{
    greet();
    return 0;
}
2

Arguments + No Return Value

The function receives input but does not return a value.

C 
void square(int n)
{
    printf("%d", n * n);
}

int main()
{
    square(5);
    return 0;
}
3

No Arguments + Return Value

The function receives no input but returns a value.

C 
int getNumber()
{
    return 100;
}

int main()
{
    int x = getNumber();

    printf("%d", x);

    return 0;
}
4

Arguments + Return Value

The most commonly used function pattern.

C 
int multiply(int a, int b)
{
    return a * b;
}

int main()
{
    int result = multiply(4, 5);

    printf("%d", result);

    return 0;
}
08

Parameters vs Arguments

A very common interview and exam question.

Parameter

A variable listed in the function definition.

Parameters 
int add(int a, int b)
{
    return a + b;
}

a and b are parameters.

Argument

The actual value supplied during a function call.

Arguments 
add(10, 20);

10 and 20 are arguments.

Easy memory trick: Parameters are variables in the function definition. Arguments are actual values sent during the call.

Pass by Value

Understand what happens when values are passed to functions.

In ordinary C parameter passing, the function receives a copy of the argument's value. Changing the parameter does not change the caller's original variable.

C • Pass by Value 
#include <stdio.h>

void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    printf("%d", a);

    return 0;
}
main()
a = 10
→
change(a)
→
x = 10
x = 100
→
a = 10
Output: 10
The local parameter changed, but the original a remained 10.
10A

Why Normal Swap Fails

A classic C function question.

❌ Incorrect for changing caller variables

C 
void swap(int a, int b)
{
    int temp = a;
    a = b;
    b = temp;
}

Only the copies are swapped.

✅ Using Addresses

C 
void swap(int *a, int *b)
{
    int temp = *a;

    *a = *b;

    *b = temp;
}

int main()
{
    int x = 10, y = 20;

    swap(&x, &y);

    printf("%d %d", x, y);

    return 0;
}

This uses pointers to modify the original variables.

Passing Arrays to Functions

Arrays are commonly processed using functions.

C • Array Function 
#include <stdio.h>

void printArray(int arr[], int n)
{
    for(int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }
}

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    printArray(numbers, 5);

    return 0;
}

Array Processing Flow

main()
→
numbers[]
→
printArray()
→
Traversal
Important: When an array is passed to a function, the function can modify the array elements. The size is generally supplied separately because the function parameter does not automatically know the caller's array length.

Real Example — Sum of Array

Functions + arrays + loops together.

C • Sum of Array

{
    int sum = 0;

Passing Strings to Functions

Strings are character arrays, so they can be passed to functions.

C • String Function 
#include <stdio.h>

void printString(char str[])
{
    printf("%s", str);
}

int main()
{
    char name[] = "ZENSUS";

    printString(name);

    return 0;
}

Example — Count Characters

C 
int length(char str[])
{
    int count = 0;

    while(str[count] != '\0')
    {
        count++;
    }

    return count;
}

The function walks through the characters until it finds the null character '\0'.

Variable Scope

Scope tells us where a variable can be accessed.

Local Variable

Declared inside a function or block. Accessible only within that scope. 

void test()
{
    int x = 10;
}

Global Variable

Declared outside functions. It can be accessed by functions in the same translation unit, subject to linkage and declarations. 

int x = 10;

void test()
{
    printf("%d", x);
}

Block Scope

Variables declared inside a block exist only inside that block. 

if(1)
{
    int x = 10;
}
Best practice: Prefer local variables and pass required data through function parameters instead of relying heavily on global state.

Recursion

A function calling itself to solve a smaller version of a problem.

Recursion = Function calling itself.

Every recursive solution should normally have:
1. Base case — stops recursion.
2. Recursive case — moves toward the base case.
C • Factorial Recursion 
int factorial(int n)
{
    if(n == 0)
        return 1;

    return n * factorial(n - 1);
}

int main()
{
    printf("%d", factorial(5));

    return 0;
}

Animated Call Stack — factorial(5)

factorial(5) 5 × factorial(4)
factorial(4) 4 × factorial(3)
factorial(3) 3 × factorial(2)
factorial(2) 2 × factorial(1)
factorial(1) 1 × factorial(0)
factorial(0) return 1

Important Recursion Examples

Practice these classic problems.

Sum of First N Numbers

int sum(int n)
{
    if(n == 0)
        return 0;

    return n + sum(n - 1);
}

Fibonacci

int fib(int n)
{
    if(n <= 1)
        return n;

    return fib(n - 1) + fib(n - 2);
}

Power

int power(int a, int n)
{
    if(n == 0)
        return 1;

    return a * power(a, n - 1);
}

GCD

int gcd(int a, int b)
{
    if(b == 0)
        return a;

    return gcd(b, a % b);
}
Recursion warning: Recursion uses stack memory for function calls. A missing or incorrect base case can cause excessive recursion and potentially stack overflow.

Function Pointers

An advanced but important C concept.

A function pointer stores the address of a function. It can then be used to call that function indirectly.

C • Function Pointer 
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int (*operation)(int, int);

    operation = add;

    printf("%d", operation(10, 20));

    return 0;
}

Function Pointers as Callbacks

One function can receive another function as an argument.

C • Callback Example 
#include <stdio.h>

int square(int x)
{
    return x * x;
}

void process(int value, int (*func)(int))
{
    printf("%d", func(value));
}

int main()
{
    process(5, square);

    return 0;
}
Function pointers are useful in callbacks, generic algorithms, event systems and library APIs.
16B

Can C Functions Be Defined Inside Other Functions?

Important language rule.

Standard C does not allow defining a normal function inside another function. 

int main()
{
    // Standard C does not allow:
    //
    // int test()
    // {
    // }

    return 0;
}
Some compiler extensions may support nested functions, but they are not part of standard C and should not be relied on for portable C programs.

Common Mistakes

These mistakes appear frequently in exams and interviews.

✕
Calling a function before the compiler knows its declaration
✓ Use a function prototype before the call when necessary.
✕
Wrong return type
✓ Make the return value compatible with the declared return type.
✕
Forgetting return value in a non-void function
✓ Ensure every required control path returns an appropriate value.
✕
Confusing parameters and arguments
✓ Parameters are in the function definition; arguments are values in the call.
✕
Expecting pass-by-value to change the original variable
✓ Use pointers when a function needs to modify caller-owned objects.
✕
Forgetting array size information
✓ Pass the array length separately when the function needs it.
✕
Recursive function without a proper base case
✓ Define a terminating condition and ensure recursion moves toward it.
✕
Using global variables everywhere
✓ Prefer local variables and parameters for cleaner, safer programs.

Functions and Time Complexity

A function itself doesn't determine complexity; its operations do.

Constant

int square(int x)
{
    return x * x;
}

Time: O(1)

Linear

int sum(int a[], int n)
{
    int s = 0;

    for(int i=0;i<n;i++)
        s += a[i];

    return s;
}

Time: O(n)

Nested Loop

void work(int n)
{
    for(int i=0;i<n;i++)
        for(int j=0;j<n;j++)
            printf("*");
}

Time: O(n²)

20

Interview Questions

Questions you should be able to answer confidently.

Q1. Why are functions important? Modularity, reuse, readability, testing and maintainability.
Q2. Difference between declaration and definition? Declaration describes the function; definition provides its implementation.
Q3. Parameter vs argument? Parameters belong to the function definition; arguments are values supplied in a call.
Q4. Does C support pass by reference? C uses pass-by-value. Pointers can be passed by value to allow a function to modify caller-owned data.
Q5. What happens if recursion has no base case? Calls may continue until available stack space is exhausted, potentially causing stack overflow.
Q6. What is a function pointer? A pointer that stores a function address and can be used to invoke the function indirectly.
Q7. Can a function return an array directly? Not as an array type. Common approaches include returning a pointer to valid storage or modifying caller-provided storage.
Q8. Why pass array size to a function? The array parameter does not automatically carry the caller's complete array length.
Q9. What is static local variable? It retains its stored value between calls while remaining accessible only within its block.
Q10. Can functions be nested in standard C? No. Standard C does not allow defining one ordinary function inside another.
