C Unions

Share memory intelligently. Learn how unions overlap storage, how active members work, how unions differ from structures, and how professional C programs use tagged unions for flexible data representation.

02

Why Do We Need Unions?

Think about memory before learning syntax.

Imagine you have a storage box. At one moment you want to store a book. At another moment you want to store a laptop. You do not need two boxes if only one item is required at a time.

Core idea: A union provides one shared storage area that can represent different members at different times.

Structure

Every member gets its own storage.

Think: one box per item.

Union

All members share the same storage.

Think: one box, different possible contents.

03

What Is a Union?

The fundamental definition.

A union is a user-defined data type in C in which all members occupy overlapping storage.

Unlike a structure, where every member has its own storage, a union allows different members to use the same memory area.

C — Basic Union 
union Data {
    int i;
    float f;
    char c;
};

04

Declaring a Union Variable

Create an object of the union type.

Declaration 
union Data {
    int i;
    float f;
    char c;
};

int main() {

    union Data d;

    return 0;
}

The statement:

C 
union Data d;

creates a union object named d.

05

Union Initialization

Choose the member that starts with a value.

Designated Initialization

C 
union Data d = {
    .i = 100
};

This initializes the i member.

First-Member Initialization

C 
union Data d = {100};

For this union, the first member is i, so the initializer initializes i.

Important: A union initializer initializes one union member as the designated/current member. Use designated initializers when you want the code to clearly communicate which member is intended.
06

Accessing Union Members

Use the dot operator.

Member Access 
#include <stdio.h>

union Data {
    int i;
    float f;
    char c;
};

int main() {

    union Data d;

    d.i = 50;

    printf("Integer = %d\n", d.i);

    d.f = 3.14f;

    printf("Float = %.2f\n", d.f);

    d.c = 'A';

    printf("Character = %c\n", d.c);

    return 0;
}
Remember: Writing another member changes which stored member you should treat as the current meaningful value.

09

Size of a Union

Understand the memory rule correctly.

The size of a union is implementation-dependent. It must be large enough to provide storage suitable for its members and their alignment requirements. Padding may also affect the result.

sizeof() 
#include <stdio.h>

union Data {
    int i;
    float f;
    char c;
};

int main() {

    printf("%zu\n", sizeof(union Data));

    return 0;
}
Interview trap: Do not blindly say: “Union size is always exactly the size of its largest member.” A better answer is: Union size is implementation-dependent and is sufficient for its members, including alignment requirements and possible padding.
10

The Active / Current Member

How to think safely about union values.

Consider:

C 
union Data d;

d.i = 100;

At this point, i is the member whose stored value we should treat as the current meaningful value.

If we later execute:

C 
d.f = 25.5f;

the union's storage is now being used for the float member. The previous integer value should not be treated as an independently stored value.

Important: Do not think of a union as a structure where every field remembers its own independent value.
11

Union Type Punning

An advanced and implementation-sensitive topic.

Sometimes programmers use unions to inspect the same underlying object representation through another member type. This is often called type punning.

Conceptual Example 
union {
    float f;
    unsigned int bits;
} value;

value.f = 3.14f;

/*
   Some implementations use:
   value.bits
   to inspect the representation.
*/
Portability warning: Union type punning has nuanced rules in C and can depend on the implementation and the exact context. Do not present it as a universally portable way to reinterpret arbitrary types.

Portable Representation Copying

When the goal is to copy an object's representation into another object of a different type, memcpy() is often the clearer portable technique.

C — memcpy() 
#include <string.h>

float x = 3.14f;
unsigned int bits;

memcpy(&bits, &x, sizeof bits);

Pointer to a Union

Combine unions with pointers.

C 
#include <stdio.h>

union Data {
    int i;
    float f;
};

int main() {

    union Data d;

    union Data *ptr = &d;

    ptr->i = 500;

    printf("%d\n", ptr->i);

    return 0;
}
Remember: For a union object use .. For a pointer to a union use ->.
Object Syntax
Union object d.i
Pointer to union ptr->i

typedef with Union

Make union declarations cleaner.

C 
typedef union {

    int id;
    float score;

} Data;

Now you can simply write:

C 
Data d;

d.id = 101;
Professional style: Using typedef can make code easier to read when a union type is used frequently.

Union Inside a Structure

A very important real-world pattern.

A structure can contain a union. This is extremely useful when a record has common information plus one of several possible payloads.

C 
struct SensorData {

    int sensorId;

    union {
        int temperature;
        float voltage;
    } value;
};

Here the structure stores the sensor ID plus a shared payload.

16

Structure Inside a Union

Unions can contain complex members too.

C 
struct Point {
    int x;
    int y;
};

union ShapeData {

    struct Point point;

    int radius;

};

The union can represent either the point data or the radius according to the program's logic.

17

Tagged / Discriminated Unions

The professional way to track which union member is active.

A union itself does not automatically store a tag telling you which member your program intends to use. A common professional solution is to store a separate enum tag.

C — Tagged Union 
#include <stdio.h>

enum ValueType {
    INT_VALUE,
    FLOAT_VALUE,
    TEXT_VALUE
};

struct Value {

    enum ValueType type;

    union {

        int i;
        float f;
        char text[20];

    } data;
};

int main() {

    struct Value value;

    value.type = INT_VALUE;
    value.data.i = 100;

    if (value.type == INT_VALUE) {
        printf("%d\n", value.data.i);
    }

    return 0;
}

→

→
Process
Interview-level concept: The enum tells the program which union member is intended to be the current active representation.

19

Union with Pointer Members

Useful, but memory ownership becomes your responsibility.

C 
union Payload {

    int number;

    char *text;

};

If text is active, the union stores a pointer value, not the characters themselves.

Important: The union does not automatically allocate or free memory pointed to by a pointer member. The programmer is responsible for the pointer's lifetime and ownership rules.
20

Function Pointers in Unions

An advanced systems-programming concept.

C 
void start(void) {
    printf("Start\n");
}

void stop(void) {
    printf("Stop\n");

}

union Controller {

    void (*startFn)(void);

    void (*stopFn)(void);

};

C does not have class methods like C++, but function pointers can be stored in structures or unions to build callback and state-machine designs.

21

Union Assignment

Copy compatible union objects.

C 
union Data {

    int i;
    float f;

};

int main() {

    union Data a;
    union Data b;

    a.i = 100;

    b = a;

    return 0;
}

Compatible union objects can be assigned using the assignment operator. The union object is copied as a value, while your program still needs to respect which member is intended to be meaningful.

22

Can We Compare Unions Using ==?

A classic interview trick.

No. C does not provide the == operator for comparing union objects directly.

For a tagged union, compare the tag first and then compare the appropriate active member.

Correct Approach 
if (a.type == b.type) {

    if (a.type == INT_VALUE) {

        if (a.data.i == b.data.i) {
            printf("Equal\n");
        }

    }

}
23

Anonymous Unions

A C11 feature that can simplify member access.

C11 
struct Data {

    int type;

    union {

        int i;
        float f;

    };

};

With an anonymous union, the union does not have a named member. The contained members can be accessed directly through the surrounding structure where supported by the C standard.

Access 
struct Data d;

d.i = 100;

Real-World Applications

Where unions become genuinely useful.

🔌 Embedded Systems

Represent different kinds of sensor or device data using shared storage.

📡 Protocol Messages

A message may contain different payload formats depending on its message type.

🎮 Game Engines

Represent variant data such as integer, float or object references in a compact form.

⚙️ Operating Systems

Low-level structures may use unions when multiple representations share storage.

📦 Memory Optimization

Useful when only one of several possible values is needed at a time.

🔄 State Machines

Tagged unions can represent different state-specific payloads.

Real-World Example — Sensor Payload

One device can report different types of measurements.

C 
#include <stdio.h>

enum SensorType {
    TEMPERATURE,
    VOLTAGE
};

struct Sensor {

    int id;

    enum SensorType type;

    union {

        int temperature;
        float voltage;

    } data;
};

int main() {

    struct Sensor s;

    s.id = 101;

    s.type = TEMPERATURE;

    s.data.temperature = 32;

    printf("Sensor ID: %d\n", s.id);
    printf("Temperature: %d C\n",
           s.data.temperature);

    return 0;
}
Why this design is useful: The sensor has common information such as an ID, while the payload changes depending on the sensor type.
26

Why Unions Save Memory

Compare storage conceptually.

Structure

struct Data {
    int i;
    float f;
    char c;
};

Each field requires its own storage, subject to alignment and padding.

Union

union Data {
    int i;
    float f;
    char c;
};

The members overlap, so only one shared storage region is needed for the union object.

Use union when: The program logically needs alternative representations rather than several independent values at the same time.

Alignment and Padding

The advanced memory detail.

C implementations may require objects to be stored at suitable memory boundaries. A union therefore has alignment requirements based on its members.

Remember: Do not assume a union's size or exact memory layout is identical across every compiler, architecture and ABI.

Can a Union Contain Itself?

An important type-system question.

Directly: No. A union cannot contain a member whose type is the same union type, because that would require infinite storage.

But a union can contain a pointer to itself.

C 
union Node {

    int value;

    union Node *next;

};

The pointer has a finite size, so this is possible.

Common Mistakes

Errors students frequently make.

❌ Mistake 1

Thinking a union stores all members independently.

Fix: Members overlap storage.

❌ Mistake 2

Assuming union size is always exactly the largest member.

Fix: Consider implementation and alignment.

❌ Mistake 3

Reading a different member without understanding the language/implementation rules.

Fix: Treat the intended current member carefully.

❌ Mistake 4

Using a union without tracking which member is active.

Fix: Use a tag for variant data.

❌ Mistake 5

Using . with a union pointer.

Fix: Use ->.

❌ Mistake 6

Forgetting pointer-member memory ownership.

Fix: Manage allocation and lifetime explicitly.

32

Best Practices

Write safer and more maintainable union-based code.

✓ Use unions when alternatives share storage logically.
✓ Use an enum tag for variant data.
✓ Keep tag and union payload synchronized.
✓ Use designated initializers for clarity.
✓ Use sizeof instead of assumptions.
✓ Be cautious with type punning.
✓ Use memcpy for portable representation copying.
✓ Document implementation-specific layouts.

Time Complexity

Union operations are generally constant-time.

Operation Complexity
Member access O(1)
Member assignment O(1)
Pointer access O(1)
Union assignment O(size of copied object)

The important advantage of unions is generally memory representation, not algorithmic speed.

Practice Solution — Tagged Value

A compact interview-style implementation.

Complete C Program 
#include <stdio.h>

enum Type {
    TYPE_INT,
    TYPE_FLOAT,
    TYPE_TEXT
};

struct Value {

    enum Type type;

    union {

        int i;
        float f;
        char text[30];

    } data;
};

int main() {

    struct Value value;

    value.type = TYPE_FLOAT;
    value.data.f = 98.6f;

    switch (value.type) {

        case TYPE_INT:
            printf("Integer: %d\n",
                   value.data.i);
            break;

        case TYPE_FLOAT:
            printf("Float: %.2f\n",
                   value.data.f);
            break;

        case TYPE_TEXT:
            printf("Text: %s\n",
                   value.data.text);
            break;
    }

    return 0;
}

Lesson Summary

From basic unions to professional designs.

A union is one of the most important low-level data representation features in C. Its members share overlapping storage, allowing different representations to occupy the same memory area.

The most important distinction is:

STRUCT

Multiple independent values coexist.

Separate storage.

UNION

Alternative representations share storage.

Overlapping storage.

Mastery formula: Union → Shared Memory → Current Member → Tagged Union → Memory Efficiency → Systems Programming.
