01 · Fundamentals

What is a Method?

ƒ

A reusable block of code

A method is a block of code that performs a specific task. Instead of writing the same statements repeatedly, you define them once inside a method and call that method whenever you need the task.

☕

Think of a method like a machine

You give the machine some input, it performs a task, and it may produce an output.

11 · Important Concept

Method Overloading

Java allows multiple methods to have the same name as long as their parameter lists are different.

SAME METHOD NAME add()
add(int, int)
add(double, double)
add(int, int, int)
Method 1 
static int add(int a, int b) {

    return a + b;

}
Method 2 
static double add(
    double a,
    double b
) {

    return a + b;

}
!
Important Rule

Changing only the return type is not enough to overload a method. The parameter list must differ.

15 · Common Mistakes

Mistakes Beginners Make

01

Forgetting to call the method

Defining a method does not automatically execute it. You must call it.

02

Wrong return type

The returned value must be compatible with the method's declared return type.

03

Confusing parameters and arguments

Parameters are declared in the method. Arguments are supplied during the call.

04

Overloading only by return type

Java cannot distinguish overloaded methods using only different return types.

05

Writing everything inside main()

Large programs become difficult to maintain when all logic is placed inside main().

16 · Interview Preparation

Java Method Questions

What is a method in Java? +

A method is a reusable block of code designed to perform a particular task.

What is the difference between parameter and argument? +

A parameter is a variable declared in the method definition. An argument is the actual value passed when the method is called.

What is method overloading? +

Method overloading allows methods with the same name to have different parameter lists.

Can methods be overloaded by return type only? +

No. Java does not consider return type alone when distinguishing overloaded methods.

What is a void method? +

A void method performs an action but does not return a value.

What does return do? +

return terminates the current method and, when used with an expression, sends a value back to the caller.
