What is a Collection?

Understanding the basic idea

Collection

A collection is an object that represents a group of objects. Java provides the Collections Framework to store, retrieve, manipulate and process groups of data efficiently.

Real-World Analogy

Imagine a college classroom. You have a group of students. Instead of creating separate variables like student1, student2, student3, you can store them together inside a collection.

Basic Example 
ArrayList<String> students = new ArrayList<>();

students.add("Pradeep");
students.add("Rahul");
students.add("Anjali");

System.out.println(students);
OUTPUT
[Pradeep, Rahul, Anjali]

Problems with arrays

Dynamic Size

Collections provide methods for adding, removing, searching and sorting data.

Different Data Structures

Java provides List, Set, Queue and Map implementations.

Better Productivity

You don't have to implement common data structures from scratch.

List Interface

Ordered collections

What is List?

List is an ordered collection that allows duplicate elements and provides index-based access.

A

ArrayList

Best general-purpose List when frequent random access is required.

Most Common
L

LinkedList

Useful when insertion and deletion patterns favor linked-node operations.

Vector

Legacy synchronized List implementation. Usually prefer modern alternatives.

Stack

Legacy stack implementation. ArrayDeque is generally preferred for stack behavior.

ArrayList Example

ArrayList.java 
import java.util.ArrayList;

public class Main {

    public static void main(String[] args) {

        ArrayList<String> names = new ArrayList<>();

        names.add("Pradeep");
        names.add("Rahul");
        names.add("Anjali");

        System.out.println(names);

        System.out.println(names.get(1));

        names.set(1, "Kiran");

        names.remove("Anjali");

        System.out.println(names);
    }
}

Set Interface

Unique elements

What is Set?

A Set is a collection that does not allow duplicate elements.

HashSet

Stores unique elements using hashing. Does not guarantee insertion order.

Fast Lookup

LinkedHashSet

Maintains insertion order while storing unique elements.

TreeSet

Stores unique elements in sorted order.

HashSet Example 
import java.util.HashSet;

public class Main {

    public static void main(String[] args) {

        HashSet<Integer> numbers = new HashSet<>();

        numbers.add(10);
        numbers.add(20);
        numbers.add(10);
        numbers.add(30);

        System.out.println(numbers);
    }
}

Key Idea

If your main requirement is unique values, think about Set.

Map Interface

Key-value data

What is Map?

A Map stores data as key-value pairs. Each key identifies a value according to the map's rules.

101 → Pradeep
102 → Rahul
103 → Anjali

HashMap

General-purpose hash-based Map.

Most Common

LinkedHashMap

Maintains insertion order.

TreeMap

Maintains keys in sorted order.

HashMap Example 
import java.util.HashMap;

public class Main {

    public static void main(String[] args) {

        HashMap<Integer, String> students = new HashMap<>();

        students.put(101, "Pradeep");
        students.put(102, "Rahul");
        students.put(103, "Anjali");

        System.out.println(students);

        System.out.println(

}

Iterator

Traversing collections

Iterator

Iterator provides a standard way to traverse elements of a collection.

Iterator Example 
import java.util.ArrayList;
import java.util.Iterator;

public class Main {

    public static void main(String[] args) {

        ArrayList<String> names = new ArrayList<>();

        names.add("Java");
        names.add("Python");
        names.add("C++");

        Iterator<String> iterator =
            names.iterator();

        while (iterator.hasNext()) {

            String value = iterator.next();

            System.out.println(value);
        }
    }
}

hasNext()

Checks whether another element exists.

next()

Returns the next element.

remove()

Removes the last element returned by the iterator when supported.

Which Collection Should You Choose?

Decision-making guide

↓
Use Map

↓

Duplicates allowed + order matters → ArrayList

Unique values → HashSet

Sorted unique values → TreeSet

Fast key-value lookup → HashMap

Insertion-ordered key-value data → LinkedHashMap

Sorted keys → TreeMap

Common Mistakes

Avoid these errors

1

Using List when uniqueness is required

If duplicates must be prevented, consider Set instead.

2

Assuming HashSet preserves insertion order

Use LinkedHashSet when insertion order must be preserved.

3

Assuming HashMap is sorted

Use TreeMap when sorted key order is required.

4

Modifying a collection incorrectly

Be careful when removing elements during traversal. Iterator can be used when appropriate.

5

Ignoring Generics

Prefer type-safe declarations such as List<String> over raw collections.

Interview Questions

Test your understanding

1. What is the Java Collections Framework? +

It is a unified architecture of interfaces, implementations and algorithms for working with groups of objects.

2. ArrayList vs LinkedList? +

ArrayList is backed by a resizable array and provides efficient indexed access. LinkedList is node-based and has different performance characteristics for insertion and removal at known positions.

3. HashSet vs TreeSet? +

HashSet is hash-based and does not guarantee sorted order. TreeSet maintains elements in sorted order and typically provides O(log n) operations.

4. HashMap vs TreeMap? +

HashMap is hash-based and typically provides O(1) average lookup. TreeMap stores keys in sorted order and typically provides O(log n) operations.

5. Why are equals() and hashCode() important? +

Hash-based collections use hashing and equality to locate and compare keys or elements. Correctly implementing their contract is essential for custom objects.

6. Comparable vs Comparator? +

Comparable defines a class's natural ordering through compareTo(). Comparator provides an external comparison strategy through compare().
