CORE CONCEPT

What is Java?

☕

Java is a high-level programming language

Java is a general-purpose programming language designed to allow developers to build applications that can run across different computing platforms.

Java programs are normally compiled into bytecode, which is executed by the Java Virtual Machine (JVM).

High-Level

Java provides human-readable syntax instead of requiring programmers to work directly with machine instructions.

Object-Oriented

Java supports classes, objects, inheritance, polymorphism, abstraction and encapsulation.

General-Purpose

Java can be used to develop many different types of applications.

Platform Independent

Java bytecode can run on different platforms when a compatible JVM is available.

IMPORTANT CONCEPT

JDK vs JRE vs JVM

One of the most important things beginners should understand is the relationship between the JDK, JRE and JVM.

🛠️

JDK

Java Development Kit

↓
📦

Runtime Environment

Libraries + JVM

↓
⚙️

JVM

Java Virtual Machine

Component Purpose Used For
JDK Provides development tools Developing Java applications
JRE Provides runtime environment Running Java applications
JVM Executes Java bytecode Running compiled Java code
💡 Remember

Think of the JDK as the complete developer toolkit. The JVM is the engine that actually executes Java bytecode.

WATCH OUT

Common Beginner Mistakes

✕

Wrong File Name

Beginners often forget that a public class name should match the Java source file name.

Class: HelloWorld
File: HelloWorld.java
✕

Forgetting Semicolon

Java statements generally end with a semicolon.

System.out.println("Hello");
✕

Case Sensitivity

Java is case-sensitive. System and system are different.

✕

Running With .class

When using the Java launcher with a class, beginners may incorrectly include .class.

✓ java HelloWorld
✕

Incorrect main Method

The traditional Java application entry point uses the expected main method signature.

PLACEMENT PREPARATION

Java Interview Questions

01 What is Java?
Java is a general-purpose programming language commonly used for building applications. Java source code is compiled into bytecode, which is executed by the JVM.
02 Why is Java called platform independent?
Java source code is compiled into bytecode. A compatible JVM on a target platform can execute that bytecode.
03 What is JVM?
JVM stands for Java Virtual Machine. It is the runtime component responsible for executing Java bytecode.
04 What is JDK?
JDK stands for Java Development Kit. It provides tools required to develop, compile and run Java applications.
05 What is bytecode?
Bytecode is the intermediate code generated when Java source code is compiled. It is stored in class files and executed by the JVM.
06 What is the difference between Java and JVM?
Java is the programming language and platform ecosystem, while the JVM is the runtime environment that executes Java bytecode.
