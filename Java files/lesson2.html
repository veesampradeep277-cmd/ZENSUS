CORE CONCEPT

What is a Variable?

📦

A variable is a named storage location for a value.

A variable allows a program to store information and refer to that information using a meaningful name.

Every variable has a type, a name, and a current value.

VARIABLE
age
20
→

What does this mean?

The variable age stores the value 20.

int age = 20;

Variable Syntax

dataType variableName = value;

02 Variable Name

The identifier used to access the value.

03 Assignment

The actual data stored in the variable.

UNDERSTAND THE DIFFERENCE

Declaration vs Initialization

①

Declaration

Tells Java the variable's type and name.

int age;
→
②

Initialization

Gives the variable its first value.

age = 20;
→

Both Together

Declaration and initialization can happen in the same statement.

MODERN JAVA

The var Type Identifier

var

Let the compiler infer the local variable type.

Starting with Java SE 10, var can be used for local variables when the compiler can determine the variable's type from its initializer.

Traditional 
String name = "Java";

int age = 20;

double price = 99.5;
→
Using var 
var name = "Java";

var age = 20;

var price = 99.5;
✓ Only local variables
✓ Must have an initializer
✓ Type cannot change later
✕ Not for fields
✕ Not for method parameters
The compiler determines the actual type of a var variable at declaration time; var does not make Java dynamically typed. :contentReference[oaicite:2]{index=2}

VARIABLE CATEGORIES

Types of Variables in Java

01

Local Variable

Declared inside a method, constructor or block and used within its scope. 

void show() {

    int age = 20;

}
02

Instance Variable

A non-static field associated with an individual object. 

class Student {

    int age;

}
03

Class Variable

A static field associated with the class rather than an individual object. 

class Student {

    static int count;

}
04

Parameter

A variable declared in a method or constructor parameter list. 

void show(int age) {

}
Java distinguishes local variables, parameters, instance variables and class variables. Their scope and lifetime depend on where they are declared. :contentReference[oaicite:3]{index=3}

Variable Naming Rules

✓

Use meaningful names

✓

Use camelCase

totalMarks
✓

Start with a letter

age
✕

Don't use spaces

✕

Don't use keywords

✕

Avoid unclear names

int x;
❌ Difficult

double a = 45000;
✓ Better

Java identifiers are case-sensitive and must follow Java's identifier rules. Common conventions use lower camelCase for variables and uppercase names separated by underscores for constants. :contentReference[oaicite:4]{index=4}

IMMUTABLE VALUES

final Variables & Constants

final

A final variable cannot be reassigned after it has been initialized.

Constants are commonly declared using static final and named in uppercase with underscores.

Constants.java 
final int AGE = 20;

static final double PI = 3.14159;

static final int MAX_STUDENTS = 60;
⚠️ Remember

Trying to reassign a final variable causes a compile-time error. 

final int age = 20;

// age = 21;  // Error
18

WATCH OUT

Common Beginner Mistakes

✕

Using an uninitialized local variable 

int age;

System.out.println(age);

Local variables must be assigned before they are read.

✕

Using double quotes for char 

char grade = "A"; // Wrong

char grade = 'A'; // Correct
✕

Forgetting the float suffix 

float price = 10.5;  // Wrong

float price = 10.5f; // Correct
✕

Confusing char and String 

char letter = 'A';

String word = "Java";
✕

Assuming var means dynamic typing

Java still has a fixed compile-time type. var simply lets the compiler infer the type for a permitted local variable.

✕

Losing data during narrowing 

double x = 10.99;

int y = (int) x;

// y becomes 10

PLACEMENT PREPARATION

Java Interview Questions

01 What is a variable?
A variable is a named entity used by a program to work with a value of a particular type.
02 How many primitive data types are there in Java?
Java has eight primitive data types: byte, short, int, long, float, double, char and boolean.
03 Is String a primitive data type?
No. String is a class and therefore a reference type.
04 What is the difference between int and double?
int is an integer primitive type used for whole-number values. double is a double-precision floating-point type.
05 What is type casting?
Type casting is explicitly converting a value from one compatible type to another type.
06 What is var in Java?
var is a type identifier that allows the compiler to infer the type of a permitted local variable from its initializer.
07 What is the difference between local and instance variables?
A local variable is declared within a method, constructor or block. An instance variable is a non-static field associated with an object.
08 What is a final variable?
A final variable cannot be reassigned after its initialization.
