What is Django?

Understanding Django before writing your first project.

Django at a glance

Django is a high-level web framework written in Python. It provides developers with a structured way to create secure, scalable and maintainable web applications.

Instead of building common web-development features from scratch, Django provides many of the tools needed to create a complete web application.

Simple Definition
Django is a Python-based web framework that provides the structure and tools needed to build secure, database-driven web applications efficiently.

03

Django MVT Architecture

Understand Model, View and Template.

Django follows an architecture commonly described as MVT — Model, View, Template.

M

Model

Handles application data and database interactions.

V

View

Processes requests and contains application logic.

T

Template

Defines the HTML presentation shown to the user.

Python — Model 
class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
Python — View 
def students(request):
    return render(request, "students.html")
HTML — Template 
<h1>Students</h1>
<p>Welcome to the student portal.</p>

Django Project vs Django App

One project can contain multiple specialized apps.

A Django project represents the complete application configuration, while a Django app usually represents a specific feature or functional area.
