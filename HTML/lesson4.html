01 • Fundamentals

What is an HTML Link?

An HTML link allows a user to move from one resource to another. A resource can be another webpage, another section of the same page, a file, an email address, a phone number or an external website.

HTML links are created using the <a> element, commonly called the anchor element.

Basic Link 
<a href="https://www.example.com">
    Visit Example
</a>

<a>

Defines the hyperlink element.

href

Specifies the destination URL or resource.

Link Text

The visible, clickable content.

Remember: Without a useful href, an anchor does not provide a normal navigation destination.

03 • URLs

Understanding URLs

A URL, or Uniform Resource Locator, identifies the location of a resource on the web.

https:// www.example.com /courses ?topic=html #links
Part Example Purpose
Scheme https:// Defines the protocol.
Domain example.com Identifies the website.
Path /courses Identifies a resource/path.
Query ?topic=html Sends additional parameters.
Fragment #links Targets a location within a document.
04 • Link Types

Types of HTML Links

🌐 Absolute URL

Contains the complete destination URL. 

<a href="https://www.example.com">
    Example
</a>

Useful when linking to another website.

📁 Relative URL

Points to a resource relative to the current document. 

<a href="about.html">
    About Us
</a>

📂 Parent Directory

<a href="../index.html">
    Home
</a>

.. means move to the parent directory.

📌 Same Directory

<a href="contact.html">
    Contact
</a>

Looks for the file in the current directory.

05 • Navigation

Internal Website Navigation

Relative links are commonly used to connect pages inside the same website.

Website Navigation 
<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="courses.html">Courses</a>
    <a href="contact.html">Contact</a>
</nav>
Professional practice: Use the semantic <nav> element for major navigation areas.
06 • Page Sections

Bookmark / Fragment Links

Fragment links allow users to jump directly to a specific element on the same page.

The destination element receives an id. The link uses the same identifier with #. 

<a href="#contact">
    Jump to Contact
</a>

<section id="contact">
    <h2>Contact Us</h2>
</section>
Important: The value after # must match the target element's id.
07 • Target

Opening Links in Different Browsing Contexts

Target Meaning
_self Opens in the current browsing context.
_blank Opens in a new browsing context, commonly a new tab.
_parent Opens in the parent browsing context.
_top Opens in the top-level browsing context. 
<a
    href="https://www.example.com"
    target="_blank"
    rel="noopener noreferrer">
    Open Example
</a>
Security tip: When using target="_blank" for an external link, using rel="noopener" is a good defensive practice. Add noreferrer when you also want to suppress the HTTP referrer.
08 • Special Links

Email, Telephone & Download Links

📧 Email Link

<a href="mailto:hello@example.com">
    Email Us
</a>

Opens the user's configured email application.

📱 Telephone Link

<a href="tel:+911234567890">
    Call Us
</a>

Useful especially on mobile devices.

⬇ Download

<a href="resume.pdf" download>
    Download Resume
</a>

Requests that the browser download the resource.

The download attribute is a request to download and browser/server behavior can vary, especially for cross-origin resources.

10 • Images

Making an Image Clickable

An image can be placed inside an anchor element to make the image clickable. 

<a href="product.html">
    <img
        src="product.jpg"
        alt="Laptop product">
</a>
Accessibility: The image should still have meaningful alt text when appropriate.
11 • Link Text

Write Meaningful Link Text

Link text should tell users where the link will take them.

❌ Weak

<a href="courses.html">
    Click here
</a>

✅ Better

<a href="courses.html">
    Explore HTML Courses
</a>

Descriptive link text is easier to understand for users, screen-reader users and search engines.

12 • Accessibility

Accessible HTML Links

  • Use meaningful link text.
  • Do not rely only on color to identify links.
  • Maintain visible keyboard focus.
  • Use normal anchor elements for navigation.
  • Avoid turning a <div> into a fake link with JavaScript.
  • Make sure the destination is understandable.
  • Avoid excessive "Click here" links. 
<a href="student-dashboard.html">
    Open Student Dashboard
</a>
A good link should make sense even when read independently from the surrounding paragraph.

17 • Common Mistakes

Common HTML Link Mistakes

❌ Missing href

<a>Courses</a>

Use a real destination when navigation is intended.

❌ Wrong file path

<a href="course.html">
    Course
</a>

Verify the filename and directory.

❌ Poor link text

<a href="about.html">
    Click here
</a>

Prefer descriptive text.

❌ Fake navigation

<div onclick="go()">
    Open
</div>

Use an anchor when the action is navigation.

18 • Security

Link Security

Links can navigate users to external websites, so developers should consider security and trust.

  • Be careful when linking to untrusted websites.
  • Use HTTPS for secure web resources whenever possible.
  • Use rel="noopener" with links opened in a new browsing context when appropriate.
  • Do not place secrets such as API keys or passwords in URLs.
  • Never assume a link destination is safe merely because it is clickable.
Important: HTML links do not provide authentication or authorization. Sensitive operations should be protected by the server/application, not merely hidden behind a link.

20 • Exam Preparation

5-Mark Answer

Explain HTML Links.

HTML links are created using the anchor <a> element. The href attribute specifies the destination of the link. Links can connect webpages, files, page sections, email addresses and telephone numbers.

Example: 

<a href="about.html">
    About Us
</a>

Links can use absolute or relative URLs. The target attribute controls the browsing context, while meaningful link text improves accessibility and usability.

22 • Interview Preparation

Important Interview Questions

1. What is an anchor element?

The HTML element used to create hyperlinks.

2. What is href?

It specifies the destination of a hyperlink.

3. Absolute vs relative URL?

Absolute URLs specify a complete address; relative URLs are resolved from the current document.

4. What is target="_blank"?

It requests navigation in a new browsing context.

5. What is rel="noopener"?

It prevents the new page from accessing the opener through window.opener.

6. What is a fragment link?

A link containing # that targets an element identified by its id.

7. What is mailto?

A URL scheme used to create email links.

8. What is tel?

A URL scheme commonly used for telephone links.

9. Why is link text important?

It communicates the destination to users and assists accessibility.

10. Can an image be a link?

Yes. Place the image inside an anchor element.

11. What does download do?

It requests that the browser download a linked resource.

12. Why use nav?

It semantically identifies a major navigation section.
