01 • Fundamentals

What is an HTML Table?

An HTML table is used to represent information arranged in rows and columns.


Tables are especially useful when each piece of information has a meaningful relationship with other information in the same row or column.

Real-world examples Student marks, employee records, product specifications, pricing comparisons, timetables, financial data, leaderboards and reports.
02 • Important Concept

When Should You Use a Table?

Good Use

  • Student marks
  • Product comparison
  • Schedules
  • Financial reports
  • Statistical data
  • Leaderboards

Do NOT use tables for

  • General page layout
  • Positioning buttons
  • Creating columns for design
  • Replacing CSS layouts
Golden Rule HTML tables are for tabular data, not for designing the overall layout of a webpage.

05 • Table Headers

The <th> Element

Table headers identify what each row or column represents.

HTML 
<table>

    <tr>

        <th>Student</th>
        <th>Course</th>
        <th>Score</th>

    </tr>

    <tr>

        <td>Pradeep</td>
        <td>Python</td>
        <td>92</td>

    </tr>

</table>
Student Course Score
Pradeep Python 92
Why <th> matters A header provides meaning to the data beneath it and helps assistive technologies understand table relationships.

08 • Advanced Tables

colspan and rowspan

These attributes allow cells to span multiple columns or rows.

colspan

Makes one cell span across multiple columns.

HTML 
<table>

    <tr>

        <th colspan="3">
            Student Details
        </th>

    </tr>

    <tr>

        <td>Name</td>
        <td>Course</td>
        <td>Score</td>

    </tr>

</table>
Student Details
Name Course Score

rowspan

Makes one cell span across multiple rows.

HTML 
<table>

    <tr>

        <th rowspan="2">
            Programming
        </th>

        <td>Python</td>

    </tr>

    <tr>

        <td>Java</td>

    </tr>

</table>
Programming Python
Java
Remember colspan = spans columns horizontally.
rowspan = spans rows vertically.

12 • Responsive Design

Making Tables Mobile-Friendly

Large tables can overflow small screens. A common solution is to place the table inside a horizontally scrollable container.

CSS 
.table-container {
    overflow-x: auto;
}

table {
    min-width: 650px;
}
Professional pattern Keep the data intact and allow horizontal scrolling rather than hiding important information on mobile.

15 • Accessibility

Accessible HTML Tables

Use <th>

Clearly identify headers rather than using normal data cells for headings.

Use scope

Use scope when it helps communicate row or column header relationships.

Use caption

Give complex or important tables meaningful context.

Keep structure logical

Use thead, tbody and tfoot when they improve the structure of the table.

Accessibility Principle A sighted user may understand a table visually, but semantic HTML helps assistive technologies understand the same relationships programmatically.

17 • Debugging

Common Table Mistakes

!

Using tables for page layout

Tables are for tabular data. Use CSS layout systems such as Flexbox or Grid for page layout.

!

Forgetting <th>

Important table headers should generally use semantic header cells.

!

Incorrect colspan or rowspan values

Make sure the spanning value matches the actual number of columns or rows being covered.

!

Missing mobile behavior

Wide tables can overflow smaller screens. Add responsive scrolling when necessary.

!

Poor semantic structure

Use caption, thead, tbody and tfoot where they make the table clearer and more meaningful.

18 • Semantics

Tables, Semantics and Content

Semantic table markup makes the structure of data easier for browsers, assistive technologies and developers to understand.


  • Use tables for actual tabular relationships.
  • Give important tables meaningful captions.
  • Identify headers using th.
  • Keep rows and columns logically organized.
  • Use CSS for presentation.

20 • Exam Preparation

5-Mark Answer

Explain HTML Tables.


HTML tables are used to represent data in rows and columns. A table is created using the <table> element.


Rows are created using <tr>, normal cells using <td> and header cells using <th>.


HTML also provides <caption>, <thead>, <tbody> and <tfoot> for better structure.


The colspan and rowspan attributes are used to merge cells across columns or rows.

22 • Interview Preparation

Important Interview Questions

1. What is an HTML table?

An HTML table is a semantic structure used to represent related data in rows and columns.

2. Which element creates a table?

The <table> element.

3. What does <tr> represent?

A table row.

4. What is the difference between <td> and <th>?

<td> represents a normal data cell, while <th> represents a header cell.

5. What is the purpose of <caption>?

It provides a title or description for the table.

6. What is colspan?

colspan allows a cell to span multiple columns.

7. What is rowspan?

rowspan allows a cell to span multiple rows.

8. What is the purpose of thead?

It groups the header rows of a table.

9. What is tbody?

It groups the main body rows containing table data.

10. What is tfoot?

It groups footer or summary rows of the table.

11. What is scope?

scope identifies whether a header applies to a column or row and can improve accessibility.

12. Can tables be responsive?

Yes. A common approach is to wrap the table in a container with horizontal scrolling.

13. Should tables be used for page layout?

No. Tables should represent tabular data. CSS layout systems should be used for page layout.

14. How do you style an HTML table?

CSS properties such as border, padding, border-collapse, background, text alignment and hover styles can be used.
