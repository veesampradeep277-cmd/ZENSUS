What Is an HTML Document?

An HTML document is a text file containing HTML markup that describes the structure and meaning of a web page.

The browser reads this document, parses the markup, creates a DOM (Document Object Model), and uses that structure together with CSS and JavaScript to create the page users interact with.

Important: HTML provides the structure and meaning of content. CSS controls presentation, while JavaScript provides behavior and interactivity.

Basic HTML Document

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Web Page</title>
</head>

<body>

    <h1>Hello World</h1>
    <p>Welcome to my website.</p>

</body>

</html>

DOCTYPE & Document Anatomy

1. DOCTYPE Declaration

<!DOCTYPE html>

DOCTYPE tells the browser that the document should be interpreted using modern HTML standards.

HTML5 uses the simple declaration <!DOCTYPE html>.

Important Points

  • DOCTYPE is a declaration, not a normal HTML element.
  • It appears before the <html> element.
  • It helps browsers use standards mode.
  • It is not case-sensitive, but lowercase is conventional.

DOCTYPE

The <html> Root Element

<html lang="en">

The <html> element is the root of the HTML document. Every other HTML element is ultimately inside it.

The lang Attribute

<html lang="en">

The lang attribute identifies the primary language of the document.

Correct language information helps browsers, search engines and assistive technologies interpret the document more accurately.

Examples

<html lang="en">
<html lang="te">
<html lang="hi">

The <head> Section

The <head> contains information about the document.

Most content placed inside the head is not directly displayed as page content.

    <meta charset="UTF-8">

    <meta
        name="viewport"

    >

    <title>My Website</title>

</head>

Important Head Elements

Element Purpose Example
<title> Browser tab/page title My Website

<meta viewport> Responsive viewport behavior width=device-width
<meta name="description"> Page description Search preview information
<link> External resources CSS, icons, etc.

The <body> Section

The <body> contains the actual document content that users interact with. 

<body>

    <header>
        Website Header
    </header>

    <main>

        <h1>Welcome</h1>

        <p>
            This is the main content.
        </p>

    </main>

    <footer>
        Copyright 2026
    </footer>

</body>
Think of head = information about the page and body = the page content.

HTML → DOM Tree

When the browser parses HTML, it creates a tree-like representation called the Document Object Model (DOM).

html
head
title
meta
body
header
main
footer

Parent

An element containing another element. 

<body>
    <main></main>
</body>

body is the parent of main.

Child

An element directly contained inside another element.

main is a child of body.

Sibling

Elements sharing the same parent. 

<header></header>
<main></main>
<footer></footer>

Comments & HTML Entities

HTML Comments

Comments are ignored as visible page content, but they remain in the source delivered to the browser.

Do not place passwords, API keys or secrets inside comments.

Block vs Inline: Important Context

Historically, HTML elements were often described as block-level or inline elements. Modern HTML should be understood primarily by semantic meaning, while CSS controls how elements are displayed.

Block-like Examples

  • div
  • p
  • section
  • article
  • main

Inline-like Examples

  • span
  • a
  • strong
  • em
  • code
Do not choose an HTML element only because of how it looks. Choose it based on meaning, then use CSS for presentation.

Accessibility Essentials

Good document structure improves accessibility for people using screen readers, keyboard navigation, magnification and other assistive technologies.

Good Practices

  • Use a correct lang.
  • Give the page a meaningful <title>.
  • Use headings in a logical structure.
  • Use semantic landmarks.
  • Provide useful image alt text.
  • Use real buttons for actions.
  • Associate form controls with labels.

Example

<label for="email">
    Email address
</label>

<input
    id="email"
    type="email"
>

<button type="submit">
    Submit
</button>

Exam Preparation

5-Mark Question

Explain the basic structure of an HTML document.

An HTML document normally starts with the HTML5 DOCTYPE declaration. The root <html> element contains two major sections: <head> and <body>. The head contains metadata such as character encoding, viewport information and title. The body contains the visible and interactive content of the web page. Proper nesting and semantic elements help create a meaningful document structure.

10-Mark Question

Explain the complete structure of an HTML5 document with a suitable example.

Answer structure:
  1. DOCTYPE declaration
  2. HTML root element
  3. lang attribute
  4. Head section
  5. Character encoding
  6. Viewport metadata
  7. Title
  8. Body section
  9. Semantic layout
  10. Importance of proper nesting and accessibility
20

Interview Questions

  1. What is DOCTYPE?
    It declares the document type and helps the browser use standards mode.
  2. What is the root element of HTML?
    The <html> element.
  3. What is the difference between head and body?
    Head contains document metadata and resources; body contains page content.
  4. Why is lang important?
    It identifies the document language for browsers, search engines and assistive technologies.
  5. What is DOM?
    DOM is the browser's object representation of the document structure.
  6. What is semantic HTML?
    HTML that communicates the meaning and purpose of content.
  7. What are void elements?
    Elements that do not contain child content and do not require closing tags.
  8. What is the purpose of meta charset?
    It declares the document's character encoding.
  9. Why use viewport metadata?
    It helps control viewport behavior on mobile devices.
  10. Why should HTML be properly nested?
    Proper nesting creates a predictable and meaningful document structure.
  11. What is the difference between id and class?
    An id identifies an element uniquely within a document; class groups elements.
  12. Why is semantic HTML useful?
    It improves structure, maintainability, accessibility and machine understanding.

Mini Project — Student Profile Page

Project Goal

Build a professional HTML-only student profile page using correct document structure and semantic elements.

Requirements

  • Use HTML5 DOCTYPE.
  • Set the document language.
  • Add charset and viewport.
  • Create a meaningful title.
  • Create header and navigation.
  • Create a main section.
  • Add About, Skills and Projects sections.
  • Add a footer.
  • Use semantic HTML.
  • Use alt text for images.

Starter Code 

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>
        Student Profile
    </title>

</head>

<body>

    <header>

        <h1>
            My Student Profile
        </h1>

        <nav>
            <a href="#about">About</a>
            <a href="#skills">Skills</a>
            <a href="#projects">Projects</a>
        </nav>

    </header>

    <main>

        <section id="about">

            <h2>About Me</h2>

            <p>
                I am a Computer Science student
                learning web development.
            </p>

        </section>

        <section id="skills">

            <h2>Skills</h2>

            <ul>
                <li>HTML</li>
                <li>CSS</li>
                <li>JavaScript</li>
            </ul>

        </section>

        <section id="projects">

            <h2>Projects</h2>

            <article>

                <h3>
                    Student Management System
                </h3>

                <p>
                    A project for managing student information.
                </p>

            </article>

        </section>

    </main>

    <footer>

        <p>
            © 2026 Student Portfolio
        </p>

    </footer>

</body>

</html>
