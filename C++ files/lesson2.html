02 • Variables

What is a variable?

A variable is a named object that stores a value of a particular type. The value can generally be changed during the lifetime of the variable unless the variable is declared as const.

Think of it like a labeled box

Imagine a box with a label. The label is the variable name, the kind of information it can hold is determined by its type, and the current content is its value.

Variable = Type + Name + Value 
int age = 19;

04 • Initialization

Initialization vs assignment

Initialization

Giving an object its initial value when it is created. 

int age = 19;
double cgpa{8.63};

Assignment

Replacing the current value of an already-existing object. 

int age = 19;
age = 20;
Modern C++ tip: Prefer initialization, and consider brace initialization such as int age{19}; because it helps prevent certain narrowing conversions.
Three common initialization styles 
int a = 10;     // copy initialization
int b(20);      // direct initialization
int c{30};      // list initialization
Identifiers

Variable naming rules

Valid names

int age;
int studentCount;
double total_marks;
char grade2;

Invalid names

int 2age;       // starts with digit
int student-name; // '-' is not allowed
int class;       // keyword
int my name;     // spaces are not allowed
Rules: Names can contain letters, digits and underscores, cannot begin with a digit, are case-sensitive, and cannot be C++ keywords.

Professional naming style

Bad Better Why?
x studentAge Meaning is immediately clear.
a1 totalMarks Describes what the value represents.
n numberOfStudents Better readability.
05 • Constants

const and constexpr

Some values should not change after initialization. C++ provides const and constexpr for different constant-expression needs.

const

A const object cannot be modified through its name after initialization. 

const double PI = 3.14159;

// PI = 4.0;  // Error

constexpr

Indicates that a value is intended to be usable in constant expressions when the initializer permits it. 

constexpr int DAYS = 7;

// DAYS = 8;  // Error
Best practice: If a value should never change, make that intent explicit with const or constexpr as appropriate.
06 • Data Types

C++ data types

A type determines what kind of value an object represents and what operations can be performed on it.

int Integer

Whole numbers

Used for integral values such as counts and ages.

int age = 19;
float Floating

Single precision

Floating-point type with lower precision than double.

float price = 99.5f;
double Floating

Double precision

Common choice for general floating-point calculations.

double cgpa = 8.63;
char Character

Single character

Stores a character from the implementation's character set.

char grade = 'A';
bool Logical

True or false

Represents one of two logical states.

bool passed = true;
string Class

Text

std::string is a standard library class for text.

std::string name = "ZENSUS";

Integer family

int, short, long and long long

Integer examples 
short smallNumber = 100;
int age = 19;
long population = 100000L;
long long distance = 9000000000LL;

When should you use int?

For most ordinary whole-number calculations, int is a sensible default unless you know you need another integer type.

When should you use long long?

Use long long when values may exceed the range of a typical int, such as large counts or some DSA problems.

Floating-point

float vs double

float

Typically provides less precision than double. A floating literal can use the f suffix. 

float temperature = 36.5f;

double

Commonly preferred for general-purpose floating-point calculations. 

double cgpa = 8.63;
Precision warning: Floating-point numbers use finite precision. Some decimal fractions cannot be represented exactly in binary floating-point, so avoid assuming that every decimal calculation will produce exact decimal equality.
07 • Characters

char and std::string

char → one character

Character literals use single quotes. 

char grade = 'A';
char symbol = '#';

std::string → text

String literals use double quotes. 

std::string name = "ZENSUS";
Easy memory trick:
'A' → one character
"A" → a string containing one character

Character representation

char is an integer-like character type. Common systems use ASCII-compatible encodings for familiar characters, but the C++ language itself does not require the entire execution character set to be ASCII. 

char ch = 'A';

std::cout << ch << '\n';
std::cout << static_cast<int>(ch) << '\n';
Logical values

bool — true or false 

bool isStudent = true;
bool isAdult = false;

std::cout << isStudent << '\n';
By default, streaming a bool with std::cout displays 1 for true and 0 for false. Use std::boolalpha for readable text. 
std::cout << std::boolalpha;
std::cout << isStudent;
08 • Type modifiers

signed, unsigned, short and long

Examples 
signed int temperature = -10;
unsigned int count = 100;

short smallValue = 20;
long largeValue = 100000L;
long long hugeValue = 9000000000LL;
Important: An unsigned integer type cannot represent negative values. Unsigned arithmetic has defined modular behavior, while signed integer overflow is not something you should rely on; it results in undefined behavior.

09 • sizeof()

How much memory does a type use?

The sizeof operator reports the size, in bytes, of a type or object on the current implementation.

sizeof example 
#include <iostream>

int main()
{
    std::cout << sizeof(int) << '\n';
    std::cout << sizeof(double) << '\n';
    std::cout << sizeof(char) << '\n';
    std::cout << sizeof(bool) << '\n';
}
sizeof(int) Implementation dependent
sizeof(double) Implementation dependent
sizeof(char) Always 1 byte
sizeof(bool) Implementation dependent
Exam tip: Never memorize a single universal size for every C++ type. The language specifies minimum requirements and relationships, while the implementation determines many exact sizes.
Integer ranges

Finding exact limits

Instead of guessing ranges, C++ provides standard library facilities such as std::numeric_limits.

numeric_limits 
#include <iostream>
#include <limits>

int main()
{
    std::cout << std::numeric_limits<int>::min() << '\n';
    std::cout << std::numeric_limits<int>::max() << '\n';

    return 0;
}

Why use numeric_limits?

It gives information about the actual implementation's type limits, making programs more portable and accurate.

Useful members

Common members include min(), max(), lowest(), digits and is_integer.

11 • Type conversion

Type conversion and casting

C++ can convert values between compatible types automatically, or you can explicitly request a conversion.

Implicit conversion

The compiler performs the conversion automatically when the language rules allow it. 

int x = 10;
double y = x;

Explicit conversion

You explicitly state the conversion you want. 

double price = 99.99;
int rounded = static_cast<int>(price);
Integer
10
→
Double
10.0
→
Calculation
5.0
Very important for DSA

Integer division

Both operands are integers

int result = 5 / 2;

// result = 2

Convert before division

double result =
    static_cast<double>(5) / 2;

// result = 2.5
DSA warning: Integer division is one of the most common sources of unexpected answers in competitive programming and interviews.
12 • Modern C++

auto and decltype

auto

auto asks the compiler to deduce the variable's type from its initializer. 

auto age = 19;
// age → int

auto price = 99.5;
// price → double

decltype

decltype can obtain the type of an expression without evaluating that expression. 

int age = 19;

decltype(age) anotherAge = 20;
Modern C++ principle: Use auto when type deduction improves readability and does not hide an important piece of information.

14 • Common mistakes

Mistakes beginners frequently make

!

Using an uninitialized local variable

Avoid reading a local variable before giving it a meaningful value. 

int age;
cout << age; // wrong
!

Using double quotes for char

A character uses single quotes; a string literal uses double quotes. 

char grade = "A"; // wrong
char grade = 'A'; // correct
!

Unexpected integer division

5 / 2 → 2
static_cast<double>(5) / 2 → 2.5
!

Assuming every type has a fixed universal size

Exact sizes are implementation-dependent. Use sizeof or numeric_limits when exact information matters.

!

Changing a const variable

const int x = 10;
x = 20; // error

16 • Interview preparation

Interview questions

A declaration introduces a name and its type to the compiler. A definition provides the entity itself and, for an object, typically allocates storage. A variable definition is also a declaration.
Type casting means converting a value from one type to another. In modern C++, explicit conversions such as static_cast are generally preferred when appropriate.
static_cast makes the programmer's intention clearer and restricts the conversion to the categories that static_cast supports, making code easier to review and reason about.
Integer overflow occurs when a calculation produces a value outside the representable range. Signed integer overflow is undefined behavior; unsigned integer arithmetic has defined modulo behavior.
Both are floating-point types, but double normally provides greater precision than float. Their exact representation and characteristics are implementation-defined within the standard's requirements.
Type deduction is when the compiler determines a type from context. auto is a common feature that uses type deduction for variables.
