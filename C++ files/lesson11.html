01 • OOP Fundamentals

What is Object-Oriented Programming?

Object-Oriented Programming, or OOP, organizes software around objects that combine data and behavior.

📦

Data

Represents the state of an entity. For a Student: name, age, roll number and CGPA.

🔧

Behavior

Represents actions performed by an entity. For example: display(), calculateGrade(), login().

🎯

Object

A concrete instance that owns its own non-static data.

Simple idea: Instead of thinking only in terms of functions, OOP lets us model a program using entities that contain both state and behavior.
02 • Core Concept

Class vs Object

This is the most important distinction in this lesson.

🧱 Class

A class is a user-defined type that describes the data and functions that its objects can have.

Think: Blueprint / Design / Template
Example: class Student { ... };

🎯 Object

An object is an instance of a class. It represents an actual entity created from the class.

Think: Actual house built from a blueprint
Example: Student s1;

03 • Class Syntax

Class Syntax & Anatomy

A class can contain data members, member functions, constructors and access-control sections. 

class Student {

private:

    std::string name;
    int age;

public:

    void display() {
        std::cout << name;
    }
};
class Student

Declares a new user-defined type named Student.

private:

Begins a section whose members are inaccessible directly from unrelated outside code.

std::string name;

A non-static data member representing object state.

public:

Begins a section accessible through an object's public interface.

void display()

A member function describing behavior.

};

The semicolon after a class definition is required.

Important: The default access level of a class is private. The default access level of a struct is public.
04 • Class Members

Data Members & Member Functions

A class usually combines state and behavior.

📊

Data Members

Variables declared inside a class. They represent the state of each object. 

int age;
double cgpa;
std::string name;
⚙️

Member Functions

Functions declared inside a class. They represent behavior. 

void display() {
    std::cout << name;
}
🔗

Combined Model

The object combines its own non-static data with the class's member-function behavior.

Real-world example: A BankAccount object may contain accountNumber and balance as state, while deposit() and withdraw() represent behavior.
05 • Access Control

public, private & protected

Access specifiers control where class members can be accessed.

public

Open Interface

Accessible from outside the class through an object, subject to the usual access rules. 

public:
    void display();
private

Protected State

Direct access is restricted to the class's permitted member/friend context. 

private:
    double balance;
protected

Inheritance Interface

Accessible within the class and appropriate derived-class contexts, with friend access also possible. 

protected:
    int score;
Interview shortcut: For a class, members are private by default. For a struct, members are public by default.
Creating Objects

How do we create an object?

class Student {

public:

    std::string name;

    void display() {
        std::cout << name;
    }
};

int main() {

    Student s1;
    Student s2;

    s1.name = "Pradeep";
    s2.name = "Rahul";

    s1.display();
    s2.display();
}
Key idea: Student s1; creates an object named s1 whose type is Student.

07 • Constructors

Constructors — Automatic Object Initialization

A constructor is a special member function that runs when an object is initialized.

1️⃣

Default Constructor

A constructor that can be called without arguments. 

Student() {
    age = 0;
}
2️⃣

Parameterized Constructor

Accepts values used to initialize an object. 

Student(
    int a
) {
    age = a;
}
3️⃣

Constructor Overloading

Multiple constructors can exist with different parameter lists.

08 • this Pointer

What is the this pointer?

Inside a non-static member function, this points to the current object. 

class Student {

private:

    int age;

public:

    void setAge(int age) {

        this->age = age;

    }
};

Parameter

age
The function parameter.

Object Member

this->age
The age member belonging to the current object.
Interview point: this is a pointer available in non-static member functions. A static member function does not have a this pointer.
09 • Encapsulation

Encapsulation — Protecting Object State

Encapsulation combines data and the operations that work on that data while controlling direct access.

❌ Poor Design

Expose important internal state directly. 

class BankAccount {

public:
    double balance;

};

✅ Encapsulated Design

Keep the state private and expose controlled operations. 

class BankAccount {

private:
    double balance;

public:

    void deposit(
        double amount
    ) {
        if (amount > 0)
            balance += amount;
    }

};

Getters & Setters 

class Student {

private:

    int age;

public:

    void setAge(int value) {

        if (value >= 0)
            age = value;
    }

    int getAge() const {
        return age;
    }

};
Important: Encapsulation is not simply “making variables private”. It is about designing a controlled public interface around an object's internal state.
Const Correctness

Const Member Functions

A const member function promises not to modify the ordinary state of the object. 

class Student {

private:

    int age;

public:

    int getAge() const {

        return age;

    }

};
Remember: The const after the parameter list is part of the member-function declaration. It allows the function to be called on const objects and prevents modification of ordinary non-mutable members through that function.
10 • Static Members

Static Data Members & Functions

Static members belong to the class rather than each individual object.

🔢

Static Data Member

Only one shared member exists for the class, rather than one separate copy per object.

⚡

Static Function

Can be called without an object and does not have a this pointer.

👥

Shared State

Useful when information logically belongs to the class, such as an object counter. 

class Student {

private:

    inline static
    int count = 0;

public:

    Student() {
        ++count;
    }

    static
    int getCount() {
        return count;
    }
};

Student a;
Student b;

std::cout <<
    Student::getCount();
Version note: inline static data members can be defined inside the class in C++17 and later. Older C++ standards usually require an out-of-class definition for a static data member.
11 • Object Techniques

Working with Objects

Object Arrays

An array can contain multiple objects of the same type. 

Student students[3];

Pass Objects

Objects can be passed to functions, often by const reference. 

void show(
    const Student& s
){
    s.display();
}

Return Objects

Functions can return objects by value. Modern C++ handles this efficiently in many cases. 

Student createStudent() {

    return Student(
        "Alex",
        20
    );
}
Advanced Preview

Friend Function

A friend function is not a member function, but a class can grant it access to private and protected members. 

class Box {

private:

    int value;

public:

    Box(int v)
        : value(v) {}

    friend
    void show(
        const Box& b
    );
};

void show(
    const Box& b
) {
    std::cout << b.value;
}
Use carefully: Friendship is powerful but weakens strict encapsulation. Use it when it genuinely improves the design.
Advanced Preview

Nested Classes

A class can be declared inside another class. This is useful when the helper type is tightly related to the outer type. 

class University {

public:

    class Department {

    public:

        void show() {
            std::cout <<
                "CSE";
        }
    };
};
Preview only: Nested-class access rules have details that depend on which entity is accessing what. Learn the basic concept now and study the complete rules with nested classes and access control later.

Common Mistakes

⚠️ Mistakes Beginners Make

1. Forgetting semicolon

class Student {
};

// Correct

2. Accessing private data

Private members cannot normally be accessed directly from outside the class.

3. Constructor has return type

Constructors do not have a return type — not even void.

4. Confusing class and object

Class = type/blueprint. Object = instance of that type.

5. Forgetting const

Use const member functions when a function should not modify ordinary object state.

6. Misunderstanding static

A static member belongs to the class and is shared, rather than being duplicated for every object.

Exam Preparation

5-Mark & 10-Mark Questions

A class is a user-defined type that specifies data members and member functions. An object is an instance of that class. Example: Student s1; Here Student is the class and s1 is an object.
C++ provides public, private and protected access specifiers. Public members form the accessible interface. Private members are restricted to permitted class/friend contexts. Protected members can also be accessed in appropriate derived-class contexts.
A constructor is a special member function used during object initialization. Common forms include default constructors, parameterized constructors and overloaded constructors.
Encapsulation combines state and behavior and controls access to internal state. Private data with public getter/setter or domain-specific methods is a common implementation technique.
