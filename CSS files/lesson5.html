Fonts & Text

Typography is more than changing the size or color of letters. Professional web design depends on font selection, hierarchy, spacing, readability, alignment, responsive sizing and controlled text behavior.

1. What is Typography?

Understanding how text is constructed and displayed.

In CSS, typography is controlled using properties such as:

  • font-style

2. font-family

Controls which typeface the browser should use.

The font-family property specifies the typeface used to display text. 

p {
    font-family: Arial, sans-serif;
}

Why are multiple fonts written?

Because the requested font might not be available on the user's device. CSS therefore allows a fallback chain. 

body {
    font-family:
        "Inter",
        Arial,
        sans-serif;
}

The browser tries the fonts from left to right.

7. font Shorthand

The font shorthand can combine multiple font properties. 

p {
    font:
        italic
        700
        18px
        / 1.6
        Arial,
        sans-serif;
}

A useful mental model is: 

font-style
font-variant
font-weight
font-size / line-height
font-family
Remember: The font size and font family are the essential components of the shorthand. The ordering matters.

9. line-height

Controls the vertical distance between lines of text. 

p {
    line-height: 1.6;
}

A unitless line-height is often flexible because it scales with the element's font size.

Line-height Visualizer

CSS typography becomes easier to read when enough vertical space exists between lines. Extremely tight line-height can make paragraphs feel crowded, while excessive line-height can make related lines feel disconnected.

17. Responsive Typography

Typography should adapt to different screen sizes.

Traditional approach

h1 {
    font-size: 64px;
}

This remains 64px regardless of viewport size.

Modern approach 

h1 {
    font-size:
        clamp(2rem, 6vw, 4.5rem);
}

The browser calculates a fluid value while respecting a minimum and maximum boundary.

Resize the browser window
clamp() mental model: 
clamp(MINIMUM, PREFERRED, MAXIMUM)
The font cannot become smaller than the minimum or larger than the maximum.

20. Common Typography Mistakes

❌ Mistake 1 — Using too many fonts

Using many unrelated typefaces can destroy visual consistency.

❌ Mistake 2 — Extremely small text

Text should remain readable across devices.

❌ Mistake 3 — Poor contrast

Light gray text on a white background may become difficult to read.

❌ Mistake 4 — Excessive letter spacing

Letter spacing should support readability, not make words look artificially separated.

❌ Mistake 5 — Fixed typography everywhere

A 70px heading may look excellent on desktop but become uncomfortable on a mobile device.

❌ Mistake 6 — Ignoring line-height

Correct font size with poor line-height can still produce a difficult reading experience.
