02 — COLOR SYSTEMS

CSS Color Formats

CSS provides multiple ways to describe the same visual color. Each format is useful for different situations.

Named

color: blue;

Easy to understand but limited for precise design systems.

HEX

color: #2563EB;

Compact hexadecimal representation using red, green and blue channels.

RGB

color: rgb(37,99,235);

Represents red, green and blue channel values.

03 — HEX

HEX Colors — Understand Every Character

A six-digit HEX color contains three pairs: red, green and blue.

#2563EB
RED 25
GREEN 63
BLUE EB
/* Six digit HEX */ #RRGGBB RR = Red GG = Green BB = Blue

Common HEX Values

#000000 → Black #FFFFFF → White #FF0000 → Red #00FF00 → Green #0000FF → Blue

Three-Digit HEX

Short HEX notation expands each character.

#fff ↓ #ffffff #369 ↓ #336699
04 — RGB & TRANSPARENCY

RGB and RGBA

RGB describes a color using red, green and blue channels. RGBA adds an alpha channel for transparency.

RED 255
GREEN 0
BLUE 0
rgb(255, 0, 0);

Each traditional RGB channel ranges from 0 to 255.

Alpha — The Fourth Channel

Alpha controls how transparent the color is.

Alpha: 0.55
background: rgba(37, 99, 235, 0.55);

0 means fully transparent and 1 means fully opaque.

05 — DESIGN COLOR MODEL

HSL — Hue, Saturation & Lightness

HSL describes colors in a way that is often easier for designers to reason about.

Hue

Hue represents the position around a color wheel.

HSL Formula

hsl( 220, 80%, 50% )

220 = Hue

80% = Saturation

50% = Lightness

Saturation 80% hsl(220,80%,50%)
Saturation 50% hsl(220,50%,50%)
Saturation 20% hsl(220,20%,50%)
hsla( 220, 80%, 50%, 0.7 );

08 — SIZE

Cover vs Contain

These two values behave very differently and are essential when working with background images.

cover

Fills the complete area. Parts of the image may be cropped.

COVER
background-size: cover;

contain

Keeps the complete image visible while empty space may remain.

CONTAIN
background-size: contain;
09 — POSITION

Background Position — 9 Point Visualizer

10 — GRADIENTS

CSS Gradients

Gradients are CSS-generated transitions between colors. They are useful for visual hierarchy, decoration, overlays and modern interfaces.

Linear Gradient

135deg LINEAR GRADIENT
background: linear-gradient( 135deg, #2563EB, #7C3AED, #EC4899 );

Radial Gradient

RADIAL GRADIENT
background: radial-gradient( circle, #2563EB, #7C3AED, #111827 );

Color Stops

A gradient can contain multiple colors and explicit positions.

MULTI-LAYER GRADIENT
background: linear-gradient( to right, blue 0%, purple 50%, pink 100% );
11 — COMPOSITION

Multiple Background Layers

CSS allows multiple background layers. The first background is painted above the following layers.

12 — TRANSPARENCY

Opacity vs RGBA

This distinction is extremely important in professional UI development.

opacity

.card { opacity: .5; }

The entire element and its children become transparent.

RGBA

.card { background: rgba(0,0,0,.5); }

You can make only the background transparent while keeping content readable.

COMMON MISTAKES

Mistakes Developers Commonly Make

❌ Mistake 1 — Wrong background property
background-color: url("hero.jpg");
✓ Correct
background-image: url("hero.jpg");
❌ Mistake 2 — Ignoring contrast

Light text on a light background becomes difficult to read.

Use a darker text color or a suitable overlay.
❌ Mistake 3 — Using opacity for only the background

opacity affects the entire element and its children.

Use RGBA or a separate overlay when appropriate.
❌ Mistake 4 — Forgetting background-size
For many hero designs:
background-size: cover; background-position: center;
