CSS Animations

Learn how to create movement, loading states, animated interfaces, staggered entrances, typing effects and professional UI motion using CSS.

CSS
01 · FUNDAMENTALS

What is CSS Animation?

CSS animation allows an element to gradually change from one CSS state to another over time. Unlike a simple hover effect, an animation can contain multiple intermediate stages.

A

Automatic

Animations can start automatically when an element appears on the page.

K

Keyframes

Keyframes define the intermediate states of an animation.

T

Time Based

Duration, delay, iteration count and timing functions control movement over time.

CSS · Basic Animation 
.box {
    animation-name: moveBox;
    animation-duration: 2s;
}

@keyframes moveBox {

    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(200px);
    }
}
02 · KEYFRAMES

Understanding @keyframes

The @keyframes rule defines what an animation should look like at different points in time.

CSS · from / to 
@keyframes slide {

    from {
        transform: translateX(0);
        opacity: 0;
    }

    to {
        transform: translateX(200px);
        opacity: 1;
    }

}

Percentage-Based Keyframes

CSS · Multiple Animation Stages 
@keyframes complexAnimation {

    0% {
        transform: translateX(0);
        opacity: 0;
    }

    25% {
        transform: translateX(100px);
        opacity: .5;
    }

    50% {
        transform: translateX(200px);
        opacity: 1;
    }

    75% {
        transform: translateX(100px);
        opacity: .5;
    }

    100% {
        transform: translateX(0);
        opacity: 1;
    }

}

03 · PROPERTIES

Animation Properties

CSS provides several properties for controlling exactly how an animation behaves.

Property Purpose Example
animation-name Selects the keyframes moveBox
animation-duration Controls animation length 2s
animation-timing-function Controls speed curve ease
animation-delay Waits before starting 0.5s
animation-iteration-count Controls repetitions infinite
animation-direction Controls playback direction alternate
animation-fill-mode Controls styles before/after forwards
animation-play-state Play or pause animation paused
CSS · Complete Animation 
.box {

    animation-name: move;

    animation-duration: 3s;

    animation-timing-function: ease-in-out;

    animation-delay: 1s;

    animation-iteration-count: infinite;

    animation-direction: alternate;

    animation-fill-mode: both;

}

@keyframes move {

    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(250px);
    }

}

06 · STAGGERING

Staggered Animations

Instead of making every element animate at exactly the same time, different delays create a sequence.

CSS · Staggered Animation 
.box {
    animation:
        slideUp 1s ease both;
}

.box:nth-child(1) {
    animation-delay: 0s;
}

.box:nth-child(2) {
    animation-delay: 0.15s;
}

.box:nth-child(3) {
    animation-delay: 0.30s;
}

.box:nth-child(4) {
    animation-delay: 0.45s;
}

@keyframes slideUp {

    from {
        opacity: 0;
        transform: translateY(30px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }

}

Staggering is commonly used in menus, dashboards, card grids and list entrances.

08 · TEXT ANIMATION

Typing Effect

Combining width, overflow, white-space and steps() can create a typing-style animation.

Learn. Build. Create with ZENSUS.
CSS · Typing Animation 
.typing {

    width: 0;

    overflow: hidden;

    white-space: nowrap;

    animation:
        typing 4s
        steps(28)
        infinite alternate;

}

@keyframes typing {

    from {
        width: 0;
    }

    to {
        width: 28ch;
    }

}

12 · ACCESSIBILITY

Respect Reduced Motion

Some users prefer less movement on screen. Professional websites should respect that preference.

prefers-reduced-motion

The prefers-reduced-motion media feature allows CSS to reduce or remove non-essential animations.

CSS · Accessibility 
@media (prefers-reduced-motion: reduce) {

    * {
        animation-duration: 0.001ms !important;

        animation-iteration-count: 1 !important;

        scroll-behavior: auto !important;
    }

}
13 · BEST PRACTICES

Professional Animation Principles

Use Animation With Purpose

  • Loading feedback
  • Navigation transitions
  • Entrance animations
  • State changes

Avoid Excessive Motion

  • Don't animate everything
  • Avoid distracting loops
  • Keep durations reasonable
  • Respect reduced-motion preferences

Prefer Transform

  • transform: translate()
  • transform: scale()
  • transform: rotate()
  • opacity for fades

Think About Performance

  • Avoid unnecessary layout changes
  • Keep animations simple
  • Test on mobile devices
  • Don't create motion without purpose
