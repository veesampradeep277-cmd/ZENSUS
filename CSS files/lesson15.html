1. CSS Custom Properties

CSS · Variables

    --primary: #4f46e5;

    --text: #111827;

    --background: #f7f8fc;

    --radius-md: 16px;

    --shadow:
        0 15px 40px rgba(15, 23, 42, .08);

}

.card {

    background: white;

    border-radius:
        var(--radius-md);

    box-shadow:
        var(--shadow);

}

2. Responsive Grid

CSS · Grid 
.projects-grid {

    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;

}

@media (max-width: 1000px) {

    .projects-grid {

        grid-template-columns:
            repeat(2, 1fr);

    }

}

@media (max-width: 700px) {

    .projects-grid {

        grid-template-columns:
            1fr;

    }

}

3. Professional Hover Effect

CSS · Transition 
.project-card {

    transition:
        transform .3s ease,
        box-shadow .3s ease;

}

.project-card:hover {

    transform:
        translateY(-8px);

    box-shadow:
        0 15px 40px
        rgba(15, 23, 42, .08);

}
