CSS COURSE • LESSON 02

Understanding CSS Syntax

Learn how CSS rules are written, how selectors, properties and values work together, and how the browser transforms your CSS code into a styled webpage.

p { color: blue; font-size: 20px; }
01 • FOUNDATION

What is CSS Syntax?

CSS syntax is the set of rules that defines how CSS instructions must be written. It tells the browser which HTML elements should be styled, which characteristics should change, and what values should be applied.

S

Selector

Identifies the HTML element that you want to style.

P

Property

Specifies the characteristic that you want to change.

V

Value

Specifies the setting assigned to the property.

02 • CSS RULE

The CSS Rule

A complete CSS rule consists of a selector followed by a declaration block. Inside the declaration block, one or more declarations define the styles.

p {
   color : blue ;
}
Hover over the syntax. Select a part of the code to understand its role.
03 • SYNTAX ANATOMY

Anatomy of a CSS Rule

Let's break a CSS rule into its smallest important pieces.

p

Selector

Selects the target HTML element.

{ }

Declaration Block

Contains one or more CSS declarations.

:

Colon

Separates a property from its value.

;

Semicolon

Separates one declaration from the next.

04 • SELECTOR

1. Selector

A selector tells the browser which HTML element should receive the style.

p selects all <p> elements.

Example

h1 {
   color: blue;
}

Here, h1 is the selector. The browser searches for HTML <h1> elements and applies the declarations inside the braces.

05 • PROPERTY

2. Property

A property describes the specific visual feature that you want to modify.

C

color

Changes the text color.

F

font-size

Controls the size of text.

B

background-color

Changes the background color.

p {
   color: blue;
}

In this example, color is the property.

06 • VALUE

3. Value

A value tells the browser what setting should be assigned to a property.

p {
   color: blue;
}

Here, blue is the value assigned to the color property.

07 • DECLARATION

What is a Declaration?

A declaration is a combination of a property and its value.

color : blue ;

Therefore:

Property + Value = Declaration

color: blue; is one CSS declaration.

08 • DECLARATION BLOCK

Declaration Block

The curly braces { } create a declaration block. It can contain multiple CSS declarations.

p {
   color: blue;
   font-size: 20px;
   font-weight: bold;
}

Everything between { and } belongs to the declaration block.

09 • MULTIPLE PROPERTIES

Using Multiple Properties

A single CSS rule can contain many declarations. This is how real websites combine several styles for the same element.

.card {
   background-color: white;
   padding: 20px;
   border-radius: 12px;
   box-shadow: 0 5px 20px #ddd;
}
10 • PUNCTUATION

CSS Punctuation

CSS uses a few important symbols. Understanding them prevents many beginner errors.

{ }

Curly Braces

Define the declaration block.

:

Colon

Separates property and value.

;

Semicolon

Ends a declaration.

,

Comma

Can separate multiple selectors.

11 • MULTIPLE SELECTORS

Multiple Selectors

Multiple selectors can be grouped using commas. The same styles will then be applied to each selected element.

h1, h2, p {
   font-family: Arial;
}

The same declaration block is applied to h1, h2, and p.

12 • WHITESPACE

Whitespace and Formatting

Spaces and line breaks generally make CSS easier for humans to read. Good formatting is especially important when working on large projects.

p {
   color: blue;
   font-size: 18px;
}

Indentation does not usually change what the CSS means, but it makes your code much easier to understand and maintain.

13 • COMMENTS

CSS Comments

Comments are notes written for developers. The browser ignores CSS comments when applying styles.

/* This styles the main heading */

16 • COMMON ERRORS

Common CSS Syntax Mistakes

Small syntax errors can prevent a declaration from working correctly. Learn these mistakes early.

❌ Missing Colon
p {
  color blue;
}
A colon must separate the property and value.
✓ Correct Syntax
p {
  color: blue;
}
The property and value are correctly separated with a colon.
❌ Missing Opening Brace
p
  color: blue;
}
The declaration block must begin with {.
✓ Correct Syntax
p {
  color: blue;
}
The opening and closing braces correctly contain the declaration.
❌ Missing Closing Brace
p {
  color: blue;
The rule needs a closing } to finish the declaration block.
❌ Wrong Property Name
p {
  textcolour: blue;
}
CSS property names must be valid CSS properties. Use color instead.
17 • REAL WORLD

Real-World Example

Imagine you are designing a ZENSUS course card. You could use CSS syntax to style its appearance.

.course-card {
   background: white;
   padding: 24px;
   border-radius: 16px;
   font-size: 18px;
   text-align: center;
}

One selector identifies the course card, while multiple declarations control its appearance.

Lesson Summary

  • A property describes what should be changed.

  • Declarations are placed inside { }.
